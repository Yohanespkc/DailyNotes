### 🔍 Mengapa `slurp` Gagal Menampilkan Gambar?

1. **JavaScript Tidak Dieksekusi (`Skeleton Loading`)**:
   - CrazyGames mengirimkan HTML mentah awal yang hanya berisi elemen *placeholder/skeleton* (`<div class="skeleton"></div>`) dan status *loading*.
   - Gambar asli baru dipanggil dan ditampilkan di layar setelah browser mengeksekusi JavaScript.
   - `slurp` hanya mengambil HTML mentah awal tanpa menjalankan JavaScript, sehingga yang tersimpan hanya kotak-kotak *skeleton* kosong tanpa elemen `<img>`.

2. **Domain Gambar Terpisah (CDN)**:
   - Gambar thumbnail di CrazyGames tidak disimpan di domain utama, melainkan di server CDN terpisah (`https://imgs.crazygames.com/`).
   - Pengunduh biasa sering kali gagal menyalin atau mengarahkan path gambar dari CDN tersebut secara benar.

3. **Lazy Loading**:
   - Gambar baru di-load saat halaman di-scroll (menggunakan *IntersectionObserver* di JavaScript).

---

#### Solusi 2: Scraping Menggunakan Headless Browser (Playwright / Puppeteer / Python)
Jika Anda menggunakan `slurp` untuk keperluan otomatisasi/scraping data dan butuh file HTML lengkap setelah JavaScript dirender:

Gunakan script Python dengan **Playwright** yang mensimulasikan browser sungguhan:

```python
from playwright.sync_api import sync_playwright
import time

with sync_playwright() as p:
    # Buka browser
    browser = p.chromium.launch(headless=True)
    page = browser.new_page()
    
    # Buka URL CrazyGames
    page.goto('https://www.crazygames.com/c/arcade/5', wait_until='networkidle')
    
    # Scroll ke bawah agar lazy load gambar berjalan
    page.evaluate("window.scrollTo(0, document.body.scrollHeight)")
    time.sleep(2)
    
    # Simpan HTML yang sudah selesai dirender oleh JavaScript
    html_content = page.content()
    with open("crazygames_arcade_5.html", "w", encoding="utf-8") as f:
        f.write(html_content)
        
    browser.close()
print("Berhasil menyimpan halaman beserta semua gambar!")
```

### 1. Metode Paling Cepat: Kirim File `.md` Langsung (Gratis & Sederhana)
Obsidian menyimpan semua artikel Anda sebagai file **Plain Text Markdown (`.md`)** biasa di komputer Anda.

**Langkah-langkah:**
1. Di Obsidian, **klik kanan** pada artikel yang ingin dibagikan.
2. Pilih **Show in system explorer** (akan membuka folder artikel tersebut di Finder Mac / File Explorer Windows).
3. Kirim file `.md` tersebut ke teman Anda (lewat WhatsApp, Telegram, Email, Google Drive, dll.).
4. **Teman Anda** cukup memasukkan (*drag & drop*) file `.md` tersebut ke dalam folder Vault Obsidian miliknya.

> [!TIP] Catatan tentang Gambar
> Jika artikel menggunakan gambar internet (seperti URL `https://...`), gambar akan langsung muncul di Obsidian teman Anda. Jika menggunakan gambar lokal, pastikan Anda juga mengirimkan file gambarnya dari folder *attachments*.

---

### 2. Metode Sinkronisasi Folder: Google Drive / iCloud / Dropbox (Gratis)
Cocok jika Anda dan teman sering berbagi folder artikel secara terus-menerus.

**Langkah-langkah:**
1. Buat folder khusus di dalam Vault Anda (misal: `Shared Notes`).
2. Simpan folder tersebut di cloud seperti **Google Drive** / **Dropbox** / **iCloud**.
3. Bagikan (*share access*) folder cloud tersebut ke email teman Anda.
4. Teman Anda dapat membuka/menautkan folder shared tersebut di dalam Obsidian miliknya.

---

### 3. Metode Kolaborasi Tim: GitHub / Obsidian Git (Terbaik untuk Tim/Developer)
Jika Anda dan teman ingin saling *update*, mengedit bersama, dan melihat riwayat perubahan artikel.

**Langkah-langkah:**
1. Simpan Vault Anda di repositori **GitHub** (private/public).
2. Pasang community plugin **Obsidian Git** di Obsidian Anda & teman Anda.
3. Saat Anda melakukan `Commit & Push`, teman Anda tinggal melakukan `Pull` di Obsidian miliknya untuk menerima artikel/perubahan terbaru secara otomatis.

---

### 4. Metode Berbagi via Link Web: Plugin "Share Note" (Gratis & Praktis)
Jika Anda ingin teman Anda bisa langsung membaca artikel tersebut di browser (atau mobile) tanpa perlu mengunduh file `.md`:

**Langkah-langkah:**
1. Buka Obsidian -> **Settings** -> **Community plugins**.
2. Cari dan install plugin **Share Note** (oleh Ryotaushio).
3. Buka artikel yang ingin dibagikan, jalankan perintah `Share Note`.
4. Anda akan mendapatkan **Link Web**. Teman Anda bisa membaca artikel beserta tampilannya di browser dan mengkopi kodenya jika mau.

### 5. Obsidian Sync Resmi (Berbayar)
Fitur resmi dari Obsidian (**Obsidian Sync**).
