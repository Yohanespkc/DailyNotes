### 1. JavaScript / Web App (Node Package / Vite / Webpack)

#### **Instalasi:**
```bash
npm install posthog-js
# atau menggunakan yarn / pnpm
yarn add posthog-js
```

#### **Contoh Penggunaan:**
```javascript
import posthog from 'posthog-js';

// 1. Inisialisasi PostHog
posthog.init('YOUR_PROJECT_API_KEY', {
  api_host: 'https://us.i.posthog.com', // Gunakan 'https://eu.i.posthog.com' jika akun Anda di server EU
  person_profiles: 'identified_only', // Opsi rekomendasi PostHog
});

// 2. Mengirim/Tracking Event (Misal: User klik tombol)
function handleButtonClick() {
  posthog.capture('button_clicked', {
    button_name: 'Download Ebook',
    location: 'Hero Banner',
  });
}

// 3. Mengidentifikasi User (Misal: Setelah login berhasil)
function onUserLogin(user) {
  posthog.identify(user.id, {
    email: user.email,
    name: user.name,
    plan: 'Premium',
  });
}

// 4. Reset Session (Misal: Saat user logout)
function onUserLogout() {
  posthog.reset();
}
```

### 4. Python Backend (Flask, FastAPI, Django, Script Python)

#### **Instalasi:**
```bash
pip install posthog
```

#### **Contoh Penggunaan:**
```python
from posthog import Posthog

# 1. Inisialisasi PostHog Client
posthog = Posthog(
    project_api_key='YOUR_PROJECT_API_KEY',
    host='https://us.i.posthog.com'
)

# 2. Tracking event dari server backend
# distinct_id adalah ID unik user (misal user ID dari database)
posthog.capture(
    distinct_id='user_9876',
    event='payment_processed',
    properties={
        'amount': 250000,
        'payment_method': 'QRIS',
        'status': 'success'
    }
)

# 3. Memberikan properti pada User (Identify)
posthog.identify(
    distinct_id='user_9876',
    properties={
        'email': 'user@example.com',
        'role': 'subscriber'
    }
)

# 4. Penggunaan Feature Flag (jika menggunakan fitur A/B testing / Feature Flags PostHog)
if posthog.feature_enabled('new-dashboard-v2', 'user_9876'):
    print("Tampilkan dashboard versi baru")
else:
    print("Tampilkan dashboard lama")

# Pastikan panggil flush() jika script CLI/Singletask selesai agar semua event terkirim
posthog.flush()
```

### 💡 Tips Penting:
1. **API Key & Host**: Dapatkan `PROJECT_API_KEY` dari dashboard PostHog Anda (**Project Settings -> Project API Key**).
2. **Environment Variables**: Simpan API Key di file `.env` (seperti `NEXT_PUBLIC_POSTHOG_KEY` atau `POSTHOG_API_KEY`) agar aman.
3. **Fitur Utama PostHog**:
   - **Capture Event**: Mengukur aksi spesifik pengguna (`posthog.capture(...)`).
   - **Identify User**: Mengaitkan aktivitas anonim dengan identitas user setelah login (`posthog.identify(...)`).
   - **Session Recording**: Rekaman interaksi layar pengguna (otomatis aktif di Web jika diaktifkan dari Dashboard).
   - **Feature Flags**: Mengontrol rilis fitur secara dinamis tanpa perlu deploy ulang.

## 🛠️ 3 Cara Menghubungkan & Menggunakan Grafana di Obsidian

### Cara 1: Menampilkan Dashboard Grafana di Dalam Catatan Obsidian (iFrame HTML)

Anda bisa memasukkan panel Grafana secara langsung ke dalam catatan Markdown (`.md`) di Obsidian menggunakan tag `<iframe>`:

```html
<iframe 
  src="http://localhost:3000/d-solo/YOUR_DASHBOARD_ID/your-dashboard-name?orgId=1&panelId=1&kiosk" 
  width="100%" 
  height="450" 
  frameborder="0">
</iframe>
```

> ⚠️ **Catatan Iframe Embedding**: Jika panel Grafana tidak muncul di Obsidian, aktifkan opsi embedding di konfigurasi Grafana:
> Edit `/opt/homebrew/etc/grafana/grafana.ini`, cari `[security]` dan ubah menjadi:
> ```ini
> [security]
> allow_embedding = true
> ```

### 🤝 2. Bagaimana Keduanya Saling Mengisi (Sinergi Real-World)

#### 🔍 **Skenario 1: Troubleshooting Masalah Pengguna**
- **PostHog**: Memberitahu Anda bahwa **30% user gagal saat menekan tombol "Bayar"**, dan *Session Replay* menunjukkan tombol terus-menerus loading.
- **Grafana**: Menunjukkan bahwa pada menit yang sama, **database PostgreSQL mengalami spike query 100% CPU** (penyebab backend lambat merespons).
- **Hasil**: PostHog menemukan **dampak pada pengguna**, Grafana menemukan **akar masalah di server**.

#### 🧪 **Skenario 2: Peluncuran Fitur Baru (A/B Testing)**
- **PostHog**: Menguji fitur baru menggunakan *Feature Flag* dan mengukur peningkatan transaksi pengguna (+15% penjualan).
- **Grafana**: Memantau apakah fitur baru tersebut membuat beban memori server membengkak atau menaikkan latensi API secara berlebihan.

#### 📈 **Skenario 3: Dashboards Terpusat (Single Pane of Glass)**
- Grafana bisa mengambil data event/metrik dari PostHog (via Postgres/ClickHouse export atau REST API Grafana Plugin).
- Hasilnya, Anda bisa memiliki 1 dashboard di Grafana yang menampilkan **Beban CPU Server** persis di sebelah **Jumlah User Aktif Real-Time (dari PostHog)**.
