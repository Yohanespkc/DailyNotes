   - Isi saldo awal (minimal **$5 USD** atau sekitar Rp80.000).
   - **Metode Pembayaran**:
     - 💳 **Kartu Kredit / Debit Online**: Visa, Mastercard (Bisa menggunakan kartu debit bank digital Indonesia seperti **Bank Jago, Jenius, Livin' Mandiri, BCA Mastercard, Blu**).
     - 🪙 **Crypto**: USDC, Bitcoin, Ethereum.
3. **Ambil API Key**:
   - Masuk ke menu **Keys** ➔ **Create Key**.

### 3. Bagaimana Cara OmniRouter Mengurangi Token 5% - 95%?

OmniRouter mencapai penghematan token yang sangat drastis melalui **4 Teknik Optimasi Pintar**:

#### A. ⚡ **Semantic Prompt Caching (Penghematan 50% - 95%)**
- **Cara Kerja**: Jika Anda/sistem mengajukan pertanyaan yang mirip atau instruksi berulang (misalnya: *"Bagaimana harga beras dan stok sembako hari ini?"*), OmniRouter tidak mengirim ulang seluruh teks ke cloud.
- **Hasil**: OmniRouter mengambil jawaban langsung dari *Semantic Cache Memory* lokal dalam 1 milidetik. **Biaya Token = 0 (Hemat 100% pada request berulang)**.

#### B. 🔀 **Smart Model Routing / Offloading (Penghematan 40% - 80%)**
- **Cara Kerja**: OmniRouter menganalisis tingkat kesulitan pertanyaan.
  - Pertanyaan sederhana (format teks, ringkasan singkat, manipulasi JSON) dirutekan ke **Model Lokal Gratis (Ollama DeepSeek-7B / Qwen 32B)** di server sendiri.
  - Hanya pertanyaan yang butuh penalaran rumit yang diteruskan ke **Model Cloud (DeepSeek R1 / GPT-5.6 / Kimi 3)**.

#### C. 🗜️ **Context Window Pruning & Deduplication (Penghematan 20% - 50%)**
- **Cara Kerja**: Teks konteks panjang (seperti file rujukan atau riwayat chat lama) dipangkas oleh OmniRouter dengan membuang *filler words* (kata-kata mubazir) dan hanya menyisakan inti informasi sebelum dikirim ke API cloud.

#### D. 🧩 **Prefix Caching & Prompt Sharing (Penghematan 10% - 30%)**
- **Cara Kerja**: Jika instruksi sistem (*System Prompt*) seperti *"Anda adalah asisten intelijen presiden..."* bernilai 2.000 token dan dikirim terus-menerus, OmniRouter melakukan *Lock-Caching* pada header prompt tersebut sehingga cloud provider hanya menagih token pesan baru.

### 1. 🟢 Skema A: Model Lokal (Ollama / vLLM / Local GPU)
*   **Penyedia**: Model Open-Source yang berjalan di komputer/server GPU Anda sendiri (misal: *DeepSeek-R1-7B, Llama-3.3, Qwen-2.5*).
*   **Alur Pembayaran**: **Rp 0 / GRATIS SEPENUHNYA**.
*   **Penjelasan**: OmniRouter mengarahkan pemrosesan ke mesin lokal via Ollama. Tidak ada data yang keluar ke internet, dan tidak ada saldo yang terpotong.

---

### 2. 🌐 Skema B: Cloud API (OpenRouter, OpenAI, Moonshot Kimi, Zhipu GLM)
*   **Penyedia**: Layanan AI Cloud global (*OpenRouter, OpenAI, Moonshot, Anthropic*).
*   **Alur Pembayaran**:
    1. Anda memasukkan **API Key milik Anda sendiri** (misal: API Key OpenRouter `sk-or-v1-...` atau API Key OpenAI `sk-proj-...`) ke dalam dashboard pengaturan OmniRouter.
    2. Saat ada pertanyaan rumit yang harus dijawab AI Cloud, OmniRouter mengirimkan request tersebut langsung ke provider terkait menggunakan API Key Anda.
    3. Provider (misal: OpenRouter) memotong saldo credit akun Anda di situs resmi mereka sesuai jumlah token yang terpakai.
    4. OmniRouter mencatat riwayat penggunaan (*usage log & latency*) di dashboard lokal Anda agar Anda bisa memantau pengeluaran token.

---

### 📊 Contoh Simulasi Penghematan Tagihan dengan OmniRouter:

Skenario: 1.000 pertanyaan masuk ke sistem dalam sehari.

*   ❌ **Tanpa OmniRouter (Langsung ke Cloud API)**:
    *   1.000 request x 2.000 token = 2.000.000 token.
    *   Tagihan di OpenRouter/OpenAI = **$4.00 USD (~Rp64.000 / hari)**.

*   ✅ **Dengan OmniRouter (Smart Router + Semantic Cache)**:
    *   **700 request** (pertanyaan berulang/serupa) ➔ Dijawab dari **Local Semantic Cache** **($0.00)**.
    *   **200 request** (pertanyaan sederhana) ➔ Dirutekan ke **Local Ollama GPU** **($0.00)**.
    *   **100 request** (pertanyaan sangat rumit) ➔ Baru dikirim ke **Cloud API** **($0.40)**.
    *   **Total Tagihan Terpotong di OpenRouter = Hanya $0.40 USD (~Rp6.400 / hari)**.
    *   🎉 **Penghematan Saldo API Anda: 90%!**
