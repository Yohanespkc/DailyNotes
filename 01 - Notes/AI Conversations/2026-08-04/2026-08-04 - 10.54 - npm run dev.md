---

### **Cara 1: Menggunakan PM2 Process Manager (Paling Praktis & Direkomendasikan)**

`pm2` adalah pengelola proses Node.js yang akan menjaga `omniroute` tetap berjalan di latar belakang, otomatis restart jika crash, dan otomatis menyala setiap kali Mac Anda dinyalakan (*booting*).

1. **Install PM2 secara global:**
   ```bash
   npm install -g pm2
   ```

2. **Jalankan OmniRoute di background dengan PM2:**
   ```bash
   pm2 start omniroute --name "omniroute"
   ```

3. **Atur agar otomatis berjalan saat Mac dinyalakan (*Auto-start on Boot*):**
   ```bash
   pm2 save
   pm2 startup
   ```
   *(Salin dan jalankan perintah `sudo env PATH=...` yang dimunculkan oleh `pm2 startup` di terminal Anda).*

4. **Perintah Berguna PM2:**
   * Cek status: `pm2 status`
   * Lihat log keluaran: `pm2 logs omniroute`
   * Stop service: `pm2 stop omniroute`

---

### **Cara 2: Menggunakan macOS `launchd` (Background Service bawaan macOS)**

Jika tidak ingin menginstall PM2, Anda bisa membuat service background bawaan macOS (*LaunchAgent*):

1. **Buat file konfigurasi service:**
   Buka terminal dan buat file plist:
   ```bash
   nano ~/Library/LaunchAgents/com.omniroute.service.plist
   ```

2. **Isikan kode konfigurasi berikut:**
   ```xml
   <?xml version="1.0" encoding="UTF-8"?>
   <!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
   <plist version="1.0">
   <dict>
       <key>Label</key>
       <string>com.omniroute.service</string>
       <key>ProgramArguments</key>
       <array>
           <string>/opt/homebrew/bin/omniroute</string>
       </array>
       <key>RunAtLoad</key>
       <true/>
       <key>KeepAlive</key>
       <true/>
       <key>StandardOutPath</key>
       <string>/tmp/omniroute.log</string>
       <key>StandardErrorPath</key>
       <string>/tmp/omniroute.err</string>
   </dict>
   </plist>
   ```

3. **Aktifkan service:**
   ```bash
   launchctl load ~/Library/LaunchAgents/com.omniroute.service.plist
   ```
   *Sekarang OmniRoute akan otomatis berjalan di latar belakang setiap kali Anda login ke Mac.*

Di dashboard ini Anda dapat:
* **Memasukkan API Keys:** Cukup masukkan API Key (OpenAI, Gemini, Anthropic, DeepSeek, dll) **sekali saja** di OmniRoute, tanpa perlu mengetik ulang API Key di setiap aplikasi AI terpisah.
* **Routing & Fallback:** Mengatur jalur otomatis (misal: jika OpenAI *rate limit*, otomatis dialihkan ke Groq atau DeepSeek).
* **Monitoring:** Memantau jumlah token, biaya (*cost*), dan kecepatan respons (*latency*) semua model AI Anda.

---

### **2. Dihubungkan ke Extension / CLI AI (Cursor, Cline, Roo Code, Aider, dll)**

### **3. Dipakai dalam Script / Proyek Kode (Python & Node.js)**
Anda bisa memanggil berbagai jenis AI dalam kode Python/JavaScript Anda hanya menggunakan pustaka standar OpenAI:

**Contoh di Python:**
```python

    base_url="http://localhost:20128/v1",
    api_key="omniroute"
)

response = client.chat.completions.create(
    model="deepseek-coder", # atau claude-3-5-sonnet / gpt-4o
    messages=[
        {"role": "user", "content": "Buatkan fungsi rekursif penjumlahan matematika"}
    ]
)

print(response.choices[0].message.content)
```
