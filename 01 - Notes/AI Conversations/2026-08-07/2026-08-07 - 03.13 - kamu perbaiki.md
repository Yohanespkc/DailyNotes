### 🤖 AI Agent (Antigravity)

Tentu, mari kita perjelas perbedaan dan hubungan antara **OmniRouter** dan **OpenRouter**:

---

### 💡 Perbedaan Peran: OmniRouter vs OpenRouter

| Komponen | Jenis | Peran / Fungsi Utama |
| :--- | :--- | :--- |
| **OmniRouter** | **Local Proxy / Gateway** *(Berjalan di komputer Anda, Port 20128)* | Berfungsi sebagai **pintu gerbang lokal** yang mengatur, menyatukan, dan mengarahkan lalu lintas request dari aplikasi lokal (seperti Continue / VS Code) ke berbagai API backend. |
| **OpenRouter** | **Cloud Service / Aggregator** *(Berjalan di Server Cloud / Internet)* | Berfungsi sebagai **penyedia (provider) model AI** yang menyediakan akses ke ratusan model (seperti DeepSeek R1, Qwen 2.5 Coder, Gemini, Llama 3.3, GPT-4o, dll). |

---

### ❓ Mengapa Kita Memakai Keduanya?

1. **OmniRouter tidak memiliki model AI sendiri**  
   OmniRouter hanya sebuah *router/proxy* lokal. Ketika Anda meminta jawaban dari model `DeepSeek` atau `Qwen` melalui OmniRouter, OmniRouter harus meneruskan request tersebut ke cloud—dan cloud yang dituju di balik layar adalah **OpenRouter**.

2. **Manfaat Menggunakan OmniRouter di Depan OpenRouter:**
   - **Unified Management:** Semua tool lokal Anda (Continue, script Python, extension lain) cukup terhubung ke satu titik yaitu `http://localhost:20128`.
   - **Keamanan API Key:** API Key asli tidak perlu disebar ke semua aplikasi, cukup disimpan di OmniRouter lokal.
   - **Logging & Fallback:** OmniRouter bisa melakukan caching, mengatur rate limit, serta mengalihkan ke model cadangan jika salah satu provider down.

* Jika OmniRouter sedang mati, kita bisa menghubungkan Continue **langsung ke OpenRouter** (`https://openrouter.ai/api/v1`) tanpa melalui OmniRouter lokal.
