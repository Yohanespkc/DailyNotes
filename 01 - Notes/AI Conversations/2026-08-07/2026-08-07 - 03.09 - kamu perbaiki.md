### 🔍 Penyebab Utama
Ekstensi **Continue** pada editor Anda mencoba melakukan *tab autocomplete* menggunakan **local proxy / server** di alamat `http://localhost:20128/v1`. 

Karena layanan/proxy di port **`20128`** tersebut saat ini **tidak aktif / mati**, koneksi ditolak (`ECONNREFUSED`).

Detail konfigurasi ini terdapat pada file [config.json](file:///Users/yohanessurya/.continue/config.json):
```json
"tabAutocompleteModel": {
  "title": "Qwen 2.5 Coder 32B Autocomplete (OpenRouter)",
  "provider": "openai",
  "model": "openrouter/qwen/qwen-2.5-coder-32b-instruct",
  "apiBase": "http://localhost:20128/v1",
  ...
}
```

---

### 🛠️ Cara Mengatasinya

Anda dapat memilih salah satu dari solusi berikut:

#### **Opsi 1: Hubungkan langsung ke OpenRouter (Tanpa Proxy Local)**
Jika Anda memiliki API Key OpenRouter resmi dan tidak ingin menggunakan proxy lokal di port 20128, ubah `apiBase` pada file `~/.continue/config.json` dari `http://localhost:20128/v1` menjadi:
```json
"apiBase": "https://openrouter.ai/api/v1"
```

---

#### **Opsi 2: Jalankan Kembali Local Proxy (Port 20128)**
Jika Anda menggunakan layanan proxy lokal (misalnya script proxy AI/OpenRouter lokal), jalankan kembali aplikasi/script proxy tersebut di terminal agar port `20128` aktif mendengarkan request.

---

#### **Opsi 3: Matikan Autocomplete Sementara di Continue**
Jika Anda sedang tidak membutuhkan fitur *Tab Autocomplete* dari Continue:
1. Klik ikon **Continue** atau status bar di bagian bawah editor.
2. Matikan toggle **Tab Autocomplete** (Disable Autocomplete).
3. Atau hapus/komentari blok `"tabAutocompleteModel"` pada file [config.json](file:///Users/yohanessurya/.continue/config.json).
