Setelah Anda **merekam presentasi di PowerPoint (PPT)**, hasil rekaman itu **tersimpan di dalam file PowerPoint Anda sendiri** terlebih dahulu — jadi belum otomatis menjadi video. Berikut langkah-langkah untuk **menyimpan hasil rekaman sebagai video (MP4)**:

---

### 🎬 **Langkah Menyimpan Rekaman di PowerPoint ke Video**

1. **Buka file PowerPoint Anda.**  
   Pastikan presentasi yang sudah Anda rekam terbuka.

2. Klik **File → Export → Create a Video**  
   (Dalam bahasa Indonesia: **File → Ekspor → Buat Video**)

3. Pilih **Video Quality (Kualitas Video)**  
   - “Full HD (1080p)” → kualitas bagus untuk YouTube atau seminar.  
   - “HD (720p)” → cukup untuk ukuran file lebih kecil.  
   - “Standard (480p)” → untuk ukuran paling ringan.

4. Pilih **Use Recorded Timings and Narrations**  
   Ini penting agar PowerPoint memakai suara dan waktu transisi hasil rekaman Anda.

5. Klik **Create Video**

6. Beri nama file dan pilih lokasi penyimpanan (misalnya Desktop atau Folder Dokumen).

7. Tunggu proses **rendering video** hingga selesai (biasanya beberapa menit tergantung panjang rekaman).

8. File video hasil rekaman akan disimpan dalam format **.mp4**  
   Anda bisa membukanya lewat **File Explorer (Windows)** atau **Finder (Mac)**.

---

### 💡 Tips
- Jika Anda hanya ingin **menyimpan versi PowerPoint-nya saja (dengan rekaman)**, cukup tekan **Ctrl+S** (atau **Cmd+S**) — semua rekaman tetap tersimpan di dalam file `.pptx`.
- Anda bisa membuka ulang file itu dan memilih **Slide Show → Play Recorded Slide Show** untuk memutar rekamannya lagi.
