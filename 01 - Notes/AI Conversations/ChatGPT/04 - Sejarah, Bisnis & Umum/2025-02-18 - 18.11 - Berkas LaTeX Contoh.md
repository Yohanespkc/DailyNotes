**Kode LaTeX:**

```latex
\documentclass[12pt,a4paper]{article}
\usepackage[utf8]{inputenc}    % Untuk dukungan karakter UTF-8
\usepackage[T1]{fontenc}       % Memperbaiki keluaran font
\usepackage[indonesian]{babel} % Mengaktifkan bahasa Indonesia
\usepackage{lipsum}            % Paket untuk contoh teks

\title{Contoh Dokumen \LaTeX}
\author{Nama Anda}
\date{\today}

\begin{document}

\maketitle

\section{Pendahuluan}
Dokumen ini adalah contoh sederhana penggunaan \LaTeX\ dalam bahasa Indonesia. 
Anda dapat menulis artikel, laporan, tesis, dan berbagai dokumen lainnya dengan nyaman 
dan rapi menggunakan \LaTeX.

\section{Teks Contoh}
Berikut adalah contoh teks menggunakan paket \texttt{lipsum}:
\lipsum[1]

\section{Penutup}
Untuk membuat PDF, Anda dapat menjalankan perintah berikut di terminal (untuk sistem operasi 
berbasis Unix) atau Command Prompt (Windows):
\begin{verbatim}
pdflatex contoh.tex
\end{verbatim}

\end{document}
```

---

### Cara Menggunakan

1. **Salin kode** di atas dan simpan dalam berkas dengan nama misalnya `contoh.tex`.
2. **Buka terminal** atau Command Prompt, lalu navigasikan ke folder tempat `contoh.tex` disimpan.
3. Jalankan perintah:
   ```bash
   pdflatex contoh.tex
   ```
4. Jika kompilasi berhasil, Anda akan mendapatkan berkas `contoh.pdf`.

Untuk memudahkan, Anda juga bisa menggunakan [Overleaf](https://www.overleaf.com):
1. Masuk/log in ke akun Overleaf Anda.
2. Buat proyek baru, pilih **Blank Project**.
3. Salin kode LaTeX di atas ke berkas utama (misalnya `main.tex`) di Overleaf.
4. Overleaf akan otomatis melakukan kompilasi dan Anda dapat mengunduh PDF dengan menekan tombol **Menu > Download PDF**.

## Kode LaTeX

```latex
\documentclass[12pt,a4paper]{article}
\usepackage[utf8]{inputenc}    % Untuk dukungan karakter UTF-8
\usepackage[T1]{fontenc}       % Memperbaiki keluaran font
\usepackage[indonesian]{babel} % Mengaktifkan aturan ejaan Indonesia
\usepackage{lipsum}            % Paket untuk contoh teks (opsional)

\title{Contoh Dokumen \LaTeX}
\author{Nama Anda}
\date{\today}

\begin{document}

\maketitle

\section{Pendahuluan}
Dokumen ini merupakan contoh sederhana penggunaan \LaTeX\ dalam bahasa Indonesia. 

\section{Contoh Teks}
Berikut adalah contoh paragraf panjang yang dihasilkan dari paket \texttt{lipsum} (opsional). 
Jika Anda tidak memerlukan teks contoh, Anda dapat menghapusnya.
\lipsum[1]

\section{Cara Kompilasi}
Jika menggunakan *command line* di Windows, macOS, atau Linux, Anda dapat menjalankan:
\begin{verbatim}
pdflatex contoh.tex
\end{verbatim}
Hal ini akan menghasilkan berkas \texttt{contoh.pdf} di folder yang sama.

\section{Penutup}
Anda sudah berhasil membuat dokumen \LaTeX\ sederhana!

\end{document}
```

---

## Langkah-Langkah Mengunduh dan Menggunakan

1. **Salin Kode** di atas ke dalam berkas teks baru.
2. **Simpan** berkas tersebut dengan nama `contoh.tex` (atau nama lain sesuai keinginan).
3. Untuk **mengompilasi** di komputer lokal:
   - Buka Terminal (macOS/Linux) atau Command Prompt (Windows).
   - Pastikan Anda sudah berada di direktori tempat `contoh.tex` disimpan.
   - Jalankan perintah:
     ```bash
     pdflatex contoh.tex
     ```
   - Hasilnya, akan muncul berkas `contoh.pdf` di direktori yang sama.
4. Jika Anda lebih suka **platform online** seperti Overleaf:
   - Buka [Overleaf](https://www.overleaf.com) dan login (jika belum punya akun, bisa mendaftar gratis).
   - Klik **New Project** lalu pilih **Blank Project**.
   - Ganti nama proyek jika diinginkan.
   - Salin seluruh kode *LaTeX* di atas ke dalam berkas utama (misalnya `main.tex`).
   - Overleaf akan otomatis mengompilasi dan menampilkan hasil PDF.
   - Untuk mengunduh PDF, klik **Menu > Download PDF** (biasanya di sisi kiri atas atau kanan atas, tergantung tema Overleaf).

Dengan langkah-langkah tersebut, Anda dapat dengan mudah membuat dan mengunduh dokumen *LaTeX* sederhana. Semoga membantu!
