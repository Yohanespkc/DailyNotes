### 🔧 LANGKAH UMUM INSTALL GOOGLE PLAY DI HP CHINA

#### 1. **Periksa apakah GMS sudah tersedia secara tersembunyi**
Beberapa HP China (misalnya Xiaomi) memungkinkan install GMS dengan hanya mengaktifkannya lewat App Store-nya (Mi App Store, Huawei App Gallery, dsb).

Coba langkah ini:
- Buka App Store bawaan (misalnya "Mi App Store" atau "AppGallery")
- Cari **“Google Installer”** atau **“GMS Installer”**
- Download dan install
- Ikuti petunjuk instalasi hingga selesai

Jika berhasil, kamu akan mendapatkan Play Store dan layanan Google lainnya.

---

#### 2. **Install manual via APK (jika tidak tersedia di App Store)**
Kamu butuh 4 APK berikut ini (dari sumber terpercaya seperti APKMirror):
- Google Play Services
- Google Services Framework
- Google Account Manager
- Google Play Store

**Langkah:**
1. Aktifkan “Install from unknown sources” di pengaturan HP.
2. Install **Google Services Framework** dulu.
3. Lalu install **Google Account Manager**.
4. Install **Google Play Services** (pastikan versi cocok dengan arsitektur dan Android versi HP kamu).
5. Terakhir, install **Google Play Store**.
6. Reboot HP kamu.
7. Login ke akun Google.

---

#### 3. **Gunakan Googlefier (untuk Huawei atau Honor)**
Jika kamu pakai Huawei atau Honor tanpa GMS:
- Install **Googlefier** (bisa dicari di XDA Developers)
- Ikuti langkah-langkahnya, aplikasi ini memudahkan instalasi GMS secara otomatis

---

#### 4. **Flash ROM Global (Advanced)**
Kalau HP kamu Xiaomi, Oppo, atau lainnya, dan punya versi Global ROM, kamu bisa flash ke versi Global ROM yang sudah punya GMS. Tapi ini **berisiko** dan butuh:
- Unlock bootloader
- Download ROM resmi global
- Gunakan MiFlash atau sejenis

## 🔧 Opsi 1: Flash Global ROM Huawei (Kalau Tujuanmu Hanya Ingin GMS/Play Store)

> Ini cocok kalau HP kamu versi China dan kamu ingin versi Global yang sudah ada Google-nya.

### Langkah Umum:
1. **Cek ketersediaan ROM Global untuk model kamu**  
   Situs referensi: [Firmware Finder for Huawei](https://www.firmwarefinder.com/)
2. **Unlock bootloader** (⚠ Huawei sudah tidak resmi mendukung ini, jadi butuh tool pihak ketiga atau jasa khusus)
3. **Flash Global ROM** pakai HiSuite atau tool lain seperti dload method (SD card flashing)
4. **Factory reset setelah flashing**

---

## ⚙️ Opsi 2: Install Custom ROM (LineageOS, HarmonyOS mod, AOSP)

> Ini cocok kalau kamu ingin ganti sistem operasi sepenuhnya dan bukan hanya GMS.

### Tapi perlu dicatat:
- **Bootloader harus di-unlock** (Huawei **sudah menutup akses resmi unlock** sejak 2018)
- Perlu **TWRP (recovery custom)** dan **akses root**
- Tidak semua model Huawei didukung custom ROM
- **Garansi bisa hangus** dan potensi *bricked* (mati total) kalau salah langkah

### Langkah Umum:
1. Cari tahu apakah **model HP kamu didukung LineageOS** di sini:  
   👉 [https://wiki.lineageos.org/devices/](https://wiki.lineageos.org/devices/)
2. Kalau didukung, kamu perlu:
   - Unlock bootloader (via pihak ketiga seperti DC-Unlocker, HCU Client)
   - Install TWRP Recovery
   - Flash ROM (zip file) dari microSD atau PC via ADB sideload
   - Install Google Apps (GApps) secara terpisah
   - Reboot dan setup

---

## 💸 Catatan Penting:
- Unlock bootloader Huawei **hanya bisa dilakukan** pakai jasa pihak ketiga sekarang, seperti:
  - [DC-Unlocker](https://www.dc-unlocker.com/)
  - [HCU Client](https://hcu-client.com/)
  - Biasanya berbayar (sekitar $10–30 tergantung model)

### 📌 Apa itu Googlefier?
Aplikasi yang dibuat khusus untuk memasang layanan Google (GMS) di HP **Huawei/Honor** yang tidak punya GMS. Disediakan oleh XDA Developers (aman).

---

### 📥 CARA INSTALL GOOGLEFIER

#### 1. **Download Googlefier APK**
- Kunjungi [XDA Forum resmi Googlefier](https://forum.xda-developers.com/t/googlefier-install-gms-on-your-huawei-device.4171963/)
- Scroll ke bawah, cari link download APK (atau aku bisa kasih langsung jika kamu mau)

#### 2. **Izinkan install dari sumber tidak dikenal**
- Masuk ke:  
  `Settings > Security > Install unknown apps`  
  Pilih browser atau file manager yang kamu pakai → aktifkan

#### 3. **Install dan Jalankan Googlefier**
- Ikuti semua langkah di aplikasi (biasanya ada 5 tahap)
- Proses ini akan:
  - Pasang GMS
  - Masukkan akun Google
  - Install Play Store

#### 4. **Restart HP**
- Setelah selesai, kamu bisa buka **Google Play Store** dan login

---

### ⚠️ PERSYARATAN:
- HP Huawei kamu harus masih pakai **EMUI 10 atau 10.1**
- Kalau sudah pakai **HarmonyOS atau EMUI 11+**, metode ini **tidak selalu berhasil**
- Untuk HarmonyOS, kamu bisa downgrade dulu (bisa aku bantu carikan caranya)
