### Langkah 2: Coba faktorisasi atau metode numerik

Karena ini persamaan kubik (derajat 3), kita bisa coba **teorema faktor rasional** untuk mencari akar rasional.

Misalkan:
\[
f(x) = 6x^3 + 5x^2 + 8x - 10

**Kemungkinan akar rasional** (faktor dari -10 dibagi faktor dari 6):
\[
\pm1, \pm2, \pm5, \pm10, \pm\frac{1}{2}, \pm\frac{5}{2}, \pm\frac{1}{3}, \pm\frac{2}{3}, \pm\frac{5}{3}, \pm\frac{10}{3}, \pm\frac{1}{6}, \ldots
\]

### Langkah 3: Coba nilai dengan substitusi
Coba \( x = 1 \):

\[
f(1) = 6(1)^3 + 5(1)^2 + 8(1) - 10 = 6 + 5 + 8 - 10 = 9 \neq 0
\]

Coba \( x = 0 \):  
\[
f(0) = -10 \neq 0
\]

Coba \( x = 1/2 \):  
\[
f(1/2) = 6(1/8) + 5(1/4) + 8(1/2) - 10 = \frac{6}{8} + \frac{5}{4} + 4 - 10 = 0.75 + 1.25 + 4 - 10 = -4 \neq 0
\]

Coba \( x = 1 \) lagi → tidak cocok.

Sepertinya tidak ada akar rasional yang cocok.

### ✦ Langkah 1: Substitusi \( x = y + h \)

Tujuannya adalah memilih \( h \) agar suku kuadrat hilang. Kita mulai dari bentuk:

\[
f(x) = 6x^3 + 5x^2 + 8x - 10
\]

Misalkan:
\[
x = y + h \quad\Rightarrow\quad \text{cari } h \text{ supaya koefisien } y^2 \text{ = 0}
\]

Kita substitusi \( x = y + h \) ke dalam \( f(x) \):

\[
f(y + h) = 6(y + h)^3 + 5(y + h)^2 + 8(y + h) - 10
\]

Gunakan identitas binomial:
- \( (y + h)^3 = y^3 + 3hy^2 + 3h^2y + h^3 \)
- \( (y + h)^2 = y^2 + 2hy + h^2 \)

Maka:
\[
f(y + h) =
6(y^3 + 3hy^2 + 3h^2y + h^3) + 5(y^2 + 2hy + h^2) + 8y + 8h - 10
\]

\[
= 6y^3 + 18hy^2 + 18h^2y + 6h^3 + 5y^2 + 10hy + 5h^2 + 8y + 8h - 10
\]

Gabungkan suku-suku:
- \( y^3: \) \(6y^3\)
- \( y^2: \) \( (18h + 5)y^2 \)
- \( y^1: \) \( (18h^2 + 10h + 8)y \)
- Konstanta: \(6h^3 + 5h^2 + 8h - 10\)

Agar bentuk menjadi \( ay^3 + by + c = 0 \), kita ingin **koefisien \(y^2 = 0\)**:

\[
18h + 5 = 0 \Rightarrow h = -\frac{5}{18}
\]

### 👤 User:
bagaimana cara menyelesaikan persamaan ax^3 + bx + c = 0

### 🤖 ChatGPT:
Untuk menyelesaikan persamaan berbentuk:

\[
ax^3 + bx + c = 0
\]

(khusus bentuk **tanpa suku kuadrat**, yaitu *depressed cubic*), kita bisa menggunakan **rumus Cardano**. Berikut langkah-langkahnya secara sistematis:

---

### 🔷 Bentuk Umum

Misalkan:
\[
ax^3 + bx + c = 0
\]

Langkah pertama: **bagi seluruh persamaan dengan \( a \)** (jika \( a \neq 1 \)):

\[
x^3 + px + q = 0
\]

dengan:
- \( p = \frac{b}{a} \)
- \( q = \frac{c}{a} \)

---

### 🔷 Langkah 1: Hitung diskriminan

\[
\Delta = \left(\frac{q}{2}\right)^2 + \left(\frac{p}{3}\right)^3
\]

Nilai diskriminan menentukan jenis akar:

- Jika \( \Delta > 0 \): satu akar real, dua akar kompleks konjugat.
- Jika \( \Delta = 0 \): semua akar real, dan minimal dua sama.
- Jika \( \Delta < 0 \): tiga akar real dan berbeda.

---

### 🔷 Langkah 2: Gunakan rumus Cardano

Jika sudah dalam bentuk:
\[
x^3 + px + q = 0
\]

Solusinya:
\[
x = \sqrt[3]{-\frac{q}{2} + \sqrt{\Delta}} + \sqrt[3]{-\frac{q}{2} - \sqrt{\Delta}}
\]

Catatan:
- Jika akar kubik dari bilangan negatif, gunakan akar kompleks (atau pakai trigonometri jika ingin semua akar real ditulis eksplisit).
- Kalau \(\Delta < 0\), akar kubik tersebut akan kompleks, dan kita bisa pakai **metode trigonometri** (pakai cos/arccos).

---

### 🔷 Contoh Nyata:

Misalkan kita punya:

\[
x^3 + 3x + 1 = 0
\]

- \( p = 3 \), \( q = 1 \)

Hitung:

\[
\Delta = \left( \frac{1}{2} \right)^2 + \left( \frac{3}{3} \right)^3 = \frac{1}{4} + 1 = \frac{5}{4} > 0
\]

Berarti: satu akar real.

Gunakan rumus Cardano:

\[
x = \sqrt[3]{-\frac{1}{2} + \sqrt{\frac{5}{4}}} + \sqrt[3]{-\frac{1}{2} - \sqrt{\frac{5}{4}}}
\]

\[
x \approx \sqrt[3]{-0.5 + 1.118} + \sqrt[3]{-0.5 - 1.118}
\approx \sqrt[3]{0.618} + \sqrt[3]{-1.618}
\approx 0.850 - 1.194 = -0.344
\]

Jadi, akar realnya kira-kira \( x \approx -0.344 \)

---

### 🔷 BONUS: Trigonometri (Jika \( \Delta < 0 \))

Kalau kamu ingin menyelesaikan saat \(\Delta < 0\), maka bentuk solusinya:

\[
x_k = 2\sqrt{-\frac{p}{3}} \cos\left( \frac{\theta + 2k\pi}{3} \right), \quad k = 0, 1, 2
\]
dengan:
\[
\cos \theta = -\frac{q}{2} \cdot \left( \sqrt{-\left( \frac{3}{p} \right)^3} \right)
\]

Metode ini dipakai jika ingin mendapatkan ketiga akar real secara eksak.

### ✅ Ringkasan

Untuk menyelesaikan:
\[
ax^3 + bx + c = 0
\]

1. Bagi dengan \( a \): jadi \( x^3 + px + q = 0 \)
2. Hitung \( \Delta = \left(\frac{q}{2}\right)^2 + \left(\frac{p}{3}\right)^3 \)
3. Gunakan:
   - Jika \( \Delta > 0 \): Rumus Cardano (1 akar real, 2 kompleks)
   - Jika \( \Delta = 0 \): Solusi real, mungkin akar kembar
   - Jika \( \Delta < 0 \): Gunakan metode trigonometri (3 akar real)
