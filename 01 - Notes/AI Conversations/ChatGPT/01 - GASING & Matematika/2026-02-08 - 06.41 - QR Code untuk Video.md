## ✅ **Cara 1: Matikan AutoFit (Paling Sering Berhasil)**

1. Klik di dalam tabel.
2. Klik **Table Tools → Layout** (di menu atas).
3. Klik **AutoFit**.
4. Pilih 👉 **Fixed Column Width**.

📌 Ini membuat lebar kolom bisa diatur manual.

---

## ✅ **Cara 2: Matikan “Automatically Resize”**

1. Klik kanan di tabel.
2. Pilih **Table Properties**.
3. Masuk tab **Table**.
4. Klik **Options…**
5. Hilangkan centang:
   ☑ Automatically resize to fit contents
6. Klik **OK → OK**

---

## ✅ **Cara 3: Atur Lebar Kolom Manual (Presisi)**

Kalau masih “terkunci”:

1. Blok kolom yang mau diubah.
2. Klik **Layout → Cell Size**
3. Atur **Width** (Lebar) secara manual.

Contoh:  
➡️ Isi `3 cm`, `4 cm`, dll.

---

## ✅ **Cara 4: Pastikan Tidak di Dalam Text Box / Shape**

Kadang tabel terasa “terkunci” karena:

- Ada di dalam **Text Box**
- Ada di dalam **Shape**

Cek:
➡️ Klik tabel → apakah ada bingkai kotak di luarnya?

Kalau iya:
- Cut tabel
- Paste ke halaman biasa

---

## ⚠️ Jika Masih Tidak Bisa

Biasanya karena:

❌ Mode dokumen “Read Only”  
❌ File hasil PDF convert  
❌ Proteksi dokumen

Solusi cepat:

1. Klik **File → Info**
2. Klik **Protect Document**
3. Pilih **Disable Protection** (jika ada)

## ✅ **CARA 1 — Save as PDF dengan Kompresi (Paling Disarankan di Word)**

1. Buka file Word
2. **File → Save As**
3. Pilih **File Format: PDF**
4. Klik **Options…**
5. Pilih:
   - ☑ **Optimize for: Minimum size (publishing online)**  
   - ❌ Jangan pilih “Best for printing” dulu
6. Save

📌 Cocok kalau mau **cepat & aman**, tapi kualitas gambar sedikit turun.

---

## ✅ **CARA 2 — Export PDF (Lebih Stabil untuk File Besar)**

1. **File → Export**
2. Pilih **PDF**
3. Pilih:
   - **Best for electronic distribution**
4. Export

👉 Ini sering **lebih stabil** daripada Save As untuk file >200 MB.

---

## ✅ **CARA 3 — Cetak ke PDF (Bypass Error Word)**

Kalau Word **crash / gagal export**:

1. **File → Print**
2. Printer: **Save as PDF**
3. Klik **PDF → Save as PDF**
4. Save

📌 Ini **melewati engine export Word**, sering berhasil untuk file raksasa.

---

## ✅ **CARA 4 — Pecah File Word (PALING AMAN UNTUK BUKU TEBAL)**

Untuk buku seperti GASING (ratusan halaman):

### Langkah:
1. Duplikasi file Word
2. Pecah jadi:
   - Bab 1–4
   - Bab 5–8
   - Bab 9–Lampiran
3. Export masing-masing ke PDF
4. Gabungkan PDF (lihat Cara 6)

📌 Ini **standar penerbit profesional**.

---

## ✅ **CARA 5 — Kurangi Ukuran Gambar di Word (WAJIB TAHU)**

Biasanya penyebab 200 MB = **gambar 300–600 DPI**

### Langkah:
1. Klik salah satu gambar
2. **Picture Format → Compress Pictures**
3. Pilih:
   - Resolution: **220 ppi (Print)** atau **150 ppi**
   - ☑ Delete cropped areas of pictures
4. Apply to **All pictures**
5. Save → Export PDF

💥 Efek: ukuran file bisa turun **5–10×** tanpa terlihat rusak.

3. Atur urutan
4. **File → Export as PDF**
