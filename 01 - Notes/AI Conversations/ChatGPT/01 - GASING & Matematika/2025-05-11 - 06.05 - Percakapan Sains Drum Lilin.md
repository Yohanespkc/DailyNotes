89.	VIBRASI

Mematikan api lilin tanpa ditiup? Ya, banyak sekali caranya. Salah satunya adalah percobaan ini!

Alat dan bahan yang diperlukan :
	Drum 
	Corong besar  
	Lilin 
	Korek api

Prosedur percobaan :
	Peganglah corong dan arahkan pada drum.
	Nyalakan lilin dan letakkan di depan ujung corong
	Pukullah drum.
	Apa yang terjadi ?

Hasil yang terjadi :
Api lilin akan padam.

Mengapa :
Suara drum menimbulkan gerakan udara. Semakin besar suara yang dihasilkan maka semakin kuat pula gerakan-gerakan udara. Dan pada akhirnya terkumpul/terfokuskan melalui corong, sehingga api lilin mengalami gangguan.
