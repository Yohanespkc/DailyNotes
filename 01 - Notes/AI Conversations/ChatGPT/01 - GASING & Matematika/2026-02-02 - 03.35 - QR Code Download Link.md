### 1) Beri **Full Disk Access** ke Terminal
1. **System Settings** → **Privacy & Security**
2. Scroll ke **Full Disk Access**
3. **ON** untuk aplikasi yang Anda pakai:
   - **Terminal.app** (dan/atau **iTerm**, kalau pakai iTerm)
4. **Tutup Terminal** (Quit, bukan cuma close window)
5. Buka lagi Terminal, lalu coba lagi:

```bash
yt-dlp --cookies-from-browser safari "https://www.youtube.com/watch?v=MqmfQ0quDU0"
```

> Catatan: kadang perlu **restart Mac** sekali agar izin benar-benar “nempel”.

### 2) Pastikan Safari tidak menghalangi file cookie
- Coba **quit Safari** dulu (Cmd+Q), lalu jalankan command di atas lagi.

## ✅ Kalau masih ditolak: pakai cara paling stabil (cookies.txt)

Ini biasanya **paling pasti berhasil** di macOS modern.

### A) Di Chrome (atau browser yang Anda login YouTube)
1. Install extension **Get cookies.txt** (atau “cookies.txt exporter” yang setara).
2. Login YouTube.
3. Export cookies untuk domain youtube → simpan sebagai `cookies.txt`

### B) Jalankan yt-dlp dengan cookies file
```bash
yt-dlp --cookies cookies.txt "https://www.youtube.com/watch?v=MqmfQ0quDU0"
```

---

## 🔍 Kenapa Safari error “Operation not permitted”?
Karena folder `~/Library/Containers/.../Safari/...` termasuk area yang **dilindungi macOS Privacy**, jadi CLI tool seperti yt-dlp **harus** lewat aplikasi yang punya **Full Disk Access**.

## 🔍 PENYEBAB PALING UMUM

Biasanya karena salah satu ini:

### 1️⃣ Video = Private / Unlisted
- Hanya bisa dibuka pemilik / yang diizinkan
- yt-dlp → otomatis ditolak

➡️ Cek: buka link di browser:

https://www.youtube.com/watch?v=MqmfQ0quDU0

Kalau muncul:
> “Video ini tidak tersedia”
> “Private video”

→ Ini penyebabnya.

---

### 2️⃣ Video = Umur (Age Restricted)
Kalau ada tulisan:
> “Confirm your age”

yt-dlp sering gagal tanpa flag khusus.

Solusi:

```bash
yt-dlp --cookies cookies.txt --age-limit 99 "URL"
```

---

### 3️⃣ Video = Regional Block
Video diblokir di lokasi Anda.

Solusi:

```bash
yt-dlp --geo-bypass --cookies cookies.txt "URL"
```

Atau:

```bash
yt-dlp --proxy socks5://127.0.0.1:1080 "URL"
```

(kalau pakai VPN)

---

### 4️⃣ Video = Hanya Member / Berbayar
Kalau video khusus member / course / premium → yt-dlp tidak bisa.
