### 🔍 Penjelasan Soal

Soal ini meminta kita untuk mencari **semua bilangan real \( \alpha \)** sehingga untuk **setiap bilangan bulat positif \( n \)**, jumlah:
\[
\lfloor \alpha \rfloor + \lfloor 2\alpha \rfloor + \cdots + \lfloor n\alpha \rfloor
\]
selalu merupakan **kelipatan dari \( n \)**.

Ingat bahwa simbol \( \lfloor x \rfloor \) berarti **nilai bulat terbesar yang kurang dari atau sama dengan \( x \)**. Misalnya:
- \( \lfloor \pi \rfloor = 3 \)
- \( \lfloor -2.1 \rfloor = -3 \)

---

### 🔢 Langkah Awal: Contoh Konkret

Mari kita coba nilai \( \alpha = 0 \). Maka:
\[
\lfloor k\alpha \rfloor = \lfloor 0 \rfloor = 0 \text{ untuk setiap } k
\Rightarrow \text{jumlahnya } 0 + 0 + \cdots + 0 = 0
\]
0 adalah kelipatan dari \( n \), jadi **\( \alpha = 0 \) adalah solusi**.

Sekarang coba \( \alpha = 1 \):
\[
\lfloor \alpha \rfloor + \lfloor 2\alpha \rfloor + \cdots + \lfloor n\alpha \rfloor = 1 + 2 + \cdots + n = \frac{n(n+1)}{2}
\]
Apakah ini kelipatan dari \( n \)? Tidak selalu! Contoh: kalau \( n = 3 \), hasilnya 6, iya kelipatan 3. Tapi kalau \( n = 4 \), hasilnya 10, bukan kelipatan 4. Jadi **\( \alpha = 1 \) bukan solusi**.

---

### 💡 Intuisi Menuju Jawaban

Misalkan kita ingin:
\[
S(n) = \lfloor \alpha \rfloor + \lfloor 2\alpha \rfloor + \cdots + \lfloor n\alpha \rfloor \equiv 0 \pmod{n}
\]
Artinya \( S(n) \) harus habis dibagi \( n \).

Gunakan fakta bahwa:
\[
\lfloor k\alpha \rfloor = k\alpha - \{k\alpha\}
\]
dengan \( \{x\} \) menyatakan **bagian desimal** \( x - \lfloor x \rfloor \).

Maka:
\[
S(n) = \sum_{k=1}^{n} \lfloor k\alpha \rfloor = \sum_{k=1}^{n} k\alpha - \sum_{k=1}^{n} \{k\alpha\}
= \alpha \cdot \frac{n(n+1)}{2} - \sum_{k=1}^{n} \{k\alpha\}
\]

Agar \( S(n) \) kelipatan dari \( n \), maka:
\[
\alpha \cdot \frac{n(n+1)}{2} - \sum_{k=1}^{n} \{k\alpha\} \equiv 0 \pmod{n}
\]

Tapi \( \sum \{k\alpha\} \) sulit dikendalikan — **kecuali jika \( \alpha \) adalah bilangan rasional khusus.**

---

### ✅ Solusi: Coba \( \alpha = \frac{a}{b} \) bilangan rasional

Kita coba \( \alpha = \frac{1}{m} \), contoh \( \frac{1}{2} \):

\[
\lfloor \frac{1}{2} \rfloor = 0, \quad \lfloor \frac{2}{2} \rfloor = 1, \quad \lfloor \frac{3}{2} \rfloor = 1, \quad \lfloor \frac{4}{2} \rfloor = 2, \text{ dll}
\]

Coba hitung \( n = 4 \):
\[
\lfloor \alpha \rfloor + \lfloor 2\alpha \rfloor + \lfloor 3\alpha \rfloor + \lfloor 4\alpha \rfloor = 0 + 1 + 1 + 2 = 4
\Rightarrow \text{kelipatan } 4 ✅
\]

Coba \( \alpha = \frac{a}{b} \) dan lihat syarat agar hasil penjumlahan selalu kelipatan dari \( n \). Ini **selalu terjadi hanya jika \( \alpha = \frac{p}{q} \) dengan \( q = 1 \)** (bilangan bulat) **atau \( \alpha = \frac{1}{k} \)**.

Namun, jika kita ingin **semua \( n \)** menjamin pembagian, maka ternyata:
\[
\boxed{\alpha \in \mathbb{Z} \cup \left\{ \frac{1}{k} \mid k \in \mathbb{Z}_{>0} \right\}}
\]
**bukan selalu valid**, karena untuk \( \alpha = \frac{1}{2} \), saat \( n = 3 \) jumlahnya:
\[
\lfloor \frac{1}{2} \rfloor + \lfloor 1 \rfloor + \lfloor \frac{3}{2} \rfloor = 0 + 1 + 1 = 2
\Rightarrow \text{tidak habis dibagi } 3 ❌
\]

---

### 🎯 Jawaban Final

Satu-satunya nilai \( \alpha \in \mathbb{R} \) sehingga:
\[
\sum_{k=1}^{n} \lfloor k\alpha \rfloor \text{ adalah kelipatan dari } n \text{ untuk semua } n \in \mathbb{Z}^+
\]
adalah:
\[
\boxed{\alpha = 0}
\]

\section*{Soal}
Tentukan semua bilangan real \( \alpha \) sedemikian sehingga, untuk setiap bilangan bulat positif \( n \), jumlah berikut:
\[
\lfloor \alpha \rfloor + \lfloor 2\alpha \rfloor + \cdots + \lfloor n\alpha \rfloor
\]
selalu merupakan kelipatan dari \( n \). Di mana \( \lfloor x \rfloor \) menyatakan bagian bulat terbesar yang kurang dari atau sama dengan \( x \) (floor function).

\section*{Langkah Awal: Contoh Konkret}
Coba beberapa nilai \( \alpha \) untuk melihat pola.

\subsection*{Contoh 1: \( \alpha = 0 \)}
\[
\lfloor k \cdot 0 \rfloor = 0 \text{ untuk setiap } k \Rightarrow \text{jumlah } = 0
\]
Hasilnya adalah kelipatan dari \( n \). Maka \( \alpha = 0 \) adalah solusi.

\subsection*{Contoh 2: \( \alpha = 1 \)}
\[
\lfloor \alpha \rfloor + \lfloor 2\alpha \rfloor + \cdots + \lfloor n\alpha \rfloor = 1 + 2 + \cdots + n = \frac{n(n+1)}{2}
\]
\textbf{Tidak selalu} kelipatan dari \( n \). Misalnya: untuk \( n = 4 \), jumlahnya 10, bukan kelipatan dari 4.

\section*{Pendekatan Umum}
Misalkan:
\[
S(n) = \sum_{k=1}^{n} \lfloor k\alpha \rfloor
\]
Kita tahu bahwa:
\[
\lfloor k\alpha \rfloor = k\alpha - \{k\alpha\}
\]
di mana \( \{x\} = x - \lfloor x \rfloor \) adalah bagian desimal dari \( x \).

Sehingga:
\[
S(n) = \sum_{k=1}^{n} k\alpha - \sum_{k=1}^{n} \{k\alpha\}
= \alpha \cdot \frac{n(n+1)}{2} - \sum_{k=1}^{n} \{k\alpha\}
\]

Agar \( S(n) \equiv 0 \pmod{n} \), maka selisih ini harus habis dibagi \( n \), yang sulit dipenuhi kecuali jika \( \alpha \) sangat khusus.

\section*{Pemeriksaan Rasional}
Coba \( \alpha = \frac{1}{2} \) dan \( n = 3 \):
\[
\lfloor \tfrac{1}{2} \rfloor + \lfloor 1 \rfloor + \lfloor \tfrac{3}{2} \rfloor = 0 + 1 + 1 = 2
\Rightarrow \text{tidak habis dibagi 3}
\]
Jadi, \( \alpha = \frac{1}{2} \) bukan solusi.

\section*{Kesimpulan}
Satu-satunya \( \alpha \in \mathbb{R} \) yang memenuhi syarat:
\[
\sum_{k=1}^{n} \lfloor k\alpha \rfloor \equiv 0 \pmod{n} \text{ untuk semua } n \in \mathbb{Z}^+
\]
adalah:
\[
\boxed{\alpha = 0}
\]
