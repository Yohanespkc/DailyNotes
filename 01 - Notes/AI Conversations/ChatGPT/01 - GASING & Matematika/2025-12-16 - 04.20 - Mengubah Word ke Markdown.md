---

## 1️⃣ Cara paling praktis (disarankan): **Pandoc**
Pandoc adalah standar emas untuk konversi dokumen.

### 🔹 Langkah (macOS / Linux / Windows)
1. **Install Pandoc**
   - macOS (Homebrew):
     ```bash
     brew install pandoc
     ```
   - Windows: unduh installer dari situs resmi Pandoc
   - Linux:
     ```bash
     sudo apt install pandoc
     ```

2. **Konversi Word → Markdown**
   ```bash
   pandoc file.docx -o file.md
   ```

3. (Opsional) Markdown lebih bersih:
   ```bash
   pandoc file.docx -t markdown_strict -o file.md
   ```

✅ Kelebihan:
- Heading, tabel, daftar, bold/italic relatif rapi  
- Sangat cocok untuk paper, buku, dan dokumen akademik (termasuk GASING 🙂)

---

## 2️⃣ Cara cepat tanpa install (Online)
Jika hanya sesekali:

- **CloudConvert**
- **Zamzar**
- **Word to Markdown (writage.com)**

📌 Catatan:  
Jangan gunakan untuk dokumen sensitif atau NDA.

---

## 3️⃣ Copy–Paste (manual tapi cepat)
1. Buka file Word
2. Copy semua isi
3. Paste ke editor Markdown (Obsidian, VS Code, Typora)
4. Rapikan heading:
   ```md
   # Judul
   ## Subjudul
   ```

⚠️ Cocok hanya untuk teks sederhana (tanpa tabel rumit).

---

## 4️⃣ Jika banyak rumus matematika (LaTeX)
Gunakan Pandoc + opsi Math:
```bash
pandoc file.docx -o file.md --mathjax
```

Rumus akan menjadi:
```md
$$
E = mc^2
$$
```

Sangat cocok untuk **paper matematika / fisika GASING**.

### 🤖 ChatGPT:
Masalahnya jelas: di Mac Anda, perintah `gs` yang jalan **bukan Ghostscript**, tapi **skrip Python dari package lain** (terlihat dari traceback: `/Users/ys/.pyenv/.../bin/gs` dan modul `genesis`). Jadi nama command `gs` “ketabrak” oleh environment `pyenv`.

Solusinya: panggil Ghostscript dengan **path Homebrew** (atau perbaiki PATH).

---

## 1) Pastikan Ghostscript Homebrew ada
Jalankan:

```bash
brew --prefix ghostscript
```

Harus keluar sesuatu seperti:
- Apple Silicon: `/opt/homebrew/opt/ghostscript`
- Intel Mac: `/usr/local/opt/ghostscript`

Lalu cek binary-nya:

```bash
ls -l "$(brew --prefix ghostscript)/bin/gs"
```

---

## 2) Jalankan kompresi dengan path penuh (langsung beres)
Ganti perintah Anda jadi:

```bash
"$(brew --prefix ghostscript)/bin/gs" \
 -sDEVICE=pdfwrite \
 -dCompatibilityLevel=1.4 \
 -dPDFSETTINGS=/screen \
 -dNOPAUSE -dQUIET -dBATCH \
 -sOutputFile=Buku_Gasing_diHatiku_OPSI_C.pdf \
 "Buku Gasing-diHatiku.pdf"
```

Catatan: saya pakai tanda kutip untuk nama file yang ada spasi.

---

## 3) Verifikasi ukuran hasil
```bash
ls -lh Buku_Gasing_diHatiku_OPSI_C.pdf
```

---

## 4) Perbaikan permanen (agar `gs` tidak ketabrak lagi)
Lihat dulu yang aktif sekarang:

```bash
which -a gs
```

Kalau yang pertama masih `~/.pyenv/.../bin/gs`, maka prioritaskan Homebrew di PATH.

### Apple Silicon (M1/M2/M3)
Tambahkan ke `~/.zshrc`:

```bash
echo 'export PATH="/opt/homebrew/opt/ghostscript/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

### Intel Mac
```bash
echo 'export PATH="/usr/local/opt/ghostscript/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

Cek lagi:
```bash
which gs
gs --version
```

Harus menampilkan versi Ghostscript (mis. 10.x), bukan error Python.
