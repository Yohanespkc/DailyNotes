**Soal:**
Tentukan semua bilangan real \(\alpha\) sedemikian sehingga, untuk setiap bilangan bulat positif \(n\), bilangan
\[
\lfloor \alpha \rfloor + \lfloor 2\alpha \rfloor + \cdots + \lfloor n\alpha \rfloor
\]
adalah kelipatan dari \(n\).  
Di mana \(\lfloor x \rfloor\) adalah fungsi **lantai** (floor), yaitu bilangan bulat terbesar yang kurang dari atau sama dengan \(x\).

---

### Langkah 1: Notasi dan Interpretasi
Misalkan
\[
S(n) = \lfloor \alpha \rfloor + \lfloor 2\alpha \rfloor + \cdots + \lfloor n\alpha \rfloor
\]
dan kita ingin \(S(n)\) habis dibagi \(n\), yaitu:
\[
S(n) \equiv 0 \pmod{n}, \quad \forall n \in \mathbb{Z}^+
\]

---

### Langkah 2: Uji Kasus Sederhana

Misal \(\alpha = a\) adalah bilangan bulat. Maka:
\[
\lfloor k\alpha \rfloor = k\alpha
\Rightarrow S(n) = \alpha(1 + 2 + \dots + n) = \alpha \cdot \frac{n(n+1)}{2}
\]
Ini jelas kelipatan dari \(n\). Jadi semua bilangan **bulat** memenuhi syarat!

---

### Langkah 3: Coba Bilangan Non-Bulat

Misal \(\alpha = r\) dengan \(r\) bukan bilangan bulat.

Misal \(\alpha = a + \theta\) dengan \(a \in \mathbb{Z}\), \(0 < \theta < 1\). Maka:
\[
\lfloor k\alpha \rfloor = \lfloor k(a+\theta) \rfloor = ka + \lfloor k\theta \rfloor
\Rightarrow S(n) = a(1 + 2 + \dots + n) + \sum_{k=1}^{n} \lfloor k\theta \rfloor = a\cdot \frac{n(n+1)}{2} + \sum_{k=1}^{n} \lfloor k\theta \rfloor
\]

Agar \(S(n) \equiv 0 \pmod{n}\), maka:
\[
\sum_{k=1}^{n} \lfloor k\theta \rfloor \equiv -a \cdot \frac{n(n+1)}{2} \pmod{n}
\]

Tapi perhatikan:  
- \(\lfloor k\theta \rfloor\) tidak bersifat linear jika \(\theta\) irasional atau pecahan tak sesuai.
- Misal \(\theta = \frac{1}{2}\), maka \(\lfloor k\theta \rfloor\) berubah setiap dua langkah.

Misal \(\alpha = \frac{1}{2}\):  
\[
\lfloor \alpha \rfloor = 0,\; \lfloor 2\alpha \rfloor = 1,\; \lfloor 3\alpha \rfloor = 1,\; \lfloor 4\alpha \rfloor = 2
\]
\[
S(4) = 0 + 1 + 1 + 2 = 4 \Rightarrow \text{OK}
\]
\[
S(5) = 0 + 1 + 1 + 2 + 2 = 6 \Rightarrow 6 \not\equiv 0 \pmod{5} \Rightarrow \text{TIDAK VALID}
\]

Jadi, \(\alpha = \frac{1}{2}\) **tidak valid**.

---

### Langkah 4: Generalisasi

Dari bentuk umum:
\[
S(n) = \sum_{k=1}^{n} \lfloor k\alpha \rfloor = \sum_{k=1}^{n} k\alpha - \sum_{k=1}^{n} \{k\alpha\} = \alpha \cdot \frac{n(n+1)}{2} - \sum_{k=1}^{n} \{k\alpha\}
\]
Agar \(S(n)\) kelipatan dari \(n\), maka
\[
\alpha \cdot \frac{n(n+1)}{2} - \sum_{k=1}^{n} \{k\alpha\} \equiv 0 \pmod{n}
\]
\[
\Rightarrow \sum_{k=1}^{n} \{k\alpha\} \equiv \alpha \cdot \frac{n(n+1)}{2} \pmod{n}
\]

Namun \(\sum_{k=1}^{n} \{k\alpha\}\) tidak rasional jika \(\alpha\) tidak rasional. Hanya jika \(\alpha\) bilangan bulat, \(\{k\alpha\} = 0\), maka semuanya valid.

---

### ✅ Kesimpulan:

**Satu-satunya bilangan real \(\alpha\) yang memenuhi syarat untuk semua \(n \in \mathbb{Z}^+\) adalah bilangan bulat.**

\[
\boxed{\alpha \in \mathbb{Z}}
\]
