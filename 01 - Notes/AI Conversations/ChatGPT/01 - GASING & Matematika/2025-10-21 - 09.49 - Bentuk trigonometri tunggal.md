# 💬 Bentuk trigonometri tunggal

**Tanggal:** `2025-10-21 09.49`  
**Sumber:** ChatGPT Export  

---

### 👤 User:
ubah dalam bentuk trigonometri tunggal cos⁡〖x+sin⁡x 〗                               

### 🤖 ChatGPT:
Kita ubah  
\[
\cos x + \sin x
\]  
menjadi bentuk **trigonometri tunggal** berbentuk  
\[
R \cos(x - \alpha) \quad \text{atau} \quad R \sin(x+\alpha)
\]

---

### Bentuk ke \(R\cos(x-\alpha)\)

Kita cari \(R\) dan \(\alpha\) sehingga

\[
\cos x + \sin x = R\cos(x-\alpha)
\]

Gunakan identitas:
\[
\cos(x-\alpha)=\cos x \cos\alpha + \sin x \sin \alpha
\]

Maka harus berlaku:
\[
\cos x + \sin x = R(\cos x \cos \alpha + \sin x \sin \alpha)
\]

Bandingkan koefisien:
\[
\begin{cases}
R\cos\alpha = 1\\
R\sin\alpha = 1
\end{cases}
\]

Bagi kedua persamaan:
\[
\tan\alpha = \frac{1}{1} = 1 \Rightarrow \alpha = 45^\circ
\]

Cari \(R\):
\[
R = \sqrt{1^2+1^2} = \sqrt{2}
\]

Maka
\[
\cos x + \sin x = \sqrt{2}\cos(x-45^\circ)
\]

---

### Jawaban akhir

\[
\boxed{\cos x + \sin x = \sqrt{2}\cos(x-45^\circ)}
\]

---

Bila ingin dalam bentuk sinus tunggal:

\[
\cos x + \sin x = \sqrt{2}\sin(x+45^\circ)
\]

---

### 👤 User:
tentukan nilai maks dan min nya

### 🤖 ChatGPT:
Dari hasil sebelumnya:

\[
\cos x + \sin x = \sqrt{2}\cos(x-45^\circ)
\]

Kita tahu bahwa untuk semua \(x\):
\[
-1 \le \cos(\,\cdot\,) \le 1
\]

Maka:

\[
-\sqrt{2} \le \sqrt{2}\cos(x-45^\circ) \le \sqrt{2}
\]

---

### **Nilai maksimum**
Terjadi saat \(\cos(x-45^\circ)=1\)

\[
\max = \sqrt{2}\cdot 1 = \boxed{\sqrt{2}}
\]

### **Nilai minimum**
Terjadi saat \(\cos(x-45^\circ)=-1\)

\[
\min = \sqrt{2}\cdot (-1) = \boxed{-\sqrt{2}}
\]

---

### **Kapan terjadi?**
- Maksimum ketika \(x-45^\circ = 360^\circ k\)  
  \(\Rightarrow x = 45^\circ + 360^\circ k\)
- Minimum ketika \(x-45^\circ = 180^\circ + 360^\circ k\)  
  \(\Rightarrow x = 225^\circ + 360^\circ k\)

### 👤 User:

### 🤖 ChatGPT:
Kita punya
\[
(p-1)\cos x+(p+1)\sin x=p+3.
\]
Tuliskan kiri sebagai satu sinus:
\[
a\cos x+b\sin x=R\sin(x+\varphi),\quad
R=\sqrt{a^2+b^2}.
\]
Di sini \(a=p-1,\; b=p+1\), jadi
\[
R=\sqrt{(p-1)^2+(p+1)^2}=\sqrt{2p^2+2}=\sqrt{2(p^2+1)}.
\]

Agar persamaan punya solusi nyata, nilai kanan harus berada dalam jangkauan \([-R,\,R]\):
\[
|p+3|\le R=\sqrt{2(p^2+1)}.
\]
Kuadratkan kedua sisi:
\[
(p+3)^2\le 2(p^2+1)
\;\Longleftrightarrow\;
p^2+6p+9\le 2p^2+2
\]
\[
\Longleftrightarrow\;
0\le p^2-6p-7
\;=\;(p-3)^2-16.
\]

Maka
\[
(p-3)^2\ge 16
\;\Longleftrightarrow\;
|p-3|\ge 4
\;\Longleftrightarrow\;
\boxed{\,p\le -1\;\;\text{atau}\;\;p\ge 7\,}.
\]

Catatan:
- Jika \(p=-1\) atau \(p=7\), persamaan tepat menyentuh batas (solusi ada, tetapi “ekstrim”, mis. \(\sin(\cdot)=\pm1\)).
- Untuk \(p\) di antara \(-1\) dan \(7\), tidak ada solusi karena ruas kanan melebihi amplitudo maksimum ruas kiri.

### 👤 User:
selesaikan ini 4 sin⁡〖x+2√3>0〗

### 🤖 ChatGPT:
Kita selesaikan

\[
4\sin x + 2\sqrt3 > 0
\]

Bagi kedua ruas dengan \(2\) (positif tidak mengubah tanda):

\[
2\sin x + \sqrt3 > 0
\]

Pindahkan \(\sqrt3\):

\[
2\sin x > -\sqrt3
\]

Bagi 2 (positif lagi aman):

\[
\sin x > -\frac{\sqrt3}{2}
\]

---

### Cari interval umum untuk \(\sin x > -\frac{\sqrt3}{2}\)

Kita tahu:
\[
\sin x = -\frac{\sqrt3}{2} \quad \text{pada}\quad x = 240^\circ,\; 300^\circ \;(+360^\circ k)
\]

Grafik sinus positif di atas garis itu pada semua sudut **di luar** interval di mana sinus lebih kecil atau sama.

\(\sin x = -\frac{\sqrt3}{2}\) membatasi interval di mana \(\sin x < -\frac{\sqrt3}{2}\), yaitu antara 240° sampai 300°.

Karena kita butuh **lebih besar**, kita ambil komplemennya:

\[
\boxed{x \in (300^\circ + 360^\circ k,\; 240^\circ + 360^\circ(k+1)),\quad k\in\mathbb{Z}}
\]

---

### Jika dibatasi \(0^\circ \le x < 360^\circ\)

Daerah yang **tidak boleh** adalah antara \(240^\circ\) sampai \(300^\circ\).  
Maka solusinya:

\[
\boxed{x \in (0^\circ,240^\circ)\cup(300^\circ,360^\circ)}
\]

### 👤 User:
pada jawaban diatas mengapa tanα=11​=1⇒α=45∘, apakah yang sudut tumpul kita abaikan?

### 🤖 ChatGPT:
Pertanyaan bagus.

Pada saat kita menetapkan
\[
\tan \alpha = 1,
\]
secara **umum** memang benar bahwa
\[
\alpha = 45^\circ + 180^\circ k.
\]

Jadi solusi **umumnya** bukan hanya \(45^\circ\), tetapi
\[
\alpha = 45^\circ,\ 225^\circ,\ 405^\circ, \dots
\]

---

### Lalu kenapa yang dipakai adalah \(45^\circ\) saja?

Karena \(\alpha\) di sini bukan sudut solusi persamaan,  
tetapi hanyalah **sudut referensi** untuk menuliskan bentuk satu fungsi trigonometrik:

Contoh:
\[
\cos x + \sin x = R \cos(x - \alpha).
\]

Dalam tahap ini, \(\alpha\) hanya berperan sebagai sudut **fase** dalam bentuk identitas.  
Kita pilih \(\alpha\) yang **paling sederhana**, yaitu sudut **lancip** (acute angle),  
agar bentuknya mudah dipakai.

Kalau kita pakai \(\alpha = 225^\circ\):

\[
\cos(x-225^\circ)=\cos(x-45^\circ-180^\circ)= -\cos(x-45^\circ)
\]

Nanti bentuknya jadi tidak sederhana lagi — tetap benar, tapi lebih berantakan.

---

### Intinya

- **Semua sudut 45° + 180°k** valid secara teori
- Yang dipilih **45°** hanya karena **konvensi penyederhanaan**
- Sudut tumpul tidak “diabaikan”, hanya “tidak dipilih” demi bentuk yang lebih rapi
- Untuk keperluan identitas, cukup pilih satu yang nyaman (biasanya sudut lancip)
