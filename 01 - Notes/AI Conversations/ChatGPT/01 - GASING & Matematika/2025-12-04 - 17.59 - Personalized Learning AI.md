## 🔎 Apa itu Type Theory

- Singkatnya: di Type Theory, “tipe” (type) adalah klasifikasi dasar dari objek-objek matematika atau komputasi — mirip dengan “tipe data” di pemrograman. citeturn0search6turn0search19turn0search13  
- Sebuah objek (sering disebut “term”) dikatakan “bertipe” (of some type), dan kita tulis misalnya `x : T` untuk menyatakan bahwa `x` bertipe `T`. citeturn0search18turn0search19turn0search16  
- Berbeda dengan teori himpunan (set theory), di mana kita bicara tentang “elemen dari himpunan”, di type theory kita bicara tentang “term dari sebuah type”. citeturn0search19turn0search8turn0search0

---

## 🧠 Mengapa dan untuk apa Type Theory

Type Theory digunakan luas dalam **logika**, **matematika dasar**, dan **ilmu komputer** — terutama kompilator bahasa pemrograman, sistem verifikasi formal, hingga asistem pembuktian. citeturn0search0turn0search10turn0search17  

Beberapa hal spesifik:

- Sebagai **fondasi alternatif matematika**: dibandingkan dengan teori himpunan, type theory menawarkan cara berbeda mendasari matematika — kadang lebih cocok untuk matematika konstruktif atau untuk representasi komputasi. citeturn0search0turn0search13turn0search18  
- Dalam **pemrograman & verifikasi program**: konsep seorang variabel, fungsi, data, semuanya bisa dipandang sebagai “term bertipe”. Type checking (mengecek tipe sebelum runtime) punya dasar formal di sini — membantu mendeteksi kesalahan sebelum program dijalankan. citeturn0search10turn0search16turn0search13  
- Dalam **pembuktian matematis secara formal (proof assistants)**: di sistem yang memakai type theory, pernyataan matematis dan buktinya bisa diperlakukan sebagai type dan term — sehingga matematika bisa “ditulis & dicek” oleh komputer. citeturn0search6turn0search19turn0search3

---

## 🧩 Cara Pandang “Tipe” di Type Theory

Tergantung interpretasi / filosofi, type bisa dipahami dengan cara berbeda — ini membuat type theory fleksibel:

- Type sebagai **set** → term sebagai elemen set. citeturn0search4turn0search18  
- Type sebagai **ruang / “space”** → term sebagai titik di ruang itu. citeturn0search8turn0search18  
- Type sebagai **proposisi / pernyataan logika** → term sebagai **bukti** dari proposisi itu. (Inilah inti dari hubungan antara logika, bukti, dan komputasi di type theory.) citeturn0search18turn0search3turn0search6

Karena itu di type theory, hal yang biasanya berbeda di matematika klasik — seperti “objek (angka, fungsi, dsb.)”, “pernyataan (teorema)”, dan “bukti” — semuanya bisa dipandang sebagai **term bertipe** yang berbeda. citeturn0search11turn0search19turn0search6

## 🌱 Intuisi paling sederhana

Di lambda calculus, **tidak ada angka, tidak ada variabel global, tidak ada loop, bahkan tidak ada if–else**.

Yang ada hanya:
1. **Fungsi**
2. **Menerapkan fungsi ke argumen**

Segalanya dibangun dari dua hal itu.

---

## 🧱 Tiga komponen inti Lambda Calculus

### 1. **Variabel**
Contoh:
```
x
```

### 2. **Abstraksi (membuat fungsi)**
Bentuk umum:
```
λx. x
```
Artinya:
> fungsi yang menerima `x` dan mengembalikan `x`

Ini seperti:
```text
f(x) = x
```

---

### 3. **Aplikasi (memanggil fungsi)**
Bentuk:
```
(λx. x) 5
```

Artinya:
> terapkan fungsi λx. x ke nilai 5

Hasilnya:
```
5
```

---

## 🔄 Aturan utama: **Substitusi**

Aturan inti lambda calculus:
```
(λx. body) value   →   body[x := value]
```

Contoh:
```
(λx. x + 1) 4  →  4 + 1  →  5
```

*(walaupun `+` sendiri sebenarnya juga bisa didefinisikan lewat lambda)*

---

## 🧠 Hal yang mengejutkan

Dengan hanya:
- fungsi
- aplikasi fungsi

kita bisa membangun:
- ✅ bilangan (0,1,2,3,…)
- ✅ operasi +, −, ×
- ✅ logika (true, false, if)
- ✅ loop & rekursi
- ✅ seluruh program komputer

👉 **Ini membuktikan: komputer pada dasarnya adalah mesin fungsi.**

---

## 🔢 Contoh ekstrem: Bilangan di Lambda Calculus

Bilangan **2** direpresentasikan sebagai:
> “lakukan fungsi **dua kali**”

```
2 ≡ λf. λx. f (f x)
```

Bilangan **3**:
```
3 ≡ λf. λx. f (f (f x))
```

Ini disebut **Church Numerals**.

## Apa arti  
\[
\boxed{2 \equiv \lambda f.\,\lambda x.\, f (f\,x)}
\]

Artinya:

> **Angka 2 adalah “fungsi yang melakukan sesuatu sebanyak dua kali”.**

Bukan “dua benda”.  
Bukan “nilai 2 di memori”.  
Tapi **perilaku**.

---

## Kita uraikan satu per satu

### 1️⃣ Simbol `≡`
`≡` dibaca:
> *“didefinisikan sebagai”*  
bukan “sama dengan”.

Jadi:
```
2 didefinisikan sebagai λf. λx. f (f x)
```

---

### 2️⃣ Bentuk umum

```
λf. λx. f (f x)
```

Artinya:
- Terima **sebuah fungsi f**
- Terima **sebuah nilai awal x**
- Terapkan f ke x **dua kali**

---

### 3️⃣ Makna kalimat manusianya

> “Ambil fungsi f dan nilai awal x.  
> Kerjakan f pada x,  
> lalu kerjakan f **sekali lagi** pada hasilnya.”

Itulah **dua**.

---

## Contoh konkret (ini bagian penting)

### Misal:
```
f(x) = x + 1
x = 0
```

Gunakan definisi angka 2:

```
2 f x
= (λf. λx. f (f x)) f x
→ f (f x)
→ f (f 0)
→ f 1
→ 2
```

✅ Hasilnya **2**

---

### Ganti fungsi lain

Misal:
```
f(x) = x × 2
x = 1
```

```
2 f x
→ f (f 1)
→ f 2
→ 4
```

Di sini **2 berarti “dua kali transformasi”**, bukan angka statis.

---

## Jadi apa sebenarnya “angka” di Lambda Calculus?

Dalam **church numerals**:

> **Angka n = fungsi yang mengulang sebuah aksi sebanyak n kali**

- 0 → tidak melakukan apa-apa
- 1 → lakukan sekali
- 2 → lakukan dua kali
- 3 → lakukan tiga kali

---

### Definisi umum

\[
n \;≡\; \lambda f.\,\lambda x.\, f^n(x)
\]

---

## Kenapa ini mendalam?

Karena ini mengubah cara berpikir:

| Matematika biasa        | Lambda Calculus |
|------------------------|-----------------|
| Angka = objek          | Angka = aksi |
| 2 = dua unit           | 2 = dua kali |
| Hitungan = nilai       | Hitungan = proses |

> **penjumlahan adalah penggabungan jumlah pengulangan**

---

# 3️⃣ Definisi formal penjumlahan (ini kunci)

Dalam lambda calculus:

\[
\boxed{
\text{add} \;\equiv\;
\lambda m.\,\lambda n.\,\lambda f.\,\lambda x.\,
m\,f\,(n\,f\,x)
}
\]

Dibaca manusiawi:

> “Untuk menjumlahkan m dan n:  
> pertama lakukan f sebanyak n kali,  
> lalu lanjutkan dengan m kali.”

---

# 4️⃣ Kita buktikan: **1 + 1 = 2**

### Definisi 1:
```
1 ≡ λf. λx. f x
```

### Gunakan definisi penjumlahan:
```
add 1 1
= λf. λx. 1 f (1 f x)
```

---

### Hitung bagian dalam dulu:
```
1 f x = f x
```

Masukkan:
```
1 f (f x) = f (f x)
```

Hasil:
```
λf. λx. f (f x)
```

🎉 Dan itu adalah…

```
2 ≡ λf. λx. f (f x)
```

✅ **TERBUKTI: 1 + 1 = 2**

Tanpa angka.  
Tanpa simbol +.  
Tanpa asumsi tersembunyi.
