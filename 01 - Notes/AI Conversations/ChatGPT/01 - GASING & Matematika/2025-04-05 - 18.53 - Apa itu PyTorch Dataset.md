### 🤖 ChatGPT:
`PyTorch Dataset` adalah salah satu komponen penting dalam library **PyTorch** yang digunakan untuk **mengelola dan memuat data** saat melatih model machine learning, khususnya deep learning.

### Penjelasan Singkat
`torch.utils.data.Dataset` adalah sebuah **abstraksi** yang memungkinkan kita untuk membuat objek dataset yang bisa:
- Menyimpan data (seperti gambar, teks, atau angka)
- Mengembalikan satu sampel data saat dipanggil (dengan indeks tertentu)
- Digunakan bersama `DataLoader` untuk batching dan shuffling

---

### Contoh Sederhana
Misalnya kamu punya dataset angka dan label:

```python
from torch.utils.data import Dataset

class AngkaDataset(Dataset):
    def __init__(self):
        self.data = [i for i in range(10)]       # data dari 0 sampai 9
        self.label = [i % 2 for i in range(10)]  # label 0 atau 1

    def __len__(self):
        return len(self.data)

    def __getitem__(self, idx):
        return self.data[idx], self.label[idx]
```

Dengan ini, kamu bisa akses data seperti:
```python
dataset = AngkaDataset()
print(dataset[3])  # Output: (3, 1)
```

---

### Kenapa Perlu Dataset?

Karena:
- Dataset bisa **dibuat custom** (buat sendiri sesuai kebutuhan)
- Bisa digunakan bersama `DataLoader` untuk otomatisasi proses seperti **batching**, **shuffling**, dan **paralelisasi loading data**
- Sangat cocok untuk mengelola data besar seperti gambar, suara, atau teks

---

### Kombinasi Umum:
```python
from torch.utils.data import DataLoader

dataloader = DataLoader(dataset, batch_size=2, shuffle=True)

for data, label in dataloader:
    print(data, label)
```

### 🔢 Contoh: Dataset Gambar MNIST

```python
import torch
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

# 1. Transformasi data: ubah ke tensor dan normalisasi
transform = transforms.Compose([
    transforms.ToTensor(),  # ubah gambar ke tensor
    transforms.Normalize((0.5,), (0.5,))  # normalisasi data
])

# 2. Unduh dataset MNIST (data training)
train_dataset = datasets.MNIST(root='./data', train=True, download=True, transform=transform)

# 3. Buat DataLoader untuk batching
train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)

# 4. Contoh ambil satu batch
dataiter = iter(train_loader)
images, labels = next(dataiter)

print("Ukuran batch gambar:", images.shape)  # torch.Size([32, 1, 28, 28])
print("Label dari batch:", labels)
```

---

### Penjelasan:
- `transforms.ToTensor()`: ubah gambar dari PIL Image ke tensor PyTorch.
- `transforms.Normalize((0.5,), (0.5,))`: skala piksel dari [0,1] jadi [-1,1].
- `datasets.MNIST(...)`: langsung pakai dataset MNIST dari PyTorch.
- `DataLoader(...)`: mempermudah pengambilan data per batch, bisa diacak.

### 🧠 Kode: Dataset Gambar dari Folder

```python
from torchvision import datasets, transforms
from torch.utils.data import DataLoader
import matplotlib.pyplot as plt

# 1. Transformasi gambar
transform = transforms.Compose([
    transforms.Resize((64, 64)),   # ubah ukuran ke 64x64
    transforms.ToTensor(),         # ubah ke tensor
])

# 2. Gunakan ImageFolder untuk membaca folder data
dataset = datasets.ImageFolder(root='data', transform=transform)

# 3. Buat DataLoader
dataloader = DataLoader(dataset, batch_size=8, shuffle=True)

# 4. Lihat contoh data
images, labels = next(iter(dataloader))

print("Label:", labels)
print("Ukuran gambar batch:", images.shape)  # torch.Size([8, 3, 64, 64])

# 5. Tampilkan gambar pertama
plt.imshow(images[0].permute(1, 2, 0))  # ubah dimensi dari [C, H, W] ke [H, W, C]
plt.title(f"Label: {dataset.classes[labels[0]]}")
plt.axis('off')
plt.show()
```

---

### ✨ Penjelasan:

- `datasets.ImageFolder`: otomatis membaca gambar dan mengatur label berdasarkan nama folder (`kucing` → label 0, `anjing` → label 1).
- `transform.Resize((64, 64))`: supaya semua gambar seragam ukurannya.
- `DataLoader`: mengatur pengambilan gambar per batch.

### 🔥 Apa itu GPU?

**GPU (Graphics Processing Unit)** adalah sebuah prosesor khusus yang awalnya dirancang untuk **mengolah grafis**, seperti dalam game atau animasi. Tapi sekarang, GPU juga sangat populer digunakan untuk **mempercepat proses perhitungan berat di AI / Machine Learning**, terutama dalam training model besar seperti deep learning.

---

### 🔍 Perbedaan CPU dan GPU

| Fitur             | CPU (Central Processing Unit) | GPU (Graphics Processing Unit) |
|------------------|-------------------------------|-------------------------------|
| Fokus            | Umum, semua jenis proses       | Khusus untuk proses paralel (banyak tugas bersamaan) |
| Jumlah core      | Sedikit (2–16)                | Banyak (ratusan hingga ribuan) |
| Kecepatan        | Cepat untuk tugas tunggal      | Sangat cepat untuk tugas paralel seperti matrix multiplication |
| Cocok untuk      | Logika program, operasi umum   | Training AI, rendering 3D, mining, dll |

---

### 🧠 Mengapa GPU penting di AI?

Deep learning sangat bergantung pada **matrix dan tensor** (angka-angka besar dan banyak). GPU bisa mengerjakan ribuan perhitungan ini **secara bersamaan** jauh lebih cepat dari CPU.

Contoh:
```python
# Tanpa GPU (hanya CPU)
model.to("cpu")

# Dengan GPU (kalau tersedia)
model.to("cuda")
```

> "cuda" adalah nama teknologi dari NVIDIA untuk GPU.
