# 💬 Menghitung B-A

**Tanggal:** `2025-02-11 07.35`  
**Sumber:** ChatGPT Export  

---

### 👤 User:
Jika A = 0,6 maka A + B = 18/25. Hitung B -A ketika A+B = 1,2 

### 🤖 ChatGPT:
Diketahui:

1. \( A = 0.6 \)
2. \( A + B = \frac{18}{25} \)

Mari kita cari nilai \( B \):

\[
B = \frac{18}{25} - A
\]

\[
B = \frac{18}{25} - 0.6
\]

Ubah \( 0.6 \) ke dalam bentuk pecahan:

\[
0.6 = \frac{6}{10} = \frac{15}{25}
\]

\[
B = \frac{18}{25} - \frac{15}{25} = \frac{3}{25}
\]

Sekarang, kita gunakan informasi bahwa \( A + B = 1.2 \) untuk menemukan \( B - A \):

\[
B - A = (A+B) - 2A
\]

\[
B - A = 1.2 - 2(0.6)
\]

\[
B - A = 1.2 - 1.2 = 0
\]

Jadi, nilai \( B - A \) adalah **0**.
