# 📊 RINGKASAN PERBEDAAN UTAMA

## 1. Perubahan Struktur Format
Jenis perubahan paling dominan:

| Jenis | Contoh |
|------|-------|
Format heading | `--- ✦ ---` → `✦` |
Heading markdown | `**KATA PENGANTAR**` → `# KATA PENGANTAR` |
Bold → italic | `(satu)` → `*(satu)*` |
Quote block dihapus | blok `>` metadata buku dihapus |

👉 Artinya: **file revisi fokus pada konsistensi Markdown publishing format**

---

## 2. Bagian yang DIHILANGKAN
Bagian ini ada di **asal** tetapi tidak ada di revisi:

```
**[VOLUME 1]{.smallcaps}**
*FONDASI: PENDAHULUAN, FILOSOFI, DAN LANDASAN TEORETIS*
**GASING**
**The Fastest Numeracy Transformation**
**Ever Demonstrated**
--- ✦ ---
```

➡ status: **DIHAPUS**

Kemungkinan tujuan:
- menghindari duplikasi cover
- merapikan front-matter

---

## 3. Bagian yang DITAMBAHKAN
Ada blok baru di revisi yang tidak ada di asal:

```
# TEMUAN UTAMA
✦
```

➡ status: **DITAMBAHKAN**

---

## 4. Perubahan Typografi
Contoh perubahan kecil tapi konsisten:

| Asal | Revisi | Jenis |
|------|-------|------|
dan/ atau | dan/atau | konsistensi ejaan |
Febuari | Februari | koreksi typo |
(*text*) | *(text)* | style italic |

---

## 5. Perubahan Struktur Visual Gambar
Asal:
```
**Gambar 1.1.** *Bahagia belajar dan menjadi pintar...*
```

Revisi:
```
![](media/image2.jpg)
***Gambar 1.1.** Bahagia belajar dan menjadi pintar...*
```

➡ status: **FORMAT GAMBAR DIPERBAIKI**

---

## 6. Perubahan Judul Bagian
Asal:
```
GASING -- BAHAGIA BELAJAR -- MENGAPA SUKSES?
```

Revisi:
```
GASING: BAHAGIA BELAJAR, MENGAPA SUKSES?
```

➡ status: **GAYA TIPOGRAFI DIPERHALUS**

# 📚 Cara Membuat Daftar Gambar Otomatis

## ✅ LANGKAH 1 — Beri Caption pada Setiap Gambar
Daftar gambar hanya bisa dibuat otomatis jika semua gambar punya caption.

4. Klik OK

Hasil contoh:

   ```
   Gambar
   ```
4. Klik OK

➡ Word otomatis membuat daftar gambar lengkap + nomor halaman.

# 📍 Di Mana Letak **Multilevel List** di Word?

```
• Bullet list
1. Numbered list
≡ Multilevel list   ← INI
```

Ikonnya terlihat seperti:
```
1
1.1
1.1.1
```

---

## 🖥 Cara Menemukannya (Step Cepat)
1. Klik tab **Home**
2. Lihat grup **Paragraph**
3. Cari ikon dengan angka bertingkat

- Perbesar jendela Word
- atau klik tanda panah kecil di pojok grup Paragraph
