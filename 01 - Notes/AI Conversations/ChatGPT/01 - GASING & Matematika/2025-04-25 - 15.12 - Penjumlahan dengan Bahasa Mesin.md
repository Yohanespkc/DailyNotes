```python
# Simulasi "Mesin Virtual" sederhana
class MesinVirtual:
    def __init__(self):
        self.memory = {}  # Penyimpanan variabel
        self.accumulator = 0  # Register utama (accumulator)

    def LOAD(self, variable):
        self.accumulator = self.memory.get(variable, 0)

    def ADD(self, variable):
        self.accumulator += self.memory.get(variable, 0)

    def STORE(self, variable):
        self.memory[variable] = self.accumulator

    def PRINT(self):
        print("Hasil:", self.accumulator)

# Program utama
def program_penjumlahan(a, b):
    mesin = MesinVirtual()
    
    # Simpan nilai ke "memory"
    mesin.memory['A'] = a
    mesin.memory['B'] = b

    # Simulasi instruksi bahasa mesin
    mesin.LOAD('A')     # LOAD A
    mesin.ADD('B')      # ADD B
    mesin.STORE('C')    # STORE C
    mesin.PRINT()       # Tampilkan hasil (C)

# Contoh penggunaan
program_penjumlahan(7, 5)
```

### Penjelasan
- `LOAD A`: memuat nilai A ke dalam accumulator.
- `ADD B`: menambahkan nilai B ke accumulator.
- `STORE C`: menyimpan hasil ke variabel C.
- `PRINT`: mencetak isi accumulator (hasil akhir).

Mantap! Di versi **bit-level**, kita akan membuat penjumlahan dua bilangan **tanpa menggunakan operator `+`**, dan hanya pakai operasi bitwise seperti `AND`, `XOR`, dan `SHIFT`, layaknya di arsitektur bahasa mesin.

Berikut versi Python-nya:

```python
def tambah_bitwise(a, b):
    print(f"Input A: {a} ({bin(a)})")
    print(f"Input B: {b} ({bin(b)})")
    langkah = 1

    while b != 0:
        carry = a & b        # Cari carry (bawa)
        hasil = a ^ b        # Tambahkan tanpa bawa

        print(f"\nLangkah {langkah}:")
        print(f"  a      = {bin(a)}")
        print(f"  b      = {bin(b)}")
        print(f"  carry  = {bin(carry)}")
        print(f"  hasil  = {bin(hasil)}")

        b = carry << 1       # Geser carry ke kiri (bawa ke bit lebih tinggi)
        a = hasil
        langkah += 1

    print(f"\nHasil akhir: {a} ({bin(a)})")
    return a

# Contoh penggunaan
tambah_bitwise(7, 5)
```

### Penjelasan logika:
- `a ^ b`: menjumlahkan bit tanpa carry (XOR).
- `a & b`: mencari bit mana yang menghasilkan carry.
- `carry << 1`: geser carry ke kiri untuk ditambahkan di iterasi berikutnya.

---

### 🎯 Tujuan:
Menjumlahkan dua bilangan bulat `a` dan `b` **menggunakan operasi bitwise saja**, yaitu:

- `XOR (^)` — untuk menjumlahkan bit **tanpa** memperhatikan carry
- `AND (&)` dan `SHIFT (<<)` — untuk menghitung dan memindahkan carry

---

### 🔁 Loop Utama:
```python
while b != 0:
```
Kita terus menjumlahkan hingga **tidak ada lagi carry** (b sudah nol).

---

### 🧠 Langkah Dalam Loop:

#### 1. Hitung Carry
```python
carry = a & b
```
Operasi AND menghasilkan carry di bit-bit tempat **kedua bit bernilai 1**. Misalnya:

```
  a:  0b0111 (7)
  b:  0b0101 (5)
AND:  0b0101 (carry: posisi bit ke-0 dan ke-2)
```

#### 2. Hitung Hasil Sementara (tanpa carry)
```python
hasil = a ^ b
```
Operasi XOR adalah penjumlahan bit tanpa carry. Misalnya:

```
  a:  0b0111
  b:  0b0101
XOR:  0b0010  (karena bit ke-1 beda)
```

#### 3. Geser Carry ke Kiri
```python
b = carry << 1
```
Carry perlu "naik" ke bit berikutnya (digeser kiri), karena pada proses penjumlahan, carry mempengaruhi bit di posisi yang lebih tinggi.

---

#### 4. Ulangi
```python
a = hasil
```
Kita ulangi proses dengan hasil baru `a` dan carry yang digeser menjadi `b`. Ulangi sampai `b == 0`.

---

### ✅ Contoh Kasus: `a = 7 (0b0111)`, `b = 5 (0b0101)`
Langkah-langkahnya:

1. `carry = a & b = 0b0101`
2. `hasil = a ^ b = 0b0010`
3. `b = carry << 1 = 0b1010`
4. Ulangi proses sampai `carry` jadi 0

Akhirnya kita dapat hasil: `0b1100` = **12** ✅

### 🚀 Kenapa Ini Menarik?

- Cocok untuk simulasi **komputasi low-level**, emulator, atau sistem digital.
- Bisa dikembangkan jadi **simulator ALU**, bahkan **CPU sederhana**.

### ✅ Kode Simulasi CPU:

```python
class CPU:
    def __init__(self):
        self.register = {'A': 0, 'B': 0, 'C': 0}
        self.memory = {}
        self.accumulator = 0

    def load(self, reg, value):
        self.register[reg] = value
        print(f"LOAD {value} ke register {reg}")

    def store(self, reg):
        self.memory[reg] = self.accumulator
        print(f"STORE hasil ke memory[{reg}] = {self.accumulator}")

    def add(self, reg1, reg2):
        a = self.register[reg1]
        b = self.register[reg2]
        print(f"ADD {reg1} ({a}) + {reg2} ({b})")
        self.accumulator = self.bitwise_add(a, b)

    def print_result(self):
        print(f"HASIL akhir (ACC): {self.accumulator} ({bin(self.accumulator)})")

    def bitwise_add(self, a, b):
        langkah = 1
        while b != 0:
            carry = a & b
            hasil = a ^ b
            print(f"  [Langkah {langkah}] a: {bin(a)}, b: {bin(b)}, carry: {bin(carry)}")
            b = carry << 1
            a = hasil
            langkah += 1
        return a

# Program utama
def simulasi_cpu():
    cpu = CPU()

    # Eksekusi instruksi "bahasa mesin"
    cpu.load('A', 7)      # Masukkan 7 ke register A
    cpu.load('B', 5)      # Masukkan 5 ke register B
    cpu.add('A', 'B')     # Tambahkan A + B
    cpu.store('C')        # Simpan ke memori C
    cpu.print_result()    # Cetak hasil akhir

simulasi_cpu()
```
