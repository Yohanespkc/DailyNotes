### 🤖 ChatGPT:
Algoritma yang paling umum dan efisien untuk menghitung **FPB (Faktor Persekutuan Terbesar)** dari dua bilangan `a` dan `b` adalah **Algoritma Euclidean (Euclides)**. Ini adalah algoritma klasik yang sangat cepat dan digunakan oleh mesin (komputer) juga.

---

### 🔢 **Langkah-langkah Algoritma Euclidean untuk menghitung FPB(a, b)**

Misalkan `a ≥ b`. Maka algoritmanya:

1. **Jika b = 0**, maka **FPB(a, b) = a**. (Selesai)
2. Jika tidak, **ganti a dengan b, dan b dengan a mod b**.
3. Ulangi langkah 1.

---

### 📦 Contoh: FPB(48, 18)

1. `48 mod 18 = 12` → ubah `a = 18`, `b = 12`
2. `18 mod 12 = 6` → ubah `a = 12`, `b = 6`
3. `12 mod 6 = 0` → selesai, **FPB = 6**

---

### 💡 Penjelasan Sederhana

Misalnya kamu ingin tahu FPB dari dua bilangan, maka:
- Kamu terus-menerus **membagi bilangan besar dengan bilangan kecil dan mengganti** bilangan tersebut dengan hasil sisanya.
- Kamu **berhenti ketika sisanya 0**, dan angka terakhir yang tidak 0 adalah jawabannya.

---

### 🧠 Dalam Bentuk Pseudocode

```text
function FPB(a, b):
    while b ≠ 0:
        temp = b
        b = a mod b
        a = temp
    return a
```

## 🧮 1. Algoritma Logika: Pembagian Manual seperti di Sekolah (Tapi Dipakai Mesin)

Misalnya `a = 478` dan `b = 3`

Langkahnya:

1. Ambil digit pertama dari kiri (`4`), bagi dengan `3`:  
   → `4 div 3 = 1`, sisa `1`

2. Gabungkan sisa `1` dengan digit berikutnya (`7`) → jadi `17`, lalu:  
   → `17 div 3 = 5`, sisa `2`

3. Gabungkan sisa `2` dengan digit berikutnya (`8`) → jadi `28`, lalu:  
   → `28 div 3 = 9`, sisa `1`

Hasil: `478 ÷ 3 = 159 sisa 1`

---

### 🔁 Dalam bentuk pseudocode:

```python
function bagi(a, b):
    hasil = 0
    sisa = 0
    untuk setiap digit dari kiri ke kanan di a:
        temp = sisa * 10 + digit
        hasil_digit = temp div b
        sisa = temp mod b
        tambahkan hasil_digit ke hasil
    return hasil, sisa
```

## ⚙️ 2. Cara Mesin (Hardware Level)

Pada level **CPU**, pembagian `a / b` dilakukan dengan:

- **Mengubah a dan b menjadi bilangan biner**
- Menjalankan **algoritma shift dan subtract**:
  - Coba geser bit pembagi sejauh mungkin ke kiri sampai masih ≤ `a`.
  - Kurangkan dari `a`, catat angka 1 di posisi itu (seperti trial and error).
  - Ulangi sampai sisa lebih kecil dari pembagi.
  - Ini mirip **long division** tapi dalam **biner**.

Contoh:  
`13 ÷ 3` → dalam biner:  
`13 = 1101`, `3 = 11`  
Prosesnya: shift, subtract, shift, subtract, dll.

Tapi ini terlalu teknis—umumnya kita cukup pakai **pembagian long division berbasis digit** seperti penjelasan awal tadi.

## 📘 Langkah Umum Binary Division (Shift-Subtract)

Kita akan:
1. Siapkan **remainder** awal = 0.
2. Lakukan **bitwise shift** satu per satu dari angka `a` (dividen) ke `remainder`.
3. Setiap kali:
   - **Geser bit ke kiri** (`<<1`) remainder dan **tambahkan bit dari dividen**.
   - Jika **remainder ≥ divisor**, kurangkan divisor dari remainder → tulis `1` ke hasil (quotient).
   - Jika tidak, tulis `0` ke hasil.

---

## 🚀 Proses Langkah demi Langkah:  
Dividen: `1101₂` → (13 desimal)  
Divisor: `0011₂` → (3 desimal)

Kita lakukan dari **bit paling kiri dividen**: `1`, `1`, `0`, `1`  
Quotient awal = `____`  
Remainder awal = `0`

---

### 🔁 Iterasi 1:
- Geser remainder: `0` → `0`  
- Tambahkan bit: `0 << 1 + 1` → remainder = `1`  
- 1 < 3 → quotient bit = `0`

### 🔁 Iterasi 2:
- Geser remainder: `1` → `10`  
- Tambah bit: `10 << 1 + 1` → `11`  
- 3 = 3 → kurangkan: `11 - 11 = 0`  
- quotient bit = `1`

### 🔁 Iterasi 3:
- Geser remainder: `0` → `0`  
- Tambah bit: `0 << 1 + 0` → `0`  
- 0 < 3 → quotient bit = `0`

### 🔁 Iterasi 4:
- Geser remainder: `0` → `00`  
- Tambah bit: `00 << 1 + 1` → `1`  
- 1 < 3 → quotient bit = `0`

---

## ✅ Hasil Akhir

- **Quotient**: `0100₂` = `4`
- **Remainder**: `1`

---

### ✍️ Kesimpulan:

```
    4
 ──────
3 | 13
    ↓
    Biner:
    
    0011 ) 1101
           ↓
           0100  (Quotient in binary)
           Remainder = 1
```

### 🧠 Bonus: Implementasi Python Sederhana (Mirip Mesin)

```python
def binary_division(dividend, divisor):
    quotient = 0
    remainder = 0
    for i in range(dividend.bit_length()-1, -1, -1):
        # Shift remainder left, bring down next bit
        remainder = (remainder << 1) | ((dividend >> i) & 1)
        quotient <<= 1
        if remainder >= divisor:
            remainder -= divisor
            quotient |= 1
    return quotient, remainder

q, r = binary_division(13, 3)
print(f"Hasil: {q}, Sisa: {r}")
```

## 🧠 Kode Python Sederhana

```python
def bagi_biner(dividen, pembagi):
    sisa = 0
    hasil = 0
    for i in range(dividen.bit_length()-1, -1, -1):
        sisa = (sisa << 1) | ((dividen >> i) & 1)
        hasil <<= 1
        if sisa >= pembagi:
            sisa -= pembagi
            hasil |= 1
    return hasil, sisa

# Contoh
q, r = bagi_biner(13, 3)
print(f"Hasil: {q}, Sisa: {r}")
```

## 💬 Penjelasan Langkah:  
### Contoh situasi:

---

### 🧮 Apa maksudnya: `0 << 1 + 1 = 1`?

Mari kita **pecah** jadi dua operasi:

#### 1. `0 << 1` → artinya:  
**Geser angka 0 ke kiri 1 kali** dalam sistem biner:  
- `0` dalam biner = `0`
- Digeser ke kiri 1 kali = `00` → tetap 0

(Ini seperti kalikan 0 × 2 = 0)

#### 2. Tambahkan bit saat ini, yaitu `1`:
- Jadi: `0 (digeser) + 1` = `1`

---

### 🔄 Gimana kalau di langkah berikutnya?

Misal sekarang `remainder = 1`, dan bit berikutnya = `1`

1. `1 << 1` = 2 → (`1` dalam biner digeser jadi `10` = 2)
2. Tambah bit `1` → `2 + 1 = 3`

---

## 🧩 Jadi maksud `remainder << 1 + bit selanjutnya` adalah:

➡️ **Ambil angka sisa sebelumnya**  
➡️ **Kalikan 2 (alias geser kiri)**  
➡️ **Lalu tambahkan bit dari dividen**

---

### 🔁 Dalam pembagian biasa:
Ini **seperti kita "turunkan digit berikutnya"** dan lanjut membagi lagi.

---

### ✍️ Contoh Langkah Konkrit:

Kita bagi 13 (1101) dengan 3 (11):

| Langkah | Remainder Sebelum | Bit Saat Ini | Geser + Tambah | Remainder Baru |
|--------|---------------------|--------------|----------------|----------------|
| 1      | 0                   | 1            | 0×2 + 1 = 1    | 1              |
| 2      | 1                   | 1            | 1×2 + 1 = 3    | 3              |
| 3      | 0 (karena 3 - 3)    | 0            | 0×2 + 0 = 0    | 0              |
| 4      | 0                   | 1            | 0×2 + 1 = 1    | 1              |
