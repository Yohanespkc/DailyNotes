# 💬 Hapus Recent di Word

**Tanggal:** `2025-02-09 20.01`  
**Sumber:** ChatGPT Export  

---

### 👤 User:
bagaimana menghapus recent di WORD

### 🤖 ChatGPT:
Untuk menghapus daftar dokumen **Recent** di Microsoft Word, ada beberapa cara yang bisa Anda lakukan tergantung pada tujuan Anda:

### **1. Menghapus Satu Per Satu dari Recent**
Jika Anda hanya ingin menghapus beberapa dokumen dari daftar **Recent**, lakukan langkah berikut:
1. Buka **Microsoft Word**.
2. Klik **File** → **Open** (Buka).
3. Pada bagian **Recent Documents**, cari dokumen yang ingin dihapus.
4. Klik kanan pada dokumen tersebut dan pilih **Remove from list**.

---

### **2. Menghapus Semua Recent Documents Sekaligus**
Jika ingin menghapus semua dokumen di daftar recent:
1. Buka **Word** dan klik **File** → **Options**.
2. Pilih **Advanced** di menu sebelah kiri.
3. Gulir ke bawah ke bagian **Display**.
4. Ubah angka pada opsi **Show this number of Recent Documents** menjadi **0**.
5. Klik **OK** untuk menyimpan perubahan.

💡 **Catatan:** Jika ingin Word tetap menampilkan daftar recent lagi di lain waktu, ulangi langkah di atas dan ubah angka tersebut ke jumlah yang diinginkan.

---

### **3. Menghapus Recent dari Registry Editor (Metode Lanjutan)**
Jika ingin menghapus daftar recent secara permanen:
1. **Tekan** `Win + R`, lalu ketik **regedit** dan tekan **Enter**.
2. Navigasikan ke:
   ```
   HKEY_CURRENT_USER\Software\Microsoft\Office\16.0\Word\File MRU
   ```
   (Angka **16.0** dapat berbeda tergantung pada versi Word Anda, misalnya 15.0 untuk Word 2013, 14.0 untuk Word 2010).
3. Klik kanan pada entri yang ingin dihapus dan pilih **Delete**.
4. Tutup Registry Editor dan restart Word.

---

### **4. Menghapus Recent dari File Explorer (Jika Dokumen Masih Ada)**
Jika daftar recent masih muncul karena file belum dihapus:
1. Buka **File Explorer** (`Win + E`).
2. Masuk ke folder:
   ```
   C:\Users\NamaPengguna\AppData\Roaming\Microsoft\Word
   ```
3. Hapus semua file dalam folder ini.

Setelah ini, daftar recent di Word seharusnya bersih. 🚀

### 🤖 ChatGPT:
Karena Anda menggunakan **macOS**, berikut cara menghapus daftar **Recent Documents** di Microsoft Word:

---

### **1. Menghapus Satu Dokumen dari Recent**
Jika Anda hanya ingin menghapus dokumen tertentu:
1. Buka **Microsoft Word**.
2. Klik **File** → **Open Recent**.
3. Temukan dokumen yang ingin dihapus.
4. Klik kanan pada dokumen tersebut dan pilih **Remove from Recent**.

---

### **2. Menghapus Semua Recent Documents Sekaligus**
Jika ingin menghapus seluruh daftar **Recent Documents**:
1. Buka **Microsoft Word**.
2. Klik **File** → **Open Recent**.
3. Pilih **Clear Recent** di bagian bawah daftar.

---

### **3. Menghapus Secara Manual dari Library (File History)**
Jika dokumen masih muncul dalam daftar **Recent** meskipun sudah dihapus, Anda bisa membersihkannya dari sistem macOS:
1. **Tutup Word terlebih dahulu**.
2. Buka **Finder** dan tekan `Cmd + Shift + G` untuk membuka **Go to Folder**.
3. Ketik:
   ```
   ~/Library/Containers/com.microsoft.Word/Data/Library/Preferences/
   ```
4. Cari file bernama **com.microsoft.Word.plist**.
5. Hapus file tersebut atau pindahkan ke **Trash**.
6. Restart **Microsoft Word**.

---

### **4. Menghapus Recent dari Dock macOS (Jika Muncul di Dock)**
Jika dokumen masih muncul di Dock:
1. Klik kanan ikon **Microsoft Word** di Dock.
2. Pilih **Options** → **Show Recent Documents**.
3. Klik **Clear Menu** untuk menghapus semua dokumen yang muncul.

Dengan langkah-langkah ini, daftar recent di Word Anda akan bersih di macOS. 🚀
