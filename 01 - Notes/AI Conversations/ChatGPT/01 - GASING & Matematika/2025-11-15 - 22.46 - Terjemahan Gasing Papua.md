Saat ini **Canva belum bisa mengedit file .PSD secara penuh** (layer-by-layer seperti di Photoshop). Tetapi Anda tetap bisa **mengimpor** file .psd ke Canva dengan beberapa cara. Berikut panduan lengkapnya:

---

## ✅ **Cara Mengedit File .PSD di Canva**

### **1. Impor langsung file .psd ke Canva**
1. Buka Canva → klik **Create a design** (atau buka desain kosong).
2. Klik **Upload** → **Upload files**.
3. Pilih file **.psd** Anda.

**Catatan penting:**  
- Canva akan **mengonversi PSD menjadi gambar flatten (satu layer)**.  
- Artinya Anda **tidak bisa mengedit layer-layarnya** (teks, objek, shape) seperti di Photoshop.  
- Anda hanya bisa mengedit dengan cara menambah teks/elemen di atas gambar tersebut.

---

## ✅ **2. Cara agar PSD bisa diedit layer-nya (solusi alternatif)**
Jika Anda ingin **mengedit layer-layernya**, lakukan langkah ini:

### **Opsi A — Ekspor PSD dulu menjadi PNG transparan per-layer**
1. Buka file .psd di Photoshop / Photopea (alternatif gratis).
2. Sembunyikan layer lain → ekspor per layer menjadi **PNG transparan**.
3. Upload PNG tersebut ke Canva.
4. Susun kembali layer-layernya di Canva.

➡️ Dengan cara ini, Anda bisa *mengatur ulang*, *mengganti teks*, atau *memodifikasi desain* lebih fleksibel.

---

### **Opsi B — Ubah PSD menjadi PDF lalu impor**
1. Dari Photoshop / Photopea → Save As → **PDF**.
2. Upload PDF ke Canva.
3. Canva akan membuka **per halaman**, tetapi **layer tetap tidak editable** (kecuali bentuk sederhana).

Namun terkadang Canva bisa mengenali **teks sebagai elemen editable** jika PDF-nya simpel.

---

## ✅ **Opsi terbaik tanpa Photoshop: Gunakan Photopea**
Jika Anda tidak punya Photoshop:

1. Buka **https://www.photopea.com**
2. Upload PSD.
3. Edit layer sesuai kebutuhan.
4. Ekspor ke:
   - PNG (untuk gambar)
   - PDF (untuk layout)
   - SVG (untuk elemen vektor)
5. Upload hasilnya ke Canva.

Photopea gratis dan 95% mirip Photoshop.

---

## 🔥 **Ringkasan Cepat**

# 🌟 **4. Humanisme (Carl Rogers – Student-Centered Learning)**

- Anak diberi kasih sayang.  
- Guru hadir sebagai pendamping, bukan penguasa.

➡️ “Happy brain learns fastest.”

➡️ GASING selalu **gampang, asyik, menyenangkan**.
