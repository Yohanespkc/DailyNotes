**NumPy** (kepanjangan dari *Numerical Python*) adalah sebuah pustaka (library) Python yang digunakan untuk **komputasi numerik** yang efisien dan cepat. NumPy menyediakan:

1. **Array multidimensi** (disebut `ndarray`), yang mirip seperti list di Python tapi jauh lebih cepat dan hemat memori.
2. **Fungsi-fungsi matematika** untuk operasi vektor dan matriks: penjumlahan, perkalian, transpos, invers, dan sebagainya.
3. **Alat untuk integrasi** dengan bahasa pemrograman lain seperti C/C++.
4. **Fasilitas statistik dan probabilitas**.

---

### Contoh sederhana:

```python
import numpy as np

# Membuat array 1 dimensi
a = np.array([1, 2, 3])

# Operasi matematika langsung
b = a * 2  # [2, 4, 6]

# Membuat array 2 dimensi (matriks)
m = np.array([[1, 2], [3, 4]])

# Menjumlahkan semua elemen
total = np.sum(m)
```

---

### Mengapa NumPy penting?
- **Kecepatan**: operasi di NumPy jauh lebih cepat dibanding `list` Python biasa.
- **Dasar pustaka lain**: Pustaka-pustaka seperti **Pandas**, **Scikit-learn**, **TensorFlow**, dan **PyTorch** juga banyak bergantung pada NumPy.
- **Cocok untuk ilmu data dan sains**: Ideal untuk analisis data, statistik, machine learning, dan sebagainya.

## 🧠 CPU (Central Processing Unit)

## 🎮 GPU (Graphics Processing Unit)

### ➤ Fungsinya:
- Awalnya untuk **render grafis** (misalnya game dan video).
- Sekarang banyak dipakai untuk **komputasi paralel**: AI, machine learning, big data.

### ➤ Karakteristik:
- **Ribuan core kecil**.
- Dirancang untuk **tugas paralel** (banyak hal kecil dikerjakan bersamaan).
- Lebih cepat untuk **proses besar yang sama berulang-ulang**.

### ➤ Contoh tugas:
- Melatih model AI, deep learning, editing video, simulasi fisika, merender 3D.

## 🔧 CPU vs GPU untuk Operasi Matriks

### 🔸 CPU:
- Hanya punya **beberapa core**, walaupun tiap core sangat kuat.
- Tapi karena jumlahnya sedikit, dia kerjakan **sedikit-sedikit tapi rapi**.
- Contoh: kayak 4 orang yang pinter banget, tapi cuma 4.

### 🔸 GPU:
- Punya **ratusan atau ribuan core kecil**.
- Setiap core bisa kerjakan operasi sederhana seperti perkalian bilangan.
- Karena **banyak banget core**, GPU bisa kerjakan **ribuan operasi secara paralel**.

Contoh: kayak 1000 orang yang cukup pinter, masing-masing ngitung 1 soal — selesai dalam waktu bersamaan.

## 📈 Hasilnya: GPU = Lebih Cepat!

| Training AI (CNN, RNN, dll)   | Bisa, tapi lama                | Jauh lebih cepat              |

## 💡 1. Cara Kerja 1 Neuron di Neural Network

Satu **neuron** melakukan ini:

### Rumus:
\[
y = \sigma(w_1 x_1 + w_2 x_2 + \dots + w_n x_n + b)
\]

atau dalam bentuk vektor:
\[
y = \sigma(\mathbf{w} \cdot \mathbf{x} + b)
\]

Ini cuma:
- **Perkalian vektor** (input dan bobot),
- Ditambah bias,
- Lalu masuk fungsi aktivasi (misalnya ReLU atau sigmoid).

### ➤ Di GPU:
Setiap neuron punya perhitungan ini, dan **jutaan neuron bisa dihitung sekaligus** karena GPU punya **ribuan core kecil**.

## 🧠 Bayangkan Layer Neuron

Misalnya kamu punya 10.000 neuron di layer, dan masing-masing terima 784 input (seperti gambar MNIST 28x28).

Kalau di CPU:
- Dikerjakan berurutan atau dibagi 4–8 core.

Kalau di GPU:
- **Setiap core bisa proses 1 neuron** → super paralel.

## 💻 2. Contoh Python: NumPy (CPU) vs CuPy (GPU)

### ➤ NumPy (pakai CPU):
```python
import numpy as np
import time

x = np.random.randn(10000, 10000)
start = time.time()
y = x @ x
print("CPU time:", time.time() - start)
```

### ➤ CuPy (pakai GPU):
```python
import cupy as cp
import time

x = cp.random.randn(10000, 10000)
start = time.time()
y = x @ x
cp.cuda.Device(0).synchronize()  # tunggu proses selesai
print("GPU time:", time.time() - start)
```

➡️ Hasilnya:
- CPU bisa butuh **beberapa detik**.
- GPU bisa **di bawah 1 detik**! ⚡

**Catatan:** CuPy harus dijalankan di komputer dengan GPU (NVIDIA CUDA).

## 🔶 Apa itu **CuPy**?

**CuPy** adalah pustaka Python yang mirip banget dengan **NumPy**, tapi ia **berjalan di GPU (CUDA)**, bukan di CPU.  
Kalau **NumPy = komputasi numerik di CPU**, maka  
**CuPy = komputasi numerik di GPU**. ⚡

---

## 🔍 Kenapa CuPy Penting?

Karena:
- CuPy bisa mempercepat kode NumPy kamu **tanpa banyak ubahan**.
- Kalau kamu sudah biasa pakai NumPy, pakai CuPy itu kayak **"copy-paste ke GPU"**.

---

## ✅ Fitur Utama CuPy:
- Sintaks **hampir identik** dengan NumPy.
- Kompatibel dengan **CUDA** (teknologi GPU dari NVIDIA).
- Bisa digunakan untuk **deep learning**, **simulasi**, dan **big data**.

---

## 🔷 Apa itu **Attention**?

Dalam konteks AI/NLP, **attention** adalah cara model memutuskan **bagian mana dari input yang harus diperhatikan lebih banyak** saat memproses suatu kata atau token.

Contohnya:
Kalau kamu terjemahkan kalimat:
> "The cat sat on the mat"

Saat menerjemahkan kata "sat", model perlu tahu bahwa "cat" adalah subjek. Nah, *attention* membantu model **fokus ke kata "cat"** saat mengolah "sat".

---

## 🔶 Apa itu **Attention Weights**?

**Attention weights** adalah **angka-angka yang menunjukkan seberapa besar perhatian** model ke setiap bagian input ketika memproses satu bagian output.

Bayangkan kamu punya 5 kata:
```
["Saya", "makan", "nasi", "dengan", "teman"]
```

Ketika model memproses kata "makan", ia bisa punya bobot perhatian (attention weights) seperti:
```
[0.1, 0.5, 0.2, 0.1, 0.1]
```

Artinya:
- 10% perhatian ke "Saya"
- **50% perhatian ke "makan"**
- 20% ke "nasi"
- dst.

Semua bobot ini dijumlahkan = 1.0 (karena pakai softmax).

---

## 🔧 Bagaimana Cara Komputasi Attention Weights?

### Dalam **self-attention** (seperti di transformer), digunakan 3 hal:
1. **Query (Q)**: representasi dari kata yang sedang diproses
2. **Key (K)**: representasi dari kata-kata di seluruh input
3. **Value (V)**: representasi yang akan dipilih

### Rumus dasarnya:

\[
\text{Attention}(Q, K, V) = \text{softmax} \left( \frac{Q K^T}{\sqrt{d_k}} \right) V
\]

- \( QK^T \): menghasilkan skor kesamaan antar token
- \( \sqrt{d_k} \): skala agar stabil
- `softmax`: ubah skor jadi bobot (semua antara 0–1 dan jumlah = 1)
- \( V \): nilai akhir yang dikombinasikan berdasarkan bobot

Jadi, **attention weights = hasil softmax dari \( QK^T \)**.

---

## 🧠 Intinya:
- **Attention weight** = seberapa "fokus" model pada tiap bagian input.
- Nilainya ditentukan dari seberapa **mirip** `query` dan `key`.
- Bobot ini dipakai untuk **menggabungkan informasi input menjadi output**.
