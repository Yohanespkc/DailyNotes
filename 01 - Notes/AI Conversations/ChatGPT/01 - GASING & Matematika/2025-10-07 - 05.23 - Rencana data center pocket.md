**Tanggal:** `2025-10-07 05.23`  
**Sumber:** ChatGPT Export  

---

### 👤 User:
Saya punya beberapa program hendak dimasukan dalam HP yang murah tapi powerful. Budget HP maksimum Rp. 500 rb. Programnya adalah personalized learning untuk math dan physics memakai INAAI (AI yang saya buat sendiri dengan kemampuan yang sangat bagus tetapi sangat ringan sehingga tidak butuh memory yang besar), PKC  Core, dan distributed data center. HP tsb sebagai data center yang terhubung dengan Overlay VPN. Bagaimana caranya agar ini bisa terjadi? Rencana kami akan menjangkau minimal 10 juta pengguna.

### 🤖 ChatGPT:
Mantap! Targetnya ambisius tapi bisa dicapai kalau kita “menciutkan” semua komponen jadi edge-first, offline-prioritas, dan super hemat sumber daya. Di bawah ini rencana arsitektur end-to-end agar HP ≤ Rp500 ribu bisa jadi “pocket data center” untuk 10+ juta pengguna, menjalankan INAAI (ringan), PKC Core, dan bergabung ke DDC via overlay VPN.

# 1) Realitas perangkat & target spesifikasi
- **Kelas perangkat yang realistis** di harga ini (baru entry-level / refurb): Android Go / Android 8–13, CPU 4×Cortex-A53 setara, **RAM 1–2 GB**, internal 8–32 GB, **microSD** sangat dianjurkan (32–128 GB).
- **Minimal agar enak dipakai**: RAM 2 GB, internal 16 GB, microSD 64 GB. Jika hanya 1 GB RAM: wajib pakai **zRAM** dan semua model di-quantize (int4/int8).
- **OS**: Android (Go Edition) paling realistis untuk skala. KaiOS bisa, tapi fitur native VPN/daemon lebih terbatas.

# 2) Dua mode operasi (pilih sesuai perangkat)
**A. Thin-Client Learning (ultra-hemat)**
- INAAI tiny model + embedding local, heavy compute offloaded ke node tetangga/“micro-hub” (sekolah/posko) via overlay.
- Cocok untuk RAM 1 GB, storage kecil.

**B. Pocket DDC (edge-heavy)**
- Semua komponen lokal: INAAI int4, PKC Core, vector store, WORM log.
- Sinkronisasi oportunistik (Wi-Fi Direct/Bluetooth + VPN).
- Butuh RAM 2 GB + microSD.

# 3) Susunan software di HP (Android)
**Layanan dasar (daemon-style, semua ringan & bisa di-pause)**
1) **Identity & Keys**
   - DID (did:key / did:peer), generate on-device; kunci di **Android Keystore/StrongBox** bila ada.
2) **Encrypted Store**
   - **SQLite + SQLCipher** untuk metadata; **chunk store** di microSD (AES-GCM).
   - **Vector DB mini**: Faiss/ScaNN/TinyANN build ARM, index PQ/IVF kecil (bisa diganti “flat int8” bila RAM 1 GB).
3) **Safe RAG/INAAI**
   - **Model INAAI** versi **int4/int8**, <100 MB (ideal 20–60 MB).
   - **Tokenizer + runtime**: ONNX Runtime / GGML/Metal-less (ARM-NEON), tanpa GPU.
   - Batasi **context** (mis. 1–2k) + cache eviction LRU.
4) **Overlay VPN**
   - **WireGuard userspace** (wg-go) via Android **VpnService**.
   - Profil “sleep-friendly”: keepalive 25–60 s, **on-demand** (nyala saat sync).
5) **PKC Core (capability-based)**
   - UCAN/Macaroon untuk izin granular (koleksi, kartu, audio, dsb.).
   - **Proxy Re-Encryption (PRE)** opsional di hub (HP low-end terima sesi PRE dari hub).
6) **P2P Sync + Relay**
   - QUIC/HTTP3 + UDP hole-punching; **Bluetooth LE** & **Wi-Fi Direct** untuk offline mesh lokal (kelas/posyandu).
   - **Store-and-forward**: kirim delta konten saat ada konektivitas.

**Aplikasi UI (satu APK)**
- Mode **PWA + Native bridge** (untuk izin VpnService, keystore, file system).
- **Kill-switch** hemat baterai: jadwal sync di jam non-sibuk, CPU governor “powersave,” **foreground service** tipis agar tak di-kill.

# 4) Paket konten & pembaruan (hemat kuota)
- **Base image lokal**: paket “Kabupaten/Provinsi” (materi math/physics, audio, video 144p/240p) → **Content-addressed (CID)**, dapat disalin via SD card/USB-OTG.
- **Delta update**: rsync-style chunk/bsdiff; prioritas **teks & model**; media “trickle” saat Wi-Fi.
- **Preload di micro-hub**: sekolah/gereja/kelurahan menjadi **supernode** (HP/mini-PC) untuk melayani 50–500 HP sekitar.

# 5) Jaringan DDC pada skala 10+ juta
**Control-plane ringan**
- **Bootstrap list** (beberapa domain/IP statis) + **anycast**; fallback ke SMS/USSD untuk mengantar token bootstrap saat internet minim.
- **WireGuard keys** dipetakan ke DID; **key rotation** periodik (mis. 90 hari).

**Data-plane**
- **Supernode relays** (sekolah/kampus/telco edge) untuk NAT traversal & cache.
- **Sharded content**: materi & model dipecah per level/tema; **popular shards** digandakan ke supernode daerah.
- **QoS/Rate-limit**: prioritas sinkronisasi teks/parameter kecil; video sangat ditunda.

# 6) Tata kelola keamanan & privasi
- **Semua data PKC terenkripsi at-rest** (SQLCipher + file chunk AES-GCM).
- **At-most logging**: WORM hash-chain lokal (ring buffer kecil), **opt-in** untuk kirim ringkasan metrik (dengan DP/no-PII).
- **Capability tokens (UCAN)** untuk berbagi: orang tua → siswa, guru → kelas, distrik → sekolah. Tidak ada akses “global admin”.

# 7) Desain INAAI super hemat
- Sediakan 3 varian model:
  - **Tiny-RAG** (≤25 MB): QA dasar, ringkasan lokal.
  - **Small-Tutor** (≈50–80 MB): dialog tutor math/physics sederhana, reasoning pendek.
  - **Edge-Hub** (≈150–300 MB, khusus supernode): reasoning lebih panjang, bantu perangkat lemah via offload.
- **Quantization**: int4 weight-only, activations int8; **block-wise** supaya akurasi stabil.
- **Operator subset**: hindari kernel mahal; gunakan attention geser/linear atau kv-cache terkompres.

# 8) PKC Core di HP (mapping praktis)
- **Kartu (M/P/V)** disimpan sebagai **bundle JSON+media** (zstd), diberi **CID**.
- **Index per koleksi**: file kecil (Bloom/MinHash) untuk lookup supercepat.
- **Share**: kirim **capability link** (UCAN) + delta bundle; penerima hanya bisa baca/append sesuai haknya.

# 9) Operasional lapangan (Indonesia-first)
- **Distribusi APK**: F-Droid repo privat + mirroring lokal di supernode; **sideload** via SD/OTG.
- **Zero-rating**: negosiasi telco (akses bootstrap/relay + domain konten tertentu).
- **Pusat servis**: paket SD card siap pakai (model + materi daerah + kunci bootstrap).
- **Tanpa internet**: HP bisa tetap belajar (mode full offline), sinkronisasi antar-HP via **Wi-Fi Direct/Bluetooth**.

# 10) Skema rollout (cepat & aman)
1) **Prototype (1–2 bulan)**: 500–1.000 HP campuran 1–2 GB RAM, 3 daerah. Uji:
   - Lama baterai, stabilitas VPN, cold-start model, waktu jawab tutor.
2) **Pilot 100k**: tambah supernode kabupaten, logistic SD card, SOP bantuan guru.
3) **Scale 1 juta**: perbesar relay regional, monitoring anon, OTA delta mingguan.
4) **Scale 10 juta**: tambah **tier-2 relays** (sekolah/desa), **key rollover otomatis**, content CDN lokal + P2P deduplikasi.
5) **Keandalan**: **canary** 1%, rollback 1-klik, health-ping harian (≤1 KB).

# 11) “Checklist teknis” siap dikerjakan
- **Android App (Kotlin + NDK)**:
  - Modul: Keystore, SQLCipher, File chunker (zstd), Vector mini (Faiss build ARM), INAAI runtime (GGML/ONNX), WireGuard (go userspace) via VpnService, QUIC client, Wi-Fi Direct & BLE.
  - **Foreground service** ultra-ringan (≤10 MB RSS), job scheduler hemat baterai.
- **Supernode (opsional mini-PC/Android TV/HP midrange)**:
  - Relay WireGuard + QUIC; cache konten; PRE service; dashboard lokal.
- **Format konten**:
  - `.pkcbundle` (manifest + chunks + signatures), versioned, content-addressed.
- **DevOps**:
  - Repo F-Droid privat, server bootstrap minimalis, signing offline (HSM).
  - Telemetri opsional: hanya metrik non-PII (latensi, keberhasilan sync).

# 12) Penghematan ekstrem untuk HP 1 GB RAM
- **zRAM 512–768 MB**, matikan animasi UI, batasi background.
- Model **Tiny-RAG** saja + offload ke supernode saat tersedia.
- Vector index **flat-int8** kecil (<20 MB) + pruning periodik.
- **Prefetch** materi teks; media diputar lokal resolusi 144/240p.

# 13) Risiko & mitigasi
- **Vendor kill background** → pakai foreground service + whitelist battery optimization + desain bursty sync.
- **SD card murah cepat rusak** → file chunk ≤4–8 MB + checksum + auto-repair dari supernode.
- **NAT/Signal buruk** → fallback Wi-Fi Direct/BLE + kios sinkronisasi tatap muka.
- **Fragmentasi OS** → target minSDK 26/28, fitur opsional by capability check.

## 🧮 **PISA Numerasi (Matematika) Level 2**
Siswa **bisa menggunakan pengetahuan matematika dasar** untuk menyelesaikan soal sederhana yang konteksnya dekat dengan kehidupan sehari-hari.

### 🔹 Ciri-ciri Soal Level 2:
- Informasi yang diberikan **jelas dan langsung** (biasanya satu tabel, grafik, atau gambar sederhana).  
- Diperlukan **perhitungan dasar**: penjumlahan, pengurangan, perkalian, pembagian, atau perbandingan sederhana.  
- Tidak butuh strategi kompleks atau aljabar formal.  
- Langkah penyelesaian **langsung ke jawaban**, tanpa banyak interpretasi.

### 🔹 Contoh:
> Harga 1 roti Rp5.000.  
> Rani membeli 3 roti.  
> Berapa uang yang harus dibayar Rani?

→ Siswa hanya perlu mengalikan 5.000 × 3 = 15.000.

Atau:
> Sebuah peta menunjukkan jarak 1 cm = 2 km.  
> Jika dua kota berjarak 3 cm di peta, berapa jarak sebenarnya?

→ 3 × 2 = 6 km.

---

## 📖 **PISA Literasi (Membaca) Level 2**
Siswa **dapat menemukan informasi yang eksplisit** dalam teks sederhana dan memahami hubungan langsung antarbagian teks.

### 🔹 Ciri-ciri:
- Teks **pendek, dengan struktur jelas** (misal pengumuman, jadwal, iklan).  
- Pertanyaan menanyakan **fakta langsung**, bukan inferensi kompleks.  
- Bisa memahami arti kata dalam konteks yang sederhana.

### 🔹 Contoh:
> Baca teks:  
> *"Toko Bunga Melati buka setiap hari dari pukul 08.00–17.00.  
> Pada hari Minggu hanya buka sampai pukul 12.00."*  
>  
> Pertanyaan:  
> “Apakah toko buka pukul 13.00 pada hari Minggu?”

→ Jawaban: Tidak.

---

## 🔬 **PISA Sains Level 2**
Siswa **dapat mengenali penjelasan ilmiah dasar dan menerapkannya dalam konteks nyata yang sederhana**.

### 🔹 Ciri-ciri:
- Soal menggunakan **fenomena sehari-hari** (misalnya air mendidih, tanaman tumbuh).  
- Hanya perlu **menghubungkan satu konsep ilmiah sederhana** dengan pengamatan.

### 🔹 Contoh:
> Mengapa embun terbentuk di kaca mobil pada pagi hari?
>  
> a) Karena kaca menjadi dingin dan uap air di udara mengembun.  
> b) Karena kaca memancarkan cahaya.  
> c) Karena kaca menyerap udara.  

→ Jawaban benar: (a)

---

## 🟢 **Makna Penting Level 2**
- **OECD menyebut Level 2 sebagai ambang batas literasi minimum.**
- Siswa di bawah Level 2 berarti **berisiko tertinggal** dan sulit menerapkan konsep dasar untuk hidup mandiri.
- Target nasional banyak negara (termasuk Indonesia) adalah **memastikan sebagian besar siswa minimal mencapai Level 2.**
