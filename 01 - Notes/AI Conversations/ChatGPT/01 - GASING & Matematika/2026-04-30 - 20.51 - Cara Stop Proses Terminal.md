# 💬 Cara Stop Proses Terminal

**Tanggal:** `2026-04-30 20.51`  
**Sumber:** ChatGPT Export  

---

### 👤 User:
bagaimana stop proses di terminal?

### 🤖 ChatGPT:
Di terminal, cara menghentikan proses tergantung situasinya:

**1. Proses sedang berjalan di foreground**
Tekan:

```bash
Ctrl + C
```

Ini biasanya menghentikan command yang sedang aktif, misalnya `npm run dev`, `python script.py`, `ping`, dll.

**2. Proses ingin dijeda, bukan dihentikan**
Tekan:

```bash
Ctrl + Z
```

Lalu proses masuk background dalam keadaan paused. Untuk melihatnya:

```bash
jobs
```

Untuk menghentikannya:

```bash
kill %1
```

Angka `%1` disesuaikan dengan nomor job.

**3. Hentikan proses berdasarkan PID**
Cari prosesnya:

```bash
ps aux | grep nama_proses
```

Lalu hentikan:

```bash
kill PID
```

Kalau tidak berhenti:

```bash
kill -9 PID
```

**4. Hentikan proses berdasarkan port**
Misalnya server jalan di port 3000:

```bash
lsof -i :3000
kill PID
```

Atau langsung:

```bash
npx kill-port 3000
```

Untuk kebanyakan kasus, coba **Ctrl + C** dulu.
