# 💬 Memory tabel perkalian

**Tanggal:** `2026-02-26 15.35`  
**Sumber:** ChatGPT Export  

---

### 👤 User:
berapa memory untuk menyimpan 1x1 sampai 10x10?

### 🤖 ChatGPT:
Tabel perkalian **1×1 sampai 10×10** punya **100 hasil** (10×10).

### Kalau disimpan sebagai angka (paling umum di komputer / LUT)
Nilai hasilnya dari **1 sampai 100**.

- **1 byte per hasil (uint8, 0–255)** → **100 × 1 = 100 byte**
- **2 byte per hasil (uint16)** → **100 × 2 = 200 byte**
- **4 byte per hasil (uint32)** → **100 × 4 = 400 byte**

### Kalau Anda hanya simpan yang unik (karena 3×7 = 7×3)
Jumlah pasangan unik = \(10×11/2 = 55\)

- **1 byte per hasil** → **55 byte**
- **2 byte per hasil** → **110 byte**
- **4 byte per hasil** → **220 byte**

### Kalau disimpan sebagai teks ASCII (“1 2 3 …”)
Total digit untuk semua hasil 1..100 adalah:
- 1–9: 9 digit  
- 10–99: 90×2 = 180 digit  
- 100: 3 digit  
Total = **192 karakter ≈ 192 byte**, **belum termasuk spasi/koma/baris baru**.

Kalau konteks Anda “memory” ini untuk **hardware LUT** (lookup table), biasanya jawaban yang dipakai: **100 byte** (pakai 8-bit).
