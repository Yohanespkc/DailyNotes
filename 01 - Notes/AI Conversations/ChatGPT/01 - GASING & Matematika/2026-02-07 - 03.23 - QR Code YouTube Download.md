### 🤖 ChatGPT:
Berikut beberapa cara **mengubah file Word (.docx) menjadi Markdown (.md)** yang paling praktis:

---

## ✅ **Cara 1: Pakai Pandoc (Paling Direkomendasikan)**
Cocok kalau Bapak sering konversi dokumen (untuk Obsidian, GitHub, buku digital, dll).

### 1️⃣ Install Pandoc (sekali saja)
- macOS (Homebrew):
```bash
brew install pandoc
```

- Atau download: https://pandoc.org/installing.html

### 2️⃣ Konversi Word → Markdown
Di Terminal:

```bash
pandoc file.docx -o file.md
```

Contoh:
```bash
pandoc bab8.docx -o bab8.md
```

➡️ Hasilnya langsung file Markdown rapi.

---

## ✅ **Cara 2: Lewat Google Docs (Tanpa Install)**
Kalau tidak mau install apa pun:

1. Upload Word ke Google Drive  
2. Buka dengan Google Docs  
3. File → Download → **Markdown (.md)**

⚠️ Kadang format tabel/gambar kurang rapi.

---

## ✅ **Cara 3: Pakai Website Online (Cepat, Sekali Pakai)**
Beberapa converter online:
- CloudConvert
- Convertio
- WordToMarkdown

➡️ Upload → Download .md  
⚠️ Tidak ideal untuk dokumen besar/buku.

---

## ⭐ Rekomendasi untuk Proyek GASING
Karena Bapak sering mengolah buku & naskah besar, saya sarankan:

> ✅ **Gunakan Pandoc + Obsidian**

Alurnya:
```
Word → Pandoc → Markdown → Obsidian → Buku Digital
```

Ini paling stabil untuk:
- Bab buku
- Caption gambar
- Referensi
- QR link
- Struktur rapi

---

## 📌 Bonus: Supaya Gambar Ikut Rapi
Kalau Word berisi gambar:

```bash
pandoc file.docx -o file.md --extract-media=media
```

➡️ Gambar masuk folder `media/`  
➡️ Markdown otomatis link ke gambar

---

Kalau Bapak mau, saya juga bisa buatkan **template workflow khusus buku GASING (Word → MD → Canva/Obsidian → Cetak)** supaya lebih sistematis.

### 🤖 ChatGPT:
Pesan error itu artinya **Pandoc tidak menemukan file Word yang ingin Bapak konversi**.

Intinya:

> ❌ File **`B1.docx` / `B1` tidak ada di folder tempat Terminal sekarang berada.**

---

## ✅ Langkah Perbaikan (Ikuti Pelan-pelan)

### 1️⃣ Cek dulu: file Word ada di mana?

Di Terminal, ketik:

```bash
ls
```

Lihat apakah muncul:
```
B1.docx
```

Kalau **tidak ada**, berarti filenya ada di folder lain.

---

### 2️⃣ Masuk ke folder tempat file berada

Misalnya file ada di folder **Documents**:

```bash
cd ~/Documents
```

Lalu cek lagi:

```bash
ls
```

Kalau sudah muncul `B1.docx`, baru lanjut.

---

### 3️⃣ Gunakan perintah yang benar (lengkap .docx)

Gunakan:

```bash
pandoc B1.docx -o B1.md
```

⚠️ Penting: **harus pakai `.docx`**, jangan hanya `B1`.

---

## ✅ Alternatif Aman (Pakai Path Lengkap)

Kalau masih error, pakai alamat lengkap:

Misalnya:

```bash
pandoc /Users/yohaness/Documents/B1.docx -o /Users/yohaness/Documents/B1.md
```

(Disesuaikan dengan folder Bapak)

---

## ⭐ Cara Cepat (Paling Mudah di macOS)

Trik praktis:

1. Ketik di Terminal:
```bash
pandoc 
```

2. Drag file `B1.docx` ke Terminal  
3. Lanjutkan:
```bash
 -o B1.md
```

Hasilnya jadi:

```bash
pandoc /path/file/B1.docx -o B1.md
```

➡️ Hampir pasti berhasil.

---

## 📌 Kenapa Error Tadi Terjadi?

Karena Bapak mengetik:

```bash
pandoc B1 -o b1.md
```

Padahal:

❌ Tidak ada file bernama `B1`  
✅ Yang ada: `B1.docx`

Pandoc → bingung → error.

---

Kalau masih bermasalah, kirimkan hasil:

```bash
pwd
ls
```

## ✅ **Cara 1: Tarik Langsung (Paling Cepat)**

2. Akan muncul titik kecil di sudut-sudut
3. Tarik **dari sudut** (jangan dari sisi) 👉 supaya tidak gepeng

📌 **Tips:**  
Selalu tarik dari **pojok**, agar proporsi tetap bagus.

---

## ✅ **Cara 2: Atur Ukuran Presisi (Untuk Buku / Layout)**
Kalau Bapak butuh ukuran tepat (misalnya untuk buku):

1. Klik gambar
2. Klik tab **Picture Format**
3. Di kanan atas → bagian **Size**
4. Isi:
   - Height (Tinggi)
   - Width (Lebar)

Contoh:
```
Width: 8 cm
Height: otomatis
```

---

## ✅ **Cara 3: Lewat Menu “Size and Position” (Paling Lengkap)**
Untuk kontrol penuh:

1. Klik kanan gambar
2. Pilih **Size and Position**
3. Masuk tab **Size**
4. Centang:
   ☑️ Lock aspect ratio
5. Atur tinggi / lebar

➡️ Ini cara paling aman untuk dokumen profesional.

---

## ✅ **Cara 4: Samakan Ukuran Banyak Gambar Sekaligus**
Kalau Bapak punya banyak gambar (misalnya QR Code):

1. Klik gambar pertama
2. Tahan **Shift**
3. Klik gambar lain
4. Atur ukurannya → semua ikut berubah

Cocok untuk buku GASING + QR Code.

---

## ⭐ Rekomendasi untuk Buku / Laporan GASING

Untuk layout rapi:

| Jenis Gambar | Lebar Ideal |
|-------------|-------------|
| QR Code | 3–4 cm |
| Foto kegiatan | 8–12 cm |
| Ilustrasi penuh | 14–16 cm |

(untuk A5/A4 standar)

❌ Perbesar gambar kecil → pecah  
❌ Tidak lock ratio → rusak proporsi

## ✅ **Cara Utama: Kompres Gambar di Word (WAJIB Dicoba)**

1. Klik salah satu gambar
2. Masuk tab **Picture Format**
3. Klik **Compress Pictures**
4. Akan muncul kotak dialog
5. Atur seperti ini:

   ☑️ **Delete cropped areas of pictures**  
   ☑️ **Apply to all pictures in this document**  
   Pilih resolusi:
   - 📄 Untuk buku / cetak → **Print (220 ppi)**
   - 💻 Untuk PDF / online → **Web (150 ppi)**

6. Klik **OK**
7. Save ulang file

➡️ Biasanya ukuran file langsung turun drastis.

---

## ✅ **Cara Kedua: Matikan Penyimpanan Gambar Asli (Sekali Setting)**

Kadang Word menyimpan “original image” tanpa dikompres.

1. Klik **File → Options**
2. Pilih **Advanced**
3. Scroll ke **Image Size and Quality**
4. Centang:
   ☑️ **Do not compress images in file** → ❌ (pastikan TIDAK dicentang)
5. Pilih dokumen ini
6. OK → Save ulang

---

## ✅ **Cara Ketiga (Kalau Masih Besar): Kecilkan di Luar Word**

Kalau foto dari HP/kamera (5–10 MB per foto), sebaiknya kecilkan dulu:

### Di macOS:
1. Klik kanan gambar → **Open with Preview**
2. Tools → **Adjust Size**
3. Ubah:
   - Width: 1500–2000 px (cukup untuk buku)
4. Save

Lalu masukkan ulang ke Word.

## ✅ **Cara Paling Cepat di Word Mac (Tanpa Masuk Preferences)**

Karena menu Bapak ada:

3. Pilih:

4. OK
5. Save ulang

➡️ Biasanya langsung turun drastis.
