## OPSI A — PALING CEPAT (tanpa ulang download)
### 🎯 Konversi **MKV → MP4** dengan **ffmpeg (copy stream)**

Jalankan di Terminal (di folder tempat file `.mkv` berada):

```bash
ffmpeg -i input.mkv -c copy output.mp4
```

🔁 Contoh nyata:
```bash
ffmpeg -i "NamaVideo.mkv" -c copy "NamaVideo.mp4"
```

✅ Kelebihan:
- Super cepat (detik)
- Tidak turun kualitas
- Aman untuk video GASING

---

## OPSI B — OTOMATIS LANGSUNG MP4 (tanpa file MKV)
### 🎯 Suruh yt-dlp langsung menghasilkan MP4

Gunakan perintah ini:

```bash
yt-dlp -f "bv*[height<=1080][ext=mp4]+ba[ext=m4a]/bv*+ba" \
--merge-output-format mp4 \
"https://www.youtube.com/watch?v=9fy38Jg-QEo"
```

📌 Untuk 720p:
```bash
yt-dlp -f "bv*[height<=720][ext=mp4]+ba[ext=m4a]/bv*+ba" \
--merge-output-format mp4 \
"https://www.youtube.com/watch?v=9fy38Jg-QEo"
```

---

## OPSI C — BANYAK FILE SEKALIGUS
### 🎯 Konversi semua MKV → MP4 di folder

```bash
for f in *.mkv; do
  ffmpeg -i "$f" -c copy "${f%.mkv}.mp4"
done
```
