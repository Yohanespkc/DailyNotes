# 💬 Menampilkan Persamaan Matematika

**Tanggal:** `2025-02-04 03.54`  
**Sumber:** ChatGPT Export  

---

### 👤 User:
bagaimana cara run program diterminal, tetapi tulisan persamaan matematikanya tidak dalam bentuk latex, tapi dalam bentuk persamaan yang enak dilihat 

### 🤖 ChatGPT:
Untuk menjalankan program di terminal dengan persamaan matematika yang tetap enak dilihat tetapi tidak dalam format LaTeX, ada beberapa cara yang bisa digunakan:

### 1. **Menggunakan Unicode (Symbolic Representation)**
   Anda bisa menggunakan simbol Unicode untuk menampilkan persamaan dengan lebih baik di terminal. Misalnya:

   ```python
   print("  𝑓(𝑥) = 𝑎𝑥² + 𝑏𝑥 + 𝑐")
   ```

   Contoh output di terminal:
   ```
   𝑓(𝑥) = 𝑎𝑥² + 𝑏𝑥 + 𝑐
   ```

   Beberapa simbol Unicode yang berguna:
   - **²** → `\u00B2` (superscript 2)
   - **³** → `\u00B3` (superscript 3)
   - **√** → `\u221A` (akar)
   - **π** → `\u03C0` (pi)
   - **∑** → `\u2211` (sigma)

---

### 2. **Menggunakan `sympy.pretty_print`**
   Jika menggunakan Python, pustaka `sympy` menyediakan metode `pretty_print` untuk menampilkan persamaan dalam bentuk yang lebih enak dilihat:

   ```python
   from sympy import symbols, Eq, pretty_print

   x = symbols('x')
   eq = Eq(x**2 + 2*x + 1, 0)

   pretty_print(eq)
   ```

   Output yang dihasilkan:
   ```
        2
      x  + 2⋅x + 1 = 0
   ```

---

### 3. **Menggunakan ASCII Art dengan `sympy.pprint`**
   Jika terminal tidak mendukung Unicode dengan baik, bisa pakai ASCII:

   ```python
   from sympy import symbols, Eq, pprint

   x = symbols('x')
   eq = Eq(x**2 + 3*x + 2, 0)

   pprint(eq, use_unicode=False)
   ```

   Output:
   ```
      2
   x  + 3*x + 2 = 0
   ```

---

### 4. **Menggunakan `rich` untuk Format yang Lebih Menarik**
   Jika ingin tampilan lebih menarik dengan warna, gunakan pustaka `rich`:

   ```python
   from rich.console import Console

   console = Console()
   console.print("[bold blue]f(x) = ax² + bx + c[/bold blue]")
   ```

   Outputnya akan berwarna di terminal yang mendukung ANSI escape codes.

---

### Kesimpulan
- **Jika terminal mendukung Unicode**, gunakan Unicode langsung.
- **Jika menggunakan Python dan ingin bentuk lebih rapi**, gunakan `sympy.pretty_print()`.
- **Jika hanya ASCII yang didukung**, gunakan `pprint(use_unicode=False)`.
- **Jika ingin tampilan lebih estetik**, gunakan `rich`.
