# 💬 Titik Belok Fungsi Kubik

### 🤖 ChatGPT:
Titik belok (inflection point) pada suatu fungsi adalah titik di mana kurva fungsi tersebut berubah dari cekung (concave) ke cembung (convex) atau sebaliknya. Sebuah fungsi \( f(x) \) memiliki titik belok di \( x = c \) jika \( f''(c) = 0 \) dan \( f''(x) \) berubah tanda di sekitar \( x = c \).

Contoh fungsi sederhana yang memiliki titik belok adalah \( f(x) = x^3 \). Mari kita analisis fungsi ini untuk menemukan titik beloknya.

1. Fungsi: \( f(x) = x^3 \)
2. Turunan pertama: \( f'(x) = 3x^2 \)
3. Turunan kedua: \( f''(x) = 6x \)

Untuk mencari titik belok, kita cari nilai \( x \) yang membuat turunan kedua sama dengan nol:

\[ f''(x) = 6x = 0 \]
\[ x = 0 \]

Kemudian, kita periksa perubahan tanda dari \( f''(x) \) di sekitar \( x = 0 \):

- Jika \( x < 0 \), misalnya \( x = -1 \):
  \[ f''(-1) = 6(-1) = -6 \]
- Jika \( x > 0 \), misalnya \( x = 1 \):
  \[ f''(1) = 6(1) = 6 \]

Karena \( f''(x) \) berubah tanda dari negatif menjadi positif saat \( x \) melewati 0, maka \( x = 0 \) adalah titik belok. Pada titik ini, kurva berubah dari cekung ke cembung.

Jadi, fungsi \( f(x) = x^3 \) memiliki titik belok di \( x = 0 \).

Untuk ilustrasi visual, berikut adalah grafik dari \( f(x) = x^3 \):

```python
import numpy as np
import matplotlib.pyplot as plt

# Definisikan fungsi dan turunannya
x = np.linspace(-2, 2, 400)
y = x**3
dy = 3*x**2
ddy = 6*x

# Plot grafik fungsi dan turunannya
plt.figure(figsize=(10, 6))

# Grafik fungsi
plt.plot(x, y, label='$f(x) = x^3$')

# Titik belok
plt.scatter(0, 0, color='red')
plt.text(0, 0, '  (0, 0)', color='red')

# Label dan grid
plt.axhline(0, color='black',linewidth=0.5)
plt.axvline(0, color='black',linewidth=0.5)
plt.grid(color = 'gray', linestyle = '--', linewidth = 0.5)
plt.title('Grafik $f(x) = x^3$ dengan Titik Belok di (0,0)')
plt.xlabel('x')
plt.ylabel('f(x)')
plt.legend()
plt.show()
```
