## 📌 Kepanjangan HS Code

**HS = Harmonized System (Sistem Harmonisasi)**  
Nama lengkapnya:

> **Harmonized Commodity Description and Coding System**

Artinya: sistem global untuk memberi “nama dan nomor” pada setiap jenis barang.

Sistem ini dikelola oleh **entity["organization","World Customs Organization","international customs body"]**.

---

## 📦 Bentuk HS Code

Secara internasional: **6 digit standar**

Contoh:
```
8471.30
```

Artinya:
- 84 = Mesin & elektronik
- 71 = Komputer
- 30 = Laptop/portable

---

Di Indonesia biasanya dipakai **8 digit atau 10 digit**, misalnya:

```
8471.30.90
```

Semakin panjang → semakin spesifik.

---

## 🧭 Fungsi HS Code

HS Code menentukan:

### 1️⃣ Besar Pajak & Bea Masuk
Barang beda kode → pajaknya beda.

Contoh:
- Laptop → pajak rendah
- Mainan → pajak bisa lebih tinggi

---

### 2️⃣ Aturan Impor/Ekspor
Dari HS Code bisa diketahui:
- Perlu izin atau tidak
- Perlu SNI
- Perlu karantina
- Dilarang atau bebas

---

### 3️⃣ Statistik Negara
Pemerintah tahu:
- Impor apa paling banyak
- Dari negara mana
- Nilainya berapa

---
