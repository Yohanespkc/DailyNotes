## 1️⃣ Apa itu *matrix multiplication (matmul)*?

image_group{"query":["matrix multiplication visualization","neural network matrix multiplication","tensor matmul deep learning"]}

Perkalian matriks adalah operasi:
\[
C = A \times B
\]

Setiap elemen hasil:
\[
c_{ij} = \sum_k a_{ik} \cdot b_{kj}
\]

Artinya:
- **kali → tambah → ulang ribuan/jutaan kali**
- Operasi dasar: **multiply–accumulate (MAC)**

Inilah **otot utama** AI.

---

## 2️⃣ Kenapa AI “didominasi” matmul?

Karena hampir semua komponen AI modern **direduksi menjadi matmul**:

### 🔹 a. Neural Network (MLP, CNN, Transformer)
- Layer penuh (Dense):  
  `output = W × input`
- Attention (Transformer):  
  \[
  QK^T,\quad \text{softmax},\quad AV
  \]
  👉 semuanya **matmul**

### 🔹 b. Training & Inference
- **Forward pass** → matmul  
- **Backward pass (backprop)** → matmul lagi  
- **Update bobot** → matmul + add

> Bahkan 90%+ FLOPs di model besar itu matmul.

## 3️⃣ Kenapa *floating-point*?

image_group{"query":["floating point precision fp16 fp32 fp8","gpu tensor cores fp16","ai accelerator floating point"]}

Karena AI butuh:
- Bilangan **pecahan**
- Gradien kecil
- Dinamika nilai luas

Digunakan:
- FP32 (dulu)
- FP16 / bfloat16 (sekarang)
- FP8 (model besar terbaru)

👉 Hardware AI dioptimalkan khusus untuk **floating-point matmul**.

## 1️⃣ **Digital Convolution**  
👉 *“Menggeser + mengalikan + menjumlahkan”*

image_group{"query":["digital convolution signal processing","convolution operation step by step","cnn convolution filter visualization"]}

### Makna inti
**Digital convolution** adalah proses:
1. Sebuah **filter/kernel** kecil
2. **digeser** di atas data (sinyal / gambar)
3. Di setiap posisi:  
   **nilai dikalikan → lalu dijumlahkan**

### Contoh super sederhana
Sinyal:
```
[2, 4, 6, 8]
```

Filter:
```
[1, -1]
```

Perhitungan:
```
(2×1 + 4×(-1)) = -2
(4×1 + 6×(-1)) = -2
(6×1 + 8×(-1)) = -2
```

Hasil:
```
[-2, -2, -2]
```

👉 Convolution = **mendeteksi pola lokal**
- di gambar → tepi, bentuk
- di audio → frekuensi
- di AI → fitur bermakna

---

## 2️⃣ **Signal Accumulation**  
👉 *“Menumpuk hasil kali jadi satu nilai”*

image_group{"query":["signal accumulation diagram","multiply accumulate mac operation","neural network accumulation"]}

### Makna inti
**Signal accumulation** adalah bagian dalam convolution (dan neural network):

\[
y = \sum (x_i \times w_i)
\]

Artinya:
- banyak sinyal kecil
- **dikumpulkan (diakumulasi)**
- jadi satu respon

### Contoh
```
Input  : [0.2, 0.5, 0.3]
Bobot  : [0.4, 0.1, 0.5]

Hitung:
0.2×0.4 = 0.08
0.5×0.1 = 0.05
0.3×0.5 = 0.15

Akumulasi:
0.08 + 0.05 + 0.15 = 0.28
```

👉 Inilah **MAC (Multiply–Accumulate)**  
👉 Operasi **terbanyak** di AI & otak digital

---

## 3️⃣ **Normalization**  
👉 *“Menjaga hasil tetap stabil & sebanding”*

image_group{"query":["data normalization before after","batch normalization deep learning","signal normalization example"]}

### Makna inti
**Normalization** = mengatur ulang skala nilai agar:
- tidak terlalu besar
- tidak terlalu kecil
- mudah dibandingkan
- stabil diproses berikutnya

### Contoh sederhana
Tanpa normalisasi:
```
[120, 130, 125]
```

Dinormalisasi (0–1):
```
[0.92, 1.00, 0.96]
```

Atau dengan rata-rata & simpangan baku:
\[
x' = \frac{x - \mu}{\sigma}
\]

### Di AI
- **Batch Normalization**
- **Layer Normalization**
- **Attention Normalization (softmax)**

👉 Tanpa normalisasi:
- training liar
- gradien meledak / mati
- AI tidak stabil

## 🧠 Apa itu Pembelajaran Multimodal?
> **Pembelajaran multimodal** adalah pembelajaran yang **menggunakan lebih dari satu mode** (cara) secara bersamaan agar otak lebih mudah memahami, mengingat, dan menikmati proses belajar.

Mode = **cara informasi masuk dan diproses otak**.

## 🔗 Mengapa Multimodal itu KUAT?

Karena:
- Otak **tidak belajar lewat satu jalur**
- Informasi yang masuk lewat banyak jalur → **lebih kuat & tahan lama**
- Kalau satu jalur lemah, jalur lain **menolong**

📌 Prinsip neurosains:
> *The more pathways activated, the stronger the learning.*
