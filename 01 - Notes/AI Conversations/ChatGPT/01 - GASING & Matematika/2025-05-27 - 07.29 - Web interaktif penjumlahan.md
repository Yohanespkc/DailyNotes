### ✅ **Langkah Menjalankan di Komputer Kamu**

#### 1. **Buat proyek baru dengan Vite:**
```bash
npm create vite@latest penjumlahan-game --template react
cd penjumlahan-game
npm install
```

#### 2. **Install Tailwind CSS:**
```bash
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

#### 3. **Edit `tailwind.config.js`:**
```js
content: ["./index.html", "./src/**/*.{js,ts,jsx,tsx}"],
```

#### 4. **Edit `src/index.css`:**
```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

#### 5. **Tambahkan framer-motion dan shadcn/ui:**
```bash
npm install framer-motion
npm install @radix-ui/react-slot class-variance-authority tailwind-variants lucide-react
```

> Untuk `shadcn/ui`, kamu bisa salin komponen `Card`, `Button`, dan `Input` dari [https://ui.shadcn.com/docs/components](https://ui.shadcn.com/docs/components)

#### 6. **Ganti isi `src/App.jsx` dengan kode tadi.**

---

### ✅ Penjumlahan Interaktif (HTML versi)

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Game Penjumlahan Interaktif</title>
  <style>
    body {
      font-family: sans-serif;
      display: flex;
      justify-content: center;
      align-items: center;
      height: 100vh;
      margin: 0;
      background: linear-gradient(to right, #c3f0ff, #b9fbc0);
    }
    .container {
      background: white;
      padding: 2rem;
      border-radius: 20px;
      box-shadow: 0 8px 24px rgba(0, 0, 0, 0.2);
      text-align: center;
      width: 300px;
    }
    h1 {
      margin-bottom: 1rem;
    }
    .question {
      font-size: 2rem;
      margin: 1rem 0;
    }
    input {
      padding: 0.5rem;
      font-size: 1.2rem;
      text-align: center;
      width: 80px;
    }
    button {
      margin-top: 1rem;
      padding: 0.5rem 1rem;
      font-size: 1rem;
      border: none;
      border-radius: 8px;
      background-color: #4ade80;
      color: white;
      cursor: pointer;
    }
    .feedback {
      margin-top: 1rem;
      font-weight: bold;
      font-size: 1.1rem;
    }
    .score {
      margin-top: 0.5rem;
      font-size: 0.9rem;
      color: #555;
    }
  </style>
</head>
<body>

  <div class="container">
    <h1>Game Penjumlahan 🎲</h1>
    <div class="question" id="soal">7 + 5 = ?</div>
    <input type="number" id="jawaban" placeholder="Jawab" />
    <br />
    <button onclick="periksaJawaban()">Periksa</button>
    <div class="feedback" id="feedback"></div>
    <div class="score" id="skor">Skor: 0</div>
  </div>

  <script>
    let a, b, skor = 0;

    function acakSoal() {
      a = Math.floor(Math.random() * 10) + 1;
      b = Math.floor(Math.random() * 10) + 1;
      document.getElementById('soal').textContent = `${a} + ${b} = ?`;
    }

    function periksaJawaban() {
      const input = parseInt(document.getElementById('jawaban').value);
      const feedback = document.getElementById('feedback');
      const skorEl = document.getElementById('skor');

      if (input === a + b) {
        feedback.textContent = 'Benar! 🎉';
        feedback.style.color = 'green';
        skor++;
        skorEl.textContent = `Skor: ${skor}`;
        setTimeout(() => {
          acakSoal();
          feedback.textContent = '';
          document.getElementById('jawaban').value = '';
        }, 1000);
      } else {
        feedback.textContent = 'Coba lagi ✋';
        feedback.style.color = 'red';
      }
    }

    acakSoal();
  </script>

</body>
</html>
```

3. Mainkan dan nikmati!
