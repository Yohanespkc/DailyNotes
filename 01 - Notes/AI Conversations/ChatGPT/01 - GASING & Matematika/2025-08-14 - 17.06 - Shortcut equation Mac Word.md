Di Microsoft Word untuk Mac, shortcut untuk membuat atau menyisipkan **equation** tergantung versi Word yang digunakan:  

**1. Shortcut langsung (versi baru Word Mac, biasanya 2016 ke atas)**  
- **Control + Command + Space** → membuka panel simbol (untuk simbol matematika cepat).  
- **Option + =** → langsung masuk ke mode Equation Editor (MathType bawaan Word).  

**2. Shortcut versi lama (atau jika Option + = tidak berfungsi)**  
- Tekan **Command + Shift + E** (untuk beberapa konfigurasi lama Word for Mac).  
- Atau pilih menu **Insert → Equation**.  

**3. Mengetik equation dengan LaTeX di Word Mac**  
Jika mode LaTeX aktif di pengaturan:  
- Tekan **Option + =** lalu ketik sintaks LaTeX, misalnya `\frac{a}{b}` → hasilnya otomatis menjadi pecahan.

## **1. Shortcut Umum di Word untuk Mac**
| Fungsi | Shortcut |
|--------|----------|
| Masuk ke Equation Editor | **Option + =** |
| Masuk ke Symbol Viewer (emoji & simbol) | **Control + Command + Space** |
| Superscript (pangkat atas) | **Command + Shift + =** |
| Subscript (pangkat bawah) | **Command + =** |
| Menulis akar kuadrat cepat | Ketik `\sqrt` + **Space** |
| Menulis pecahan cepat | Ketik `\frac` + **Space** |
| Simbol tak hingga ∞ | **Option + 5** |
| Simbol π (pi) | **Option + P** |
| Simbol ± | **Shift + Option + =** |
| Simbol ≈ | **Option + X** |
| Simbol ≤ | **Option + ,** |
| Simbol ≥ | **Option + .** |
| Simbol ≠ | **Option + =** |

---

## **2. Kode LaTeX di Equation Editor Word**
Jika sudah tekan **Option + =** (masuk equation mode), ketik kode berikut lalu tekan **Space** untuk mengubah menjadi simbol:

| Kode LaTeX | Hasil | Keterangan |
|------------|-------|------------|
| `\alpha` | α | Huruf Yunani kecil alpha |
| `\beta` | β | Huruf Yunani kecil beta |
| `\gamma` | γ | Huruf Yunani kecil gamma |
| `\pi` | π | Pi |
| `\theta` | θ | Theta |
| `\sum` | ∑ | Summation |
| `\int` | ∫ | Integral |
| `\prod` | ∏ | Product notation |
| `\infty` | ∞ | Infinity |
| `\sqrt{x}` | √x | Akar kuadrat |
| `\frac{a}{b}` | 𝑎/𝑏 | Pecahan |
| `x^{2}` | 𝑥² | Pangkat |
| `x_{1}` | 𝑥₁ | Subscript |
| `\leq` | ≤ | Lebih kecil atau sama dengan |
| `\geq` | ≥ | Lebih besar atau sama dengan |
| `\neq` | ≠ | Tidak sama dengan |
| `\approx` | ≈ | Hampir sama dengan |

💡 **Tips cepat**:
- Ketik semua rumus dalam mode **Option + =** lalu gunakan kode LaTeX, hasilnya jauh lebih cepat daripada klik menu satu per satu.
- Jika sering pakai simbol tertentu, aktifkan **AutoCorrect Math** di Word supaya kode singkat langsung berubah menjadi simbol.
