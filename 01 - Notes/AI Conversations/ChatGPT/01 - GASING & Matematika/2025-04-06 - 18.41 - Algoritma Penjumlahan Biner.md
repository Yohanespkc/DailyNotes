### 🔢 1. **Cara Manual Manusia**
Kita sebagai manusia biasanya menjumlahkan angka **desimal** (basis 10) dari kanan ke kiri:
```
   11
+   9
-----
   20
```

---

### 💻 2. **Bagaimana Mesin Melihat Angka?**
Komputer tidak pakai desimal. Mereka pakai **biner** (basis 2), jadi angka **11 = 1011**, dan **9 = 1001**.

---

### ⚙️ 3. **Algoritma Penjumlahan Biner di Mesin**

Komputer memakai **full-adder** atau logika penjumlahan **bit per bit**, seperti ini:

Misalnya kita mau hitung `1011 (11)` + `1001 (9)`:

```
   1011
+  1001
-------
  10100  (hasilnya: 20 dalam desimal)
```

Langkah per langkah (bit-per-bit dari kanan ke kiri):

| Bit 1 | 1 + 1 = 10 → tulis 0, simpan carry 1 |
|-------|-------------------------------------|
| Bit 2 | 1 + 0 + carry(1) = 10 → tulis 0, carry 1 |
| Bit 3 | 0 + 0 + carry(1) = 1 → tulis 1, carry 0 |
| Bit 4 | 1 + 1 = 10 → tulis 0, carry 1 |
| Tambah carry terakhir jadi bit ke-5 |

Hasil akhir: `10100` (biner) = **20 (desimal)** ✅

---

### 🧠 4. **Algoritma di Level Software**

Di software, bisa dilakukan seperti ini:

```python
def tambah(a, b):
    while b != 0:
        carry = a & b
        a = a ^ b  # XOR: penjumlahan tanpa carry
        b = carry << 1  # geser carry ke kiri
    return a

print(tambah(11, 9))  # Output: 20
```

Ini cara keren buat *mensimulasikan* penjumlahan biner tanpa pakai simbol `+`.

---

### 🔌 5. **Di Level Hardware**

- **ALU (Arithmetic Logic Unit)** di dalam CPU punya rangkaian adder.
- Yang paling umum: **Ripple Carry Adder** atau **Carry Lookahead Adder** untuk mempercepat proses.
- Semua operasi aritmatika (termasuk 11 + 9) dikonversi jadi operasi logika biner seperti AND, OR, XOR, dan SHIFT.

## 🔍 **Simulasi Langkah-demi-Langkah Penjumlahan 11 + 9 Secara Biner**

### Langkah 0: Konversi ke Biner
- 11 → `1011`
- 9  → `1001`

Kita mau jumlahkan:

```
   1011
+  1001
-------
```

### Langkah 1: Tambah bit demi bit dari kanan ke kiri
Kita akan gunakan 3 hal:
- `bit A`
- `bit B`
- `carry` (bawaan dari bit sebelumnya)

| Posisi Bit | A | B | Carry In | A + B + Carry | Hasil | Carry Out |
|------------|---|---|----------|---------------|--------|------------|
| 1 (LSB)    | 1 | 1 |    0     |    2 (10)     |   0    |     1      |
| 2          | 1 | 0 |    1     |    2 (10)     |   0    |     1      |
| 3          | 0 | 0 |    1     |    1 (01)     |   1    |     0      |
| 4 (MSB)    | 1 | 1 |    0     |    2 (10)     |   0    |     1      |
| Tambahan   | - | - |    -     |       -       |   1    |     -      |

Hasil akhir (dari bawah ke atas): `10100` (biner) = **20 (desimal)** ✅

## 💡 Simulasi via Python (tanpa pakai `+`)
Ini simulasi bagaimana komputer bisa menjumlahkan dua bilangan hanya dengan bitwise operation:

```python
def binary_addition(a, b):
    steps = []
    while b != 0:
        steps.append((a, b))
        carry = a & b        # bagian yang menghasilkan "bawaan"
        a = a ^ b            # hasil penjumlahan tanpa carry
        b = carry << 1       # geser carry ke kiri
    steps.append((a, b))     # hasil akhir
    return a, steps

# Coba 11 + 9
result, proses = binary_addition(11, 9)

for i, (a, b) in enumerate(proses):
    print(f"Langkah {i}: a = {a:05b}, b = {b:05b}")

print(f"\nHasil: {result} (biner: {result:05b})")
```

Kalau kamu jalankan ini, kamu akan lihat:
```
Langkah 0: a = 01011, b = 01001
Langkah 1: a = 00010, b = 10100
Langkah 2: a = 10110, b = 00000

Hasil: 20 (biner: 10100)
```

## ⚙️ Bonus: Di Level **Hardware / Elektronika**

### Komponen: **Full Adder**
- Setiap "bit penjumlahan" dikerjakan oleh rangkaian **full adder**.
- Full adder menerima 3 input: A, B, dan Carry In.
- Menghasilkan: Sum dan Carry Out.
  
Rumus logikanya:
```
Sum  = A XOR B XOR Cin
Cout = (A AND B) OR (Cin AND (A XOR B))
```

Jadi, **penjumlahan** adalah **rangkaian logika**!
