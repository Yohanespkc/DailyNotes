## **1. Algoritma menghitung `a mod b` (sisa pembagian a oleh b)**

### **Konsep Dasar:**
`a mod b` adalah **sisa** dari pembagian `a` dengan `b`.

Misalnya:  
`23 mod 7 = 2`, karena  
`23 = 3 × 7 + 2`  
→ 2 adalah sisanya.

---

### **Algoritma Sederhana (untuk mesin atau pemula):**

```plaintext
Langkah 1: Bagi a dengan b → hasilnya c (bagian bulat dari pembagian)
Langkah 2: Kalikan c dengan b → hasilnya x = b × c
Langkah 3: Kurangkan x dari a → hasilnya adalah a mod b
```

### **Contoh `23 mod 7`:**

1. Bagi 23 dengan 7 → hasilnya 3 (karena 7 × 3 = 21, 7 × 4 = 28 terlalu besar)
2. Kalikan 3 × 7 = 21
3. Kurangi 23 - 21 = **2**  
   Jadi: `23 mod 7 = 2`

---

### **Jika ditulis sebagai pseudocode:**

```plaintext
function mod(a, b):
    q = floor(a / b)      # ambil hasil pembagian bulat ke bawah
    r = a - q * b         # hitung sisa
    return r
```

## **2. Algoritma Pembagian Bersisa (a dibagi b = c sisa d)**

### **Notasi Umum:**
```
a : b = c sisa d
```
berarti:
```
a = b × c + d  dengan  0 ≤ d < b
```

---

### **Algoritma Langkah per Langkah:**

```plaintext
Langkah 1: Hitung c = floor(a / b)        → hasil bagi bulat
Langkah 2: Hitung d = a - (b × c)         → sisa
```

---

### **Contoh `23 : 7`:**

1. `23 / 7 = 3` → karena 3 × 7 = 21
2. Sisa = `23 - 21 = 2`

Jadi:
```
23 : 7 = 3 sisa 2
```

---

### **Jika ditulis sebagai algoritma atau program:**

```python
def bagi_bersisa(a, b):
    c = a // b     # hasil bagi
    d = a % b      # sisa
    return (c, d)
```

---

### **Catatan untuk Mesin:**
- Mesin biasanya menyimpan hasil pembagian dalam dua register:
  - **Quotient** (hasil bagi)
  - **Remainder** (sisa atau mod)
- Di level hardware (seperti dalam prosesor), pembagian dan modulus kadang dilakukan dalam satu instruksi mesin.
