## 🛑 Cara Universal (WAJIB TAHU)

### **1️⃣ `Ctrl + C` (paling umum)**

- Berlaku untuk:  
  Python, Node, server, download, loop, script panjang, dsb.
- Aman dan standar.

👉 Contoh:
```bash
python script.py
```
Tekan:
```
Ctrl + C
```

---

## ⏸️ Pause & Lanjutkan

### **2️⃣ `Ctrl + Z` (pause, bukan stop)**
➡️ Menghentikan sementara (suspend)

```bash
Ctrl + Z
```

Terminal akan menampilkan:
```bash
[1]+  Stopped   python script.py
```

Lalu:
- **Lanjutkan di foreground**:
```bash
fg
```
- **Lanjutkan di background**:
```bash
bg
```

---

## 🔪 Paksa Hentikan (Kalau Bandel)

### **3️⃣ Cari & kill proses**
Jika `Ctrl + C` tidak mempan:

#### a) Lihat proses
```bash
ps aux | grep nama_program
```

#### b) Kill dengan PID
```bash
kill PID
```

#### c) Paksa (last resort)
```bash
kill -9 PID
```

⚠️ `-9` = paksa mati total (jangan sering dipakai).

### 🔹 Program salah jalan di background
