### 👤 User:
bagaimana mengubah wav menjadi mp3 dengan terminal

### 🤖 ChatGPT:
Untuk mengubah file WAV menjadi MP3 menggunakan terminal, Anda dapat menggunakan **FFmpeg**, sebuah alat baris perintah yang kuat untuk mengolah file audio dan video. Berikut adalah langkah-langkahnya:

### 1. **Pastikan FFmpeg Terpasang**
   - Untuk Linux (Ubuntu/Debian):
     ```bash
     sudo apt update
     sudo apt install ffmpeg
     ```
   - Untuk macOS (dengan Homebrew):
     ```bash
     brew install ffmpeg
     ```
   - Untuk Windows:
     - Unduh FFmpeg dari [situs resmi FFmpeg](https://ffmpeg.org/download.html).
     - Tambahkan folder instalasi ke variabel PATH di sistem Anda.

### 2. **Perintah untuk Konversi WAV ke MP3**
   Gunakan perintah berikut untuk mengonversi file WAV ke MP3:
   ```bash
   ffmpeg -i input.wav -codec:a libmp3lame -qscale:a 2 output.mp3
   ```

   **Penjelasan:**
   - `-i input.wav`: Menentukan file input (format WAV).
   - `-codec:a libmp3lame`: Menggunakan encoder MP3 (LAME) untuk audio.
   - `-qscale:a 2`: Menentukan kualitas audio (nilai 0-9, 0 kualitas tertinggi dan 9 kualitas terendah).
   - `output.mp3`: Nama file output.

### 3. **Contoh Lengkap**
   Misalnya, Anda memiliki file `audio.wav` dan ingin mengonversinya menjadi `audio.mp3`:
   ```bash
   ffmpeg -i audio.wav -codec:a libmp3lame -qscale:a 2 audio.mp3
   ```

### 4. **Konversi Folder Penuh (Opsional)**
   Jika Anda ingin mengonversi semua file WAV di folder menjadi MP3:
   ```bash
   for file in *.wav; do
       ffmpeg -i "$file" -codec:a libmp3lame -qscale:a 2 "${file%.wav}.mp3"
   done
   ```

### 5. **Hasil**
   File MP3 yang dihasilkan akan muncul di direktori kerja Anda. Anda dapat memeriksa file tersebut dengan:
   ```bash
   ls *.mp3
   ```

Jika Anda memerlukan penyesuaian lebih lanjut, beri tahu saya! 😊
