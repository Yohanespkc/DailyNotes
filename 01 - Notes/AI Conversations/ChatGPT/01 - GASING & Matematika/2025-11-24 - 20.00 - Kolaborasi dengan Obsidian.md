# ⭐ **3. Mengubah Catatan Obsidian Menjadi MCard, PCard, VCard**
Karena Bapak menggunakan sistem card (manusia → pikiran → konsep), maka:

- **MCard** = ringkasan 1 konsep  
- **PCard** = proses / langkah / pipeline  
- **VCard** = visualisasi (diagram / struktur)

ChatGPT bisa otomatis mengubah teks panjang menjadi:

### ✦ MCard  
Format:
```
# MCard: Krilangkun
- Kritis = …
- Langkah = …
- Tekun = …
- Contoh singkat
```

### ✦ PCard  
Format:
```
# PCard: Proses Pelatihan GASING 2 Minggu
1. Assessment hari 1
2. Penguasaan pasangan 10
3. …
```

### ✦ VCard  
ChatGPT bisa membuat diagram → lalu Bapak tempel ke Obsidian.

## 1. Konsep Besarnya

Intinya:

- **Vault Obsidian = 1 folder di komputer**
- Folder itu dijadikan **Git repository**
- Disimpan di **GitHub / GitLab / Codeberg** (sebaiknya repo *private*)
- Semua orang yang kolaborasi:
  - clone repo yang sama  
  - buka folder itu di Obsidian  
  - commit & push perubahan

Jadi bukan “kolaborasi real-time” seperti Google Docs, tapi:
- versi terkontrol  
- bisa lihat history  
- bisa rollback  
- bisa kerja pakai branch (misalnya branch *Bab 3*, branch *Papua Report*, dll.)

---

## 2. Setup Dasar di Mac (untuk 1 vault)

### 2.1. Buat repo di GitHub (sekali saja)
1. Buka GitHub → New repository  
2. Nama misalnya: `gasing-vault`  
3. Pilih **Private**  
4. Buat repo.

### 2.2. Clone di Mac
Di Terminal (karena Bapak pakai macOS):

```bash
cd ~/Documents
git clone https://github.com/USERNAME/gasing-vault.git
cd gasing-vault
```

Lalu di Obsidian:
1. Open → **Open folder as vault**
2. Pilih folder `gasing-vault`.

Sekarang vault itu sudah terhubung dengan Git.

---

## 3. Kalau Bapak sudah punya vault duluan

Misalnya vault `GASING Master` sudah penuh isinya.

1. Di Terminal, masuk ke folder vault itu:

```bash
cd "/path/ke/GASING Master"
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/USERNAME/gasing-vault.git
git push -u origin main
```

2. Lalu di komputer lain, tinggal:

```bash
git clone https://github.com/USERNAME/gasing-vault.git
```

dan buka folder itu di Obsidian.

---

## 4. Mempermudah dengan Plugin **Obsidian Git**

Supaya Bapak tidak perlu terus-terusan buka Terminal, pakai plugin:

1. Di Obsidian → **Settings → Community plugins → Browse**
2. Cari: **“Obsidian Git”** → Install → Enable
3. Seting penting:
   - Auto pull when Obsidian opens → ON  
   - Auto commit interval → misalnya setiap **10 atau 30 menit**  
   - Commit message template → misalnya:  
     `update from Obsidian on {{date}} {{time}}`

Setelah itu:
- Bapak kerja seperti biasa di Obsidian  
- Plugin akan:
  - **pull** saat Obsidian dibuka
  - **commit & push** berkala (atau saat Bapak klik manual “Commit & push”)

---

## 5. Pola Kolaborasi Multi-Orang

Misalnya Bapak, 1 editor, dan 1 co-author pakai vault yang sama.

### Aturan sederhana (supaya tidak berantakan):

1. **Selalu pull dulu sebelum kerja**
   - Dengan Obsidian Git: klik tombol “Pull” (atau otomatis saat buka)
2. **Kerja seperti biasa di Obsidian**
   - edit file  
   - tambah note baru  
   - pindah-pindah folder
3. **Commit kecil dan sering**
   - Misalnya:  
     - `edit: Bab 3 - cerita krilangkun Papua`  
     - `add: template MCard numerasi`
4. **Push setelah selesai sesi kerja**

Kalau dua orang mengedit *file yang sama / paragraf yang sama* di waktu berdekatan → bisa muncul **merge conflict**.  
Git akan minta Bapak pilih versi mana. Untuk teks markdown, ini masih cukup mudah diselesaikan (tinggal edit manual).

---

## 6. Pakai *Branch* untuk Eksperimen

Ini berguna untuk pengerjaan bab buku:

- `main` → versi yang “aman” / siap baca  
- `bab3-draft` → branch khusus untuk utak-atik Bab 3  
- `digital-mestakung-v2` → eksperimen gaya penulisan baru

Contoh:

```bash
git checkout -b bab3-draft
# edit-edit di Obsidian
git commit -am "Rework Bab 3: masalah sebagai kondisi kritis"
git push -u origin bab3-draft
```

Setelah puas, bisa di-**merge** ke `main` via GitHub (pull request) supaya:
- ada catatan review  
- bisa lihat diff dengan rapi.

## 8. Contoh `.gitignore` Minimal

```gitignore

.obsidian/plugins/obsidian-git/logs/*
.trash/
```

## 9. Hal yang Perlu Diwaspadai

- **Jangan** pakai Git + Obsidian Sync + Dropbox **bersamaan** untuk vault yang sama, nanti bisa kacau.
- Kalau mau pakai Git **saja**:
  - nonaktifkan sync lain
- Untuk file besar (video, rekaman pelatihan, dsb):
  - sebaiknya **tidak** dimasukkan ke repo  
  - atau pakai subfolder lain + Git LFS (kalau perlu)
