# 💬 Menggabungkan 100 file Word

**Tanggal:** `2025-09-13 22.44`  
**Sumber:** ChatGPT Export  

---

### 👤 User:
bagaimana menggabungkan 100 file word

### 🤖 ChatGPT:
Ada beberapa cara untuk menggabungkan 100 file Word menjadi satu dokumen, tergantung apakah Anda ingin melakukannya **manual** (langsung dari Word) atau **otomatis** (pakai script).  

---

## 🔹 Cara 1: Manual lewat Microsoft Word
1. Buka dokumen Word baru (kosong).
2. Pergi ke **Insert > Object > Text from File**.
3. Pilih semua file Word yang mau digabung (bisa tekan **Ctrl+A** kalau dalam satu folder).
4. Klik **Insert** → semua file akan masuk ke dokumen baru secara berurutan.
   - Kekurangannya: kalau ada format berbeda (margin, heading, dll.), bisa jadi hasilnya campur.

---

## 🔹 Cara 2: Pakai PowerShell (Windows)
Kalau Anda pakai Windows, bisa jalankan script ini untuk otomatis menggabungkan:

```powershell
$word = New-Object -ComObject Word.Application
$word.Visible = $false
$master = $word.Documents.Add()

$files = Get-ChildItem "C:\path\ke\folder\*.docx"
foreach ($file in $files) {
    $selection = $word.Selection
    $selection.InsertFile($file.FullName)
    $selection.InsertBreak([Microsoft.Office.Interop.Word.WdBreakType]::wdPageBreak)
}

$master.SaveAs("C:\path\ke\output\gabungan.docx")
$master.Close()
$word.Quit()
```

Hasilnya semua file dalam folder akan digabung jadi satu file `gabungan.docx`.

---

## 🔹 Cara 3: Pakai Python (Mac/Windows/Linux)
Kalau Anda suka lebih fleksibel, bisa gunakan library `python-docx`:

```python
from docx import Document
import glob

merged = Document()

files = glob.glob("/path/ke/folder/*.docx")

for file in files:
    doc = Document(file)
    for element in doc.element.body:
        merged.element.body.append(element)
    merged.add_page_break()

merged.save("/path/ke/output/gabungan.docx")
```

---

## 🔹 Cara 4: Pakai Aplikasi Online
Ada banyak situs gratis seperti **ILovePDF, SmallPDF, atau Combine Word** yang bisa gabungkan banyak file Word. Tinggal upload semua → unduh hasil gabungannya.  
⚠️ Tapi, hati-hati kalau dokumen berisi data sensitif (lebih aman pakai cara offline).
