### 🔹1. Download Audio dari YouTube
Gunakan `yt-dlp` untuk mendownload audio.

Kalau belum punya `yt-dlp`, install dulu:
```bash
pip install yt-dlp
```

Lalu download audionya:
```bash
yt-dlp -x --audio-format mp3 "URL_VIDEO_YOUTUBE"
```
Contoh:
```bash
yt-dlp -x --audio-format mp3 "https://www.youtube.com/watch?v=Pq2uwssaFRo"
```
Ini akan menghasilkan file audio `.mp3`.

### 🔹2. Transkrip Audio menjadi Teks
Gunakan **whisper** dari OpenAI (akurat banget).

Kalau belum install `whisper`, jalankan:
```bash
pip install openai-whisper
```

Lalu transkrip audionya:
```bash
whisper nama_file_audio.mp3 --language Indonesian
```
Contoh:
```bash
whisper Pq2uwssaFRo.mp3 --language Indonesian
```

Setelah selesai, Whisper akan menghasilkan file `.txt` yang berisi hasil transkripsi.

# 🔹Cara 1: Pakai `say` command (Mac & Linux)

Kalau kamu pakai MacBook (seperti kemarin), ini cara super gampang:

1. Buka Terminal.
2. Jalankan perintah ini untuk membuat audio file:

```bash
say -v Samantha "The battle was very hard. He won the battle. They are preparing for the next battle. The battle lasted all night. She wrote a book about the battle." -o battle_audio.aiff
```

Artinya:
- **`-v Samantha`** → pilih suara (bisa ganti jadi Alex, Victoria, Daniel, dll).
- **`-o battle_audio.aiff`** → hasilnya disimpan jadi file `battle_audio.aiff`.

3. Setelah selesai, file `battle_audio.aiff` ada di folder kamu.

Kalau mau ubah jadi MP3, gampang:
```bash
ffmpeg -i battle_audio.aiff battle_audio.mp3
```
(*Kalau belum install ffmpeg, install dengan `brew install ffmpeg`*)

# 📦 Apa itu **Cubical Model** dalam AI?

**Cubical model** dalam konteks AI **bukan istilah mainstream**, seperti neural network, decision tree, atau reinforcement learning.  
Tetapi **"cubical"** di AI biasanya muncul dalam beberapa konteks **khusus**, seperti:

1. **Topological Data Analysis (TDA)** → **Cubical Complex**  
2. **High-Dimensional Discrete Spaces** → Representasi data dalam bentuk **kubus berdimensi tinggi**.

Kita bahas satu-satu:

---

## 1. 🔹 **Cubical Complex** di Topological Data Analysis (TDA)
- Ini tentang bagaimana **struktur data** dipetakan dan dianalisis dengan bentuk **kubus** (bukan titik, bukan edge, tapi *kubus*).
- Dalam TDA, **data points** dianalisis berdasarkan bentuk geometris mereka (termasuk lubang, rongga, dimensi).
- Di cubical complex, **data** dipetakan menjadi kumpulan kubus kecil (cube 1D = edge, 2D = square, 3D = cube, dst).

**Contoh Kasarnya:**
- Kalau kamu punya data 2D → kamu bagi menjadi **grid kotak-kotak kecil**.
- Kalau 3D → kamu potong jadi **banyak kubus kecil**.

Kenapa penting?  
Karena AI yang mau memahami **bentuk data** (seperti clustering berdasarkan bentuk, bukan hanya jarak) bisa menggunakan *cubical model* ini.

**Biasanya dipakai untuk:**
- Menganalisis bentuk dari data (contohnya: mendeteksi pola aneh di gambar medis, molekul, dan lainnya).
- Membantu machine learning memahami **struktur ruang** yang lebih kompleks.

---

## 2. 🔹 **High-Dimensional Cubical Representation**
- Dalam beberapa bidang AI (seperti **Reinforcement Learning** atau **State Space Modeling**), keadaan (states) direpresentasikan sebagai **grid kubus berdimensi tinggi**.
- Misalnya:
  - 2D grid: posisi robot di lantai (x, y)
  - 3D grid: posisi robot + sudut rotasi (x, y, θ)
  - 4D grid: x, y, θ, dan waktu (t)
  - dst...
- Jadi, **cubical model** berarti **setiap "state"** di dunia robot atau simulasi itu **seperti titik di dalam kubus multidimensi**.

**Dipakai untuk:**
- Navigasi robot (path planning)
- Pemodelan probabilistik AI
- Simulasi dunia dalam game AI

---

|:--------|:--------------------|:-------------|
| TDA | Menganalisis bentuk data lewat kubus-kubus kecil | Clustering bentuk, image analysis |
| State Space | Merepresentasikan semua kemungkinan keadaan dalam kubus dimensi-tinggi | Robotik, simulasi AI |
