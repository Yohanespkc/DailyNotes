# 💬 Convert Word to PDF Terminal

**Tanggal:** `2026-05-21 10.02`  
**Sumber:** ChatGPT Export  

---

### 👤 User:
bagaimana mengubah file word menjadi pdf pakai terminal

### 🤖 ChatGPT:
Bisa pakai **LibreOffice headless** dari terminal.

### Linux / macOS

```bash
libreoffice --headless --convert-to pdf "file.docx"
```

PDF akan dibuat di folder yang sama.

Untuk menentukan folder output:

```bash
libreoffice --headless --convert-to pdf --outdir ./hasil "file.docx"
```

### Banyak file sekaligus

```bash
libreoffice --headless --convert-to pdf *.docx
```

### Kalau command `libreoffice` tidak ada

Coba:

```bash
soffice --headless --convert-to pdf "file.docx"
```

### Windows PowerShell

```powershell
soffice --headless --convert-to pdf "C:\path\file.docx" --outdir "C:\path\hasil"
```

Biasanya `soffice.exe` ada di:

```text
C:\Program Files\LibreOffice\program\soffice.exe
```

Contoh lengkap:

```powershell
& "C:\Program Files\LibreOffice\program\soffice.exe" --headless --convert-to pdf "C:\Users\Yohanes\Documents\file.docx" --outdir "C:\Users\Yohanes\Documents\hasil"
```

Kalau belum ada LibreOffice, install dulu:

```bash
sudo apt install libreoffice
```

di Ubuntu/Debian.

### 🤖 ChatGPT:
`apt` itu untuk Ubuntu/Debian Linux, bukan macOS. Karena kamu pakai **MacBook**, pakai salah satu cara ini:

### 1. Install LibreOffice di macOS

Kalau punya Homebrew:

```bash
brew install --cask libreoffice
```

Kalau `brew` belum ada, install Homebrew dulu dari Terminal:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Lalu jalankan lagi:

```bash
brew install --cask libreoffice
```

### 2. Convert Word ke PDF dari terminal

Setelah LibreOffice terinstall, jalankan:

```bash
/Applications/LibreOffice.app/Contents/MacOS/soffice --headless --convert-to pdf file.docx
```

Kalau file-nya ada di folder `documents`, contoh:

```bash
/Applications/LibreOffice.app/Contents/MacOS/soffice --headless --convert-to pdf "nama-file.docx"
```

Output PDF akan muncul di folder yang sama.

### 3. Simpan hasil ke folder tertentu

```bash
mkdir -p hasil
/Applications/LibreOffice.app/Contents/MacOS/soffice --headless --convert-to pdf --outdir hasil "nama-file.docx"
```

### 4. Convert semua `.docx` di folder sekarang

```bash
/Applications/LibreOffice.app/Contents/MacOS/soffice --headless --convert-to pdf *.docx
```

Cek dulu nama file Word-nya dengan:

```bash
ls
```
