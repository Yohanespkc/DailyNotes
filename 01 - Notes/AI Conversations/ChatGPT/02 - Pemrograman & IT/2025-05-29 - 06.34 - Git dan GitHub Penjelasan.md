### 🔧 **Apa itu Git?**

**Git** adalah **sistem kontrol versi** (Version Control System atau VCS). Fungsinya:

- Melacak perubahan pada file dan folder dalam proyek (terutama kode program).
- Memungkinkan kamu untuk **kembali ke versi sebelumnya** dari kode kamu.
- Memudahkan **kerja tim**, karena beberapa orang bisa bekerja pada bagian berbeda dari proyek secara bersamaan tanpa langsung bentrok.

#### Contoh:
Misalnya kamu sedang membuat aplikasi, dan kamu ingin bereksperimen tanpa merusak versi yang sudah jalan. Dengan Git, kamu bisa buat **cabang (branch)** untuk eksperimen, dan kalau berhasil, baru digabungkan lagi ke versi utama.

---

### 🌐 **Apa itu GitHub?**

**GitHub** adalah **platform hosting untuk proyek yang menggunakan Git**. Bisa dibilang:

> Git = alatnya  
> GitHub = tempat menyimpan dan berbagi hasil kerjanya di internet

Fitur GitHub:
- Menyimpan proyek kamu secara **online** (di cloud).
- Memungkinkan **kolaborasi tim** secara jarak jauh.
- Mendukung fitur seperti **pull request**, **issue tracking**, dan **CI/CD**.

GitHub juga populer untuk proyek open-source: kamu bisa melihat kode sumber ribuan proyek besar (termasuk Python, React, dll), dan bahkan ikut berkontribusi.

## 💻 Bagian 1: **Install Git di Komputermu**
(✅ Lewati jika Git sudah terpasang)

### Untuk macOS:
1. Buka Terminal
2. Ketik:
   ```bash
   git --version
   ```
   Jika muncul versi seperti `git version 2.38.1`, artinya sudah terinstall.
3. Kalau belum, bisa install lewat Homebrew:
   ```bash
   brew install git
   ```

---

## 🌐 Bagian 2: **Buat Akun GitHub dan Repository**

1. Kunjungi [https://github.com](https://github.com)
2. Daftar / login
3. Klik **New repository**
4. Isi:
   - Repository name: `belajar-git`
   - Deskripsi (opsional): `Proyek latihan Git pertama`
   - Centang "Add a README file"
5. Klik **Create repository**

---

## 🖥️ Bagian 3: **Clone Repository ke Komputermu**

Buka Terminal:

```bash
git clone https://github.com/USERNAME/belajar-git.git
```

> Ganti `USERNAME` dengan username GitHub kamu.

---

## ✍️ Bagian 4: **Edit dan Simpan Perubahan**

1. Masuk ke folder project:
   ```bash
   cd belajar-git
   ```

2. Buat file baru:
   ```bash
   echo "Halo, dunia Git!" > hello.txt
   ```

3. Cek status:
   ```bash
   git status
   ```

---

## 📦 Bagian 5: **Simpan Perubahan ke Git (Commit)**

```bash
git add .
git commit -m "Tambah file hello.txt"
```

---

## ☁️ Bagian 6: **Kirim ke GitHub (Push)**

```bash
git push origin main
```

---

## ✅ Cara Memperbaiki: Pakai Personal Access Token

### 🔐 1. Buat Personal Access Token (PAT)

1. Masuk ke GitHub: [https://github.com](https://github.com)
2. Klik kanan atas fotomu → **Settings**
3. Di sidebar kiri, pilih **Developer settings**
4. Pilih **Personal access tokens → Tokens (classic)**
5. Klik **Generate new token → Generate new token (classic)**

6. Isi:
   - **Note**: misal `token untuk push`
   - **Expiration**: boleh pilih `90 days`, atau `no expiration`
   - Centang scope minimal:
     - ✅ `repo` (untuk akses ke repository pribadi/publik)

7. Klik **Generate token**
8. Salin token yang muncul (hanya muncul **sekali**). **Amankan baik-baik!**

## 🔁 Opsi 1: **Buat Alias di Git**
Supaya kamu cukup ketik `gp` daripada `git push origin main`.

### ✅ Langkah:
Di terminal, jalankan:

```bash
git config --global alias.gp "push origin main"
```

Setelah itu, cukup ketik:

```bash
git gp
```

dan itu akan menjalankan:

```bash
git push origin main
```

Kamu juga bisa buat alias lain, misalnya:

```bash
git config --global alias.co "checkout"
git config --global alias.cm "commit -m"
git config --global alias.st "status"
```

Contoh penggunaan:

```bash
git cm "tambah fitur baru"
git st
git co -b fitur-1
```

---

## 🔁 Opsi 2: **Buat Skrip Otomatis untuk Banyak Project**

Misalnya kamu sering kerja di 3 folder Git: `Artikel-Gasing`, `Buku-Gasing`, `Video-Gasing`, dan ingin semua dipush sekaligus.

### Buat file bernama `gitpushsemua.sh`:

```bash
#!/bin/bash

echo "Push Artikel-Gasing"
cd ~/Documents/Artikel-Gasing && git add . && git commit -m "$1" && git push

echo "Push Buku-Gasing"
cd ~/Documents/Buku-Gasing && git add . && git commit -m "$1" && git push

echo "Push Video-Gasing"
cd ~/Documents/Video-Gasing && git add . && git commit -m "$1" && git push

echo "Selesai semua!"
```

### Simpan dan jalankan:

1. Simpan file, lalu beri izin eksekusi:

```bash
chmod +x gitpushsemua.sh
```

2. Jalankan dengan pesan commit:

```bash
./gitpushsemua.sh "update semua project"
```

---

## 💡 BONUS: Auto `git add .`, commit, dan push dalam 1 alias

Kalau kamu kerja sendirian dan ingin push cepat:

```bash
git config --global alias.acp '!f() { git add . && git commit -m "$1" && git push; }; f'
```

Cara pakai:

```bash
git acp "update isi file"
```
