# 💬 Apa itu Bash

**Tanggal:** `2026-05-08 14.18`

### 👤 User:
apa itu bash?

### 🤖 ChatGPT:
**Bash** adalah program *shell* atau *command-line interpreter* yang dipakai untuk mengetik dan menjalankan perintah di sistem operasi, terutama Linux dan macOS.

Contohnya, di Bash kamu bisa mengetik:

```bash
ls
```

untuk melihat daftar file/folder, atau:

```bash
cd Documents
```

untuk pindah ke folder `Documents`.

Nama **Bash** berasal dari **Bourne Again SHell**. Bash sering dipakai untuk:

- menjalankan perintah terminal
- mengelola file dan folder
- menjalankan program
- membuat skrip otomatisasi, misalnya `backup.sh`

Contoh skrip Bash sederhana:

```bash
#!/bin/bash
echo "Halo!"
```

Saat dijalankan, skrip itu akan menampilkan:

```text
Halo!
```
