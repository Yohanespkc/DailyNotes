### 🤖 ChatGPT:
Di Mac, cara paling praktis lewat Terminal adalah pakai **Ghostscript**.

## 1. Cek apakah Homebrew sudah ada
Buka Terminal, lalu ketik:

```bash
brew --version
```

Kalau muncul versi, lanjut ke langkah 2.

Kalau muncul `command not found`, install Homebrew dulu:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Setelah selesai, cek lagi:

```bash
brew --version
```

## 2. Install Ghostscript
Ketik:

```bash
brew install ghostscript
```

Setelah selesai, cek:

```bash
gs --version
```

## 3. Pindah ke folder tempat PDF berada
Misalnya file PDF ada di folder Downloads:

```bash
cd ~/Downloads
```

Lalu lihat nama file:

```bash
ls
```

Misalnya nama file Anda `dokumen_besar.pdf`.

## 4. Kompres PDF
Coba perintah ini dulu:

```bash
gs -sDEVICE=pdfwrite -dCompatibilityLevel=1.4 -dPDFSETTINGS=/ebook -dNOPAUSE -dQUIET -dBATCH -sOutputFile=hasil_kompres.pdf dokumen_besar.pdf
```

Hasilnya akan menjadi file baru: `hasil_kompres.pdf`

## 5. Cek ukuran file
Ketik:

```bash
ls -lh
```

Lihat apakah ukuran sudah mendekati **20 MB**.

---

## Kalau hasilnya masih terlalu besar
Coba kompres lebih kuat dengan setting `/screen`:

```bash
gs -sDEVICE=pdfwrite -dCompatibilityLevel=1.4 -dPDFSETTINGS=/screen -dNOPAUSE -dQUIET -dBATCH -sOutputFile=hasil_kompres_kecil.pdf dokumen_besar.pdf
```

Urutan kualitas umumnya:

- `/prepress` = kualitas tinggi, file masih besar
- `/printer` = sedang
- `/ebook` = cukup bagus, sering cocok
- `/screen` = paling kecil, kualitas turun lebih banyak

---

## Kalau Anda ingin target sekitar 20 MB dengan kontrol lebih halus
Bisa pakai pengaturan resolusi gambar, misalnya:

```bash
gs -sDEVICE=pdfwrite -dCompatibilityLevel=1.4 \
-dDownsampleColorImages=true -dColorImageResolution=110 \
-dDownsampleGrayImages=true -dGrayImageResolution=110 \
-dDownsampleMonoImages=true -dMonoImageResolution=110 \
-dNOPAUSE -dQUIET -dBATCH \
-sOutputFile=hasil_20mb.pdf dokumen_besar.pdf
```

Kalau masih terlalu besar, turunkan `110` jadi `90` atau `72`.

Kalau kualitas terlalu jelek, naikkan ke `130` atau `150`.

---

## Contoh paling sederhana
Misalnya file Anda bernama:

```bash
Laporan.pdf
```

Maka perintahnya:

```bash
gs -sDEVICE=pdfwrite -dCompatibilityLevel=1.4 -dPDFSETTINGS=/ebook -dNOPAUSE -dQUIET -dBATCH -sOutputFile=Laporan_kecil.pdf Laporan.pdf
```

---

## Catatan penting
- PDF yang isinya banyak **scan gambar** biasanya bisa dikompres cukup banyak.
- PDF yang sudah dari awal sangat terkompres kadang **sulit turun drastis** tanpa kualitas jatuh.
- Dari **150 MB ke 20 MB** itu sering bisa, tapi tidak selalu mulus dalam satu kali coba. Biasanya mulai dari `/ebook`, lalu kalau masih besar pindah ke `/screen`.

Kalau Anda mau, saya bisa buatkan **langkah yang super pelan, satu per satu, khusus untuk Mac baru**, mulai dari buka Terminal sampai file jadi.
