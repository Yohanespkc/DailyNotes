## 1. Arti link tersebut

```
obsidian://open
?vault=StudyNotes
&file=Permanent/Projects/PKC Kernel/MCard
```

### Maknanya:
- **obsidian://open** → protokol khusus untuk memanggil Obsidian
- **vault=StudyNotes** → nama vault Obsidian (HARUS persis sama)
- **file=Permanent/Projects/PKC Kernel/MCard**  
  → path note di dalam vault  
  → Obsidian otomatis mengartikan: `MCard.md`

📌 Jadi maksud link ini:
> **Buka vault `StudyNotes`, lalu buka file `MCard.md` di folder `Permanent/Projects/PKC Kernel/`.**

---

## 2. Kapan link ini BERHASIL dibuka ✅

Link ini akan bekerja **hanya jika semua syarat terpenuhi**:

1. ✅ Obsidian **sudah terinstall**
2. ✅ Vault bernama **`StudyNotes` benar-benar ada**
3. ✅ Path folder **tepat huruf besar–kecilnya**
4. ✅ File **`MCard.md` ada** (atau minimal foldernya ada)
5. ✅ Dibuka dari:
   - browser desktop
   - terminal
   - aplikasi lain (misalnya Notion, email, PDF)

📌 **Tidak selalu bisa diklik langsung dari chat** (tergantung sandbox browser).

## 4. Masalah yang PALING sering terjadi ❌

### ❌ Vault tidak ditemukan
Nama vault **HARUS IDENTIK**  
Misal vault aslinya:
- `Study Notes`
- `studynotes`
- `StudyNotes (1)`

➡️ Maka link **pasti gagal**.

✅ Solusi:  
Buka Obsidian → **Open another vault** → lihat nama tepatnya.

---

### ❌ Folder / file belum ada
Jika `MCard.md` tidak ada:

✅ Solusi cepat:
- Buat note kosong bernama `MCard`
- Letakkan di path:
  ```
  Permanent/Projects/PKC Kernel/
  ```

---

### ❌ Spasi tidak diencode
Versi aman:
```
%20  → spasi
%2F  → /
```

Versi manusia (untuk Obsidian internal):
```
Permanent/Projects/PKC Kernel/MCard
```
