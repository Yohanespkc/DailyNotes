### 🤖 ChatGPT:
Cara paling efektif di terminal untuk menurunkan PDF **200 MB menjadi sekitar 8 MB** biasanya adalah memakai **Ghostscript**, karena `qpdf` umumnya hanya merapikan struktur PDF dan tidak banyak mengecilkan ukuran jika sumber pembengkakan ada pada gambar. Dokumentasi resmi Ghostscript juga menyediakan preset kompresi seperti `/screen` dan `/ebook` untuk `pdfwrite`. citeturn266249search0turn266249search1turn266249search2

Di **macOS**, kalau belum ada Ghostscript:

```bash
brew install ghostscript
```

Lalu coba perintah ini dulu:

```bash
gs -sDEVICE=pdfwrite \
   -dCompatibilityLevel=1.4 \
   -dPDFSETTINGS=/screen \
   -dNOPAUSE -dQUIET -dBATCH \
   -sOutputFile=output_kecil.pdf \
   input.pdf
```

Preset `/screen` biasanya memberi kompresi paling agresif, cocok kalau target Anda memang sekitar **8 MB**. Preset lain yang lebih bagus kualitasnya adalah `/ebook`, tapi hasil file biasanya lebih besar. Preset-preset ini adalah parameter distiller resmi di Ghostscript untuk mengontrol output PDF. citeturn266249search0turn266249search2

Kalau hasil `/screen` masih terlalu besar, pakai versi yang lebih agresif ini:

```bash
gs -sDEVICE=pdfwrite \
   -dCompatibilityLevel=1.4 \
   -dNOPAUSE -dQUIET -dBATCH \
   -dDownsampleColorImages=true \
   -dColorImageDownsampleType=/Bicubic \
   -dColorImageResolution=72 \
   -dDownsampleGrayImages=true \
   -dGrayImageDownsampleType=/Bicubic \
   -dGrayImageResolution=72 \
   -dDownsampleMonoImages=true \
   -dMonoImageDownsampleType=/Subsample \
   -dMonoImageResolution=150 \
   -sOutputFile=output_8mb.pdf \
   input.pdf
```

Kalau PDF Anda banyak berisi scan atau foto, inilah yang biasanya paling berpengaruh: **menurunkan resolusi gambar**. Kalau PDF lebih banyak teks murni, kompresinya sering tidak bisa sedrastis itu. Itu sebabnya target dari **200 MB ke 8 MB** sangat mungkin untuk PDF hasil scan, tetapi kadang sulit untuk PDF yang isinya sudah efisien sejak awal.

Urutan praktik yang saya sarankan:

```bash
# 1. Coba dulu preset cepat
gs -sDEVICE=pdfwrite -dCompatibilityLevel=1.4 -dPDFSETTINGS=/screen \
   -dNOPAUSE -dQUIET -dBATCH \
   -sOutputFile=step1.pdf input.pdf

# 2. Cek ukuran
ls -lh input.pdf step1.pdf
```

Kalau masih terlalu besar, lanjutkan:

```bash
gs -sDEVICE=pdfwrite \
   -dCompatibilityLevel=1.4 \
   -dNOPAUSE -dQUIET -dBATCH \
   -dDownsampleColorImages=true \
   -dColorImageResolution=60 \
   -dDownsampleGrayImages=true \
   -dGrayImageResolution=60 \
   -dDownsampleMonoImages=true \
   -dMonoImageResolution=120 \
   -sOutputFile=step2.pdf input.pdf
```

Lalu cek lagi:

```bash
ls -lh step2.pdf
```

Kalau Anda ingin, saya bisa buatkan **satu baris perintah paling pas untuk Mac** dengan target **sekitar 8 MB**, misalnya versi **lebih tajam**, **lebih kecil**, atau **aman untuk dokumen teks**.

**Cara 1 — paling mudah dari pengaturan**
1. Klik ** Apple menu**.
2. Buka **System Settings**.
3. Klik **Users & Groups**.
4. Lihat daftar akun yang ada.

Di sana biasanya akan tertulis jenis akun, misalnya:
- **Admin**
- **Standard**
- kadang **Sharing Only**

Kalau di bawah nama akun tertulis **Admin**, berarti akun itu administrator. Apple memang menampilkan tipe akun di bagian **Users & Groups**. citeturn0search0

**Cara 2 — cek akun yang sedang dipakai lewat Terminal**
Buka **Terminal**, lalu ketik:

```bash
id -Gn
```

Kalau hasilnya ada kata:

```bash
admin
```

berarti akun yang sedang login sekarang adalah admin. Perintah `id` di macOS menampilkan grup yang dimiliki user aktif, dan anggota grup `admin` punya hak administrator. citeturn0search1turn0search2

Supaya lebih jelas, cek nama akun aktif sekarang:

```bash
whoami
```

Lalu cek grupnya:

```bash
id -Gn $(whoami)
```

Kalau muncul `admin`, akun itu admin. citeturn0search1turn0search2

**Cara 3 — lihat semua user admin di Mac**
Di Terminal, jalankan:

```bash
dscl . -read /Groups/admin GroupMembership
```

Hasilnya akan menampilkan daftar username yang termasuk grup `admin`. Itulah akun-akun administrator di Mac Anda. Perintah `dscl` memang digunakan untuk membaca informasi user dan group lokal di macOS. citeturn0search2turn0search3

**Cara membaca hasilnya**
Misalnya keluar:

```bash
GroupMembership: root ys david
```

Artinya:
- `ys` = admin
- `david` = admin
- `root` itu akun sistem

**Kalau mau cocokkan username dengan nama lengkap akun**
Ketik:

```bash
dscl . list /Users RealName
```

Itu membantu melihat username dan nama akun yang lebih mudah dikenali. citeturn0search3

**Tes terakhir**
Kalau Anda curiga akun aktif sekarang admin, coba:

```bash

```

- Kalau diminta password, lalu diterima tanpa error, akun itu punya hak admin.
- Kalau muncul pesan bahwa user tidak boleh pakai sudo, akun itu bukan admin. Hak `sudo` di macOS umumnya diberikan ke admin. citeturn0search2
