### **Apa itu Jupyter Notebook?**
Jupyter Notebook adalah aplikasi berbasis web yang memungkinkan Anda menulis dan menjalankan kode, membuat catatan, serta memvisualisasikan data dalam satu tempat. Sangat cocok untuk belajar pemrograman dan sains data.

---

### **Langkah 1: Instalasi Jupyter Notebook**
1. **Pastikan Python Terinstal**:
   - Unduh dan instal [Python](https://www.python.org/downloads/) (pilih versi terbaru).
   - Saat instalasi, pastikan Anda mencentang opsi **Add Python to PATH**.

2. **Install Jupyter Notebook**:
   - Buka terminal/command prompt dan jalankan perintah:
     ```
     pip install notebook
     ```
   - Tunggu hingga instalasi selesai.

---

### **Langkah 2: Membuka Jupyter Notebook**
1. Buka terminal atau command prompt.
2. Ketik:
   ```
   jupyter notebook
   ```
3. Browser Anda akan terbuka secara otomatis dengan halaman Jupyter Notebook. Jika tidak, salin tautan yang ditampilkan di terminal ke browser.

---

### **Langkah 3: Membuat Notebook Baru**
1. Di halaman Jupyter, klik tombol **New** di sisi kanan atas.
2. Pilih **Python 3** dari daftar.
3. Anda sekarang memiliki sebuah notebook baru yang siap digunakan!

---

### **Langkah 4: Struktur Dasar Notebook**
- Notebook memiliki sel (**cell**) untuk menjalankan kode atau menulis teks.
- Ada dua jenis utama:
  1. **Code Cell**: Tempat Anda menulis kode Python.
  2. **Markdown Cell**: Tempat untuk menulis teks, catatan, atau format lain.

---

### **Langkah 5: Menulis dan Menjalankan Kode**
1. **Menulis Kode di Code Cell**:
   - Klik di dalam sel pertama dan tuliskan kode berikut:
     ```python
     print("Halo, dunia!")
     ```
   - Tekan **Shift + Enter** untuk menjalankan kode.
   - Anda akan melihat hasilnya di bawah sel.

2. **Menulis Markdown**:
   - Klik di dalam sel, lalu ubah jenis sel menjadi "Markdown" dengan toolbar di atas.
   - Tulis teks berikut:
     ```
     ## Ini adalah heading
     Selamat datang di Jupyter Notebook!
     ```
   - Tekan **Shift + Enter** untuk memformat teks.

---

### **Langkah 6: Menyimpan Notebook**
- Klik **File > Save and Checkpoint** untuk menyimpan pekerjaan Anda.
- File akan disimpan dengan format `.ipynb` yang bisa dibuka lagi nanti.

---

### **Langkah 7: Contoh Proyek Sederhana**
Cobalah membuat kalkulator sederhana:
1. Tambahkan sel kode baru.
2. Tulis kode berikut:
   ```python
   # Kalkulator Sederhana
   angka1 = float(input("Masukkan angka pertama: "))
   angka2 = float(input("Masukkan angka kedua: "))
   operasi = input("Masukkan operasi (+, -, *, /): ")

   if operasi == '+':
       hasil = angka1 + angka2
   elif operasi == '-':
       hasil = angka1 - angka2
   elif operasi == '*':
       hasil = angka1 * angka2
   elif operasi == '/':
       hasil = angka1 / angka2
   else:
       hasil = "Operasi tidak valid"

   print("Hasil:", hasil)
   ```
3. Jalankan kode dengan **Shift + Enter**, masukkan input sesuai instruksi, dan lihat hasilnya.

---

### **Langkah 8: Menutup Jupyter Notebook**
- Untuk menutup notebook, klik **File > Close and Halt**.
- Kembali ke terminal, tekan **Ctrl + C** untuk menghentikan server Jupyter.

### **Langkah 1: Instalasi Cookiecutter**
1. **Pastikan Python sudah terinstal**:
   - Cek versi Python dengan perintah:
     ```bash
     python --version
     ```
   - Jika belum terinstal, unduh dari [situs resmi Python](https://www.python.org).

2. **Instal Cookiecutter**:
   - Buka terminal/command prompt dan jalankan:
     ```bash
     pip install cookiecutter
     ```

---

### **Langkah 2: Menggunakan Template Cookiecutter**
Cookiecutter bekerja dengan menggunakan template yang sudah ada. Sebagai contoh, kita akan membuat proyek Python sederhana.

1. **Gunakan Template Resmi Python**:
   - Jalankan perintah:
     ```bash
     cookiecutter https://github.com/audreyfeldroy/cookiecutter-pypackage.git
     ```

2. **Isi Informasi Proyek**:
   - Cookiecutter akan meminta Anda untuk mengisi detail seperti nama proyek, deskripsi, dan lainnya. Contohnya:
     ```
     project_name [My Python Project]: MyFirstProject
     repo_name [my-python-project]: my_first_project
     author_name [Your name (or your organization/company/team)]: YourName
     description [A short description of the project.]: Program Sederhana
     ```

3. **Struktur Proyek Akan Dibuat**:
   - Setelah selesai, folder proyek Anda akan terlihat seperti ini:
     ```
     MyFirstProject/
     ├── README.rst
     ├── setup.py
     ├── my_first_project/
     │   └── __init__.py
     ├── tests/
     │   └── test_my_first_project.py
     ```

---

### **Langkah 3: Memodifikasi Program**
1. **Tambahkan Kode Anda**:
   - Buka file `my_first_project/__init__.py` dan tambahkan kode berikut sebagai contoh:
     ```python
     def hello_world():
         return "Hello, World!"
     ```

2. **Modifikasi Test (Opsional)**:
   - Buka file `tests/test_my_first_project.py` dan tambahkan test:
     ```python
     from my_first_project import hello_world

     def test_hello_world():
         assert hello_world() == "Hello, World!"
     ```

---

### **Langkah 4: Menjalankan Proyek**
1. **Masuk ke Direktori Proyek**:
   ```bash
   cd MyFirstProject
   ```

2. **Menginstal Dependensi (Opsional)**:
   - Jika proyek menggunakan dependensi, instal dengan:
     ```bash
     pip install -e .
     ```

3. **Menjalankan Program**:
   - Buat file baru `main.py` di folder proyek dengan isi:
     ```python
     from my_first_project import hello_world

     if __name__ == "__main__":
         print(hello_world())
     ```
   - Jalankan program:
     ```bash
     python main.py
     ```

4. **Menjalankan Tes**:
   - Gunakan `pytest` untuk memastikan semua tes lulus:
     ```bash
     pip install pytest
     pytest
     ```

---

### **Langkah 5: Penyesuaian dan Penggunaan**
- Anda dapat memodifikasi fungsi, menambah fitur, dan memperluas proyek sesuai kebutuhan.
- Untuk menambahkan dependensi, tambahkan ke `setup.py` atau `requirements.txt`.

Kita akan membuat **aplikasi CLI (Command Line Interface)** sederhana yang menarik menggunakan **Cookiecutter**. Aplikasi ini adalah **"Todo Manager"**, sebuah alat untuk mencatat daftar tugas (To-Do) dan mengelolanya langsung dari terminal.

---

### **Langkah 1: Buat Proyek Menggunakan Cookiecutter**
1. Jalankan perintah berikut untuk menggunakan template proyek Python:
   ```bash
   cookiecutter https://github.com/audreyfeldroy/cookiecutter-pypackage.git
   ```
2. Isi informasi berikut saat diminta:
   ```
   project_name [My Python Project]: TodoManager
   repo_name [my-python-project]: todo_manager
   author_name [Your Name]: [Tulis nama Anda]
   description [A short description of the project.]: CLI untuk mengelola daftar tugas
   ```

---

### **Langkah 2: Tambahkan Logika "Todo Manager"**
1. Masuk ke folder proyek:
   ```bash
   cd TodoManager
   ```

2. Buka file `todo_manager/__init__.py` dan tambahkan kode berikut:
   ```python
   import os
   import json

   TODO_FILE = "todo.json"

   def load_todos():
       """Load todos from the JSON file."""
       if not os.path.exists(TODO_FILE):
           return []
       with open(TODO_FILE, "r") as file:
           return json.load(file)

   def save_todos(todos):
       """Save todos to the JSON file."""
       with open(TODO_FILE, "w") as file:
           json.dump(todos, file, indent=4)

   def list_todos():
       """List all todos."""
       todos = load_todos()
       if not todos:
           print("No tasks available.")
       else:
           print("Your To-Do List:")
           for idx, task in enumerate(todos, 1):
               status = "✓" if task["completed"] else "✗"
               print(f"{idx}. {task['task']} [{status}]")

   def add_todo(task):
       """Add a new todo."""
       todos = load_todos()
       todos.append({"task": task, "completed": False})
       save_todos(todos)
       print(f"Task '{task}' added.")

   def complete_todo(index):
       """Mark a task as completed."""
       todos = load_todos()
       if 0 <= index < len(todos):
           todos[index]["completed"] = True
           save_todos(todos)
           print(f"Task '{todos[index]['task']}' marked as completed.")
       else:
           print("Invalid task number.")

   def delete_todo(index):
       """Delete a task."""
       todos = load_todos()
       if 0 <= index < len(todos):
           removed = todos.pop(index)
           save_todos(todos)
           print(f"Task '{removed['task']}' deleted.")
       else:
           print("Invalid task number.")
   ```

3. Buat file `main.py` di direktori utama proyek dengan kode berikut:
   ```python
   from todo_manager import list_todos, add_todo, complete_todo, delete_todo

   def main():
       print("Welcome to Todo Manager!")
       while True:
           print("\nMenu:")
           print("1. List Tasks")
           print("2. Add Task")
           print("3. Complete Task")
           print("4. Delete Task")
           print("5. Exit")

           choice = input("Choose an option: ")

           if choice == "1":
               list_todos()
           elif choice == "2":
               task = input("Enter task description: ")
               add_todo(task)
           elif choice == "3":
               index = int(input("Enter task number to complete: ")) - 1
               complete_todo(index)
           elif choice == "4":
               index = int(input("Enter task number to delete: ")) - 1
               delete_todo(index)
           elif choice == "5":
               print("Goodbye!")
               break
           else:
               print("Invalid choice. Please try again.")

   if __name__ == "__main__":
       main()
   ```

---

### **Langkah 3: Menjalankan Aplikasi**
1. **Instal Proyek Secara Lokal**:
   ```bash

   ```

2. **Jalankan Aplikasi**:
   ```bash
   python main.py
   ```

---

### **1. Windows**
- Secara default:
  - Jika menggunakan tombol **PrtScn** (Print Screen):
    - Screenshot disalin ke clipboard. Anda perlu membuka aplikasi seperti Paint atau Word, lalu paste (Ctrl + V).
  - Jika menggunakan **Windows + PrtScn**:
    - Screenshot akan disimpan di folder:
      ```
      C:\Users\<YourUsername>\Pictures\Screenshots
      ```
  - Jika menggunakan **Snipping Tool** atau **Snip & Sketch**:
    - Anda akan diminta memilih lokasi untuk menyimpan file screenshot.

---

### **2. Mac**
- Screenshot disimpan otomatis di desktop.
- Format nama file: `Screenshot YYYY-MM-DD at HH.MM.SS.png`.
- Kombinasi tombol:
  - **Command + Shift + 3**: Screenshot seluruh layar.
  - **Command + Shift + 4**: Screenshot bagian tertentu.
  - **Command + Shift + 5**: Mengakses menu screenshot.

---

### **3. Linux (Umumnya Ubuntu)**
- Jika menggunakan tombol **PrtScn**:
  - Screenshot seluruh layar disimpan di direktori:
    ```
    ~/Pictures
    ```
  - Jika menggunakan **Shift + PrtScn**:
    - Anda dapat memilih area tertentu, dan file disimpan di lokasi yang sama.

---

### **4. Smartphone**
- **Android**:
  - Screenshot biasanya disimpan di folder:
    ```
    Internal Storage/Pictures/Screenshots
    ```
  - Atau dapat ditemukan di galeri atau aplikasi Photos di folder **Screenshots**.
- **iOS (iPhone)**:
  - Screenshot disimpan di aplikasi **Photos**, di album **Screenshots**.
