## ✅ 2. Load Model Qwen 1.8B (tanpa LoRA)

```python
from unsloth import FastLanguageModel
import torch

# Pilih device
device_map = "auto"
dtype = torch.float16

model, tokenizer = FastLanguageModel.from_pretrained(
    model_name = "Qwen/Qwen1.5-1.8B",  # Model dari Hugging Face
    max_seq_length = 2048,
    dtype = dtype,
    load_in_4bit = False,       # Full precision (tanpa quantization)
    low_cpu_mem_usage = True,   # Hemat RAM
)
```

---

## ✅ 3. Dataset Sederhana

Kita coba pakai dataset dummy dulu. Kamu bisa ganti nanti dengan dataset kamu sendiri (file `.jsonl`, `.csv`, atau dari Hugging Face Hub).

Contoh data:

```python
dataset = [
    {
        "instruction": "Apa itu gravitasi?",
        "input": "",
        "output": "Gravitasi adalah gaya tarik yang dimiliki oleh semua benda bermassa."
    },
    {
        "instruction": "Tuliskan fakta tentang kucing",
        "input": "",
        "output": "Kucing tidur sekitar 12-16 jam sehari."
    }
]
```

Ubah jadi format `Dataset`:

```python
from datasets import Dataset

dataset = Dataset.from_list(dataset)
```

---

## ✅ 4. Preprocessing (Sesuai format SFT)

```python
from unsloth import preprocess_dataset

dataset = preprocess_dataset(
    dataset = dataset,
    tokenizer = tokenizer,
    max_length = 2048,
    formatting_func = lambda x: f"### Instruction:\n{x['instruction']}\n### Response:\n{x['output']}",
    add_eos_token = True,
)
```

---

## ✅ 5. Fine-Tuning (tanpa LoRA)

```python
from transformers import TrainingArguments
from unsloth import SFTTrainer

trainer = SFTTrainer(
    model = model,
    tokenizer = tokenizer,
    train_dataset = dataset,
    dataset_text_field = "text",
    max_seq_length = 2048,
    args = TrainingArguments(
        per_device_train_batch_size = 1,
        gradient_accumulation_steps = 4,
        warmup_steps = 5,
        max_steps = 30,  # Coba kecil dulu, nanti bisa ditambah
        learning_rate = 2e-5,
        fp16 = True,
        logging_steps = 1,
        output_dir = "qwen_finetuned",
        save_total_limit = 1,
        save_strategy = "steps",
        save_steps = 30,  # Simpan model setelah selesai
        evaluation_strategy = "no",
        report_to = "none",
    )
)

trainer.train()
```

---

## ✅ 6. Simpan Model

```python
model.save_pretrained("qwen-finetuned-full")
tokenizer.save_pretrained("qwen-finetuned-full")
```

## ✅ 7. Uji Model

```python
from transformers import pipeline

pipe = pipeline("text-generation", model=model, tokenizer=tokenizer, device=0)

result = pipe("### Instruction:\nApa itu gravitasi?\n### Response:\n", max_new_tokens=100)
print(result[0]["generated_text"])
```

## Catatan Penting
- **Qwen 1.8B** cukup besar, jadi butuh GPU dengan VRAM lumayan (di atas 16GB ideal).
- Untuk Google Colab free, bisa coba model yang lebih kecil seperti **Qwen 0.5B** kalau out-of-memory.
- Hindari `load_in_4bit=True` kalau memang ingin full-finetune tanpa LoRA atau quantization.
