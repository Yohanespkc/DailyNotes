### 🤖 ChatGPT:
Kalau maksud Anda “translate ke Inggris di Excel (Xcell)”, ada beberapa cara praktis yang bisa dipakai:

### 1. Menggunakan **Fungsi Microsoft Translator di Excel 365**
Jika Anda pakai **Microsoft 365 / Excel terbaru**, ada add-in **Translator** dari Microsoft.
- Klik **Review** → **Translate**.
- Pilih bahasa asal (Indonesia) dan bahasa tujuan (English).
- Hasil terjemahan akan muncul di panel, bisa langsung dimasukkan ke sel.

### 2. Menggunakan **Formula `WEBSERVICE` + API Google Translate**
Jika add-in tidak tersedia, bisa juga pakai formula dengan API gratis/berbayar:
- Contoh (perlu API key Google Translate atau DeepL):
  ```excel
  =WEBSERVICE("https://api.mymemory.translated.net/get?q=" & A1 & "&langpair=id|en")
  ```
  → ini akan mengirim isi sel **A1** untuk diterjemahkan dari Indonesia (`id`) ke Inggris (`en`).

### 3. Menggunakan **Power Query + Translator**
- Masukkan teks ke tabel.
- Buka **Data → Get & Transform (Power Query)**.
- Tambahkan kolom kustom dengan fungsi web (API Translate).
- Hasilnya bisa dimuat kembali ke worksheet.

### 4. Cara Manual Cepat
Jika tidak ingin rumit:
- Copy kolom teks Indonesia dari Excel.
- Paste ke Google Translate / DeepL.
- Copy hasilnya kembali ke Excel.

## 🔹 A. Cara paling mudah (pakai fitur bawaan Excel / Office 365)
1. Buka file Excel Anda.  
2. Klik tab **Review** → pilih **Translate**.  
3. Di panel kanan, pilih:  
   - From: **Indonesian (id)**  
   - To: **English (en)**  
4. Klik **Insert** untuk memasukkan hasil terjemahan langsung ke sel.  

👉 Ini tidak perlu coding atau API, tapi hanya ada di versi Microsoft 365 yang sudah ada fitur Translator.

---

## 🔹 B. Cara pakai formula (dengan API gratis MyMemory)
Kalau Excel Anda tidak punya fitur Translate bawaan, bisa pakai API.  
Misalnya isi sel **A1** adalah teks bahasa Indonesia.  
Di sel **B1**, tulis formula ini:

```excel
=WEBSERVICE("https://api.mymemory.translated.net/get?q=" & A1 & "&langpair=id|en")
```

⚠️ Catatan: hasil yang keluar masih berupa JSON (format teks). Supaya ambil terjemahannya saja, bisa pakai fungsi `FILTERXML`, contoh:

```excel
=FILTERXML(WEBSERVICE("https://api.mymemory.translated.net/get?q=" & A1 & "&langpair=id|en"),"//translatedText")
```

Hasilnya langsung keluar dalam bahasa Inggris.
