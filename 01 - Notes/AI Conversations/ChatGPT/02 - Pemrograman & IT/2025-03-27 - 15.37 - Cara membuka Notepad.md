# 💬 Cara membuka Notepad

**Tanggal:** `2025-03-27 15.37`  
**Sumber:** ChatGPT Export  

---

### 👤 User:
bagaimana cara membuka notepad

### 🤖 ChatGPT:
Untuk membuka **Notepad**, caranya tergantung sistem operasi yang kamu gunakan. Berikut panduan untuk **Windows** dan **macOS**:

---

### 🪟 **Jika kamu menggunakan Windows:**

#### 🔹 Cara 1: Lewat Pencarian
1. Klik tombol **Start** (ikon Windows di pojok kiri bawah).
2. Ketik **Notepad**.
3. Klik **Notepad** dari hasil pencarian.

#### 🔹 Cara 2: Lewat Run
1. Tekan tombol **Windows + R** di keyboard.
2. Ketik `notepad` lalu tekan **Enter**.

#### 🔹 Cara 3: Lewat Command Prompt
1. Tekan **Windows + R**, ketik `cmd`, lalu Enter.
2. Di jendela Command Prompt, ketik `notepad` lalu Enter.

---

### 🍎 **Jika kamu menggunakan macOS:**

macOS **tidak memiliki Notepad**, tapi kamu bisa pakai **TextEdit**:

#### 🔹 Cara 1: Lewat Spotlight
1. Tekan **Command (⌘) + Space**.
2. Ketik **TextEdit**.
3. Tekan **Enter** untuk membuka.

#### 🔹 Cara 2: Lewat Finder
1. Buka **Finder**.
2. Masuk ke folder **Applications**.
3. Cari dan klik **TextEdit**.

---

Kalau kamu kasih tahu kamu pakai sistem operasi apa (Windows/Mac/Linux), aku bisa kasih petunjuk lebih spesifik! 😊
