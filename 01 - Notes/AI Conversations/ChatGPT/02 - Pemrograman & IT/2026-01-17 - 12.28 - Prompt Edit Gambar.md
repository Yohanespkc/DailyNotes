## ❓ Apakah copy–paste Word ke Word menurunkan resolusi gambar?

### ✅ **TIDAK berkurang**, jika:
- Gambar **masih embedded asli** (bukan hasil screenshot)
- Word **tidak mengompres gambar**
- Copy dilakukan **langsung gambar atau seluruh halaman**, bukan “Paste as Picture (Compressed)”

👉 Dalam kondisi ini, **resolusi piksel gambar tetap sama**.

---

### ⚠️ **BISA berkurang**, jika terjadi salah satu ini:

1. **Word melakukan kompresi otomatis**
   - Word sering mengompres gambar **diam-diam**
   - Terutama jika:
     - File pernah disimpan sebagai PDF
     - Pernah dikirim via email
     - Default setting Word aktif

2. **Paste sebagai “Picture” / “Enhanced Metafile”**
   - Ini bisa mengubah gambar jadi versi **raster baru** dengan DPI lebih rendah

3. **Gambar berasal dari copy layar (screenshot)**
   - Screenshot biasanya **96–144 DPI**, bukan 300 DPI

4. **Copy dari PDF ke Word**
   - Ini hampir pasti **turun kualitas**

---

## 🛡️ Cara AMAN agar resolusi TIDAK turun (WAJIB untuk buku)

### 🔹 1. Matikan kompresi gambar di Word (PENTING)
Di **Word (Mac & Windows)**:
```
File → Preferences / Options → Advanced
→ Image Size and Quality
☑ Do not compress images in file
Default resolution: High fidelity
```

### 🔹 2. Cara copy–paste yang paling aman
