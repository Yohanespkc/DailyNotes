# 💬 Mengubah HTML ke PDF

**Tanggal:** `2025-08-02 10.47`  
**Sumber:** ChatGPT Export  

---

### 👤 User:
bagaimana mengubah file:///Users/ys/Downloads/boc_report_pdf.html kedalam pdf

### 🤖 ChatGPT:
Untuk mengubah file HTML lokal seperti `file:///Users/ys/Downloads/boc_report_pdf.html` menjadi PDF di Mac, Anda bisa mengikuti salah satu dari beberapa cara berikut:

---

### ✅ **Cara 1: Menggunakan Browser (Safari, Chrome, atau Firefox)**

1. **Buka file HTML**
   - Klik dua kali pada file `boc_report_pdf.html` di folder **Downloads**.
   - Biasanya akan terbuka di **browser default** (Safari, Chrome, dsb).

2. **Print sebagai PDF**
   - Tekan `Command + P` (⌘+P) untuk membuka jendela Print.
   - Pada bagian **Destination** atau **Printer**, pilih **"Save as PDF"** atau **"Cetak ke PDF"**.
   - Klik **Save**, lalu pilih lokasi penyimpanan dan nama file PDF-nya.

---

### ✅ **Cara 2: Menggunakan Terminal (jika butuh otomatisasi)**
Jika Anda ingin menggunakan terminal (misalnya untuk skrip), Anda bisa pakai tool seperti `wkhtmltopdf` atau `pandoc`.

#### a. Instalasi `wkhtmltopdf` (jika belum ada):
```bash
brew install wkhtmltopdf
```

#### b. Ubah file menjadi PDF:
```bash
wkhtmltopdf ~/Downloads/boc_report_pdf.html ~/Downloads/boc_report.pdf
```

---

### ✅ **Cara 3: Gunakan Microsoft Word (jika HTML ingin diubah dan diformat dulu)**

1. Buka file HTML menggunakan Microsoft Word (bisa drag and drop).
2. Sesuaikan jika perlu.
3. Klik `File > Save As` → pilih **PDF** sebagai format output.

---

Kalau kamu ingin saya bantu mengonversinya, silakan unggah file `.html`-nya ke sini. Saya bisa langsung hasilkan PDF-nya untukmu.
