### 🤖 ChatGPT:
Turun dari **500 MB ke 3 MB (≈ 167× lebih kecil)** itu biasanya **hanya mungkin** kalau isi PDF-nya mayoritas **gambar hasil scan**, dan Anda bersedia menurunkan kualitas (DPI) + kompres agresif. Kalau PDF berisi teks vektor (hasil ekspor Word/InDesign), penurunan sebesar itu jarang masuk akal.

Berikut cara paling efektif di macOS (pilih yang cocok):

## Opsi 1 — Paling ampuh: kompres dengan Ghostscript (gratis)
1) Install Ghostscript:
```bash
brew install ghostscript
```

2) Kompres (mulai dari yang paling agresif):
```bash
gs -sDEVICE=pdfwrite -dCompatibilityLevel=1.4 -dNOPAUSE -dBATCH -dSAFER \
-dPDFSETTINGS=/screen \
-sOutputFile=output_3mb_target.pdf input.pdf
```

Kalau masih terlalu besar, coba tambah reduksi gambar:
```bash
gs -sDEVICE=pdfwrite -dCompatibilityLevel=1.4 -dNOPAUSE -dBATCH -dSAFER \
-dPDFSETTINGS=/screen \
-dDownsampleColorImages=true -dColorImageResolution=72 \
-dDownsampleGrayImages=true  -dGrayImageResolution=72 \
-dDownsampleMonoImages=true  -dMonoImageResolution=300 \
-sOutputFile=output_more_compressed.pdf input.pdf
```

**Catatan:** `/screen` biasanya menghasilkan PDF kecil, tapi gambar bisa terlihat blur.

## Opsi 2 — Cepat tanpa terminal: Preview (Pratinjau) macOS
- Buka PDF → **File → Export…**
- Pilih **Quartz Filter: “Reduce File Size”**
- Simpan.

Ini mudah, tapi sering **tidak cukup agresif** untuk target 3 MB.

## Opsi 3 — Kalau PDF scan: buat ulang jadi “scan PDF” ber-DPI rendah
Ini yang sering bisa mengecilkan drastis:
- Ubah ke gambar per halaman (atau re-export) lalu buat PDF baru di **100–150 DPI**.
Tools yang biasa dipakai: Adobe Acrobat Pro, PDF Expert, atau workflow scan ulang.

## Opsi 4 — Adobe Acrobat Pro (kalau ada)
- **File → Save as Other → Optimized PDF**
- Turunkan:
  - Color/Grayscale images: **Downsample 100–150 dpi**, JPEG quality **Medium/Low**
  - Buang metadata, embedded thumbnails, unused objects
- Lihat perkiraan size lalu simpan.
