## 🔍 **APA ITU EMBEDDING?**

Embedding adalah proses mengubah **data simbolik** (seperti kata, kalimat, paragraf) menjadi **representasi numerik (vektor)** di ruang berdimensi tinggi.

Tujuannya:  
Agar **komputer bisa memahami makna** teks secara semantik (bukan cuma hurufnya), sehingga bisa dibandingkan, dicari kemiripan, klasifikasi, dll.

---

## ⚙️ **PROSES EMBEDDING SECARA UMUM**

### 1. **Preprocessing (Pra-pemrosesan)**
   - Input teks diubah menjadi bentuk siap diproses:
     - Lowercase, hapus tanda baca (opsional)
     - Tokenisasi → memecah teks jadi potongan kata / token

   Contoh:
   ```
   Input: "Aku suka belajar AI."
   Token: ["Aku", "suka", "belajar", "AI"]
   ```

---

### 2. **Token Embedding / Lookup**
   - Setiap token diubah menjadi vektor dari tabel embedding yang telah dilatih.
   - Contoh tabel embedding:
     ```plaintext
     "aku"     → [0.3, -0.1, 0.6, ...]
     "suka"    → [0.2,  0.8, -0.4, ...]
     "belajar" → [-0.5, 0.1, 0.9, ...]
     ```

   - Tabel ini diperoleh dari model yang sebelumnya telah belajar dari korpus besar (seperti Wikipedia, buku, web).

---

### 3. **Contextualization (untuk model modern seperti BERT, GPT)**
   - Token-token tadi masuk ke dalam arsitektur transformer.
   - Model mempertimbangkan **konteks kata** (misal: "bank" bisa beda artinya tergantung kalimatnya).
   - Output: satu vektor per token yang sudah mengandung makna berdasarkan konteks.

---

### 4. **Pooling (opsional)**
   - Dari semua vektor token, kita ringkas jadi satu vektor representatif untuk keseluruhan kalimat / paragraf.
     - Bisa pakai **mean pooling** (rata-rata semua token)
     - Atau ambil vektor khusus, seperti `[CLS]` token di BERT

---

### 5. **Hasil Akhir: Vector Embedding**
   - Vektor final ini adalah representasi dari teks aslinya.
   - Contoh:
     ```python
     [0.123, -0.452, 0.002, ..., 0.316]  # Misalnya panjang 384 dimensi
     ```

---

## 🔁 **Ilustrasi Sederhana:**
```plaintext
Input: "Saya suka matematika"
↓
Token: ["saya", "suka", "matematika"]
↓
Embedding:
    "saya" → [0.1, 0.2, 0.3]
    "suka" → [0.4, 0.5, 0.6]
    ...
↓
Mean pooling:
    Final vector → [0.23, 0.4, 0.5] (contoh)
```

## 🧠 1. **Model Klasik: Word2Vec / GloVe**

### ✅ **Inti idenya:**
Model ini menghitung embedding berdasarkan **statistik kemunculan kata** dalam konteks.

> “You shall know a word by the company it keeps.” — J.R. Firth

### 🔢 Langkah Perhitungannya:

#### a. Buat **matrix co-occurrence**  
Contoh (sederhana):
```
       makan   nasi   ayam   saya
makan    0      3      2      1
nasi     3      0      4      2
ayam     2      4      0      2
saya     1      2      2      0
```

#### b. Lakukan **reduksi dimensi** (misal dengan SVD)
- Ini mirip seperti PCA.
- Output-nya adalah vektor berdimensi rendah untuk setiap kata, misalnya 100 dimensi.

---

## 🤖 2. **Model Modern: Transformer (BERT, GPT, sentence-transformers)**

Di sinilah keajaiban AI modern bekerja.

### ✅ **Inti idenya:**
- Token (kata) → **embedding awal** (lookup)
- Lalu masuk ke dalam **lapisan self-attention** transformer
- Tiap token melihat **seluruh konteks kalimat**
- Outputnya adalah embedding yang **kontekstual** dan bermakna

### 🔢 Proses Perhitungannya:

#### a. Tokenisasi
```python
"Saya suka AI" → ["[CLS]", "Saya", "suka", "AI", "[SEP]"]
```

#### b. Embedding Lookup
Setiap token diubah jadi vektor awal berdimensi 768 misalnya (pretrained embedding table)

#### c. Masuk ke Transformer
Dilakukan **self-attention**, yaitu:
```
Attention(Q, K, V) = softmax(QKᵗ / √d_k) * V
```
Untuk setiap token, dihitung "perhatian" terhadap token lain. Di sinilah “makna dalam konteks” dibentuk.

#### d. Ambil output akhir (token `[CLS]` atau average pooling)

## 🧮 Perhitungan Cosine Similarity (Setelah Punya Embedding)
Kalau kamu ingin membandingkan dua teks:

```python
from sklearn.metrics.pairwise import cosine_similarity
similarity = cosine_similarity([vector1], [vector2])
```

Nilai similarity akan berkisar dari -1 (sangat beda) sampai 1 (sangat mirip).

---

## 🔎 Contoh Singkat
Misal kamu pakai SentenceTransformer:

```python
from sentence_transformers import SentenceTransformer, util

model = SentenceTransformer('all-MiniLM-L6-v2')

kalimat1 = "Saya belajar matematika"
kalimat2 = "Aku mempelajari hitung-hitungan"

emb1 = model.encode(kalimat1)
emb2 = model.encode(kalimat2)

similarity = util.cos_sim(emb1, emb2)
print(f"Kemiripan: {similarity.item():.3f}")
```

## 🧠 Apa itu **embedding**?  
Bayangkan kamu ingin memberi tahu komputer apa arti sebuah **kata** atau **kalimat**.  
Tapi... komputer **tidak mengerti bahasa manusia**, hanya angka.

Maka kita perlu **mengubah kata jadi angka**, supaya:
- Komputer bisa **membandingkan maknanya**
- Komputer bisa **melihat seberapa mirip** dua kata atau kalimat

---

## 🎯 Contoh Sederhana (Tanpa Model)

Bayangkan kita punya 3 kata:
- "anjing"
- "kucing"
- "roti"

Kita ingin mengubah ketiganya menjadi **angka** agar komputer bisa tahu:
- Anjing dan kucing itu **mirip** (sama-sama hewan)
- Roti itu **berbeda**

---

### 🧮 Kita ubah jadi angka (dalam bentuk **vektor**):

| Kata     | Representasi (vektor)     |
|----------|---------------------------|
| anjing   | [1, 1, 0]   ← hewan, berkaki, bukan makanan |
| kucing   | [1, 1, 0]   ← hewan, berkaki, bukan makanan |
| roti     | [0, 0, 1]   ← bukan hewan, tidak berkaki, makanan |

Vektor itu seperti label angka:
- Posisi 1: Apakah dia hewan? (1 = ya, 0 = tidak)  
- Posisi 2: Apakah dia berkaki?  
- Posisi 3: Apakah dia makanan?

---

### 🤖 Komputer lihat angka-angka itu

- "anjing" dan "kucing" → sama persis: [1, 1, 0]  
- "roti" → beda banget: [0, 0, 1]

Jadi komputer **tahu bahwa anjing dan kucing lebih mirip** dibanding roti.

Itulah **makna embedding**:  
> "Representasi angka dari sebuah hal, supaya maknanya bisa dibandingkan."

---

## ✅ **Langkah-Langkah Menonaktifkan FortiGuard Intrusion Prevention (IPS)**

### 📍 **Syarat:**
- Kamu harus punya **akses ke FortiGate firewall** (melalui browser atau CLI)
- Biasanya dilakukan oleh admin jaringan

---

### 🔧 **Via GUI (FortiGate Web Interface)**

1. **Login ke FortiGate**
   - Buka browser → Masuk ke IP FortiGate (contoh: `https://192.168.1.99`)
   - Masukkan username dan password admin

2. **Masuk ke Menu:**
   - *Security Profiles* → *Intrusion Prevention*

3. **Nonaktifkan IPS:**
   - Temukan policy atau rule yang menerapkan Intrusion Prevention
   - Klik dan **hapus pengaturan IPS** dari rule tersebut
   - Atau, **disable IPS Profile** secara manual

4. **Simpan & Terapkan**

---

### 🧑‍💻 **Via CLI (Command Line Interface)**

Jika kamu lebih suka menggunakan perintah:

```bash
config firewall policy
edit [ID_kebijakan]  ← contoh: edit 1
unset ips-sensor
next
end
```

1. **Gunakan jaringan lain** (misalnya hotspot dari HP lain)

3. **Hubungi admin jaringan** untuk menjelaskan tujuan kamu dan minta whitelist

## 🥇 **VPN Premium (Berbayar - Kualitas Terbaik)**

| VPN | Kelebihan | Kekurangan |
|-----|-----------|------------|
| **ExpressVPN** | Cepat, stabil, sangat aman, server di banyak negara | Agak mahal |
| **NordVPN** | Aman, cepat, ada fitur Double VPN & Meshnet | UI bisa rumit untuk pemula |
| **Surfshark** | Murah, bisa dipakai di banyak perangkat sekaligus | Kadang lambat di server tertentu |
| **ProtonVPN** | Fokus privasi, bisa digunakan secara gratis terbatas | Versi gratis lambat |
| **Private Internet Access (PIA)** | Terjangkau, open-source | Tampilan agak teknis |

> **Rekomendasi umum:** Kalau kamu ingin aman dan cepat → **ExpressVPN** atau **NordVPN**.

---

## 🆓 **VPN Gratis (Terbatas tapi cukup)**

| VPN Gratis | Kelebihan | Kekurangan |
|------------|-----------|------------|
| **ProtonVPN Free** | Tanpa batas data, aman, dari Swiss | Kecepatan terbatas, pilihan negara sedikit |
| **Windscribe Free** | 10GB/bulan, banyak fitur | Batas data, kadang timeout |
| **TunnelBear** | Sangat ramah untuk pemula | Hanya 500MB per bulan (kecil banget!) |

> **Catatan:** VPN gratis **tidak cocok untuk streaming berat atau download besar**. Tapi cukup untuk akses ringan seperti browsing, buka website terblokir, dll.
