Tentu! Berikut ini contoh program web sederhana yang menggunakan **PWA (Progressive Web App)**. Program ini adalah aplikasi catatan sederhana (`Simple Notes App`) yang bisa di-*install* ke perangkat pengguna seperti aplikasi native.

## ✅ Fitur
- Dapat menambahkan catatan.
- Disimpan di LocalStorage.
- Dapat di-*install* sebagai PWA (tersedia manifest & service worker).

## 1. `index.html`
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0"/>
  <link rel="manifest" href="manifest.json" />
  <link rel="stylesheet" href="styles.css" />
  <title>Simple Notes PWA</title>
</head>
<body>
  <h1>Simple Notes</h1>
  <textarea id="noteInput" placeholder="Tulis catatan di sini..."></textarea>
  <button onclick="saveNote()">Simpan Catatan</button>
  <ul id="notesList"></ul>

  <script src="app.js"></script>
  <script>
    // Daftarkan Service Worker
    if ('serviceWorker' in navigator) {
      navigator.serviceWorker.register('sw.js')
        .then(reg => console.log('Service Worker terdaftar', reg))
        .catch(err => console.error('Service Worker gagal', err));
    }
  </script>
</body>
</html>
```

## 3. `app.js`
```javascript
function saveNote() {
  const noteInput = document.getElementById('noteInput');
  const note = noteInput.value.trim();
  if (note) {
    const notes = JSON.parse(localStorage.getItem('notes') || '[]');
    notes.push(note);
    localStorage.setItem('notes', JSON.stringify(notes));
    noteInput.value = '';
    displayNotes();
  }
}

function displayNotes() {
  const notes = JSON.parse(localStorage.getItem('notes') || '[]');
  const notesList = document.getElementById('notesList');
  notesList.innerHTML = '';
  notes.forEach((note, index) => {
    const li = document.createElement('li');
    li.textContent = note;
    notesList.appendChild(li);
  });
}

// Load saat pertama kali
displayNotes();
```

## 5. `sw.js` (Service Worker)
```javascript
const cacheName = 'notes-app-v1';
const assets = [
  '/',
  '/index.html',
  '/styles.css',
  '/app.js',
  '/manifest.json',
  '/icon-192.png',
  '/icon-512.png'
];

self.addEventListener('install', e => {
  e.waitUntil(
    caches.open(cacheName).then(cache => {
      return cache.addAll(assets);
    })
  );
});

self.addEventListener('fetch', e => {
  e.respondWith(
    caches.match(e.request).then(response => {
      return response || fetch(e.request);
    })
  );
});
```

## ✅ LANGKAH MENJALANKAN APLIKASI PWA

### 1. **Siapkan folder proyek**
- Buat folder baru, misalnya: `pwa-notes`
- Masukkan semua file yang sudah dijelaskan sebelumnya:
  - `index.html`
  - `styles.css`
  - `app.js`
  - `manifest.json`
  - `sw.js`
  - `icon-192.png` dan `icon-512.png` (ikon kecil dan besar; bisa gunakan gambar apa saja dulu)

---

### 2. **Gunakan Web Server lokal**
Karena Service Worker **tidak akan berjalan** jika dibuka langsung lewat file (`file://`), kamu harus menjalankannya lewat **web server lokal**.

Berikut cara paling mudah:

---

#### 🔸 **Menggunakan VS Code + Live Server** (cara paling simpel)
1. Buka folder `pwa-notes` di [Visual Studio Code](https://code.visualstudio.com/)
2. Install ekstensi **Live Server** (jika belum punya)
3. Klik kanan pada `index.html`, lalu pilih **"Open with Live Server"**
4. Web browser akan membuka halaman, misalnya di `http://127.0.0.1:5500`
5. Lihat di tab browser → klik ikon install 📲 di address bar → **Install app!**

---

#### 🔸 **Atau pakai Python (kalau tidak pakai VS Code)**
1. Buka terminal/command prompt
2. Arahkan ke folder tempat kamu simpan proyek:
   ```bash
   cd path/ke/folder/pwa-notes
   ```
3. Jalankan server (jika kamu pakai Python 3):
   ```bash
   python -m http.server 8080
   ```
4. Buka browser dan kunjungi:  
   👉 `http://localhost:8080`

---

### 3. **Install sebagai aplikasi**
Kalau kamu buka via Chrome atau Edge, kamu akan lihat tombol “Install” di address bar.
- Klik tombol itu → aplikasi akan ter-*install* seperti aplikasi biasa di desktop atau HP!
