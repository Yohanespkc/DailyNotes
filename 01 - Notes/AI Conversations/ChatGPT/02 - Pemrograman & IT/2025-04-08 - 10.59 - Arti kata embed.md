1. **Secara umum (fisik atau abstrak):**

2. **Dalam konteks teknologi/komputer:**  
   "Embed" sering digunakan untuk menyatakan **menyisipkan suatu elemen ke dalam sistem lain**, seperti:  
   - **Embed video**: menyisipkan video (misalnya YouTube) ke dalam halaman web.  
   - **Embedded system**: sistem tertanam, yaitu perangkat lunak yang berjalan di dalam perangkat keras khusus (contohnya: software dalam microwave, mesin cuci, mobil, dsb).

3. **Dalam bahasa pemrograman/web:**  
   Menulis atau menyisipkan kode dari satu tempat ke tempat lain.  
   Contoh:  
   - *We embedded the Google Map into our website.*  
     (Kami menyisipkan peta Google ke dalam situs kami.)

### 🔤 Apa itu Word2Vec?
**Word2Vec** adalah teknik dalam pembelajaran mesin (machine learning), khususnya di **Natural Language Processing (NLP)**, yang digunakan untuk mengubah kata-kata menjadi **vektor angka** (representasi matematis) supaya komputer bisa memproses dan memahami hubungan antar kata.

---

### ⚙️ Word2Vec punya dua model utama:
1. **CBOW (Continuous Bag of Words)** – menebak kata berdasarkan konteks sekitarnya.
2. **Skip-Gram** – **menebak konteks berdasarkan sebuah kata**.

---

### 🔍 Fokus: Apa itu Skip-Gram?

**Skip-Gram** adalah model yang mempelajari representasi kata dengan cara:

> Dari **satu kata (kata tengah)**, model ini mencoba **memprediksi kata-kata yang ada di sekitarnya** (konteks).

---

#### 💡 Contoh:
Kalimat:  
**"Aku suka makan durian manis di pagi hari."**

Misal kita ambil kata tengah = **"durian"**  
Model Skip-Gram akan mencoba **memprediksi** kata-kata di sekitar "durian", misalnya:  
- **"makan"**  
- **"manis"**

Kalau window size-nya lebih besar, bisa juga termasuk:  
- **"suka"**  
- **"di"**

Jadi, training-nya seperti:  
```
Input: durian  → Output: makan  
Input: durian  → Output: manis  
Input: durian  → Output: suka  
Input: durian  → Output: di  
```

---

### 🎯 Tujuannya?
Agar kata-kata yang **sering muncul dalam konteks serupa** memiliki **vektor yang mirip**.

Contohnya:
- Kata "durian" dan "mangga" mungkin akan punya vektor yang mirip karena sama-sama sering muncul dekat kata "buah", "manis", "makan".

---

### 📌 Kapan Skip-Gram dipakai?
- Saat data tidak terlalu banyak.
- Saat ingin menangkap **makna kata-kata yang jarang muncul**.

### 🤖 ChatGPT:
Pertanyaan bagus! Untuk membuat kata-kata seperti “durian”, “makan”, dan “manis” **dekat satu sama lain dalam ruang vektor**, kita perlu **melatih model Word2Vec** menggunakan teknik pembelajaran **dengan bobot**. Nah, berikut penjelasan sederhananya:

---

### 💡 Inti Idenya:
**Kata-kata yang sering muncul dalam konteks yang sama** harus memiliki **vektor yang mirip** (dekat secara matematis).

---

### ⚙️ Cara Memberikan Bobot:
1. **Kita representasikan setiap kata sebagai vektor** (misalnya 100 dimensi).
2. Skip-Gram mempelajari dua jenis vektor untuk tiap kata:
   - **Input vector (v_w)**
   - **Output vector (v_c)**

3. Untuk setiap pasangan:
   ```
   Input: durian → Output: manis
   ```
   Kita ingin **dot product** antara vektor "durian" dan "manis" menjadi besar (artinya mirip).

---

### 📈 Proses Belajarnya (Secara Ringan):

- Gunakan fungsi **loss** (kerugian), misalnya **Negative Sampling** atau **Softmax Loss**, untuk mengatur seberapa bagus prediksi konteksnya.
- Optimasi dilakukan dengan **gradient descent**, yaitu:
  - Jika "durian" → "manis" benar, maka bobotnya diperkuat (vektornya makin dekat).
  - Jika salah konteks (misalnya “durian” → “roda”), maka bobotnya dilemahkan (vektornya dijauhkan).

---

### 🔁 Prosesnya:
1. Mulai dari bobot acak untuk semua kata.
2. Lakukan banyak iterasi (training) dengan data teks.
3. Perlahan-lahan, **kata-kata yang sering muncul bersama akan "belajar" untuk saling mendekat** di ruang vektor.

## 🧠 2. Kode Lengkap Skip-Gram Word2Vec dengan PyTorch

```python
import torch
import torch.nn as nn
import torch.optim as optim
import numpy as np

# -------------- Data Awal -----------------
sentences = [
    'anak itu suka makan durian manis sekali',
    'ibu beli mangga manis',
    'ayah makan durian di rumah'
]

# Tokenisasi
tokens = [word for sentence in sentences for word in sentence.split()]
vocab = list(set(tokens))
word_to_ix = {word: i for i, word in enumerate(vocab)}
ix_to_word = {i: word for word, i in word_to_ix.items()}
vocab_size = len(vocab)

# Buat pasangan (input, context) untuk skip-gram
def generate_skipgram_pairs(tokens, window_size=2):
    pairs = []
    for idx, word in enumerate(tokens):
        for w in range(-window_size, window_size + 1):
            if w == 0:
                continue
            context_idx = idx + w
            if 0 <= context_idx < len(tokens):
                pairs.append((word, tokens[context_idx]))
    return pairs

pairs = generate_skipgram_pairs(tokens)

# -------------- Neural Network Model -----------------
class SkipGramModel(nn.Module):
    def __init__(self, vocab_size, embedding_dim):
        super(SkipGramModel, self).__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        self.output = nn.Linear(embedding_dim, vocab_size)
        
    def forward(self, center_word):
        embed = self.embedding(center_word)
        out = self.output(embed)
        return out

# -------------- Training -----------------
embedding_dim = 10
model = SkipGramModel(vocab_size, embedding_dim)
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.01)

# Ubah data jadi index
data = [(word_to_ix[w1], word_to_ix[w2]) for w1, w2 in pairs]

for epoch in range(200):
    total_loss = 0
    for center, context in data:
        center_tensor = torch.tensor([center], dtype=torch.long)
        context_tensor = torch.tensor([context], dtype=torch.long)

        output = model(center_tensor)
        loss = criterion(output, context_tensor)

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        total_loss += loss.item()
    if epoch % 20 == 0:
        print(f"Epoch {epoch}, Loss: {total_loss:.4f}")

# -------------- Melihat Vektor Kata -----------------
durian_vec = model.embedding(torch.tensor([word_to_ix['durian']]))
print("Vektor 'durian':", durian_vec.detach().numpy())

# -------------- Cari kata terdekat -----------------
def get_similar(word, topn=5):
    word_vec = model.embedding(torch.tensor([word_to_ix[word]])).detach()
    similarities = {}
    for other_word in vocab:
        if other_word == word:
            continue
        other_vec = model.embedding(torch.tensor([word_to_ix[other_word]])).detach()
        sim = torch.cosine_similarity(word_vec, other_vec).item()
        similarities[other_word] = sim
    return sorted(similarities.items(), key=lambda x: -x[1])[:topn]

print("Kata yang mirip dengan 'durian':", get_similar('durian'))
```
