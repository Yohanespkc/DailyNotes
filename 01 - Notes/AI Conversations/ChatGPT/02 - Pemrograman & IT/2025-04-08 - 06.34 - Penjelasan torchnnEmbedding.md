**Tanggal:** `2025-04-08 06.34`

### 👤 User:
apa itu torch.nn.Embedding.

### 🤖 ChatGPT:
`torch.nn.Embedding` adalah salah satu modul di PyTorch yang digunakan untuk **mengubah indeks integer menjadi vektor representasi berdimensi tetap**. Modul ini sangat umum digunakan dalam bidang **Natural Language Processing (NLP)** untuk memetakan kata (yang diubah jadi indeks) ke dalam vektor representasi yang bisa dipelajari selama proses training.

---

### 🔧 Sintaks
```python
torch.nn.Embedding(num_embeddings, embedding_dim)
```

- `num_embeddings`: jumlah total item unik (misalnya ukuran kosakata atau jumlah token unik).
- `embedding_dim`: dimensi dari vektor representasi untuk setiap item.

---

### 📦 Contoh Kasus
Misalnya kamu punya 10 kata unik, dan ingin mewakili tiap kata sebagai vektor berdimensi 5:
```python
import torch
import torch.nn as nn

embedding = nn.Embedding(num_embeddings=10, embedding_dim=5)

# Misalnya input: indeks kata ke-1 dan ke-2
input = torch.LongTensor([1, 2])

output = embedding(input)
print(output)
```

Output-nya adalah tensor 2x5 (karena kita beri 2 indeks, masing-masing direpresentasikan dengan vektor 5 dimensi).

---

### 🧠 Fungsi Utama
- Membuat *lookup table* yang bisa di-train (berisi bobot-bobot embedding).
- Mengubah integer ID ke bentuk vektor agar bisa digunakan dalam jaringan neural.
- Biasanya digunakan di awal model NLP seperti LSTM, Transformer, dst.

---

### 🧪 Catatan Tambahan
- Bobot dari embedding (`embedding.weight`) bisa di-*train*, tapi juga bisa dimatikan dengan `requires_grad=False`.
- Bisa juga di-*initialize* dari pre-trained embeddings (misalnya GloVe atau Word2Vec).

Kalau kamu lagi bikin model NLP atau sequence model, `nn.Embedding` ini hampir selalu jadi langkah pertama setelah konversi token ke indeks. Mau contoh aplikasi ke kalimat atau tokenisasi juga?

## 1. 🔤 Dataset Sederhana
Kita buat dataset kecil dulu:

```python
# Data: list of (kalimat, label)
data = [
    ("I love this", 1),
    ("I hate this", 0),
    ("I like it", 1),
    ("I dislike it", 0),
]
```

---

## 2. 🧭 Tokenisasi + Vocab
```python
from collections import defaultdict

# Bangun vocab dari data
word_to_idx = defaultdict(lambda: len(word_to_idx))  # auto-indexing
word_to_idx["<PAD>"] = 0  # untuk padding

# Tokenisasi dan ubah jadi indeks
def encode(sentence):
    return [word_to_idx[word] for word in sentence.split()]

encoded_data = [(encode(text), label) for text, label in data]
vocab_size = len(word_to_idx)
```

---

## 3. 🧠 Model Sederhana
```python
import torch.nn as nn
import torch.nn.functional as F

class SentimentClassifier(nn.Module):
    def __init__(self, vocab_size, embedding_dim):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        self.fc = nn.Linear(embedding_dim, 1)

    def forward(self, x):
        embedded = self.embedding(x)              # [batch_size, seq_len, embedding_dim]
        pooled = embedded.mean(dim=1)             # rata-rata semua kata
        out = self.fc(pooled)                     # [batch_size, 1]
        return torch.sigmoid(out).squeeze()       # output prob [batch_size]
```

---

## 4. 🏋️‍♂️ Training Loop (singkat)
```python
import torch
from torch.utils.data import DataLoader

# Padding agar semua kalimat panjangnya sama
def pad(batch, pad_idx=0):
    max_len = max(len(seq) for seq, _ in batch)
    padded_seqs = []
    labels = []
    for seq, label in batch:
        padded_seq = seq + [pad_idx] * (max_len - len(seq))
        padded_seqs.append(padded_seq)
        labels.append(label)
    return torch.LongTensor(padded_seqs), torch.FloatTensor(labels)

# DataLoader
train_loader = DataLoader(encoded_data, batch_size=2, shuffle=True, collate_fn=pad)

# Model dan optimizer
model = SentimentClassifier(vocab_size=vocab_size, embedding_dim=8)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)
loss_fn = nn.BCELoss()
```

---

## 5. 🔁 Training
```python
for epoch in range(10):
    for batch_x, batch_y in train_loader:
        optimizer.zero_grad()
        preds = model(batch_x)
        loss = loss_fn(preds, batch_y)
        loss.backward()
        optimizer.step()
    print(f"Epoch {epoch+1}, Loss: {loss.item():.4f}")
```

---

## 6. 🚀 Uji Model
```python
def predict(sentence):
    model.eval()
    idxs = encode(sentence)
    padded = torch.LongTensor([idxs + [0]*(max(1, 5 - len(idxs)))])  # padding agar minimal 5
    with torch.no_grad():
        pred = model(padded)
    return "Positif" if pred.item() > 0.5 else "Negatif"

print(predict("I love it"))     # Harusnya Positif
print(predict("I hate it"))     # Harusnya Negatif
```

## 🔍 Gimana `torch.nn.Embedding` Bekerja?

### 🧠 Konsep Utama:
```python
nn.Embedding(num_embeddings, embedding_dim)
```

- Membuat **matriks besar** berukuran `(num_embeddings x embedding_dim)`
- Setiap baris adalah **vektor representasi** dari 1 indeks (misalnya kata atau token)
- Nilainya di-*inisialisasi acak* saat pertama kali dibuat

---

### 🧪 Contoh Kasus Nyata:
```python
embedding = nn.Embedding(num_embeddings=4, embedding_dim=5)
```

Berarti kita membuat *lookup table* seperti ini:

```
| index | vector                  |
|-------|--------------------------|
| 0     | [0.12, -0.33, ..., 0.04] |
| 1     | [0.05,  0.21, ..., -0.18]|
| 2     | [-0.11, 0.03, ..., 0.17] |
| 3     | [0.07, -0.09, ..., 0.33] |
```

Kita bisa lihat bobot ini langsung:

```python
print(embedding.weight)  # semua vektor acak awal
```

---

### ✨ Kenapa Isinya Angka Acak?
- Saat pertama kali dipakai, `nn.Embedding` menginisialisasi bobot dari distribusi **uniform** atau **normal** kecil, mirip layer-layer neural network lain.
- Setelah itu, bobot-bobot ini **dilatih selama training** dengan backpropagation.

---

### 📌 Jadi saat kamu panggil:

```python
input = torch.LongTensor([0, 2])
output = embedding(input)
```

Itu artinya:
- Ambil baris ke-0 dan ke-2 dari `embedding.weight`
- Hasilkan 2 vektor berdimensi 5 (karena `embedding_dim=5`)

---

### 🧠 Bisa Dilatih?
Yes! Contoh:
```python
optimizer = torch.optim.Adam(embedding.parameters(), lr=0.01)
```
Berarti selama training, bobot embedding juga **belajar berubah** sesuai loss.

## 🔁 Pilihan 2: Latih Embedding agar vektor kata "saya" lebih dekat ke "adik"

Misalnya kita ingin:
- **"saya" dekat ke "adik"**
- **"catur" jauh dari "adik"**

Contoh training sederhana:

```python
import torch
import torch.nn as nn

# Vocab sederhana
vocab = {"saya": 0, "adik": 1, "catur": 2}
embedding = nn.Embedding(3, 5)  # 3 kata, dimensi 5

# Target: vektor "saya" dan "adik" mendekat
loss_fn = nn.CosineEmbeddingLoss()
optimizer = torch.optim.Adam(embedding.parameters(), lr=0.01)

# Data training
x1 = torch.LongTensor([vocab["saya"]])   # index saya
x2 = torch.LongTensor([vocab["adik"]])   # index adik
x3 = torch.LongTensor([vocab["catur"]])  # index catur
target_similar = torch.tensor([1.0])     # saya vs adik harus mirip
target_different = torch.tensor([-1.0])  # saya vs catur harus beda

# Training 100 langkah
for step in range(100):
    optimizer.zero_grad()
    vec1 = embedding(x1)
    vec2 = embedding(x2)
    vec3 = embedding(x3)

    loss1 = loss_fn(vec1, vec2, target_similar)
    loss2 = loss_fn(vec1, vec3, target_different)
    loss = loss1 + loss2
    loss.backward()
    optimizer.step()

    if step % 10 == 0:
        print(f"Step {step}, Loss: {loss.item():.4f}")
```

> Setelah training selesai, kamu bisa bandingkan vektor `saya`, `adik`, dan `catur` — dan hitung jaraknya.

## 🔢 Apa itu Cosine Similarity?
Cosine similarity = kemiripan arah antara dua vektor (bukan panjangnya). Nilainya:
- **1** kalau dua vektor sama arah
- **0** kalau tegak lurus (tidak mirip)
- **-1** kalau berlawanan arah

Formula:
```python
cosine_sim(a, b) = (a · b) / (||a|| * ||b||)
```

### 3. Latih Embedding Pakai PyTorch
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SimpleEmbeddingModel(nn.Module):
    def __init__(self, vocab_size, embed_dim):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)

    def forward(self, input_idx, context_idx):
        input_embed = self.embedding(input_idx)
        context_embed = self.embedding(context_idx)
        score = torch.sum(input_embed * context_embed, dim=1)
        return torch.sigmoid(score)

loss_fn = nn.BCELoss()
```

- Mengambil vektor dari kata `input`

### 🔹 `context_embed = self.embedding(context_idx)`
- Mengambil vektor dari kata `context`

### 🔹 `input_embed * context_embed`
- Perkalian elemen per elemen antar vektor (dot product persiapan)

### 🔹 `torch.sum(..., dim=1)`
- Menjumlahkan elemen-elemen vektor → hasilkan 1 skor

### 🔹 `torch.sigmoid(score)`
- Nilai skor dikonversi ke probabilitas antara 0 dan 1
- Ini mengukur **seberapa mirip** kata dan konteksnya

## 🎬 Visualisasi Embedding (Siap Jalankan di Komputermu)

Copy kode berikut dan simpan ke file Python, misalnya: `embedding_animation.py`:

```python
import torch
import torch.nn as nn
import matplotlib.pyplot as plt
from matplotlib.animation import FuncAnimation
import numpy as np

# Vocab sederhana
vocab = ["saya", "adik", "catur", "makan", "nasi"]
word_to_idx = {word: idx for idx, word in enumerate(vocab)}
vocab_size = len(vocab)
embedding_dim = 2  # agar bisa divisualisasikan

# Model
class SimpleEmbedding(nn.Module):
    def __init__(self, vocab_size, embedding_dim):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim)

    def forward(self, x):
        return self.embedding(x)

model = SimpleEmbedding(vocab_size, embedding_dim)
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)
loss_fn = nn.MSELoss()

# Target: "saya" dekat ke "adik", jauh dari "catur"
training_pairs = [
    (word_to_idx["saya"], word_to_idx["adik"], 1.0),
    (word_to_idx["saya"], word_to_idx["catur"], 0.0)
]

# Simpan posisi embedding setiap epoch
positions = []

for epoch in range(50):
    for input_idx, target_idx, similarity in training_pairs:
        input_tensor = torch.LongTensor([input_idx])
        target_tensor = torch.LongTensor([target_idx])
        similarity_tensor = torch.tensor([similarity])

        input_vec = model(input_tensor)
        target_vec = model(target_tensor)
        cos_sim = torch.cosine_similarity(input_vec, target_vec)
        loss = loss_fn(cos_sim, similarity_tensor)

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

    # simpan posisi vektor
    with torch.no_grad():
        pos = model.embedding.weight.detach().numpy()
        positions.append(pos.copy())

# Buat animasi
fig, ax = plt.subplots()
scat = ax.scatter([], [], color='blue')
texts = [ax.text(0, 0, word, fontsize=12) for word in vocab]
ax.set_xlim(-2, 2)
ax.set_ylim(-2, 2)
ax.set_title("Perubahan Embedding Selama Training")

def update(frame):
    coords = positions[frame]
    scat.set_offsets(coords)
    for i, txt in enumerate(texts):
        txt.set_position((coords[i][0], coords[i][1]))
    ax.set_xlabel(f"Epoch {frame}")
    return scat, *texts

ani = FuncAnimation(fig, update, frames=len(positions), interval=300, blit=True)
plt.show()
```

## 🧠 Konsep Dasar: Belajar Makna Kata dari Tetangga (Konteks)

### 🔍 Tujuan utama training:
Model **belajar menghasilkan vektor (embedding) untuk setiap kata**, sehingga:

- Kata-kata yang **sering muncul bersama** (dalam konteks yang sama) → **vektornya jadi mirip**
- Kata-kata yang **tidak berkaitan** → vektornya jauh

> Contoh:  
> `"saya makan nasi"`  
> `"adik makan nasi"`  
> Maka: `saya` dan `adik` akan **mendekat** ke `makan`, karena muncul dalam konteks yang mirip.

---

## 📦 Dataset Latihan

Model belajar dari **pasangan kata (word, context)**.

Contoh pasangan:
```
("saya", "makan")
("adik", "makan")
("saya", "nasi")
```

Ini mirip metode Word2Vec Skip-Gram: prediksi konteks dari kata pusat.

---

## 🔄 Proses Training

### 1. **Ambil 2 kata** → misalnya: `"saya"` dan `"adik"`  
Kita ingin **vektor 'saya' dan 'adik' menjadi mirip**, maka:

### 2. **Hitung cosine similarity** antara vektor mereka  
Kalau mirip → nilainya mendekati 1  
Kalau berbeda → mendekati 0 atau negatif

```python
cos_sim = cosine_similarity(vec_saya, vec_adik)
```

### 3. **Bandingkan cosine similarity dengan label target**  
- Target kita: 1 → artinya mereka seharusnya mirip  
- Kita pakai **loss function** (misalnya `MSELoss`) untuk hitung error:

```python
loss = (cos_sim - 1)²  ← makin kecil makin bagus
```

### 4. **Update bobot embedding** agar error mengecil  
Dengan `loss.backward()` dan `optimizer.step()`, PyTorch otomatis mengubah isi vektor embedding (gradien diturunkan).

---

## 🎓 Jadi Singkatnya:

| Langkah | Apa yang terjadi? |
|--------|--------------------|
| 1. Ambil pasangan kata | Misalnya ("saya", "adik") |
| 2. Ambil vektor embedding dari model | `vec_saya`, `vec_adik` |
| 3. Hitung kemiripan (cosine similarity) | Makin mirip = makin bagus |
| 4. Hitung loss dari perbedaan nilai kemiripan | Targetnya 1 atau 0 |
| 5. Perbarui bobot embedding lewat training | vektor kata jadi lebih bermakna |
