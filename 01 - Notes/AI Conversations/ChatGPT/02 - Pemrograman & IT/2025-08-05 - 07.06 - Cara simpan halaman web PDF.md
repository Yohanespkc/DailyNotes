# 💬 Cara simpan halaman web PDF

**Tanggal:** `2025-08-05 07.06`  
**Sumber:** ChatGPT Export  

---

### 👤 User:
bagaimana save isi page web dalam pdf

### 🤖 ChatGPT:
Berikut cara **menyimpan isi halaman web (webpage)** dalam **format PDF**, tergantung perangkat dan browser yang Anda gunakan:

---

### ✅ **1. Menggunakan Browser (Chrome, Edge, Firefox, Safari)**

#### 📌 **Di Chrome / Edge / Brave (Windows / macOS / Linux):**

1. Buka halaman web yang ingin disimpan.
2. Tekan `Ctrl + P` (Windows) atau `Cmd + P` (Mac) → akan muncul dialog **Print**.
3. Ubah **Destination** menjadi **"Save as PDF"**.
4. Atur layout, margin, dan opsi lainnya (misalnya centang "Background graphics").
5. Klik **Save** → pilih lokasi dan beri nama file PDF.

#### 📌 **Di Firefox:**

Firefox tidak punya opsi bawaan "Save as PDF", jadi:

- Tekan `Ctrl + P` / `Cmd + P`, lalu pilih **Microsoft Print to PDF** atau printer virtual lainnya.
- Atau gunakan ekstensi seperti **"Print Friendly & PDF"**.

#### 📌 **Di Safari (macOS):**

1. Buka halaman web.
2. Klik `File` > `Export as PDF...` atau `Print` > klik dropdown kiri bawah dan pilih **"Save as PDF"**.
3. Simpan.

---

### ✅ **2. Menggunakan Ekstensi Browser (Lebih Rapi / Tanpa Iklan)**

- **Print Friendly & PDF**  
  Plugin yang membersihkan halaman sebelum disimpan ke PDF.  
  Link: [printfriendly.com](https://www.printfriendly.com)

---

### ✅ **3. Menggunakan Fitur Khusus:**

#### 📱 **Di HP Android:**
1. Buka halaman web di Chrome.
2. Tap titik tiga (pojok kanan atas) > **Share** > **Print**.
3. Pilih **Save as PDF** > tap ikon PDF > simpan.

#### 📱 **Di iPhone:**
1. Buka Safari > tap tombol Share (ikon kotak + panah).
2. Pilih **Print**.
3. Cubit tampilan print untuk memperbesar → lalu tap **Share** lagi → pilih **Save to Files** (dalam PDF).

---

### 🔍 Tips Tambahan
- Jika halaman punya **konten interaktif / panjang**, Anda bisa scroll ke bawah dulu agar semua elemen dimuat, lalu baru simpan.
- Untuk hasil profesional atau batch conversion: gunakan alat seperti **wkhtmltopdf**, **Adobe Acrobat**, atau **Selenium + headless browser** (untuk otomatisasi).
