### 🤖 ChatGPT:
Bisa. Cara paling praktis di terminal adalah pakai **yt-dlp**. yt-dlp mendukung YouTube dan ribuan situs lain, dan dokumentasi resminya menyediakan instalasi via binary, pip, Homebrew, APT, winget, dll. citeturn434563search0turn434563search1

Pastikan Anda hanya mengunduh video yang memang Anda punya izin untuk simpan.

### 1) Install yt-dlp

**Linux/macOS:**
```bash
python3 -m pip install -U "yt-dlp[default]"
```

Atau kalau pakai Homebrew:
```bash
brew install yt-dlp
```

**Ubuntu/Debian, alternatif binary resmi:**
```bash
mkdir -p ~/.local/bin
curl -L https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp -o ~/.local/bin/yt-dlp
chmod a+rx ~/.local/bin/yt-dlp
```

### 2) Install FFmpeg agar video+audio bisa digabung

**Ubuntu/Debian:**
```bash
sudo apt update
sudo apt install ffmpeg
```

**macOS:**
```bash
brew install ffmpeg
```

### 3) Download video

```bash
yt-dlp "https://www.youtube.com/watch?v=X3tkUsNGk3I"
```

### 4) Download sebagai MP4 kualitas terbaik yang kompatibel

```bash
yt-dlp -f "bv*[ext=mp4]+ba[ext=m4a]/b[ext=mp4]/best" --merge-output-format mp4 "https://www.youtube.com/watch?v=X3tkUsNGk3I"
```

### 5) Download audio saja sebagai MP3

```bash
yt-dlp -x --audio-format mp3 "https://www.youtube.com/watch?v=X3tkUsNGk3I"
```

### 6) Cek format yang tersedia

```bash
yt-dlp -F "https://www.youtube.com/watch?v=X3tkUsNGk3I"
```

Lalu pilih format tertentu, misalnya:
```bash
yt-dlp -f 137+140 "https://www.youtube.com/watch?v=X3tkUsNGk3I"
```

### 7) Update yt-dlp kalau error

```bash
yt-dlp -U
```

Kalau Anda pakai pip:
```bash
python3 -m pip install -U "yt-dlp[default]"
```

### Opsi paling mudah kalau sudah punya Homebrew


Lalu download videonya:

### Kalau belum punya Homebrew, pakai pipx

Install pipx dulu:

```bash
python3 -m pip install --user pipx
python3 -m pipx ensurepath
```

Tutup terminal, buka lagi, lalu:

```bash

```

Kemudian download:

```bash

```

### Cek apakah sudah berhasil

```bash
yt-dlp --version
ffmpeg -version
```

Kalau `brew: command not found`, berarti Homebrew belum terpasang. Pakai ini dulu:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Setelah itu jalankan:

```bash
brew install yt-dlp ffmpeg
```

### 🤖 ChatGPT:
Dari screenshot, **audio berhasil terunduh** sebagai `.m4a`, tapi **video format 137 gagal** karena HTTP 503. Supaya hasilnya tetap **MP4**, coba pakai format lain yang sudah berupa video+audio atau biarkan `yt-dlp` memilih MP4 terbaik yang tersedia.

Jalankan ini:

```bash
yt-dlp -f "best[ext=mp4]/best" --merge-output-format mp4 "https://www.youtube.com/watch?v=X3tkUsNGk3I"
```

Kalau masih gagal, coba pakai format yang lebih aman:

```bash
yt-dlp -f "bv*+ba/b" --merge-output-format mp4 "https://www.youtube.com/watch?v=X3tkUsNGk3I"
```

Kalau sudah terlanjur punya file `.m4a` saja dan ingin coba ulang video tanpa menghapus file audio:

```bash
yt-dlp --no-overwrites -f "best[ext=mp4]/best" --merge-output-format mp4 "https://www.youtube.com/watch?v=X3tkUsNGk3I"
```

Untuk melihat pilihan format yang tersedia:

```bash
yt-dlp -F "https://www.youtube.com/watch?v=X3tkUsNGk3I"
```

Lalu pilih format MP4 yang ada tulisan `mp4` dan biasanya punya audio+video, misalnya:

```bash
yt-dlp -f FORMAT_ID --merge-output-format mp4 "https://www.youtube.com/watch?v=X3tkUsNGk3I"
```

Ganti `FORMAT_ID` dengan angka format dari hasil `yt-dlp -F`.

Setelah berhasil, file MP4 biasanya muncul di folder Anda sekarang, yaitu `documents`. Cek dengan:

```bash
ls -lh *.mp4
```
