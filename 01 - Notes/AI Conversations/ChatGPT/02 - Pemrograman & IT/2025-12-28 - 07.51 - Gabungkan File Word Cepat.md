### 🤖 ChatGPT:

---

## 🔹 OPSI 1 — **Paling Mudah (tanpa ribet, via Word)**
### Cocok jika jumlah file **tidak terlalu banyak (≤20)**

1. Buka **Microsoft Word**
2. Buat **dokumen baru**
3. Klik **Insert → Object → Text from File**
4. Pilih **semua file Word**  
   - Tekan **Cmd + A** untuk pilih semua
5. Klik **Insert**

✅ Semua file langsung **digabung berurutan**  
⚠️ Urutan mengikuti **urutan nama file** → pastikan sudah diberi nomor:
```
01_Pendahuluan.docx
02_Bab1.docx
03_Bab2.docx
```

---

## 🔹 OPSI 2 — **Super Cepat & Stabil (Copy–Paste Massal)**
### Cocok jika Anda ingin **cek isi sambil jalan**

1. Buka **dokumen tujuan**
2. Buka **file pertama**
3. Tekan **Cmd + A → Cmd + C**
4. Kembali ke dokumen tujuan → **Cmd + V**
5. Ulangi

💡 Tips:
- Gunakan **Paste → Keep Source Formatting**
- Aman untuk file yang banyak tabel & gambar

---

## 🔹 OPSI 3 — **Paling Profesional (Master Document – hati-hati!)**
⚠️ **Word sering bug** → saya **tidak rekomendasikan** untuk buku serius.

```bash
cd /Users/ys/Documents/WordBab
```

✅ Sangat cepat

⚠️ Pastikan **nama file sudah berurutan**

## 🥇 OPSI 1 — **Kompres Gambar (WAJIB, paling berdampak)**
> Biasanya **90% ukuran Word berasal dari gambar**

### Langkah:
1. Buka file Word
2. Klik **satu gambar**
3. Tab **Picture Format**
4. Klik **Compress Pictures**
5. Centang:
   - ✅ **Delete cropped areas of pictures**
   - ✅ **Apply only to this picture** → ❌ (jangan dicentang)
6. Pilih resolusi:
   - **Web (150 ppi)** → REKOMENDASI
   - **Email (96 ppi)** → jika super kecil
7. Klik **OK**
8. **Save As** file baru

📉 Dampak: bisa turun **5× – 20× lebih kecil**

---

## 🥈 OPSI 2 — **Matikan Penyimpanan Data Edit Gambar**
Word sering menyimpan **data asli + edit history**

### Langkah:
1. **Word → Preferences**
2. **Edit → Pictures**
3. Centang:
   - ✅ **Discard editing data**
4. Tutup Word
5. Buka ulang file → **Save As**

📉 Dampak: **−30% s/d −60%**

---

## 🥉 OPSI 3 — **Convert gambar manual (paling bersih)**
> Cocok jika file Anda buku ilmiah

### Cara cepat:
1. Buka folder gambar asli
2. Pilih semua gambar
3. Klik kanan → **Quick Look**
4. **Tools → Adjust Size**
5. Set:
   - Lebar max: **1200 px**
   - Format: **JPEG**
   - Quality: **80%**
6. Replace gambar di Word

📉 Dampak: **−70% s/d −90%**

---

## 🧠 OPSI 4 — **Save As PDF → Kembali ke Word**
> Trik ampuh kalau Word “bandel”

### Langkah:
1. **File → Save As → PDF**
2. Buka PDF dengan **Word**
3. Save As **.docx**

⚠️ Risiko kecil:
- Style bisa berubah
- TOC kadang rusak

📉 Dampak: **sangat besar**

---

## 🧪 OPSI 5 — **SUPER CEPAT (Terminal, Opsional)**
### Cocok untuk pengguna nyaman Terminal

### Kompres PDF dulu:
```bash
gs \
 -sDEVICE=pdfwrite \
 -dCompatibilityLevel=1.4 \
 -dPDFSETTINGS=/screen \
 -dNOPAUSE -dQUIET -dBATCH \
 -sOutputFile=output_kecil.pdf \
 input.pdf
```

Lalu buka PDF di Word → Save As `.docx`

## 🥉 JIKA MASIH > 10 MB (LANGKAH PAMUNGKAS)

## 4️⃣ Kompres PDF dengan Ghostscript (SUPER AMPUH)
📉 Bisa **turun sampai 5–10 MB**

### Install (sekali saja):
```bash
brew install ghostscript
```

### Kompres:
```bash
gs \
 -sDEVICE=pdfwrite \
 -dCompatibilityLevel=1.4 \
 -dPDFSETTINGS=/screen \
 -dNOPAUSE -dQUIET -dBATCH \
 -sOutputFile=PDF_10MB.pdf \
 PDF_awal.pdf
```

📌 Preset:
| Setting | Kualitas | Ukuran |
|------|--------|------|
| `/screen` | cukup baca | ⭐⭐⭐⭐⭐ |
| `/ebook` | bagus | ⭐⭐⭐ |
| `/printer` | cetak | ❌ |

➡️ Pakai `/screen` untuk target 10 MB.

## 🥇 CARA TERMUDAH (BUILT-IN macOS)
## **Preview → Reduce File Size**
> Cocok untuk **90% kasus**

### Langkah:
1. Klik kanan PDF → **Open With → Preview**
2. **File → Export**
3. Pada **Quartz Filter**, pilih:
   👉 **Reduce File Size**
4. Save (nama baru)

📉 Hasil:
- Ukuran turun **40–70%**
- Sangat cepat
- Tanpa install apa pun

⚠️ Catatan:
- Gambar bisa sedikit blur
- Cocok untuk PDF baca layar / kirim email

---

## 🥈 CARA PALING TERKONTROL (PROFESIONAL)
## **Ghostscript (Terminal)**
> ⭐ REKOMENDASI jika ingin **pas 50% + kualitas stabil**

### Install (sekali saja):
```bash
brew install ghostscript
```

### Kompres 50–60% (aman):
```bash
gs \
 -sDEVICE=pdfwrite \
 -dCompatibilityLevel=1.4 \
 -dPDFSETTINGS=/ebook \
 -dNOPAUSE -dQUIET -dBATCH \
 -sOutputFile=output_50pct.pdf \
 input.pdf
```

📌 Preset penting:
| Setting | Ukuran | Kualitas |
|------|------|------|
| `/screen` | −70% | cukup baca |
| `/ebook` | **−40–60%** | ⭐⭐⭐⭐ |
| `/printer` | kecil | ❌ besar |

➡️ Untuk target **50%**, pilih **`/ebook`**
