### Penjelasan Regex

Regex `r'([,.:;?_!"()\']|--|\\s)'` punya beberapa hal:
- `[,...]` artinya cocok dengan satu karakter dari daftar tersebut (misalnya `,`, `.`, `!`, dll).
- `--` artinya cocok dengan dua tanda minus berurutan.
- `\\s` seharusnya `\s` (tanpa dua backslash), yang artinya **spasi atau whitespace**.

Jadi kalau kamu ingin *split* berdasarkan **tanda baca dan spasi**, regex-nya sebaiknya ditulis:

```python
r'([,.:;?_!"()\']|--|\s)'
```

Catatan: dalam string Python dengan awalan `r'...'` (raw string), `\s` ditulis begitu saja, bukan `\\s`.

### Versi yang Sudah Diperbaiki:

```python
print(result)
```

### 🤖 ChatGPT:
Oke! Kita akan buat *tokenizer* sederhana yang memecah kalimat menjadi **kata dan tanda baca**, termasuk menangani tanda `--` dan tanda sambung seperti `AI-TOBA`.

### Kalimat:
```
"Hello saya AI-TOBA, saya senang bantu Anda belajar Matematika --."
```

### Tujuan:
Pisahkan menjadi token-token seperti:
```
['Hello', 'saya', 'AI-TOBA', ',', 'saya', 'senang', 'bantu', 'Anda', 'belajar', 'Matematika', '--', '.']
```

### Kode:

```python
import re

text = "Hello saya AI-TOBA, saya senang bantu Anda belajar Matematika --."
result = re.split(r'(\s+|--|[,.!?()])', text)
tokens = [item.strip() for item in result if item and not item.isspace()]
print(tokens)
```

### Penjelasan Regex:
- `\s+` → spasi satu atau lebih
- `--` → dua tanda strip
- `[,.!?()]` → tanda baca umum
- Kita pakai `re.split` supaya tanda baca tetap ditangkap (karena ada dalam grup `()`)

## 🔤 Apa itu *Embedding*?

**Embedding adalah cara untuk mengubah sesuatu (biasanya teks) menjadi angka** — tepatnya, vektor berdimensi tetap yang bisa dipahami oleh komputer.

Komputer kan nggak ngerti kata-kata seperti *"apel", "cinta", atau "matematika"*. Dia butuh angka untuk bisa menghitung dan membandingkan sesuatu. Nah, embedding bikin kata-kata itu jadi bentuk angka yang tetap menjaga makna atau hubungan antar kata.

---

## 🧠 Contoh Sederhana

Misalnya kita punya 3 kata:

- **raja**
- **ratu**
- **pria**

Dengan embedding, ketiganya bisa diubah jadi vektor seperti ini:

```
raja → [0.5, 0.8, 0.1]
ratu → [0.5, 0.8, 0.3]
pria → [0.4, 0.7, 0.1]
```

Lihat bahwa **raja dan ratu** punya angka yang mirip karena artinya juga mirip (pasangan kerajaan). Sedangkan **pria** lebih dekat ke *raja* daripada *ratu*, dan embedding-nya juga mencerminkan itu.

---

## 💡 Apa yang bisa di-*embedding*?

- **Kata** (word embedding): seperti Word2Vec, GloVe, atau FastText
- **Kalimat / paragraf**: disebut sentence embedding (contoh: SBERT)
- **Gambar**: diubah ke vektor juga (dalam model vision)
- **User, item, produk, lagu, dll**: dalam sistem rekomendasi

---

## ✨ Kegunaan Embedding
- Cari kata yang mirip makna: *"dokter"* dekat dengan *"perawat"*
- Cari sinonim atau analogi: *"raja" - "pria" + "wanita" = "ratu"*
- Input ke model AI seperti ChatGPT atau Google Translate
- Sistem rekomendasi: pengguna dan produk bisa di-*embedding*

## 💻 Kode Python-nya

Berikut contoh kode (bisa kamu jalankan di Jupyter Notebook atau Google Colab):

```python
import gensim.downloader as api
from sklearn.decomposition import PCA
import matplotlib.pyplot as plt

# 1. Load model Word2Vec pre-trained (Google News 100D, ringan)
model = api.load("glove-wiki-gigaword-100")  # Bisa juga "word2vec-google-news-300" kalau mau yang lebih besar

# 2. Pilih kata-kata
words = ["king", "queen", "man", "woman", "doctor", "nurse", "prince", "princess"]

# 3. Ambil vektornya
vectors = [model[word] for word in words]

# 4. Turunkan ke dimensi 2 pakai PCA
pca = PCA(n_components=2)
points = pca.fit_transform(vectors)

# 5. Visualisasi
plt.figure(figsize=(8, 6))
for i, word in enumerate(words):
    plt.scatter(points[i, 0], points[i, 1])
    plt.text(points[i, 0] + 0.01, points[i, 1] + 0.01, word, fontsize=12)
plt.title("Visualisasi Word Embedding (PCA 2D)")
plt.xlabel("PC 1")
plt.ylabel("PC 2")
plt.grid(True)
plt.show()
```

- lebih dari 1 (misalnya 3.2, 5.7)
- kurang dari 0 (misalnya -1.8, -0.4)

- atau bahkan sangat kecil (misalnya 0.0001)

**Tidak ada aturan keras** bahwa semua angka embedding harus antara 0 dan 1.

---

## 🧠 Kenapa Bisa Lebih dari 1?

Karena embedding dihasilkan lewat proses pembelajaran di neural network, di mana:

- Bobot vektor diperbarui lewat **backpropagation**
- Tidak dibatasi oleh fungsi aktivasi seperti sigmoid (yang membatasi ke [0,1]) kecuali memang sengaja
- Tidak distandarisasi ke skala tertentu kecuali diminta (misalnya L2 normalization)

---

## ✨ Contoh Nyata (Word2Vec / GloVe / BERT)

- Word2Vec bisa menghasilkan angka seperti:  
  `king → [0.72, -0.43, 1.25, ...]`
- GloVe juga:  
  `queen → [-0.58, 2.19, 1.03, ...]`
- BERT embedding bisa punya angka besar/kecil tergantung lapisan (layer) dan tokennya.

## 🧪 Bonus: Kalau Mau Dibatasi…

Kalau kamu **ingin membatasi** embedding ke rentang tertentu (misalnya 0–1 atau -1–1), kamu bisa:

- **Normalisasi** (misalnya L2 normalization)
- **Rescaling** (min-max scaling)
- Pakai fungsi aktivasi (misal `tanh`, `sigmoid`) setelah dense layer terakhir di model kamu

### 🔹 Baris 5:

```python
preprocessed = re.split(r'([,.:;?_!"()\']|--|\\s)', raw text)
```

## 💬 Istilah:
### ✅ **Vocabulary (Kamus Token)**
- Merupakan **daftar token unik** (kata, tanda baca, dll) dari teks kamu.
- Setiap token diberi **ID numerik**.
- Struktur: dictionary (token → ID)

Contoh:
```python
vocab = {
  "Aku": 0,
  "bola": 1,
  "lari": 2,
  ".": 3
}
```

🧠 **Inilah yang sering disebut sebagai "ID Token mapping" atau "token-to-ID mapping".**

---

### ✅ **ID Token (atau token ID sequence)**
- Adalah hasil konversi teks (yang awalnya berupa token) menjadi urutan angka **berdasarkan vocabulary**.
- Ini adalah representasi numerik dari **isi teks asli**.

Contoh:
Teks: `"Aku bola Aku lari ."`
Tokens: `["Aku", "bola", "Aku", "lari", "."]`

→ Dengan vocab di atas:
```python
["Aku", "bola", "Aku", "lari", "."] → [0, 1, 0, 2, 3]
```

---

## 🤔 Jadi, apakah vocabulary itu sama dengan ID token?

✅ **Secara teknis:**
- **Vocabulary = ID Token mapping** → yaitu token → ID (kamus)
- **ID Token (atau token IDs)** = teks yang sudah diubah jadi angka berdasarkan vocabulary

📌 Jadi:  
> **Vocabulary adalah peta/token mapping**, sedangkan  
> **ID Token adalah jalannya — urutan angka yang mengikuti peta itu**.

---

## 🧠 Analogi Sederhana:

Bayangkan kamu bikin kamus:
```
"Aku" = 0  
"bola" = 1  
"lari" = 2
```

Ini adalah **vocabulary**.

Lalu kamu punya cerita:
```
"Aku bola Aku lari"
```

Kalau kamu ubah jadi ID pakai kamus tadi:
```
[0, 1, 0, 2]
```

Ini adalah **ID token (atau encoded sequence)**.

## ❌ Kesalahan-kesalahan:

### 1. ❗ **Indentasi di dalam loop `for` salah**
Bagian ini:
```python
for token, idx in ID_token.items():
escaped = token.replace('"', '\\"')
f.write(f' \"{escaped}\": {idx},\n')
```

Harusnya di-indent **di dalam loop** seperti ini:
```python
for token, idx in ID_token.items():
    escaped = token.replace('"', '\\"')
    f.write(f'  "{escaped}": {idx},\n')
```

Python sangat sensitif terhadap indentasi. Tanpa indentasi yang benar, kamu akan dapat error seperti:
```
IndentationError: expected an indented block
```

---

### 2. (Opsional) 🧹 Spasi ekstra di f-string:
Yang kamu tulis:
```python
f.write(f' \"{escaped}\": {idx},\n')
```

Versi yang lebih rapi:
```python
f.write(f'  "{escaped}": {idx},\n')
```
