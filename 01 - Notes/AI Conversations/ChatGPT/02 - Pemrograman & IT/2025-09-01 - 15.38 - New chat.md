Here’s a step-by-step guide to running a **MinIO server** on macOS:

---

## 1. Install MinIO
You can install MinIO using **Homebrew** (recommended):

```bash
brew install minio/stable/minio
```

Alternatively, you can download the binary directly:

```bash
curl -O https://dl.min.io/server/minio/release/darwin-amd64/minio
chmod +x minio
sudo mv minio /usr/local/bin/
```

---

## 2. Create a Data Directory
MinIO needs a place to store your files. For example:

```bash
mkdir -p ~/minio/data
```

---

## 3. Run MinIO Server
Start the server with:

```bash
minio server ~/minio/data
```

By default, MinIO will:
- Start on port `9000` (API) and `9001` (Web console).
- Show you the access key and secret key in the terminal output.

---

## 4. Access the MinIO Console
Open your browser and go to:

```
http://127.0.0.1:9001
```

Log in using the **access key** and **secret key** from the terminal.

---

## 5. (Optional) Set Custom Credentials
You can define your own access key and secret key before running the server:

```bash
export MINIO_ROOT_USER=admin
export MINIO_ROOT_PASSWORD=supersecret
minio server ~/minio/data
```

---

## 6. Keep MinIO Running in the Background
If you want MinIO to run continuously:

```bash
brew services start minio
```

Or, if installed manually, you can use tools like `tmux`, `screen`, or `nohup`.
