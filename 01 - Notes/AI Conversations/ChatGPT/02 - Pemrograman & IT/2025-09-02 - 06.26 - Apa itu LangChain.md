### 🤖 ChatGPT:
LangChain adalah sebuah **framework open-source** yang dirancang untuk membangun aplikasi berbasis **Large Language Models (LLM)** seperti GPT, Claude, LLaMA, dsb.  
Tujuannya bukan hanya untuk memanggil LLM, tetapi juga **menghubungkan LLM dengan data, tool, dan alur kerja yang kompleks**.  

🔑 **Konsep utama LangChain:**
1. **Prompt templates** → Memudahkan membuat dan mengelola prompt agar lebih dinamis dan konsisten.  
2. **Chains** → Rangkaian langkah (misalnya ambil data → proses dengan LLM → kembalikan jawaban).  
3. **Agents** → Model yang bisa memilih aksi sendiri (misalnya, “cari data di database” atau “jalankan kalkulasi” lalu kembali ke pengguna).  
4. **Memory** → Membuat LLM bisa mengingat konteks percakapan sebelumnya.  
5. **Integrasi data** → Bisa dihubungkan ke database, file (PDF, CSV, dll.), API, atau search engine.  
6. **Tooling** → Bisa pakai calculator, Python interpreter, atau bahkan sistem lain seperti Wolfram Alpha, Google Search, dll.

🛠 **Contoh penggunaan LangChain:**
- **Chatbot cerdas** yang bisa mengakses dokumen internal perusahaan.  
- **Sistem Q&A** untuk membaca PDF/website dan menjawab pertanyaan pengguna.  
- **Pipeline analitik** yang menggabungkan LLM dengan tool perhitungan/data science.  
- **AI agents** yang bisa mengambil keputusan sendiri berdasarkan tool yang tersedia.  

📦 **Ekosistem:**
LangChain biasanya dipakai bersama:
- **Vector Database** (mis. Pinecone, Weaviate, Chroma) untuk menyimpan embedding → ini yang mendukung *RAG* (Retrieval Augmented Generation).  
- **Framework pendukung** seperti LangSmith (untuk debugging/monitoring), dan LangServe (untuk deployment API).  

Jadi, kalau diibaratkan, **LangChain itu seperti “lem perekat”** yang menyatukan LLM dengan berbagai sumber data dan tool, sehingga bisa membangun aplikasi AI yang lebih bermanfaat daripada sekadar tanya-jawab biasa.

### 2) Kode lengkap: baca PDF → index ke Chroma → tanya jawab
```python
# rag_pdf.py
import os
from langchain_community.document_loaders import PyPDFLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_community.vectorstores import Chroma
from langchain_openai import OpenAIEmbeddings, ChatOpenAI
from langchain.prompts import ChatPromptTemplate
from langchain.schema.output_parser import StrOutputParser
from langchain.schema.runnable import RunnablePassthrough

# ---------- 0) Konfigurasi ----------
PDF_PATH = "contoh.pdf"  # ganti ke path PDF-mu
CHROMA_DIR = "chroma_db"  # folder untuk penyimpanan vektor

# ---------- 1) Load & pecah dokumen ----------
loader = PyPDFLoader(PDF_PATH)
docs = loader.load()  # list[Document] (tiap halaman)
splitter = RecursiveCharacterTextSplitter(
    chunk_size=1200, chunk_overlap=200, separators=["\n\n", "\n", " ", ""]
)
chunks = splitter.split_documents(docs)

# ---------- 2) Buat embedding & vector store ----------
emb = OpenAIEmbeddings()  # pakai text-embedding-3-large (default LangChain saat ini)
vectordb = Chroma.from_documents(chunks, embedding=emb, persist_directory=CHROMA_DIR)
retriever = vectordb.as_retriever(search_kwargs={"k": 4})

# ---------- 3) Definisikan prompt & LLM ----------
SYSTEM_PROMPT = """Anda adalah asisten yang merangkum isi PDF secara akurat.
Gunakan konteks berikut untuk menjawab. Jika tidak ada di konteks, katakan tidak tahu.
Jawab singkat, jelas, dan sitir bagian relevan jika perlu.
Konteks:
{context}
"""

prompt = ChatPromptTemplate.from_messages(
    [
        ("system", SYSTEM_PROMPT),
        ("human", "Pertanyaan: {question}"),
    ]
)

llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)

# ---------- 4) RAG chain (LCEL) ----------
def format_docs(docs):
    return "\n\n---\n\n".join(d.page_content for d in docs)

rag_chain = (
    {
        "context": retriever | format_docs,
        "question": RunnablePassthrough(),
    }
    | prompt
    | llm
    | StrOutputParser()
)

# ---------- 5) Contoh pemakaian ----------
if __name__ == "__main__":
    print("RAG siap. Contoh pertanyaan:")
    questions = [
        "Apa ringkasan topik utama dokumen ini?",
        "Sebutkan 3 poin penting dari bab pendahuluan.",
        "Adakah definisi kunci atau formula penting? Jelaskan.",
    ]
    for q in questions:
        print("\n==> Q:", q)
        ans = rag_chain.invoke(q)
        print(ans)
```

**Cara pakai:**
1. Simpan PDF sebagai `contoh.pdf` di folder yang sama.
2. Jalankan: `python rag_pdf.py`
3. Ubah daftar `questions` sesuai kebutuhan, atau ganti dengan input dari user (mis. `input()`).

---

### Catatan penting & tips
- **Persistensi**: Chroma menyimpan index di folder `chroma_db`. Jika kamu ubah PDF, hapus folder itu terlebih dulu untuk re-index bersih.
- **Ukuran chunk** memengaruhi kualitas retrieval. Mulai dari `chunk_size=800–1500`, `overlap=100–300`.
- **Model**: `gpt-4o-mini` hemat & cepat. Untuk jawaban lebih detail, bisa `gpt-4.1` (lebih mahal).
- **Keamanan jawaban**: `temperature=0` menjaga jawaban faktual dan konsisten.

```python
import os
import tempfile
from typing import List, Tuple

import streamlit as st
from langchain_community.document_loaders import PyPDFLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_community.vectorstores import Chroma
from langchain.docstore.document import Document

# --- Pilihan LLM & Embeddings ---
from langchain_openai import ChatOpenAI, OpenAIEmbeddings
from langchain_community.chat_models import ChatOllama
from langchain_community.embeddings import OllamaEmbeddings

from langchain.prompts import ChatPromptTemplate
from langchain.schema import BaseMessage
from langchain.schema.output_parser import StrOutputParser
from langchain.schema.runnable import RunnablePassthrough

st.set_page_config(page_title="RAG PDF Multi-File", page_icon="📚", layout="wide")

# ======================
# Sidebar: Konfigurasi
# ======================
st.sidebar.title("⚙️ Konfigurasi")

llm_backend = st.sidebar.selectbox("Backend LLM", ["OpenAI", "Ollama"], index=0)
if llm_backend == "OpenAI":
    st.sidebar.info("Pastikan OPENAI_API_KEY sudah di-set di environment.")
    openai_model = st.sidebar.selectbox(
        "Model OpenAI", ["gpt-4o-mini", "gpt-4o", "gpt-4.1-mini", "gpt-4.1"], index=0
    )
else:
    st.sidebar.info("Pastikan Ollama sudah terinstall & model sudah di-pull.")
    ollama_model = st.sidebar.text_input("Nama model Ollama (chat)", "llama3")
    ollama_embed_model = st.sidebar.text_input("Nama model Embeddings Ollama", "nomic-embed-text")

embed_backend = st.sidebar.selectbox("Embeddings", ["OpenAI", "Ollama"], index=0)

chunk_size = st.sidebar.slider("Chunk size", 300, 2000, 1200, step=100)
chunk_overlap = st.sidebar.slider("Chunk overlap", 0, 400, 200, step=50)
top_k = st.sidebar.slider("K (dokumen ditarik)", 1, 10, 4)

persist = st.sidebar.checkbox("Persist ke disk (Chroma)", value=False)
reset_index = st.sidebar.button("🔄 Reset Index")

st.sidebar.markdown("---")
uploaded_files = st.sidebar.file_uploader(
    "Upload PDF (bisa banyak)", type=["pdf"], accept_multiple_files=True
)

# ======================
# Helper
# ======================
def save_uploaded_files(files) -> List[str]:
    """Simpan file upload ke folder sementara & return path-path-nya."""
    paths = []
    for f in files:
        suffix = ".pdf"
        tmp = tempfile.NamedTemporaryFile(delete=False, suffix=suffix)
        tmp.write(f.read())
        tmp.flush()
        tmp.close()
        paths.append(tmp.name)
    return paths

def load_and_split_pdfs(pdf_paths: List[str], chunk_size: int, chunk_overlap: int) -> List[Document]:
    docs_all = []
    splitter = RecursiveCharacterTextSplitter(
        chunk_size=chunk_size,
        chunk_overlap=chunk_overlap,
        separators=["\n\n", "\n", " ", ""],
    )
    for p in pdf_paths:
        loader = PyPDFLoader(p)
        pages = loader.load()  # halaman -> Document
        # Simpan nomor halaman ke metadata saat split
        for page_doc in pages:
            # page_doc.metadata["source"] sudah berisi path; "page" ada kalau dari PyPDFLoader
            pass
        chunks = splitter.split_documents(pages)
        docs_all.extend(chunks)
    return docs_all

def make_vectordb(docs: List[Document], embed_backend: str, persist_dir: str | None) -> Tuple[Chroma, str]:
    if embed_backend == "OpenAI":
        embeddings = OpenAIEmbeddings()  # default text-embedding-3-large (via LangChain)
    else:
        embeddings = OllamaEmbeddings(model=ollama_embed_model)

    vectordb = Chroma.from_documents(
        docs, embedding=embeddings, persist_directory=persist_dir
    )
    if persist_dir:
        vectordb.persist()
    return vectordb, persist_dir or ""

def get_llm():
    if llm_backend == "OpenAI":
        return ChatOpenAI(model=openai_model, temperature=0)
    else:
        return ChatOllama(model=ollama_model, temperature=0)

SYSTEM_PROMPT = """Anda adalah asisten RAG yang menjawab hanya berdasarkan konteks.
Jika jawaban tidak ada di konteks, katakan tidak tahu secara jujur.
Sertakan sitasi halaman dalam format (hal. X) jika relevan.

KONTEKS:
{context}
"""

prompt = ChatPromptTemplate.from_messages(
    [
        ("system", SYSTEM_PROMPT),
        ("human", "Pertanyaan: {question}"),
    ]
)

def format_docs(docs: List[Document]) -> str:
    out = []
    for d in docs:
        pg = d.metadata.get("page")
        src = d.metadata.get("source")
        label = f"(hal. {pg+1})" if isinstance(pg, int) else ""
        out.append(f"{d.page_content}\n[{label} {os.path.basename(src) if src else ''}]")
    return "\n\n---\n\n".join(out)

# ======================
# Session State
# ======================
if "vectordb" not in st.session_state:
    st.session_state.vectordb = None
if "persist_dir" not in st.session_state:
    st.session_state.persist_dir = None
if "history" not in st.session_state:
    st.session_state.history = []

# ======================
# Main UI
# ======================
st.title("📚 RAG Multi-PDF dengan Sitasi Halaman")
st.caption("LangChain + Chroma + OpenAI/Ollama")

col1, col2 = st.columns([1,1], gap="large")

with col1:
    st.subheader("1) Bangun Index")
    if uploaded_files:
        if reset_index:
            st.session_state.vectordb = None
            st.session_state.persist_dir = None
            st.success("Index direset.")

        with st.spinner("Memproses PDF & membuat index..."):
            paths = save_uploaded_files(uploaded_files)

            persist_dir = None
            if persist:
                persist_dir = tempfile.mkdtemp(prefix="chroma_")

            docs = load_and_split_pdfs(paths, chunk_size, chunk_overlap)

            # Pastikan metadata halaman ada (PyPDFLoader menyimpan 'page' di metadata)
            # Jika tidak ada, coba fallback (biarkan saja—loader biasanya mengisi).
            vectordb, persist_dir_used = make_vectordb(docs, embed_backend, persist_dir)

            st.session_state.vectordb = vectordb
            st.session_state.persist_dir = persist_dir_used

        st.success(f"Index siap! Total chunk: {len(docs)}")
        if persist and persist_dir:
            st.info(f"Chroma dipersist di: {persist_dir}")

    else:
        st.info("Upload satu atau lebih PDF di sidebar, lalu bangun index.")

with col2:
    st.subheader("2) Tanya Dokumen")
    if st.session_state.vectordb is None:
        st.warning("Belum ada index. Silakan upload PDF dan bangun index dulu.")
    else:
        question = st.text_input("Pertanyaan", placeholder="Contoh: Ringkas bab pendahuluan dan sebutkan 3 poin kunci.")
        ask = st.button("🔎 Cari & Jawab")

        if ask and question.strip():
            retriever = st.session_state.vectordb.as_retriever(search_kwargs={"k": top_k})
            llm = get_llm()

            rag_chain = (
                {
                    "context": retriever | format_docs,
                    "question": RunnablePassthrough(),
                }
                | prompt
                | llm
                | StrOutputParser()
            )

            with st.spinner("Menjawab..."):
                answer = rag_chain.invoke(question)

            # tampilkan jawaban
            st.markdown("### Jawaban")
            st.write(answer)

            # tampilkan sumber
            with st.expander("🔗 Sumber yang ditarik"):
                # jalankan retriever sekali lagi untuk menampilkan dokumen
                docs = retriever.get_relevant_documents(question)
                for i, d in enumerate(docs, 1):
                    pg = d.metadata.get("page")
                    src = d.metadata.get("source")
                    st.markdown(f"**{i}.** {os.path.basename(src) if src else 'PDF'} — hal. {pg+1 if isinstance(pg,int) else '?'}")
                    st.write(d.page_content[:1000] + ("..." if len(d.page_content) > 1000 else ""))

            # simpan riwayat
            st.session_state.history.append((question, answer))

st.markdown("---")
st.subheader("🗒️ Riwayat Tanya-Jawab")
if st.session_state.history:
    for q, a in reversed(st.session_state.history[-10:]):
        st.markdown(f"**Q:** {q}")
        st.write(a)
        st.markdown("---")
else:
    st.caption("Belum ada riwayat.")

st.sidebar.markdown("---")
st.sidebar.caption("Tip: Ubah chunk size/overlap bila sitasi terasa kurang akurat.")
```

## Catatan & Tips Praktis
- **Sitasi halaman**: di panel “Sumber yang ditarik” akan muncul asal PDF & nomor halamannya (PyPDFLoader mengisi metadata `page`).
- **Banyak PDF**: upload beberapa sekaligus; index akan mencampurkan semua chunk ke satu vektor-store.
- **Persistensi**: centang “Persist ke disk” agar index tersimpan sementara (berguna untuk eksperimen).
- **Tuning kualitas**:
  - Naikkan `k` kalau konteks terasa kurang lengkap.
  - Sesuaikan `chunk_size` 800–1500 & `overlap` 100–300.
  - Untuk analisis yang lebih detail, coba model LLM yang lebih kuat.
- **Keamanan data**: kalau dokumen sensitif, pertimbangkan menjalankan **Ollama (lokal)** agar data tidak keluar mesin.
