### 🤖 ChatGPT:
Contoh aplikasi web yang **bukan PWA (Progressive Web App)** adalah aplikasi web murni yang tidak memiliki fitur khas PWA, seperti kemampuan untuk diinstal ke perangkat pengguna, bekerja secara offline, atau mendukung notifikasi push. Aplikasi ini hanya berjalan di browser dan sepenuhnya bergantung pada koneksi internet untuk semua fungsi. Berikut adalah beberapa contoh:

### 1. **Wikipedia**
   - **URL**: [https://www.wikipedia.org](https://www.wikipedia.org)
   - **Deskripsi**: Wikipedia adalah ensiklopedia berbasis web yang hanya dapat diakses saat online. Tidak memiliki fitur offline atau kemampuan instalasi seperti PWA.

### 2. **Old School Online Forums**
   - Contoh: Forum-forum lama seperti phpBB atau vBulletin (versi awal).
   - **Deskripsi**: Ini adalah aplikasi berbasis web klasik di mana pengguna dapat membaca atau memposting di forum, tetapi semuanya bergantung pada koneksi internet tanpa fitur offline atau instalasi.

### 3. **Aplikasi Web Akademik**
   - Contoh: Portal sekolah atau kampus seperti **SIAKAD (Sistem Informasi Akademik)**.
   - **Deskripsi**: Aplikasi ini biasanya menyediakan fitur untuk melihat nilai, jadwal, dan informasi akademik lainnya, tetapi tidak memiliki kemampuan untuk bekerja secara offline atau dipasang sebagai aplikasi.

### 4. **E-commerce Sederhana**
   - Contoh: Toko online kecil yang menggunakan platform seperti **WooCommerce** tanpa tambahan PWA.
   - **Deskripsi**: Situs ini memungkinkan pengguna untuk membeli produk, tetapi semuanya dilakukan di browser tanpa fitur offline atau instalasi.

### 5. **Web Formulir Sederhana**
   - Contoh: Formulir pendaftaran online seperti **Google Forms** atau formulir HTML buatan sendiri.
   - **Deskripsi**: Formulir ini memerlukan koneksi internet untuk mengirimkan data dan tidak memiliki fitur instalasi.

### 6. **Website Statik**
   - Contoh: Portofolio pribadi berbasis HTML, CSS, dan JavaScript dasar.
   - **Deskripsi**: Website ini hanya menampilkan informasi dan tidak memiliki interaktivitas kompleks atau fitur PWA.

### 7. **Aplikasi Jadul Berbasis Web**
   - Contoh: **Zimbra Webmail** (versi awal tanpa fitur offline).
   - **Deskripsi**: Digunakan untuk mengelola email, tetapi hanya berfungsi dengan koneksi internet dan tidak memiliki elemen PWA.

Semua aplikasi ini sepenuhnya web-based, tidak memiliki fitur PWA seperti **service worker**, **cache offline**, atau **add-to-home-screen**. Mereka sepenuhnya bergantung pada browser dan koneksi internet.

WhatsApp **bukanlah PWA (Progressive Web App)**, tetapi memiliki layanan berbasis web yang dikenal sebagai **WhatsApp Web**. Berikut penjelasannya:

### **1. WhatsApp Web**:
   - WhatsApp Web adalah aplikasi berbasis browser yang memungkinkan pengguna mengakses akun WhatsApp mereka melalui komputer.
   - **Karakteristik WhatsApp Web**:
     - Tidak bekerja offline: WhatsApp Web membutuhkan koneksi aktif ke ponsel Anda (karena pesan dan data disinkronkan melalui perangkat utama).
     - Tidak bisa diinstal sebagai aplikasi mandiri di perangkat (tidak ada fitur "Add to Home Screen").
     - Tidak menggunakan **Service Workers** untuk caching atau fungsi offline.
   - Karena itu, WhatsApp Web **bukanlah PWA**.

### **2. WhatsApp Desktop**:
   - WhatsApp juga memiliki aplikasi desktop untuk Windows dan macOS.
   - **Karakteristik WhatsApp Desktop**:
     - Ini adalah aplikasi asli (native app), bukan berbasis browser, sehingga juga bukan PWA.

### **3. WhatsApp sebagai Aplikasi Mobile**:
   - Di perangkat Android dan iOS, WhatsApp adalah aplikasi **native**, dibangun menggunakan teknologi spesifik platform (bukan berbasis web).

### **Mengapa WhatsApp bukan PWA?**
- WhatsApp tidak memenuhi karakteristik PWA seperti:
  - Kemampuan **offline-first**: PWA menggunakan service workers untuk bekerja tanpa internet, sedangkan WhatsApp Web memerlukan koneksi aktif ke ponsel.
  - Tidak ada instalasi langsung dari browser: Anda tidak bisa menambahkan WhatsApp Web ke layar utama seperti PWA.
  - Tidak memiliki fitur **push notifications** di web tanpa ponsel yang terhubung.

### **Kesimpulan**:
WhatsApp secara keseluruhan **bukan PWA**. Aplikasi utamanya adalah aplikasi **native** di mobile dan desktop, sedangkan WhatsApp Web adalah aplikasi berbasis browser yang tidak memiliki fitur PWA.

### **Kesimpulan**
Uber memang memiliki versi **PWA sejati** dalam bentuk **Uber Lite**, yang ditujukan untuk menyediakan layanan pemesanan transportasi yang cepat, ringan, dan dapat diakses melalui browser. Ini menjadikan Uber sebagai salah satu contoh sukses penerapan teknologi PWA untuk menjangkau lebih banyak pengguna, terutama di wilayah dengan koneksi internet lambat atau perangkat dengan spesifikasi rendah.
