##  Cara Instalasi BMad Method V4

### 1. **Pastikan Prasyarat (Prerequisite)**
- Diperlukan **Node.js versi 20 atau lebih baru**. Pastikan sudah terpasang di sistem Anda. citeturn0search0turn0search1

### 2. **Perintah Instalasi (Quick Install)**
Untuk instalasi baru atau memperbarui instalasi yang sudah ada, cukup jalankan salah satu dari perintah berikut:

```bash
npx bmad-method install
```
Atau secara eksplisit menggunakan tag 'stable':
```bash
npx bmad-method@stable install
```
citeturn0search0turn0search2

### 3. **Jika Sudah Terinstall (Upgrade)**
Kalau Anda sudah memiliki BMad-Method v4, Anda bisa memperbaruinya dengan:
```bash
git pull
npm run install:bmad
```
citeturn0search0turn0search1

Perintah ini akan:
- Mendeteksi instalasi v4 yang sudah ada  
- Hanya memperbarui file yang berubah  
- Membuat cadangan file sebelumnya (`.bak`) untuk modifikasi Anda  
- Menjaga konfigurasi khusus di proyek tetap aman citeturn0search0turn0search1

### 4. **Perintah CLI Tambahan – Khusus V4**
BMad-Method V4 mendukung berbagai perintah CLI untuk alur kerja menyeluruh:
```bash
npx bmad-method plan
npx bmad-method develop
npx bmad-method qa
npx bmad-method flatten
```
Perintah `flatten` sangat berguna karena mengubah seluruh kode proyek menjadi satu file `.xml` yang terstruktur dan siap untuk diproses oleh agen AI. citeturn0search2
