**1. Content Layer**

Content Layer adalah fitur yang memungkinkan Anda memuat konten dari berbagai sumber ke dalam proyek Astro Anda melalui API yang terstruktur dan aman. Dengan ini, Anda dapat mengintegrasikan konten dari file Markdown, CMS, atau API eksternal dengan mudah.

*Contoh Penggunaan:*

Misalkan Anda memiliki blog dengan artikel yang disimpan dalam file Markdown dan juga ingin menampilkan data dari API eksternal seperti daftar negara. Anda dapat mendefinisikan koleksi konten sebagai berikut:

```javascript
// src/content.config.ts
import { defineCollection, z } from 'astro:content';
import { glob } from 'astro/loaders';

const blog = defineCollection({
  loader: glob({ pattern: "**/*.md", base: "./src/data/blog" }),
  schema: z.object({ /* definisi skema untuk validasi data */ }),
});

const countries = defineCollection({
  loader: () => fetch('https://api.example.com/countries').then(res => res.json()),
});

export const collections = { blog, countries };
```

Dengan konfigurasi di atas, Anda dapat mengakses konten dari kedua sumber tersebut secara terstruktur dalam proyek Astro Anda.

**2. Server Islands**

Server Islands adalah konsep yang memungkinkan penggabungan konten statis yang di-cache dengan konten dinamis yang dipersonalisasi. Ini berarti Anda dapat menyajikan halaman yang sebagian besar statis untuk performa optimal, namun tetap memiliki komponen yang dinamis sesuai kebutuhan pengguna.

*Contoh Penggunaan:*

Misalkan Anda memiliki halaman produk yang sebagian besar informasinya statis, tetapi bagian ulasan pelanggan perlu diperbarui secara real-time. Dengan Server Islands, Anda dapat merender bagian ulasan sebagai komponen dinamis sementara sisa halaman tetap statis dan di-cache untuk performa yang lebih baik.

**3. Simplified Prerendering**

Astro 5.0 menyederhanakan proses prerendering, memungkinkan Anda untuk menentukan halaman atau komponen mana yang harus dirender sebelumnya selama proses build. Ini membantu dalam mengoptimalkan waktu muat halaman dan memastikan konten tersedia segera saat diminta.

*Contoh Penggunaan:*

Anda dapat menandai halaman tertentu untuk diprerender dengan menambahkan opsi `prerender` dalam konfigurasi halaman tersebut, memastikan halaman tersebut dihasilkan selama proses build dan siap disajikan kepada pengguna tanpa penundaan.

1. Ketik skrip narasi.

## **2. Langkah-Langkah Mengotomatiskan Pembuatan Doodle Narasi**

### **Langkah 1: AI Menulis Skrip Secara Otomatis**
Gunakan ChatGPT API untuk menghasilkan teks narasi:
```python
import openai

response = openai.ChatCompletion.create(
    model="gpt-4",
    messages=[
        {"role": "system", "content": "Buatkan skrip cerita edukasi tentang matematika dengan Metode Gasing."}
    ]
)

skrip = response["choices"][0]["message"]["content"]
print(skrip)
```
📌 **Output**: Teks skrip edukasi tentang Matematika dengan Metode Gasing.

---

### **Langkah 2: AI Membuat Gambar Doodle**
Gunakan **DALL·E API atau Stable Diffusion** untuk membuat ilustrasi dalam gaya doodle.

Contoh penggunaan **DALL·E API**:
```python
import openai

response = openai.Image.create(
    model="dall-e-2",
    prompt="A simple black and white doodle drawing of a teacher explaining math to students, hand-drawn style",
    n=1,
    size="1024x1024"
)

doodle_image_url = response["data"][0]["url"]
print(doodle_image_url)
```
📌 **Output**: URL gambar doodle hitam putih.

---

### **Langkah 3: AI Menghasilkan Suara Narasi**
Gunakan **ElevenLabs API** atau **Google Text-to-Speech (TTS)** untuk mengubah teks skrip menjadi suara otomatis.
```python
import requests

url = "https://api.elevenlabs.io/v1/text-to-speech"
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}

data = {
    "text": skrip,
    "voice": "Matthew",
    "model": "eleven_multilingual_v1"
}

response = requests.post(url, headers=headers, json=data)
with open("narration.mp3", "wb") as f:
    f.write(response.content)
```
📌 **Output**: File **MP3 suara narasi otomatis**.

---

### **Langkah 4: AI Membuat Animasi Doodle**
Gunakan **Runway ML API atau VideoScribe API** untuk membuat animasi doodle dari gambar.
```python
import requests

url = "https://api.runwayml.com/v1/generate-animation"
headers = {"Authorization": "Bearer YOUR_API_KEY"}
data = {
    "image": doodle_image_url,
    "animation_type": "doodle-draw"
}

response = requests.post(url, headers=headers, json=data)
animation_url = response.json()["animation"]
print(animation_url)
```
📌 **Output**: Link video animasi doodle.

---

### **Langkah 5: AI Menggabungkan Narasi dan Animasi**
Gunakan **FFmpeg + AI Video Editor (Runway ML, Pika Labs, atau Synthesia)** untuk otomatis menyinkronkan video dengan narasi.
```sh
ffmpeg -i animation.mp4 -i narration.mp3 -c:v copy -c:a aac final_doodle.mp4
```
📌 **Output**: **Video final siap dipublikasikan!**

## **3. Publikasi Otomatis ke YouTube / TikTok**
Gunakan **YouTube API atau TikTok API** untuk mengunggah hasil video secara otomatis.
```python
from googleapiclient.discovery import build

youtube = build('youtube', 'v3', developerKey='YOUR_YOUTUBE_API_KEY')
request = youtube.videos().insert(
    part="snippet,status",
    body={
        "snippet": {
            "title": "Belajar Matematika dengan Metode Gasing",
            "description": "Video doodle edukatif tentang metode belajar cepat matematika.",
            "tags": ["Matematika", "Metode Gasing", "Edukasi"],
            "categoryId": "27"  # Education
        },
        "status": {"privacyStatus": "public"}
    },
    media_body="final_doodle.mp4"
)
response = request.execute()
print("Video berhasil diunggah!")
```
📌 **Output**: Video otomatis diunggah ke YouTube.
