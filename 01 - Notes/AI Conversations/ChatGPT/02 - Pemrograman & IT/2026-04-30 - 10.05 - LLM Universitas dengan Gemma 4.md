# 0. Tentukan dulu tujuan LLM universitas

Sebelum masuk teknis, tentukan chatbot ini akan menjawab apa.

Contoh use case:

1. **Tanya jawab umum**
   - “Kapan pendaftaran mahasiswa baru?”
   - “Apa saja fakultas di universitas ini?”
   - “Berapa biaya kuliah Teknik Informatika?”

2. **Layanan akademik**
   - Jadwal kuliah
   - Kalender akademik
   - Syarat skripsi
   - Aturan cuti kuliah
   - Panduan KRS

3. **Layanan internal**
   - SOP dosen
   - Panduan administrasi
   - Peraturan rektor
   - FAQ kepegawaian

4. **Asisten mahasiswa**
   - Rekomendasi alur administrasi
   - Penjelasan kurikulum
   - Bantu mencari dokumen kampus

Untuk universitas, model sebaiknya **tidak langsung menjawab dari ingatan internal model**, tetapi mengambil jawaban dari dokumen resmi universitas. Jadi arsitektur paling tepat adalah:

> **Gemma 4 + RAG + database dokumen universitas**

Bukan:

> “Fine-tune Gemma 4 dengan semua PDF kampus lalu berharap model hafal semuanya.”

# 1. Pahami dua pendekatan utama: RAG vs fine-tuning

## A. RAG — Retrieval-Augmented Generation

RAG artinya model mencari dulu informasi dari dokumen universitas, lalu menjawab berdasarkan dokumen itu.

Cocok untuk:

- FAQ kampus
- Peraturan akademik
- Biaya kuliah
- Jadwal
- Kurikulum
- SOP
- Kalender akademik
- Informasi yang sering berubah

Kelebihan:

- Lebih mudah diperbarui
- Jawaban bisa diberi sumber
- Risiko halusinasi lebih rendah
- Tidak perlu training besar
- Cocok untuk data kampus yang terus berubah

## B. Fine-tuning

Fine-tuning artinya bobot model dilatih ulang agar perilakunya berubah.

Cocok untuk:

- Membuat model menjawab dengan gaya bahasa kampus
- Format jawaban konsisten
- Mengikuti SOP percakapan tertentu
- Klasifikasi intent
- Ekstraksi data
- Menjawab dalam struktur khusus

Tidak cocok untuk:

- Menghafalkan semua dokumen universitas
- Menyimpan jadwal/biaya/peraturan yang sering berubah
- Mengganti database pengetahuan

Rekomendasi saya:

> **Fase 1: bangun RAG dulu.**  
> **Fase 2: evaluasi.**  
> **Fase 3: fine-tune hanya jika perlu memperbaiki gaya, format, atau instruksi.**

# 5. Ubah dokumen menjadi teks

Untuk file `.txt`, `.md`, atau `.html`, mudah.

Untuk PDF, gunakan parser seperti:

- `pymupdf`
- `pdfplumber`
- `unstructured`
- `docling`
- OCR jika PDF adalah hasil scan

Contoh script ekstraksi PDF sederhana:

```python
import fitz  # pymupdf
from pathlib import Path

def extract_pdf_text(pdf_path):
    doc = fitz.open(pdf_path)
    pages = []

    for page_number, page in enumerate(doc, start=1):
        text = page.get_text()
        pages.append({
            "page": page_number,
            "text": text
        })

    return pages

pdf_path = "data_universitas/pedoman_akademik.pdf"
pages = extract_pdf_text(pdf_path)

for page in pages[:2]:
    print("PAGE:", page["page"])
    print(page["text"][:1000])
```

# 6. Chunking: potong dokumen menjadi bagian kecil

LLM tidak sebaiknya diberi satu PDF utuh. Potong dokumen menjadi chunk.

Ukuran umum:

```text
500–1.000 token per chunk
overlap 50–150 token
```

Contoh:

```python
from langchain_text_splitters import RecursiveCharacterTextSplitter

splitter = RecursiveCharacterTextSplitter(
    chunk_size=1200,
    chunk_overlap=200,
    separators=["\n\n", "\n", ".", " ", ""]
)

text = """
Isi dokumen pedoman akademik...
"""

chunks = splitter.split_text(text)

for i, chunk in enumerate(chunks):
    print("CHUNK", i)
    print(chunk[:500])
```

Chunk jangan terlalu pendek, karena konteks hilang. Jangan terlalu panjang, karena retrieval jadi kurang presisi.

Untuk dokumen universitas, chunk ideal biasanya berbasis heading:

```text
BAB 3 - Registrasi Akademik
3.1 KRS
3.2 Perubahan KRS
3.3 Pembatalan Mata Kuliah
```

Lebih baik chunk mengikuti struktur heading daripada potong setiap 1.000 karakter secara buta.

# 7. Buat embedding dokumen

Embedding mengubah teks menjadi representasi angka agar bisa dicari secara semantik.

Contoh model embedding lokal:

- `BAAI/bge-m3`
- `intfloat/multilingual-e5-large`
- `sentence-transformers/paraphrase-multilingual-mpnet-base-v2`

Untuk bahasa Indonesia dan dokumen campuran Inggris–Indonesia, saya sarankan mulai dari:

```text
BAAI/bge-m3
```

Karena bagus untuk multilingual dan retrieval.

Install:

```bash
pip install sentence-transformers chromadb
```

Contoh indexing ke ChromaDB:

```python
from sentence_transformers import SentenceTransformer
import chromadb
from uuid import uuid4

embedding_model = SentenceTransformer("BAAI/bge-m3")

client = chromadb.PersistentClient(path="./chroma_universitas")
collection = client.get_or_create_collection("dokumen_universitas")

documents = [
    {
        "text": "Mahasiswa dapat mengisi KRS melalui portal akademik pada masa registrasi.",
        "metadata": {
            "title": "Pedoman Akademik 2026",
            "page": 12,
            "access_level": "student_only"
        }
    },
    {
        "text": "Pendaftaran mahasiswa baru dibuka mulai 1 Mei 2026.",
        "metadata": {
            "title": "Panduan Admisi 2026",
            "page": 3,
            "access_level": "public"
        }
    }
]

texts = [d["text"] for d in documents]
embeddings = embedding_model.encode(texts).tolist()

collection.add(
    ids=[str(uuid4()) for _ in documents],
    documents=texts,
    embeddings=embeddings,
    metadatas=[d["metadata"] for d in documents]
)
```

```python
from sentence_transformers import SentenceTransformer
import chromadb

embedding_model = SentenceTransformer("BAAI/bge-m3")

client = chromadb.PersistentClient(path="./chroma_universitas")
collection = client.get_or_create_collection("dokumen_universitas")

def retrieve_context(question, access_level="public", n_results=5):
    query_embedding = embedding_model.encode([question]).tolist()[0]

    results = collection.query(
        query_embeddings=[query_embedding],
        n_results=n_results,
        where={"access_level": access_level}
    )

    contexts = []

    for doc, meta in zip(results["documents"][0], results["metadatas"][0]):
        contexts.append({
            "text": doc,
            "metadata": meta
        })

    return contexts


def build_prompt(question, contexts):
    context_text = ""

    for i, item in enumerate(contexts, start=1):
        meta = item["metadata"]
        text = item["text"]

        title = meta.get("title", "Dokumen")
        page = meta.get("page", "-")

        context_text += f"""
[{i}] {title}, halaman {page}
{text}
"""

    prompt = f"""
Anda adalah asisten resmi Universitas X.

Aturan:
1. Jawab hanya berdasarkan KONTEKS.
2. Jika jawaban tidak ada di KONTEKS, katakan bahwa informasi belum tersedia.
3. Jangan mengarang.
4. Gunakan bahasa Indonesia yang formal, jelas, dan ramah.
5. Sebutkan sumber dokumen jika tersedia.

KONTEKS:
{context_text}

PERTANYAAN:
{question}

JAWABAN:
"""

    return prompt
```

Contoh `main.py` dengan FastAPI:

```python
from fastapi import FastAPI
from pydantic import BaseModel
from app.rag import retrieve_context, build_prompt
from app.llm import generate_answer

app = FastAPI()

class ChatRequest(BaseModel):
    question: str
    user_role: str = "public"

@app.post("/chat")
def chat(request: ChatRequest):
    contexts = retrieve_context(
        question=request.question,
        access_level=request.user_role,
        n_results=5
    )

    prompt = build_prompt(request.question, contexts)
    answer = generate_answer(prompt)

    sources = [
        {
            "title": c["metadata"].get("title"),
            "page": c["metadata"].get("page")
        }
        for c in contexts
    ]

    return {
        "answer": answer,
        "sources": sources
    }
```

# 12. Tambahkan reranker supaya jawaban lebih akurat

Vector search kadang mengambil dokumen yang mirip tapi bukan paling tepat.

Tambahkan reranker:

```text
User question
  ↓
Ambil 20 chunk dari vector DB
  ↓
Reranker pilih 5 terbaik
  ↓
Gemma 4 menjawab
```

Model reranker yang bisa dicoba:

```text
BAAI/bge-reranker-v2-m3
```

Contoh sederhana:

```python
from FlagEmbedding import FlagReranker

reranker = FlagReranker("BAAI/bge-reranker-v2-m3", use_fp16=True)

def rerank(question, candidate_chunks, top_k=5):
    pairs = [[question, chunk["text"]] for chunk in candidate_chunks]
    scores = reranker.compute_score(pairs)

    ranked = sorted(
        zip(candidate_chunks, scores),
        key=lambda x: x[1],
        reverse=True
    )

    return [item[0] for item in ranked[:top_k]]
```

# 16. Kapan perlu fine-tuning?

Lakukan fine-tuning hanya jika RAG sudah berjalan tetapi model masih bermasalah seperti:

- Gaya bahasa tidak sesuai identitas kampus
- Jawaban terlalu panjang
- Tidak patuh format
- Sering tidak mau mengatakan “tidak tahu”
- Sulit mengikuti SOP percakapan
- Perlu klasifikasi intent khusus

Contoh data fine-tuning yang baik:

```jsonl
{"messages":[{"role":"system","content":"Anda adalah asisten resmi Universitas X."},{"role":"user","content":"Kapan saya bisa ambil KRS?"},{"role":"assistant","content":"Untuk informasi jadwal KRS, silakan merujuk pada Kalender Akademik terbaru. Jika dokumen tersedia, saya akan menjawab berdasarkan tanggal yang tercantum di sana."}]}
{"messages":[{"role":"system","content":"Anda adalah asisten resmi Universitas X."},{"role":"user","content":"Saya mau ubah nilai saya."},{"role":"assistant","content":"Maaf, saya tidak dapat membantu mengubah nilai. Jika Anda merasa ada kesalahan nilai, silakan mengajukan proses klarifikasi nilai melalui prosedur akademik resmi."}]}
```

Data fine-tuning tidak perlu ribuan dokumen mentah. Yang dibutuhkan adalah contoh percakapan berkualitas.

Mulai dari:

```text
300–1.000 contoh Q&A berkualitas
```

Lebih baik 500 contoh bagus daripada 20.000 contoh berantakan.

# 17. Fine-tuning Gemma 4 dengan LoRA / QLoRA

Untuk universitas, gunakan **LoRA** atau **QLoRA**, bukan full fine-tuning.

Kelebihan LoRA:

- Lebih hemat GPU
- Lebih cepat
- Bisa rollback
- Cocok untuk instruction tuning

Install umum:

```bash
pip install transformers datasets peft trl accelerate bitsandbytes
```

Contoh format dataset `train.jsonl`:

```jsonl
{"instruction":"Jawab sebagai asisten resmi Universitas X.","input":"Bagaimana cara mengajukan cuti kuliah?","output":"Mahasiswa dapat mengajukan cuti kuliah melalui portal akademik sesuai prosedur yang berlaku. Pastikan Anda memeriksa persyaratan pada SOP Cuti Kuliah terbaru."}
{"instruction":"Jawab sebagai asisten resmi Universitas X.","input":"Apakah kamu bisa mengganti nilai saya?","output":"Maaf, saya tidak dapat membantu mengganti nilai. Jika terdapat dugaan kesalahan nilai, silakan mengikuti prosedur klarifikasi nilai resmi melalui bagian akademik."}
```

```python
def format_example(example):
    return f"""
Instruksi:
{example['instruction']}

Pertanyaan:
{example['input']}

Jawaban:
{example['output']}
"""

lora_config = LoraConfig(
    r=16,
    lora_alpha=32,
    lora_dropout=0.05,
    target_modules=[
        "q_proj",
        "k_proj",
        "v_proj",
        "o_proj",
        "gate_proj",
        "up_proj",
        "down_proj"
    ],
    task_type="CAUSAL_LM"
)

training_args = TrainingArguments(
    output_dir="./gemma4-university-lora",
    per_device_train_batch_size=1,
    gradient_accumulation_steps=8,
    learning_rate=2e-4,
    num_train_epochs=3,
    logging_steps=10,
    save_steps=100,
    bf16=True,
    report_to="none"
)

trainer = SFTTrainer(
    model=model,
    tokenizer=tokenizer,
    train_dataset=dataset["train"],
    formatting_func=format_example,
    peft_config=lora_config,
    args=training_args
)

trainer.train()
trainer.save_model("./gemma4-university-lora")
```

Sesudah fine-tuning, tetap gunakan RAG.

Arsitektur akhirnya:

```text
Gemma 4 instruction-tuned/fine-tuned
        +
RAG dokumen universitas
```

Jika hardware terbatas:

1. Gunakan model quantized
2. Pakai RAG
3. Fine-tune model kecil dulu
4. Jangan mulai dari model paling besar
