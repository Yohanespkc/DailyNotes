# 💬 Mengubah HTM ke PDF

**Tanggal:** `2025-07-08 03.30`  
**Sumber:** ChatGPT Export  

---

### 👤 User:
bagaimana mengubah .htm menjadi pdf?

### 🤖 ChatGPT:
Untuk mengubah file **.htm** atau **.html** menjadi **PDF**, ada beberapa cara mudah yang bisa kamu pilih, tergantung sistem operasi dan perangkat yang kamu gunakan:

---

### 🟢 **Cara 1: Menggunakan Browser (Chrome, Edge, Firefox, Safari)**
Ini adalah cara termudah.

1. **Buka file `.htm`** dengan browser (klik kanan → Open with → Google Chrome atau browser lain).
2. Tekan **Ctrl + P** (Windows) atau **Cmd + P** (Mac) untuk membuka dialog cetak.
3. Ubah **Destination/Printer** menjadi **"Save as PDF"** atau **"Microsoft Print to PDF"**.
4. Klik **Save**.
5. Pilih lokasi dan beri nama file PDF-nya.

---

### 🟢 **Cara 2: Menggunakan Microsoft Word (jika file .htm bisa dibuka di Word)**

1. Buka Microsoft Word.
2. Klik **File → Open**, lalu pilih file `.htm`.
3. Setelah terbuka, klik **File → Save As**.
4. Pilih **Save as type: PDF**.
5. Simpan.

---

### 🟢 **Cara 3: Menggunakan Alat Online (Gratis)**

Beberapa situs yang bisa kamu gunakan:
- [https://www.htmlpdf.com/](https://www.htmlpdf.com/)
- [https://www.web2pdfconvert.com/](https://www.web2pdfconvert.com/)
- [https://www.pdfcrowd.com/](https://www.pdfcrowd.com/)

Langkah umum:
1. Unggah file `.htm` atau masukkan URL jika itu halaman online.
2. Klik "Convert to PDF".
3. Unduh hasilnya.

---

### 🟢 **Cara 4: Menggunakan LibreOffice atau WPS Office**

Jika kamu tidak punya Microsoft Word:
1. Buka file `.htm` di **LibreOffice Writer** atau **WPS Writer**.
2. Klik **File → Export as PDF**.

---

Kalau kamu mau, kirim file `.htm`-nya ke sini, saya bisa bantu konversikan jadi PDF juga.
