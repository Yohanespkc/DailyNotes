# 💬 Apa itu Sistem Operasi

**Tanggal:** `2026-05-22 09.47`  
**Sumber:** ChatGPT Export  

---

### 👤 User:
apa itu operating system

### 🤖 ChatGPT:
**Operating system** atau **sistem operasi** adalah software utama yang mengatur kerja komputer atau perangkat, sekaligus menjadi penghubung antara pengguna, aplikasi, dan hardware.

Contohnya: **Windows, macOS, Linux, Android, dan iOS**.

Fungsi utama sistem operasi:
- Mengatur hardware seperti CPU, RAM, penyimpanan, keyboard, layar, dan printer.
- Menjalankan aplikasi seperti browser, Word, game, atau WhatsApp.
- Mengelola file dan folder.
- Mengatur keamanan, akun pengguna, dan izin aplikasi.
- Menyediakan tampilan antarmuka, seperti desktop, ikon, menu, atau layar sentuh.

Analoginya, sistem operasi itu seperti **manajer restoran**: pengguna memesan sesuatu lewat aplikasi, lalu sistem operasi mengatur “dapur” hardware agar pekerjaan selesai dengan benar.
