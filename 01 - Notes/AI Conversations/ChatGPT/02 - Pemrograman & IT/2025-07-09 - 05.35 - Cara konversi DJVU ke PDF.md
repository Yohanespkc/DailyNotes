# 💬 Cara konversi DJVU ke PDF

**Tanggal:** `2025-07-09 05.35`  
**Sumber:** ChatGPT Export  

---

### 👤 User:
bagaimana mengubah file .djvu dalam pdf

### 🤖 ChatGPT:
Untuk mengubah file **.djvu** menjadi **.pdf**, kamu bisa menggunakan beberapa metode, baik secara **online**, **menggunakan software**, atau **via command line** (jika kamu terbiasa dengan terminal). Berikut cara-caranya:

---

### 🔹 1. **Cara Online (paling mudah)**
Cukup upload dan konversi:

#### Situs yang bisa kamu pakai:
- [https://www.djvu-pdf.com/](https://www.djvu-pdf.com/)
- [https://cloudconvert.com/djvu-to-pdf](https://cloudconvert.com/djvu-to-pdf)
- [https://convertio.co/id/djvu-pdf/](https://convertio.co/id/djvu-pdf/)

**Langkah-langkah:**
1. Buka salah satu situs di atas.
2. Upload file .djvu kamu.
3. Tunggu proses konversi.
4. Unduh file PDF yang sudah jadi.

---

### 🔹 2. **Menggunakan Software (Offline)**
#### a. **DjView** atau **DjVuLibre**
- Install `DjView` dari DjVuLibre (tersedia untuk Windows, macOS, dan Linux)
- Buka file `.djvu`
- Pilih menu **File > Export As** → pilih format **PDF**

#### b. **Calibre (gratis, multi-platform)**
- Download: [https://calibre-ebook.com](https://calibre-ebook.com)
- Import file .djvu → pilih **Convert** → output format: **PDF**

---

### 🔹 3. **Menggunakan Terminal (Linux/macOS)**
Jika kamu suka command line:

```bash
ddjvu -format=pdf input.djvu output.pdf
```

Pastikan kamu sudah menginstall `djvulibre` (bisa diinstall via Homebrew di macOS atau apt di Linux):

```bash
# Ubuntu
sudo apt install djvulibre-bin

# macOS (Homebrew)
brew install djvulibre
```
