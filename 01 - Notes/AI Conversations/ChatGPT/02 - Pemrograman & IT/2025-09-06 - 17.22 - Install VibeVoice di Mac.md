# 💬 Install VibeVoice di Mac

**Tanggal:** `2025-09-06 17.22`  
**Sumber:** ChatGPT Export  

---

### 👤 User:
tolong ajari saya untuk install vibevoice. Saya menggunakan mac. https://microsoft.github.io/VibeVoice/

### 🤖 ChatGPT:
Ternyata, menurut halaman resmi Microsoft per **5 September 2025**, repositori **VibeVoice** telah dinonaktifkan sementara karena tim Microsoft menemukan pemakaian yang tidak sesuai dengan maksud awal mereka citeturn0view0. Jadi, saat ini kamu **belum bisa menginstal** VibeVoice melalui repo Microsoft — minimal sampai mereka mengembalikan akses atau memperbarui kondisi.

Namun, ada beberapa alternatif yang mungkin bisa kamu coba di Mac kamu:

---

###  1. Alternatif: Repositori komunitas "mpaepper/vibevoice"
Reposit ini bukan versi resmi dari Microsoft, tetapi memiliki mekanisme serupa untuk diktasi suara lokal berbasis Whisper. Meski ini bukan TTS, tapi mungkin berguna:

- **Cara install:**
  1. `git clone https://github.com/mpaepper/vibevoice.git`
  2. Masuk ke foldernya: `cd vibevoice`
  3. Install dependencies: `pip install -r requirements.txt`
  4. Jalankan: `python src/vibevoice/cli.py`  
  citeturn0search1

- **Catatan:**
  - Butuh Python ≥ 3.13.
  - Sistem menyarankan GPU dengan CUDA agar cepat meski bisa dijalankan di CPU citeturn0search1.

---

###  2. Versi VibeVoice “tidak resmi” di Hugging Face
Ada diskusi mengenai pengguna yang berhasil mendapatkan VibeVoice (versi 1.5B) berjalan di Mac Silicon:

- Langkah yang dilakukan oleh pengguna:
  1. `git clone microsoft/VibeVoice`
  2. Buat virtual environment (venv atau conda) dengan Python ≥ 3.9
  3. Upgrade pip/setuptools/wheel
  4. (Opsional) Install `ffmpeg` via Homebrew (`brew install ffmpeg`)
  5. Install package dengan `pip install -e .`
  6. Unduh model dari Hugging Face (1.5B atau Large)
  7. Jalankan demo inference  
  citeturn0search7

- **Catatan penting**: Repo Microsoft mungkin tidak lagi tersedia saat ini → butuh cek apakah bisa di-clone masih bisa, atau ada fork alternatif.

---

###  3. Unduhan resmi (vibevoice.net) — TTS ringan, bukan versi Microsoft
Ada versi “client” ringan yang bisa diunduh dari situs vibevoice.net:

- Kompatibel dengan macOS **Big Sur (11.0)** atau lebih baru citeturn0search9.
- Namun ini tampaknya bukan versi TTS LLM Microsoft, lebih mirip alat ringan untuk voice-to-code atau diktasi ringan citeturn0search14.

---

###  Rekomendasi langkah selanjutnya untuk kamu:

1. **Cek kembali akses repositori Microsoft** (`git clone microsoft/VibeVoice`). Jika berhasil, kamu bisa lanjut seperti diskusi di Hugging Face citeturn0search7.
2. Jika repo tidak bisa diakses, pertimbangkan alternatif seperti:
   - Kloning dan pasang versi `mpaepper/vibevoice` untuk diktasi berbasis Whisper citeturn0search1.
   - Coba unduhan dari vibevoice.net (yang ringan) untuk fungsi dasar voice-to-code/data.
3. Jika butuh TTS LLM dan repo Microsoft masih offline, kamu masih bisa:
   - Memantau issue atau pembaruan di repositori Microsoft.
   - Ikuti perkembangan dari komunitas atau fork yang memungkinkan.

---

 **Contoh jalur instalasi (jika repo Microsoft masih bisa diakses):**

```bash
git clone https://github.com/microsoft/VibeVoice.git
cd VibeVoice
python3 -m venv .venv
source .venv/bin/activate
pip install -U pip setuptools wheel
brew install ffmpeg  # opsi jika diperlukan
pip install -e .
huggingface-cli download microsoft/VibeVoice-1.5B --repo-type model
# atau versi Large
huggingface-cli download microsoft/VibeVoice-Large --repo-type model
python demo/inference_from_file.py \
  --model_path microsoft/VibeVoice-1.5B \
  --txt_path demo/text_examples/1p_abs.txt \
  --speaker_names Alice
```

---

Kalau kamu bisa coba langkah-langkah di atas dan butuh bantuan lebih lanjut — misalnya error saat instal, kesulitan unduh model, atau setting lingkungan Python — langsung bilang saja ya! Senang bantu terus.
