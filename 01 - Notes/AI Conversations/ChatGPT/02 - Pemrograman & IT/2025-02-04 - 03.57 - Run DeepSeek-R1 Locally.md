# 💬 Run DeepSeek-R1 Locally

### 👤 User:
how Run Locally and Privately Distilled DeepSeek-R1 With Graphics User Interface on Linux Ubuntu

### 🤖 ChatGPT:
Running a **locally and privately distilled DeepSeek-R1** with a **Graphical User Interface (GUI)** on **Linux Ubuntu** requires a few steps:

## **Step 1: System Requirements**
Ensure your system meets the following requirements:
- **Ubuntu 20.04+**
- **GPU** with at least **16GB VRAM** (NVIDIA recommended)
- **CUDA 11+** and **cuDNN**
- **Python 3.8+**
- **PyTorch with GPU support**
- **Hugging Face Transformers** or `deepseek-cpp`

## **Step 2: Install Dependencies**
Open the terminal and run:

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y python3 python3-pip git wget
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
pip install transformers accelerate gradio
```

> *Replace `cu118` with the appropriate CUDA version installed on your system.*

## **Step 3: Download and Prepare DeepSeek-R1**
You can use the **DeepSeek-R1 model** from Hugging Face:

```bash
git clone https://huggingface.co/deepseek-ai/deepseek-llm-7b
cd deepseek-llm-7b
pip install -r requirements.txt
```

Or use a distilled version with `deepseek-cpp` for efficiency:

```bash
git clone https://github.com/deepseek-ai/deepseek-cpp.git
cd deepseek-cpp
make
```

## **Step 4: Create a Simple GUI with Gradio**
You can create a local web-based GUI using **Gradio**:

```python
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer
import gradio as gr

# Load Model
model_name = "deepseek-ai/deepseek-llm-7b"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name, torch_dtype=torch.float16, device_map="auto")

# Define Function
def chat(message):
    inputs = tokenizer(message, return_tensors="pt").to("cuda")
    output = model.generate(**inputs, max_length=100)
    return tokenizer.decode(output[0], skip_special_tokens=True)

# Create Interface
iface = gr.Interface(fn=chat, inputs="text", outputs="text", title="DeepSeek-R1 Chatbot")

# Launch GUI
iface.launch(share=False)
```

Save this as `deepseek_gui.py` and run:

```bash
python3 deepseek_gui.py
```

Then, open **http://127.0.0.1:7860/** in your browser.

## **Alternative: Running with Text-Only CLI**
For a **text-based** version, run:

```python
while True:
    prompt = input("You: ")
    if prompt.lower() in ["exit", "quit"]:
        break
    response = chat(prompt)
    print("DeepSeek:", response)
```
