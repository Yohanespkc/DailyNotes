## 🔧 Persiapan
1. **Download Virtual Machine Software**  
   - Pilih salah satu:
     - **VirtualBox** (gratis) → [virtualbox.org](https://www.virtualbox.org/)  
     - **Parallels Desktop** (berbayar, tapi lebih user friendly).  

2. **Siapkan ISO Windows XP (32-bit)**  
   - Bisa cari "Windows XP SP3 ISO" (banyak tersedia online).  

3. **Installer Adobe PageMaker 7.0**  
   - File installer `.exe` (biasanya versi 7.0).  
   - Bisa dari CD lama atau unduhan arsip (karena Adobe sudah tidak menjual).  

---

## 🖥️ Step-by-Step Instalasi

### **Langkah 1 – Buat Virtual Machine**
- Buka VirtualBox → klik **New**.  
- Nama: `Windows XP`  
- Type: `Microsoft Windows`  
- Version: `Windows XP (32-bit)`  
- Memory: pilih 1024 MB atau lebih.  
- Hard disk: buat virtual disk ±10–20 GB (format VDI).  

---

### **Langkah 2 – Install Windows XP**
- Masukkan ISO Windows XP ke VirtualBox (menu *Settings → Storage → pilih ISO*).  
- Jalankan VM → ikuti proses instalasi Windows XP.  

---

### **Langkah 3 – Install Adobe PageMaker 7.0**
- Setelah Windows XP siap:  
  - Mount ISO/installer PageMaker (atau drag file installer ke VM).  
  - Jalankan **Setup.exe** → install sampai selesai.  

---

### **Langkah 4 – Buka File .PMD**
- Dari macOS, copy file `.PMD` ke folder **Shared Folder** VirtualBox.  
- Masuk ke Windows XP → buka folder tersebut.  
- Jalankan PageMaker 7.0 → **File → Open → pilih file .PMD**.  

---

### **Langkah 5 – Konversi**
- Setelah file terbuka:
  - Pilih **File → Export → PDF** (jika ada Acrobat Distiller).  
  - Atau **Print → Adobe PDF / PostScript** lalu buka di Acrobat untuk jadi PDF.  
- Alternatif: simpan dulu, lalu buka dengan **Adobe InDesign CS6** di komputer modern.  

---

⚡ Catatan penting:
- **Font lama**: Kalau file .PMD Anda pakai font jadul, pastikan font tersebut di-install juga di Windows XP agar layout tidak berantakan.  
- **Stabilitas**: Jalankan VM hanya untuk buka & konversi dokumen, karena XP tidak aman untuk internet modern.
