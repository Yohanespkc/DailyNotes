|------------------------|---------------------|--------------|

### Catatan:
- **BPE** (Byte Pair Encoding) dan **WordPiece** serupa dalam semangat: keduanya memecah kata menjadi sub-kata atau byte-level token untuk menangani kosakata besar dan kata yang jarang.
- Model seperti **GPT-2 dan GPT-3** menggunakan **byte-level BPE**, yang memperluas tokenisasi hingga tingkat karakter dan byte (sehingga bisa menangani berbagai bahasa dan simbol).
- Model seperti **T5 dan LLaMA** menggunakan **SentencePiece**, yaitu varian BPE yang tidak bergantung pada whitespace dan bisa menangani bahasa multibahasa lebih baik.

Mau dicek tokenizer tertentu?

### 👤 User:
apa yang dimaksud tokenizer

### 🤖 ChatGPT:
Tokenizer adalah **alat (komponen)** dalam Natural Language Processing (NLP) yang **memecah teks menjadi unit-unit kecil yang disebut *token***. Token bisa berupa:

- Kata (word-based tokenizer)  
- Sub-kata (subword tokenizer, seperti BPE atau WordPiece)  
- Karakter  
- Bahkan byte (byte-level tokenizer)

### Tujuan tokenizer:
Agar komputer bisa memahami teks dalam bentuk angka (karena model ML hanya paham angka), teks harus diubah jadi token, lalu token ini dikonversi menjadi **ID numerik (integer)** berdasarkan *vocabulary* atau kamus yang dimiliki model.

---

### Contoh sederhana:

Kalimat:  
```
Ini aku dan kamu
```

Tokenizer bisa mengubahnya jadi:

```
['Ini', 'aku', 'dan', 'kamu']      ← word-level tokenizer  
['In', 'i', 'ak', 'u', 'dan', 'ka', 'mu'] ← subword (BPE/WordPiece)
```

Lalu setiap token akan dikonversi jadi ID token, seperti:

```
['Ini', 'aku', 'dan', 'kamu'] → [101, 202, 303, 404]
```

---

### Jenis-jenis tokenizer:

| Jenis              | Contoh Model       | Keterangan |
|--------------------|--------------------|------------|
| **Whitespace**      | Sangat dasar       | Memisah berdasarkan spasi |
| **WordPiece**       | BERT, mBERT        | Subword tokenizer dari Google |
| **Byte Pair Encoding (BPE)** | GPT-2, RoBERTa | Menggabungkan byte yang sering muncul |
| **SentencePiece**   | T5, LLaMA          | Tidak tergantung spasi, cocok multibahasa |
| **Byte-level BPE**  | GPT-2, GPT-3       | Tokenisasi di level byte (lebih fleksibel) |

---

### Ilustrasi proses:

1. **Teks asli**:  
   `"Saya suka matematika"`

2. **Tokenizer**:  
   `['Saya', ' suka', ' matem', 'atika']`

3. **Token IDs (berdasarkan vocab)**:  
   `[201, 452, 8912, 1341]`

4. **Model**:  
   Menggunakan ID token ini sebagai input untuk proses prediksi, klasifikasi, generasi teks, dsb.

## 🧠 Intuisi Dasarnya

Saat pelatihan, model LLM **belajar memprediksi token berikutnya** dari rangkaian token sebelumnya. Ini disebut **causal language modeling** (atau **auto-regressive modeling**).

Contohnya:

> Teks:  
> `"Ini aku dan kamu bermain bola"`

Model akan belajar dari banyak contoh seperti:

| Input (konteks)            | Target (diprediksi)  |
|----------------------------|----------------------|
| `Ini`                      | `aku`                |
| `Ini aku`                  | `dan`                |
| `Ini aku dan`              | `kamu`               |
| `Ini aku dan kamu`         | `bermain`            |
| `Ini aku dan kamu bermain` | `bola`               |

Jadi model dilatih untuk menebak:  
**"Kalau sudah ada `Ini aku dan`, token selanjutnya paling mungkin apa?"**

---

## 🔧 Proses Waktu Pelatihan (Training Phase)

1. **Tokenisasi**  
   Kalimat diubah menjadi token, lalu ke token ID (angka).

2. **Input & Target Shifted**  
   - Input: `["Ini", "aku", "dan", "kamu", "bermain"]`  
   - Target: `["aku", "dan", "kamu", "bermain", "bola"]`  
   Jadi, model belajar memprediksi **target[i]** dari **input[:i]**.

3. **Loss Function**  
   Model dihukum (pakai **cross-entropy loss**) kalau prediksi tokennya meleset dari target.

---

## 🧩 Contoh Kalimat Tidak Lengkap

Misalnya kamu punya kalimat:

> `"Pagi ini aku pergi ke"`

Model akan mencoba memprediksi token selanjutnya, misalnya:

> `"sekolah"`, `"pasar"`, `"kantor"`, dst.

Model akan memberikan distribusi probabilitas dari kemungkinan token yang cocok, dan memilih yang paling mungkin.

---

## 📌 Setelah Pelatihan: Inference

Ketika model sudah selesai dilatih, dan kamu beri prompt:

```plaintext
"Dia sedang belajar"
```

Model akan **menghasilkan token berikutnya** satu per satu berdasarkan probabilitas tertinggi, misalnya:

```plaintext
"Dia sedang belajar matematika di rumah bersama temannya."
```

## 🔧 1. **Contoh Pelatihan Sederhana (Next Token Prediction)**

Kita buat model super simpel pakai PyTorch, cuma untuk memahami cara kerjanya.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

# Contoh kalimat dan tokennya
vocab = ["ini", "aku", "dan", "kamu", "bermain", "bola", "<pad>"]
word_to_idx = {word: i for i, word in enumerate(vocab)}
idx_to_word = {i: word for word, i in word_to_idx.items()}

# Kalimat: ini aku dan kamu bermain bola
sequence = ["ini", "aku", "dan", "kamu", "bermain", "bola"]
input_ids = torch.tensor([word_to_idx[w] for w in sequence[:-1]])  # input
target_ids = torch.tensor([word_to_idx[w] for w in sequence[1:]])  # label

# Model sederhana
class ToyModel(nn.Module):
    def __init__(self, vocab_size, embed_dim):
        super().__init__()
        self.embed = nn.Embedding(vocab_size, embed_dim)
        self.linear = nn.Linear(embed_dim, vocab_size)

    def forward(self, x):
        x = self.embed(x)
        return self.linear(x)

model = ToyModel(vocab_size=len(vocab), embed_dim=10)

# Training 1 step
logits = model(input_ids)
loss = F.cross_entropy(logits, target_ids)
loss.backward()

print(f"Loss: {loss.item():.4f}")
```

🧠 Di sini model mencoba mempelajari urutan token seperti:
```
"ini" → "aku"
"aku" → "dan"
"dan" → "kamu"
```

## 📊 3. **Visualisasi Prediksi Token Selanjutnya**

Untuk melihat probabilitas prediksi:

```python
import torch.nn.functional as F
import matplotlib.pyplot as plt

# Ambil logits terakhir dari output model
with torch.no_grad():
    outputs = model(**inputs)
    logits = outputs.logits[:, -1, :]  # logits untuk token terakhir
    probs = F.softmax(logits, dim=-1)

# Ambil 10 prediksi teratas
topk = torch.topk(probs, k=10)
top_probs = topk.values[0].cpu().numpy()
top_tokens = [tokenizer.decode([idx]) for idx in topk.indices[0]]

plt.figure(figsize=(10, 5))
plt.bar(top_tokens, top_probs)
plt.title("Prediksi Token Selanjutnya")
plt.ylabel("Probabilitas")
plt.xlabel("Token")
plt.show()
```

🎯 Ini akan nunjukin:
> Token-token apa yang paling mungkin muncul setelah "Pagi ini aku pergi ke", lengkap dengan probabilitasnya.

## 📦 `outputs.logits`

- Ketika kamu jalankan model LLM seperti GPT-2:
  ```python
  outputs = model(input_ids=...)
  ```
  hasilnya adalah **objek yang berisi `logits`**.

- `logits` adalah hasil mentah dari model sebelum diproses softmax. Artinya, ini adalah skor untuk setiap token di vocabulary (misalnya, 50.257 token di GPT-2).

- Bentuk (`shape`) dari `logits`:
  ```python
  (batch_size, sequence_length, vocab_size)
  ```

  Contoh:
  - `batch_size = 1` (satu kalimat)
  - `sequence_length = 5` (lima token input)
  - `vocab_size = 50257` (jumlah total token di GPT-2)

---

## 📍 `[:, -1, :]` dijelaskan:

Potongan ini berarti:

| Bagian         | Artinya                              |
|----------------|---------------------------------------|
| `:`            | Ambil semua batch (biasanya cuma 1)   |
| `-1`           | Ambil **token terakhir**              |
| `:` (kedua)    | Ambil **semua skor untuk setiap token di vocab** |

Jadi, ini mengambil **logits (skor)** hanya untuk **token terakhir** dalam prompt kamu, dan untuk **semua token yang mungkin sebagai kelanjutan**.

---

## 🎯 Tujuannya:

Karena kita hanya ingin tahu **apa token berikutnya yang paling mungkin muncul**, kita **tidak butuh seluruh output**. Kita cukup ambil skor dari token terakhir.

Setelah itu kita pakai:

```python
probs = F.softmax(logits, dim=-1)
```

Untuk mengubah skor mentah itu jadi **probabilitas token**.

## ✅ Kode Lengkap dengan Penjelasan & Contoh

```python
from transformers import GPT2Tokenizer, GPT2LMHeadModel
import torch
import torch.nn.functional as F
import matplotlib.pyplot as plt

# Load GPT-2 tokenizer & model
tokenizer = GPT2Tokenizer.from_pretrained("gpt2")
model = GPT2LMHeadModel.from_pretrained("gpt2")
model.eval()

# Kalimat input
prompt = "Pagi ini aku pergi ke"
inputs = tokenizer(prompt, return_tensors="pt")

# Lihat token yang dihasilkan
print("Token IDs:", inputs["input_ids"])
print("Tokens:", [tokenizer.decode([token]) for token in inputs["input_ids"][0]])

# Ambil output dari model
with torch.no_grad():
    outputs = model(**inputs)

# Logits shape
print("Logits shape:", outputs.logits.shape)  # (batch_size, seq_len, vocab_size)

# Ambil token terakhir → prediksi token berikutnya
last_logits = outputs.logits[:, -1, :]  # ambil skor token terakhir
probs = F.softmax(last_logits, dim=-1)  # ubah ke probabilitas

# Lihat 5 kemungkinan token berikutnya
topk = torch.topk(probs, k=5)
top_ids = topk.indices[0].tolist()
top_probs = topk.values[0].tolist()

print("\nTop 5 prediksi token setelah:", prompt)
for i, (token_id, prob) in enumerate(zip(top_ids, top_probs)):
    token_str = tokenizer.decode([token_id])
    print(f"{i+1}. {repr(token_str)} (prob: {prob:.4f})")

# Visualisasi
plt.bar([tokenizer.decode([i]) for i in top_ids], top_probs)
plt.title("Prediksi Token Selanjutnya")
plt.xlabel("Token")
plt.ylabel("Probabilitas")
plt.xticks(rotation=45)
plt.show()
```

🔹 Ini akan mengirim sinyal **KeyboardInterrupt** ke program Python, dan langsung menghentikan proses yang sedang berjalan.

---

### 2. **CTRL + Z** *(pause, bukan stop)*
Kalau kamu tekan `Ctrl + Z`, proses akan di-*pause* (bukan dihentikan sepenuhnya), dan masuk ke background.

Untuk benar-benar menghentikannya setelah itu, kamu bisa ketik:

```bash
kill %1
```

(`%1` adalah nomor job — kamu bisa cek job aktif dengan `jobs`)

---

### 3. **Matikan dari Task Manager (kalau pakai GUI)**
Kalau kamu pakai macOS atau Linux GUI:

- Buka **Activity Monitor (Mac)** atau **System Monitor (Linux)**
- Cari proses Python
- Klik **"Quit" / "End Task"**

---

### 4. **Gunakan `top` atau `htop` untuk monitor**
Kalau kamu kerja di terminal (tanpa GUI), kamu bisa:

```bash
top
```
atau
```bash
htop  # (lebih enak kalau sudah terinstall)

# lalu cari proses "python", tekan "k" untuk kill
```

Kalau kamu pakai Jupyter Notebook (bukan terminal), klik tombol:

```
⚪ ▪︎ ▪︎ ▪︎
[■] → tombol “Stop” di toolbar
```

## ✍️ Cara Edit File dengan `nano`

### 1. **Buka file**
Misalnya kamu mau edit file bernama `contoh.py`, cukup ketik:

```bash
nano contoh.py
```

Ini akan membuka file `contoh.py` di editor terminal `nano`.

---

## 🧰 Navigasi Dasar di `nano`

| Tombol                        | Fungsi                                  |
|------------------------------|------------------------------------------|
| 🔼 🔽 🔽 🔼 panah atas/bawah   | Gerak antar baris                       |
| ⬅️ ➡️ panah kiri/kanan        | Gerak antar huruf                       |
| `Ctrl` + `K`                  | Hapus satu baris                        |
| `Ctrl` + `U`                  | Paste (setelah hapus)                   |
| `Ctrl` + `W`                  | Cari kata (seperti search)              |
| `Ctrl` + `_` lalu angka       | Lompat ke baris tertentu                |

---

## 💾 Simpan & Keluar

| Perintah                     | Aksi                                     |
|-----------------------------|-------------------------------------------|
| `Ctrl` + `O`                | **Write Out** / Save file                |
| `Enter`                     | Konfirmasi nama file setelah `Ctrl + O`  |
| `Ctrl` + `X`                | Keluar dari nano                         |

---

### 🔁 Contoh alur:
Misal kamu ketik:

```bash
nano contoh.py
```

1. Layar editor terbuka.
2. Kamu edit isi file.
3. Tekan `Ctrl + O` → lalu `Enter` untuk simpan.
4. Tekan `Ctrl + X` untuk keluar.

---

Kalau kamu mau **buat file baru**, cukup lakukan hal yang sama:

```bash
nano file_baru.txt
```

Lalu tulis isi file dari nol.
