# 💬 Download Video MP4 Terminal

**Tanggal:** `2026-05-20 22.48`  
**Sumber:** ChatGPT Export  

---

### 👤 User:
saya mau download video ini pakai terminal, tolong bantu. Hasilnya dalam mp4. https://www.youtube.com/watch?v=lcL0cExjZLc

### 🤖 ChatGPT:
Saya akan beri cara terminal yang aman dan praktis memakai `yt-dlp`, dengan output MP4. Pastikan videonya memang boleh Anda unduh atau Anda punya izin dari pemiliknya.

### 🤖 ChatGPT:
Bisa pakai `yt-dlp` + `ffmpeg`.

### 1) Install dulu

**Ubuntu/Debian:**
```bash
sudo apt update
sudo apt install -y ffmpeg python3-pip
python3 -m pip install -U "yt-dlp[default]"
```

**macOS Homebrew:**
```bash
brew install yt-dlp ffmpeg
```

**Windows PowerShell:**
```powershell
winget install yt-dlp
winget install Gyan.FFmpeg
```

`yt-dlp` adalah tool command-line yang aktif dikembangkan, dan dokumentasi resminya menyarankan instalasi lewat binary/package manager/pip. citeturn943483search3

### 2) Download sebagai MP4

Jalankan:

```bash
yt-dlp -f "bv*[ext=mp4]+ba[ext=m4a]/b[ext=mp4]/b" \
  --merge-output-format mp4 \
  -o "%(title)s.%(ext)s" \
  "https://www.youtube.com/watch?v=lcL0cExjZLc"
```

Artinya: ambil video MP4 terbaik + audio M4A terbaik, lalu gabungkan menjadi `.mp4`. Opsi format dan penggabungan seperti ini didukung oleh `yt-dlp`. citeturn943483search0

### 3) Versi lebih sederhana

```bash
yt-dlp --merge-output-format mp4 "https://www.youtube.com/watch?v=lcL0cExjZLc"
```

Kalau muncul error format/merge, update dulu:

```bash
yt-dlp -U
```

atau kalau install via pip:

```bash
python3 -m pip install -U "yt-dlp[default]"
```
