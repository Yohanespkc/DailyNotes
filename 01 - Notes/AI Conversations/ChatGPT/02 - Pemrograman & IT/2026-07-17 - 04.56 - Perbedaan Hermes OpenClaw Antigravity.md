---

# 🧠 1. Hermes
👉 Fokus: **AI yang bisa belajar & berkembang sendiri**

- Dibuat oleh Nous Research  
- Jalan di server sendiri (self-hosted)
- Punya **memory kuat** → ingat apa yang pernah kamu kerjakan  
- Bisa **belajar dari task sebelumnya** dan bikin skill baru otomatis  
- Cocok untuk:
  - workflow berulang (automation)
  - coding jangka panjang
  - personal AI assistant yang makin pintar seiring waktu  

📌 Intinya:  
> Hermes itu kayak **asisten pribadi yang makin lama makin pintar**

---

# 🔌 2. OpenClaw
👉 Fokus: **AI serba bisa + banyak integrasi**

- Open-source dan lebih lama / populer
- Punya **ekosistem skill & plugin besar**
- Bisa connect ke banyak platform (WhatsApp, Slack, dll)
- Cocok untuk:
  - automation multi-channel
  - tim / bisnis
  - orkestrasi banyak agent sekaligus  

📌 Intinya:  
> OpenClaw itu kayak **hub / platform AI yang bisa nyambung ke mana-mana**

---

# ⚙️ 3. Antigravity
👉 Fokus: **AI khusus coding (lebih seperti IDE/tool developer)**

- Dibuat oleh Google (bagian dari ekosistem Gemini)  
- Lebih ke:
  - coding assistant
  - CLI + desktop tool untuk developer  
- Dipakai buat:
  - nulis kode
  - debug
  - bikin agent custom  

📌 Intinya:  
> Antigravity itu kayak **VS Code + AI super pintar**

# 🎯 Pertama: Kamu mau sistem seperti apa?

Sistem pilih saham biasanya ada 3 tipe:

1. **Screening otomatis (berdasarkan data)**
   - contoh: ROE tinggi, PER rendah, growth bagus  
2. **AI analisis (baca berita, sentimen, laporan)**
3. **Auto decision / semi-trading bot**

👉 Nah, beda tujuan → beda tool terbaik

---

# 🧠 Rekomendasi tool berdasarkan kebutuhan

## 🥇 Kalau kamu mau AI yang “belajar memilih saham”
👉 **Pakai: Hermes**

Kenapa:
- Bisa **ingat hasil keputusan sebelumnya**
- Bisa **belajar dari profit/loss**
- Cocok untuk:
  - bikin strategi sendiri
  - refine model seiring waktu

💡 Contoh:
- Hermes belajar:  
  “Saham dengan ROE > 20% + insider buying → sering naik”
- Lama-lama dia jadi makin akurat

📌 Cocok kalau:
> Kamu serius bikin sistem jangka panjang (semi hedge fund style)

---

## 🔗 Kalau kamu mau integrasi banyak data
👉 **Pakai: OpenClaw**

Kenapa:
- Bisa connect ke:
  - API saham (Yahoo Finance, Alpha Vantage)
  - berita
  - Telegram / WhatsApp alert
- Bisa bikin pipeline:
  - ambil data → analisis → kirim sinyal

💡 Contoh:
- Ambil data harga + news  
- Analisis  
- Kirim “BUY / SELL” ke HP kamu

📌 Cocok kalau:
> Kamu mau sistem otomatis + notifikasi

---

## 💻 Kalau kamu mau fokus coding & model sendiri
👉 **Pakai: Antigravity**

Kenapa:
- Powerful untuk:
  - Python
  - backtesting
  - machine learning
- Lebih “developer mode”

💡 Contoh:
- bikin model:
  - Random Forest
  - LSTM
  - faktor investing

📌 Cocok kalau:
> Kamu suka coding & data science
