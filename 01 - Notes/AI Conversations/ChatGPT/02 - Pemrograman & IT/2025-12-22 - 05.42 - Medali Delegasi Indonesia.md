## 2️⃣ Arti istilah kuncinya

### 🔹 *Three access pathways* (tiga jalur akses)
Artinya:
- **Satu konsep → disimpan dalam beberapa sistem otak sekaligus**
  - Visual cortex
  - Auditory cortex
  - Motor cortex

### 🔹 *Retrieval failure*
Bukan lupa permanen, tapi:
- Otak **gagal mengambil memori lewat satu jalur**
- Memori sebenarnya **masih ada**

Contoh:
> “Saya tahu jawabannya… tapi kok blank ya?”

---

### 🔹 *Redundansi neural*
Ini istilah kunci dan **sangat kuat secara ilmiah**.

Artinya:
> Informasi yang sama **disimpan di beberapa jaringan saraf berbeda**

➡️ Jika satu jalur terganggu, **jalur lain masih berfungsi**

Ini konsep yang sama dengan:
- Sistem pesawat (backup system)
- Jaringan komputer (redundant path)
- RAID storage

## 1️⃣ Tantangan klasik biologi & genetika (sebelum AI)

Dalam biologi modern, ada 3 masalah besar:

1. **Genom sangat kompleks**
   - 1 gen ≠ 1 sifat
   - Banyak sifat dikontrol **ratusan–ribuan gen**

2. **Lingkungan ikut “mengatur” gen**
   - Nutrisi, stres, iklim, budaya, paparan toksin
   - Efek **epigenetik** (gen hidup/mati tanpa berubah urutan DNA)

3. **Data sangat besar**
   - Whole Genome Sequencing
   - Transcriptomics, proteomics, metabolomics
   - Data lingkungan longitudinal

➡️ **Manusia tidak sanggup menganalisis semua interaksi ini secara manual.**

Di sinilah AI masuk.

## ✅ CARA 1 — PALING AMAN & PALING RAPI  
### **Word → Markdown pakai Pandoc (REKOMENDASI)**

Ini **standar akademik & penulis profesional**.

### 1️⃣ Install Pandoc (1 kali saja)
Buka **Terminal**, lalu ketik:

```bash
brew install pandoc
```

Cek berhasil:
```bash
pandoc --version
```

---

### 2️⃣ Convert Word → Markdown
Masuk ke folder file Word:

```bash
cd /path/ke/folder/anda
```

Lalu jalankan:

```bash
pandoc file.docx -o file.md
```

🎯 **Hasilnya sangat rapi**:
- Heading → `# ## ###`
- Bold / italic → `** **`
- List → `-`
- Tabel → Markdown table
- Catatan kaki ikut

📌 Ini **cara terbaik untuk buku, paper, Obsidian, GitHub**.

---

## ✅ CARA 2 — CEPAT TANPA TERMINAL  
### **Word → Google Docs → Markdown**

Cocok kalau **tidak mau Terminal**.

1️⃣ Upload Word ke **Google Docs**  
2️⃣ Buka file  
3️⃣ Klik **File → Download → Markdown (.md)**

⚠️ Catatan:
- Tabel kadang kurang rapi
- Footnote bisa berantakan
- Cocok untuk teks naratif

---

## ✅ CARA 3 — UNTUK OBSIDIAN / NOTION  
### **Word → HTML → Markdown**

1️⃣ Word → **Save As → Web Page (.html)**  
2️⃣ Convert HTML → Markdown:
```bash
pandoc file.html -o file.md
```

📌 Berguna jika Word penuh gambar.

pandoc buku.docx -t markdown --extract-media=img -o buku.md
