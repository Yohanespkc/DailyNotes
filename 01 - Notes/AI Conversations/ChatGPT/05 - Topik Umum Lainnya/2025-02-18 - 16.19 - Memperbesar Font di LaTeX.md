# 💬 Memperbesar Font di LaTeX

### 🤖 ChatGPT:
Di Overleaf (atau LaTeX secara umum), ada beberapa cara untuk memperbesar ukuran font:

### 1. **Menggunakan Ukuran Standar LaTeX**
LaTeX memiliki ukuran font standar yang bisa digunakan dengan perintah berikut di preamble (`\documentclass{}`):

```latex
\documentclass[12pt]{article}  % Ukuran font default adalah 10pt, bisa diganti menjadi 11pt atau 12pt
```

### 2. **Menggunakan Perintah Langsung dalam Dokumen**
Jika ingin mengubah ukuran font pada bagian tertentu dalam dokumen, gunakan perintah berikut:

```latex
{\tiny This is tiny text.}

{\scriptsize This is scriptsize text.}

{\footnotesize This is footnotesize text.}

{\small This is small text.}

{\normalsize This is normal text.}

{\large This is large text.}

{\Large This is Large text.}

{\LARGE This is LARGE text.}

{\huge This is huge text.}

{\Huge This is Huge text.}
```

### 3. **Menggunakan Paket `fontsize` untuk Ukuran Kustom**
Jika ingin ukuran font spesifik yang tidak ada dalam daftar di atas, gunakan paket `fontsize` dan `selectfont`:

```latex
\documentclass{article}
\usepackage{lmodern}  % Pastikan font lebih smooth
\usepackage{anyfontsize}

\begin{document}

{\fontsize{16pt}{20pt}\selectfont Ini teks dengan ukuran 16pt dan spasi antarbaris 20pt.}

\end{document}
```

- Angka pertama (`16pt`) adalah ukuran font.
- Angka kedua (`20pt`) adalah jarak antar baris.

### 4. **Mengubah Font untuk Seluruh Dokumen**
Jika ingin mengubah seluruh teks menjadi ukuran yang lebih besar, tambahkan di preamble:

```latex
\renewcommand{\baselinestretch}{1.5} % Memperbesar jarak antar baris
\fontsize{14pt}{16pt}\selectfont     % Mengubah font ke 14pt
```

Gunakan pendekatan mana yang paling cocok untuk kebutuhan dokumenmu! 🚀
