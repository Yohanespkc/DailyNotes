# 💬 Nonaktifkan FortiGuard Intrusion

**Tanggal:** `2025-04-06 13.10`  
**Sumber:** ChatGPT Export  

---

### 👤 User:
Bagaimana turnoff fortiguard intrusion

### 🤖 ChatGPT:
Untuk menonaktifkan layanan FortiGuard secara global pada perangkat FortiGate, Anda dapat menggunakan perintah berikut melalui antarmuka baris perintah (CLI):

1. **Nonaktifkan layanan Antivirus (AV) FortiGuard**:
   ```
   set avquery-force-off enable
   ```

   Perintah ini mencegah perangkat melakukan kueri ke layanan AV FortiGuard.

2. **Nonaktifkan layanan Web Filtering FortiGuard**:
   ```
   set webfilter-force-off enable
   ```

   Perintah ini mematikan fitur Web Filtering, sehingga melewati layanan Web Filtering yang disediakan oleh FortiGuard.

3. **Nonaktifkan layanan Antispam FortiGuard**:
   ```
   set antispam-force-off enable
   ```

   Perintah ini menonaktifkan layanan Antispam FortiGuard, mencegah fungsi antispam yang disediakan oleh FortiGuard.

Setelah menjalankan perintah-perintah di atas, Anda dapat memverifikasi konfigurasi dengan perintah berikut:


```
show full-configuration system fortiguard
```


Pastikan bahwa nilai untuk `avquery-force-off`, `webfilter-force-off`, dan `antispam-force-off` disetel ke `enable`. citeturn0search3

Perlu dicatat bahwa menonaktifkan layanan-layanan ini dapat mengurangi tingkat perlindungan jaringan Anda terhadap ancaman seperti malware, situs web berbahaya, dan spam. Pastikan untuk mempertimbangkan risiko keamanan sebelum menonaktifkan fitur-fitur ini.
