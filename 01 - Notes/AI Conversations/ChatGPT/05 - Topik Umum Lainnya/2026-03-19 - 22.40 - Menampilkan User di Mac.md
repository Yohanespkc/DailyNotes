---

## ✅ 1. Aktifkan Tampilan Login Semua User

Kadang Mac hanya menampilkan **user terakhir saja**, bukan semua user.

### Caranya:
1. Buka **System Settings (Pengaturan Sistem)**
2. Masuk ke **Users & Groups**
3. Klik **Login Options**
4. Ubah:
   - **Display login window as:**  
     ➜ pilih **List of users (Daftar pengguna)**

👉 Setelah itu, saat restart / logout, semua user akan muncul.

---

## ✅ 2. Gunakan “Switch User” (Ganti User Cepat)

Kalau Mac sudah masuk ke satu akun, Anda bisa memunculkan user lain tanpa logout.

### Caranya:
1. Buka **Control Center (pojok kanan atas)**
2. Klik **Fast User Switching**
3. Pilih user lain

Atau:
- Tekan **Control + Command + Q** → kembali ke layar login

---

## ✅ 3. Pastikan User Lain Memang Ada

Kadang masalahnya simpel: user lain belum dibuat.

### Cek:
1. **System Settings → Users & Groups**
2. Lihat apakah ada lebih dari 1 user

Kalau belum ada:
- Klik **Add User**
- Buat akun baru

---

## ✅ 4. Aktifkan Fast User Switching (Opsional tapi penting)

Kalau menu user tidak muncul:

1. **System Settings → Control Center**
2. Cari **Fast User Switching**
3. Set ke:
   - **Show in Menu Bar**

---

## ⚠️ 5. Kalau Tetap Tidak Muncul

Kemungkinan:
- Mode login pakai **password saja (bukan list user)**
- Mac di-set sebagai **single user (managed / MDM)**
- Ada bug setelah update macOS

### 🤖 ChatGPT:
**Floor effect (efek lantai)** adalah istilah dalam statistik/penelitian pendidikan yang terjadi ketika:

> **Nilai peserta banyak berkumpul di batas paling bawah (nilai minimum)** sehingga **kemampuan sebenarnya tidak bisa dibedakan dengan baik**.

---

## 🎯 Intuisi Sederhana
Bayangkan tes terlalu sulit.

- Banyak siswa dapat nilai: **0, 1, 2**
- Padahal kemampuan mereka sebenarnya berbeda-beda

➡️ Tapi karena semua “mentok di bawah”,  
➡️ **perbedaan kemampuan tidak terlihat**

---

## 🧠 Contoh Nyata

### 1. Dalam Tes Matematika
- Soal terlalu sulit (misalnya level olimpiade untuk siswa SD)
- Hasil:
  - Banyak siswa dapat **0–10**
- Kita tidak tahu:
  - Siapa yang sebenarnya sedikit lebih paham

---

### 2. Dalam Evaluasi Program (misalnya GASING)
Misalnya:
- Pre-test sangat sulit
- Semua siswa nilai sangat rendah

➡️ Dampaknya:
- **Tidak bisa mengukur baseline dengan akurat**
- Perbaikan setelah pelatihan bisa terlihat sangat besar (bias)

---

## ⚠️ Dampak Floor Effect

1. ❌ Tidak bisa membedakan kemampuan rendah
2. ❌ Analisis statistik jadi bias
3. ❌ Efek program bisa terlihat “terlalu besar”
4. ❌ Sulit mengukur peningkatan kecil

---

## 🔄 Lawannya: Ceiling Effect

- **Ceiling effect** = nilai menumpuk di atas (terlalu mudah)
- **Floor effect** = nilai menumpuk di bawah (terlalu sulit)

---

## 🚀 Relevansi untuk GASING (Sangat Penting)

Dalam konteks Anda:

👉 Kalau pre-test terlalu sulit:
- Semua anak terlihat “tidak bisa”
- Padahal ada variasi kemampuan

👉 GASING justru:
- Mulai dari **level sangat dasar**
- Menghindari floor effect
- Membuat:
  > setiap anak bisa “naik bertahap” (measurable progress)

---

## 💡 Prinsip Kunci
Tes yang baik harus:
- Tidak terlalu sulit (hindari floor effect)
- Tidak terlalu mudah (hindari ceiling effect)
- Berada di:
  👉 **zona optimal (ZPD – Zone of Proximal Development)**
