# 💬 Membuat Sudut dengan Jangka

**Tanggal:** `2024-11-13 09.48`

---

### 👤 User:
bagaimana membuat sudut dengan menggunakan jangka, terjemahkan dalam bahasa Inggris

### 🤖 ChatGPT:
To create an angle using a compass, follow these steps:

1. **Draw the Base Line**: Start by drawing a straight line with a ruler. This line will serve as one side of the angle.

2. **Place the Compass Point**: Position the compass point at one end of the line, which will be the angle's vertex.

3. **Draw an Arc**: Keeping the compass at a fixed width, draw an arc that intersects the line. This arc represents part of the angle's boundary.

4. **Adjust the Compass and Create the Second Arm**: Without changing the compass width, move the compass point to the point where the arc intersects the base line. Draw a second arc that crosses the first arc.

5. **Mark the Intersection**: The point where the two arcs intersect determines the other end of the angle's second arm.

6. **Draw the Second Arm**: Use a ruler to draw a straight line from the vertex through the intersection point of the arcs. This line will form the second arm of the angle.

This process creates an angle with a specific measurement, depending on the width set for the compass.
