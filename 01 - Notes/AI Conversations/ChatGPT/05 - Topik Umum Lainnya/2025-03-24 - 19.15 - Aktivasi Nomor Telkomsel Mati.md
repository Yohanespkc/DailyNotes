---

### ✅ **Cek status nomor kamu**
Nomor Telkomsel biasanya hangus karena:
- Tidak mengisi pulsa dalam masa tenggang (30 hari setelah masa aktif habis).
- Tidak digunakan dalam waktu lama.
- Melebihi masa berlaku kartu.

---

### 🔄 **Cara mengaktifkan kembali nomor Telkomsel yang sudah mati**

#### 1. **Coba reaktivasi mandiri via MyTelkomsel**
   - **Buka aplikasi MyTelkomsel**.
   - Login dengan nomor lain.
   - Di halaman awal, pilih menu **“Reaktivasi”** jika tersedia.
   - Masukkan nomor yang hangus.
   - Ikuti proses reaktivasi jika masih memungkinkan.

> 📝 *Catatan: Fitur ini hanya tersedia untuk nomor yang belum terlalu lama mati (biasanya <60 hari).*

---

#### 2. **Kunjungi GraPARI terdekat**
   Jika nomor sudah lama mati, solusi terbaik adalah datang langsung ke GraPARI.

   **Siapkan:**
   - KTP dan KK (sesuai saat registrasi dulu).
   - Kartu SIM lama (jika masih ada).
   - Jika sudah tidak ada kartunya, tetap bisa dibantu asalkan data cocok.

   **Langkah:**
   - Jelaskan bahwa kamu ingin **reaktivasi nomor yang hangus**.
   - Petugas akan cek status nomor.
   - Jika masih memungkinkan, kartu bisa diaktifkan kembali atau diganti dengan SIM baru.

---

#### 3. **Hubungi Layanan Pelanggan Telkomsel**
   Kalau belum sempat ke GraPARI, bisa juga coba:
   - **Call center**: 188 (berbayar Rp300/panggilan dari Telkomsel lain)
   - **Twitter/X**: @Telkomsel
   - **Instagram**: @telkomsel (DM)
   - **Email**: cs@telkomsel.co.id

---

### ⚠️ Kapan nomor sudah tidak bisa diaktifkan lagi?
Jika nomor sudah **lebih dari 60–90 hari** sejak hangus dan sudah **direcycle** (didaur ulang), maka tidak bisa dikembalikan lagi. Biasanya akan diberi pilihan:
- Dapat nomor baru.
- Atau, jika nomor penting (misal untuk bisnis/bank), bisa dicek apakah masih tersedia untuk di-recover.

### 🤖 Apa itu **Agent AI**?

**Agent AI** (kadang disebut juga sebagai *AI agent*) adalah **program komputer cerdas yang bisa bertindak secara mandiri untuk mencapai tujuan tertentu**, biasanya dengan cara:

1. **Mengamati lingkungan** (dengan input atau sensor),
2. **Membuat keputusan sendiri**, dan
3. **Melakukan aksi** berdasarkan tujuannya.

---

### 🎯 Contoh sederhananya:

Bayangkan kamu punya **robot vacuum**:
- Dia bisa mendeteksi tembok, karpet, debu.
- Dia memutuskan ke mana harus bergerak agar bersih maksimal.
- Dia jalan sendiri, tanpa kamu kontrol terus-menerus.

Nah, **itu contoh nyata dari AI Agent** dalam dunia fisik.

---

### 🧠 Tapi Agent AI tidak harus berupa robot.
Banyak AI Agent yang hidup di **dunia digital**. Misalnya:

| Contoh Agent AI       | Apa yang Dilakukannya                                     |
|------------------------|-----------------------------------------------------------|
| **Chatbot cerdas**     | Menjawab pertanyaan, membantu user seperti saya! 😉       |
| **Asisten trading AI** | Menganalisis data pasar, beli/jual saham otomatis         |
| **Game AI agent**      | Karakter musuh yang bergerak strategis di game            |
| **AI tutor**           | Menyesuaikan pelajaran sesuai kemampuan siswa             |
| **Web automation agent**| Mencari tiket murah, booking otomatis, dsb               |

---

### 🔁 Apa yang bikin "Agent AI" berbeda dari AI biasa?

| AI Biasa                      | Agent AI                                    |
|------------------------------|----------------------------------------------|
| Menganalisis dan memberi output | Bisa **mengambil aksi** sendiri            |
| Pasif (nunggu disuruh)       | Aktif dan bisa **merespon perubahan lingkungan** |
| Fokus pada 1 tugas saja      | Bisa punya **tujuan dan strategi jangka panjang** |

---

### 🔬 Dalam teori AI, agent biasanya digambarkan seperti ini:

```
Lingkungan <-- input/sensor -- [ AGENT ] -- aksi --> Lingkungan
```

Jadi agent menerima input, memprosesnya, dan mengeluarkan aksi yang akan mempengaruhi dunia (atau lingkungannya).

### 💬 **Proyek: Deteksi Emosi dalam Kalimat (Emotion Classifier)**

#### 🎯 Tujuan:
Kamu ngetik kalimat, lalu AI kasih tahu itu termasuk emosi apa: *senang*, *sedih*, *marah*, dll.

---

### 🧰 Alat yang dibutuhkan:
- Python
- Library: `transformers`, `torch`, `emoji` (opsional), dan `textwrap`

Kita akan pakai **pretrained model** dari Hugging Face 🤗 bernama `j-hartmann/emotion-english-distilroberta-base` (bisa dipakai meski kalimatnya Bahasa Indonesia pendek).

---

### ✅ Langkah-langkah

#### 1. **Install dulu library-nya**
```bash
pip install transformers torch emoji
```

#### 2. **Kode Programnya:**

```python
from transformers import pipeline
import emoji

# Load model NLP untuk deteksi emosi
classifier = pipeline("text-classification", model="j-hartmann/emotion-english-distilroberta-base", return_all_scores=True)

# Fungsi untuk deteksi emosi
def deteksi_emosi(teks):
    hasil = classifier(teks)[0]
    hasil = sorted(hasil, key=lambda x: x['score'], reverse=True)
    emosi_utama = hasil[0]['label']
    skor = hasil[0]['score']
    print(f"Teks kamu terdeteksi sebagai emosi: {emosi_utama.upper()} ({skor:.2f})")
    print("Detil semua emosi:")
    for e in hasil:
        print(f"- {e['label']}: {e['score']:.2f}")

# Coba kalimat
kalimat = input("Masukkan kalimatmu: ")
deteksi_emosi(kalimat)
```

### 🚀 Proyek: Web Deteksi Emosi dengan Gradio

#### 🎯 Tools:
- Python
- Gradio (`gradio`)
- Transformers (`transformers`, `torch`)

---

### ✅ 1. **Install library yang dibutuhkan**
Jalankan di terminal:

```bash

```

---

### ✅ 2. **Kode lengkap web-nya**

```python
import gradio as gr
from transformers import pipeline

# Load model deteksi emosi
emotion_classifier = pipeline(
    "text-classification",
    model="j-hartmann/emotion-english-distilroberta-base",
    return_all_scores=True
)

# Fungsi deteksi emosi
def deteksi_emosi(teks):
    hasil = emotion_classifier(teks)[0]
    hasil = sorted(hasil, key=lambda x: x['score'], reverse=True)
    
    emosi_utama = hasil[0]['label']
    skor_utama = hasil[0]['score']

    # Format hasil sebagai tabel
    tabel_hasil = "\n".join([f"{e['label']}: {e['score']:.2f}" for e in hasil])

    return f"💡 Emosi utama: **{emosi_utama.upper()}** ({skor_utama:.2f})\n\n📊 Semua emosi:\n{tabel_hasil}"

# Buat UI dengan Gradio
demo = gr.Interface(
    fn=deteksi_emosi,
    inputs=gr.Textbox(lines=4, placeholder="Tulis kalimat di sini..."),
    outputs=gr.Markdown(),
    title="🔍 Deteksi Emosi AI",
    description="Masukkan kalimat, dan biarkan AI mendeteksi emosi dominannya."
)

# Jalankan web app
demo.launch()
```

---

### ✅ 3. **Cara Menjalankan**
Simpan kode di file `app.py`, lalu jalankan:

```bash
python app.py
```
