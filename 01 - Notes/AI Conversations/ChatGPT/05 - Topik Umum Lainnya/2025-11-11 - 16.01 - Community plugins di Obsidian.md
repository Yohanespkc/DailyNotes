Untuk membuka **Community Plugins** di **Obsidian**, ikuti langkah-langkah berikut:  

1. **Buka Settings**  
   - Klik ikon **⚙️ (roda gigi)** di pojok kiri bawah jendela Obsidian.

2. **Masuk ke bagian "Community Plugins"**  
   - Di panel kiri, scroll ke bawah sampai menemukan bagian **“Community Plugins”**.  
   - Klik menu itu.

3. **Matikan “Safe Mode” (jika belum)**  
   - Pada pertama kali, kamu akan melihat tombol **Safe Mode: ON**.  
   - Geser ke **OFF** agar kamu bisa menginstal plugin dari komunitas (non-resmi).

4. **Browse & Install Plugin**  
   - Setelah Safe Mode dimatikan, klik tombol **“Browse”**.  
   - Di sini kamu bisa mencari plugin (misalnya “Templater”, “Dataview”, “Calendar”, dll.).  
   - Klik **Install**, lalu **Enable** untuk mengaktifkannya.

📦 **Catatan penting:**  
- Pastikan kamu sudah punya **internet aktif**, karena Community Plugins diambil dari repositori resmi Obsidian.  
- Untuk keamanan, hanya instal plugin dari pengembang tepercaya.  
- Setelah terinstal, sebagian plugin menambah menu baru di panel kiri atau perintah di **Command Palette** (`Cmd/Ctrl + P`).

## 🧩 1. Instalasi Plugin Dataview
1. Buka **Settings → Community Plugins**  
2. Matikan **Safe Mode (OFF)**  
3. Klik **Browse**, lalu cari **“Dataview”**  
4. Klik **Install → Enable**

---

## 📘 2. Cara Kerja Dasar Dataview

Dataview membaca **metadata** (disebut *frontmatter*) dan **isi note** kamu.  
Contoh frontmatter di bagian atas file Markdown:

```yaml
---
type: catatan
date: 2025-11-11
status: selesai
tags: [belajar, obsidian]
---
```

Frontmatter ini berfungsi seperti data tabel yang bisa di-query oleh Dataview.

---

## 🪄 3. Menampilkan Data dengan Dataview

Tulislah blok kode seperti ini di dalam note:

### 📋 **Contoh menampilkan daftar catatan**
```dataview
list
from "Catatan"
where status = "selesai"
sort date desc
```
Artinya:
- **list** → tampilkan sebagai daftar
- **from "Catatan"** → ambil dari folder “Catatan”
- **where** → filter
- **sort** → urutkan berdasarkan tanggal

---

## 📊 4. Tabel Data
Menampilkan data seperti spreadsheet:
```dataview
table date, status, tags
from "Catatan"
where type = "catatan"
sort date desc
```

Hasilnya:  
| File | Date | Status | Tags |
|------|------|--------|------|
| CatatanA | 2025-11-10 | selesai | [belajar, obsidian] |

---

## 📅 5. Query Catatan Berdasarkan Tag
```dataview
list from #belajar
```
→ Menampilkan semua note yang punya tag `#belajar`.

---

## 🔢 6. Menampilkan Hasil Perhitungan
Kamu bisa juga pakai **DataviewJS (JavaScript)** untuk menghitung data.

Contoh menghitung jumlah catatan selesai:
```dataviewjs
dv.paragraph("Jumlah catatan selesai: " + dv.pages('"Catatan"').where(p => p.status == "selesai").length)
```

---

## 🧠 7. Tips Praktis
- Gunakan `Ctrl + P` → “Dataview: Reload Dataview” kalau hasil tidak langsung muncul.  
- Kamu bisa menulis query di note manapun — Dataview otomatis memperbarui hasil kalau isi file berubah.  
- Untuk tampilan kalender, gabungkan dengan plugin **Calendar** atau **Tasks**.

## 🧭 Apa itu “Vault” di Obsidian?
Vault = **folder utama** tempat semua catatanmu disimpan.  
Semua file-nya adalah **Markdown (.md)**, jadi bisa dibuka dengan aplikasi lain juga.

Contohnya:
```
Vault Belajar/
├── Catatan/
│   ├── catatan1.md
│   ├── catatan2.md
│   ├── catatan3.md
│
└── Dashboard.md
```

## 🪄 Cara Membuat Folder di Obsidian

### **Langkah 1 — Pastikan Panel “File Explorer” Muncul**
Lihat sisi kiri layar Obsidian.  
Kalau kamu **tidak melihat daftar file**, klik ikon **📁 (folder)** di sidebar kiri — itu membuka **File Explorer**.

---

### **Langkah 2 — Klik Kanan → “New Folder”**
1. Arahkan kursor ke area kosong di dalam **File Explorer** (di panel kiri).  
2. Klik **kanan (atau Ctrl + klik)**.  
3. Pilih **“New Folder”** dari menu yang muncul.  
4. Ketik nama folder (misalnya `Catatan`), lalu tekan **Enter**.

📁 Sekarang folder baru akan muncul di daftar.

---

### **Langkah 3 — Buat Catatan di Dalam Folder**
1. Klik kanan pada folder baru `Catatan`.  
2. Pilih **“New Note”**.  
3. Buat file bernama `catatan1.md`, `catatan2.md`, dst.

---

### **Langkah Alternatif (via Finder / File Explorer komputer)**
Kalau mau lebih cepat:
1. Tutup dulu Obsidian.  
2. Buka lokasi vault kamu di Finder (biasanya ada di `Documents/ObsidianVault` atau sesuai nama vault kamu).  
3. Buat folder baru di sana dengan nama `Catatan`.  
4. Setelah itu, buka kembali Obsidian → folder itu akan langsung muncul.
