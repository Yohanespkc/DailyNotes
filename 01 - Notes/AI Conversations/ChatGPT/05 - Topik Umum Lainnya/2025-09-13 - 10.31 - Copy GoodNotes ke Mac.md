# 💬 Copy GoodNotes ke Mac

**Tanggal:** `2025-09-13 10.31`  
**Sumber:** ChatGPT Export  

---

### 👤 User:
bagaimana cara copy folder di goodnotes (dalam tablet saya) ke mac saya dengan airdrops

### 🤖 ChatGPT:
GoodNotes di iPad/tablet memang bisa mengirim file ke Mac lewat AirDrop, tapi ada beberapa hal penting: GoodNotes tidak mengirim “folder” langsung. Yang bisa dikirim adalah isi folder (file dokumen). Berikut langkah-langkahnya:  

---

### 📱 Dari iPad/Tablet (GoodNotes)
1. **Buka aplikasi GoodNotes**.
2. Masuk ke **folder** yang ingin kamu copy.
3. **Pilih semua dokumen di dalam folder**  
   - Tap tombol **Select** (Pilih).  
   - Centang semua file di folder tersebut.
4. Setelah dipilih, tap ikon **Share** (kotak dengan panah ke atas).
5. Pilih **Export** (biasanya pilih “Export as PDF” atau “GoodNotes Document”).  
   - Kalau kamu ingin tetap bisa edit di Mac, pilih format **GoodNotes Document**.  
   - Kalau hanya untuk baca/print, bisa pilih **PDF**.
6. Pilih **AirDrop**, lalu pilih nama **Mac** kamu.

---

### 💻 Di Mac
1. Pastikan **AirDrop aktif** di Finder → Go → AirDrop, lalu set ke “Everyone” atau “Contacts Only”.
2. Terima file yang dikirim dari iPad.  
   - File akan tersimpan di folder **Downloads** secara default.
3. Kalau banyak file, kamu bisa **buat folder baru di Mac** dan pindahkan semua hasil AirDrop ke dalamnya agar strukturnya rapi.

---

### 📦 Catatan Penting
- AirDrop tidak bisa mengirim **folder utuh** dari GoodNotes, hanya dokumennya. Kalau mau folder persis sama:
  - **Opsi 1:** Kompres (zip) folder di iPad (pakai app “Files”) lalu AirDrop file zip.  
  - **Opsi 2:** Gunakan sinkronisasi **iCloud Drive** di GoodNotes → nanti folder akan otomatis muncul di Mac dengan struktur aslinya.
