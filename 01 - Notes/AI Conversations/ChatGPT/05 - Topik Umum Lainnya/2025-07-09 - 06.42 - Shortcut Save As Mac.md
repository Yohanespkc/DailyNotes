# 💬 Shortcut Save As Mac

**Tanggal:** `2025-07-09 06.42`  
**Sumber:** ChatGPT Export  

---

### 👤 User:
apa shortcut mac word untuk save as

### 🤖 ChatGPT:
Shortcut **"Save As"** di **Microsoft Word untuk Mac** adalah:

**⌘ + Shift + S**

(atau disebut **Command + Shift + S**)

Shortcut ini akan membuka jendela **Save As**, di mana kamu bisa menyimpan dokumen dengan nama atau format berbeda.

Jika shortcut ini tidak berfungsi karena versi Word tertentu, kamu bisa coba:

1. Klik menu **File** di atas.
2. Pilih **Save As…**

Jika kamu sering menggunakan fitur ini, kamu juga bisa menambahkannya ke toolbar Quick Access atau membuat shortcut kustom lewat **System Settings > Keyboard > Shortcuts**.

Perlu bantuan menambahkan shortcut kustom? Saya bisa bantu langkah-langkahnya.

### 👤 User:
shortcut untuk download mac

### 🤖 ChatGPT:
Shortcut untuk **download** di Mac sebenarnya tergantung konteks aplikasinya. Berikut beberapa kemungkinan tergantung situasinya:

---

### 📥 **1. Di Browser (Safari, Chrome, Firefox, dll):**
**⌘ + S**  
(Command + S)  
➡️ Menyimpan halaman web atau file (tergantung jenis kontennya).

**⌘ + D**  
➡️ Ini untuk **menandai (bookmark)** halaman, **bukan download**.

Kalau kamu ingin mendownload file:
- Klik kanan > “Download linked file”
- Atau klik langsung tautan unduhan.

---

### 📂 **2. Melihat folder Downloads:**
**⌘ + Option + L**  
➡️ Shortcut untuk langsung membuka folder **Downloads** di Finder.

---

### 💻 **3. Di aplikasi seperti Word atau Excel (Microsoft Office):**
**⌘ + S** = Save  
**⌘ + Shift + S** = Save As  
Jika ingin **mengunduh dari OneDrive** ke lokal:
- Gunakan **File > Save As**, lalu pilih lokasi di Mac.

---

Kalau maksud kamu **"download" dari aplikasi tertentu** (misal YouTube, Mail, dll), sebutkan aplikasinya, nanti saya beri shortcut spesifik.

### 👤 User:
shortcut untuk ke back page ?

### 🤖 ChatGPT:
Shortcut untuk kembali ke **halaman sebelumnya (Back Page)** di Mac tergantung aplikasi yang digunakan. Berikut ini daftar shortcut paling umum:

---

### 🌐 **Di Browser (Safari, Chrome, Firefox):**
**⌘ + [**  
➡️ (Command + tanda kurung buka)  
👉 *Kembali ke halaman sebelumnya (Back)*

**⌘ + ]**  
➡️ (Command + tanda kurung tutup)  
👉 *Maju ke halaman berikutnya (Forward)*

---

### 🗂️ **Di Finder:**
**⌘ + [** = Kembali ke folder sebelumnya  
**⌘ + ]** = Maju ke folder berikutnya  

---

### 📄 **Di Preview atau PDF Reader:**
- **Fn + ←** atau **Command + ↑** → Ke awal dokumen
- Untuk “back page” bisa berarti **previous page**:  
  **↑ / ↓** atau **Page Up / Page Down** (tergantung konteksnya)

---

Kalau kamu ingin shortcut untuk aplikasi tertentu (misalnya Word, Excel, Xcode, dll), sebutkan saja, saya bantu detailkan.
