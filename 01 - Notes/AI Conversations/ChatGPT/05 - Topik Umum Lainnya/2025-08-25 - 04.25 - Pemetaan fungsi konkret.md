## 1. Fungsi sebagai "Mesin"
Bayangkan sebuah **mesin**:
- Kita masukkan sesuatu (input).
- Mesin mengolahnya menurut aturan tertentu.
- Mesin mengeluarkan hasil (output).

Contoh:
- Fungsi \( f(x) = 2x + 3 \).  
  Kalau kita masukkan \( x = 5 \), mesin akan menghitung \( 2(5) + 3 = 13 \).  
  Jadi 5 dipetakan ke 13.

---

## 2. Fungsi sebagai "Pasangan Anggota Klub"
Setiap orang (input) punya kartu anggota (output):
- Misalnya fungsi \( f(x) = x^2 \).  
- Orang dengan nomor baju 1, kartunya bernomor 1.  
- Orang dengan nomor baju 2, kartunya bernomor 4.  
- Orang dengan nomor baju 3, kartunya bernomor 9.  

Jadi setiap input hanya punya **satu pasangan output**.

---

## 3. Fungsi sebagai "Peta"
Pemetaan fungsi seperti **peta kota**:
- Ada titik-titik di sisi kiri (Domain).  
- Ada titik-titik di sisi kanan (Kodomain).  
- Garis panah menghubungkan setiap titik domain ke tepat **satu titik** di kodomain.

Contoh:  
Domain = {1, 2, 3}  
Kodomain = {a, b, c, d}  
Pemetaan:  
- 1 → a  
- 2 → c  
- 3 → d  

---

## 4. Bentuk Visual (Diagram Panah)
```
Domain        Kodomain
   1   ---->     2
   2   ---->     4
   3   ---->     6
```
Fungsi \( f(x) = 2x \).  
Tiap elemen domain dipetakan ke hasil 2 kali lipatnya.

### 🤖 ChatGPT:
Ada beberapa kemungkinan kenapa Word Bapak/Ibu tidak bisa menerima **paste gambar** (hanya teks yang keluar). Umumnya penyebabnya seperti ini:  

---

## 🔎 **Kemungkinan Penyebab**
1. **Clipboard hanya menyimpan teks, bukan gambar**  
   Kalau hanya menekan “Copy link” atau “Copy teks” (bukan gambar), maka Word hanya akan menempelkan teks.

2. **Copy–paste dari browser** kadang gagal membawa gambar ke Word  
   Beberapa browser (Chrome/Safari) saat copy gambar, yang tersalin justru link atau teks alternatif, bukan gambarnya.

3. **Word dalam mode tertentu** (misalnya “Paste as Text Only”)  
   Jika pengaturan paste di Word hanya izinkan teks, maka gambar tidak akan muncul.

4. **Clipboard error / penuh**  
   Terkadang clipboard Windows/macOS bermasalah sehingga gagal menyimpan data gambar.

---

## 🛠 **Solusi Praktis**
1. **Jangan langsung copy di sini → tapi klik kanan gambar → "Save image as..."**  
   Lalu di Word pilih **Insert → Pictures → This Device**.  
   🔹 Cara ini 100% berhasil, karena Word langsung ambil file gambarnya.

2. **Gunakan screenshot**  
   - Windows: tekan **Windows + Shift + S** → pilih area gambar → masuk ke Word → **Ctrl+V**.  
   - Mac: tekan **Shift + Command + 4** → pilih area gambar → gambar tersimpan → insert ke Word.

3. **Cek pengaturan Paste di Word**  
   - Buka **File → Options → Advanced → Cut, copy, and paste**  
   - Pastikan opsi **Keep Source Formatting** aktif (bukan “Text only”).

4. **Coba browser lain**  
   Kadang dari Chrome tidak bisa, tapi dari Edge/Firefox bisa langsung copy gambar → paste ke Word.
