## Pendahuluan  
File **Pencast** adalah format rekaman interaktif (biasanya dari pena digital Livescribe) yang menggabungkan audio dengan catatan tertulis. Untuk membagikannya sebagai video MP4 standar, kita perlu mengekstrak konten audio dan visual, lalu menggabungkannya. ## Tahap 1: Ekstraksi Audio dari Pencast  
Pertama, ekstrak audio dari file Pencast. Jika Anda menggunakan perangkat lunak Livescribe (Echo Desktop):  

- **Gunakan Livescribe Echo Desktop** – Buka file `.pencast` di Echo Desktop. Pilih opsi *Share/Export* dan ekspor **audio** sebagai file `.m4a` (format AAC)【6†L29-L34】. Livescribe Echo Desktop memungkinkan Anda menyimpan audio pencast secara langsung ke format M4A.  

Jika tidak memiliki software tersebut, Anda bisa mencoba cara manual:  

- **Ekstrak Manual (Alternatif)** – File `.pencast` sebenarnya adalah arsip (ZIP) berisi data. Anda dapat mengganti ekstensi menjadi `.zip` lalu mengekstraknya. Di dalamnya akan terdapat folder (misal `userdata/Session/...`) berisi file audio (format AAC). Ekstrak semua file audio `.aac` tersebut. Urutkan file-file audio sesuai urutan aslinya (biasanya sesuai urutan halaman atau waktu perekaman).  

Setelah audio didapat (baik satu file gabungan atau beberapa segmen), pastikan formatnya kompatibel. Jika berupa beberapa segmen, gabungkan menjadi satu file audio utuh sesuai urutan: Anda dapat menggunakan program seperti **ffmpeg** atau editor audio:  

```bash
# Contoh penggabungan dengan ffmpeg (daftar file audio disimpan di files.txt)
ffmpeg -f concat -safe 0 -i files.txt -c copy audio_combined.m4a
```  

Perintah di atas menggabungkan sejumlah file AAC/M4A tanpa mengubah isi codec (sangat cepat dan tanpa kehilangan kualitas). Hasilnya, Anda punya satu file audio utama (mis. `audio_combined.m4a`) yang berisi seluruh rekaman suara pencast. Pastikan durasi total audio ini sesuai dengan durasi keseluruhan pencast.  

## Tahap 2: Ekstraksi Gambar Slide dari PDF  
Berikutnya, ambil **gambar slide** dari file PDF yang disediakan. Tiap halaman PDF akan dijadikan frame (visual) di video. Ada beberapa cara:  

- **Menggunakan Software PDF** – Buka PDF `Bab M1 Persamaan linear.pdf` di Adobe Acrobat atau PDF reader lain yang mendukung ekspor gambar. Ekspor setiap halaman sebagai gambar (PNG/JPEG) dengan resolusi tinggi. Pastikan kualitas teks/gambar cukup tajam karena akan ditampilkan di video. Jika PDF memiliki 7 halaman, Anda akan mendapatkan `page1.png` sampai `page7.png`.  

- **Livescribe Echo Desktop** – Jika PDF ini adalah *Livescribe PDF*, Anda bisa mengimpornya ke Echo Desktop lalu ekspor setiap halaman sebagai **PNG**【6†L29-L34】. Ini memastikan semua tulisan tangan atau konten halaman terekspor dengan benar. Simpan dengan nama urut (misal: `slide1.png`, `slide2.png`, ...).  

Periksa setiap gambar slide hasil ekspor: pastikan isinya lengkap (semua teks/rumus terlihat) dan tidak ada bagian terpotong. Jika perlu, lakukan cropping atau penyesuaian agar setiap slide konsisten.  

## Tahap 3: Membuat Video dari Slide dan Audio  
Setelah memiliki file audio dan gambar-gambar slide, kita gabungkan menjadi video. Tujuannya: **menampilkan slide sesuai urutan, mengganti tepat waktu mengikuti narasi audio**, dalam resolusi **1280x720 (720p)**.  

Langkah-langkah:  

1. **Siapkan Durasi Tiap Slide:** Tentukan berapa lama setiap slide muncul. Cara paling tepat adalah dengan melihat waktu ketika presenter beralih ke slide berikutnya dalam pencast. Jika audio terdiri dari beberapa segmen (masing-masing untuk satu halaman), Anda bisa menggunakan durasi masing-masing segmen sebagai patokan. Misalnya:  
   - Slide 1: 5 menit 49 detik (348,7 detik)  
   - Slide 2: 3 menit 27 detik (207,0 detik)  
   - Slide 3: 4 menit 45 detik (285,1 detik)  
   - Slide 4: 6 menit 37 detik (397,4 detik)  
   - Slide 5: 7 menit 02 detik (422,8 detik)  
   - Slide 6: 7 menit 12 detik (432,1 detik)  
   - Slide 7: 8 menit 11 detik (491,1 detik)  

   *(Angka di atas hanya contoh sesuai durasi segmen audio pencast.)*  

2. **Gunakan Editor Video atau FFmpeg:**  
   - **Dengan Editor Video:** Impor semua `slide#.png` ke timeline video editor (misalnya Adobe Premiere, iMovie, dll). Atur durasi tampilan setiap gambar slide sesuai yang ditentukan. Letakkan file audio utama pada track audio. Sinkronkan sehingga pergantian ke slide berikutnya persis ketika pembicara mulai membahas slide tersebut (sesuai timing audio). Gunakan **cut sederhana** untuk pergantian (tanpa efek transisi mewah, sesuai permintaan *tanpa efek visual tambahan*).  
   - **Dengan FFmpeg (otomatis):** Anda bisa memakai ffmpeg untuk membuat slideshow dan menambahkan audio. Pastikan ffmpeg terinstal, lalu gunakan filter *concat* dan *pad* untuk skala:  

     ```bash
     ffmpeg -y \
       -r 1 -f concat -safe 0 -i slides.txt \
       -i audio_combined.m4a \
       -vf "scale=1280:720:force_original_aspect_ratio=decrease,pad=1280:720:(ow-iw)/2:(oh-ih)/2:color=white" \
       -c:v libx264 -preset ultrafast -tune stillimage -pix_fmt yuv420p \
       -c:a copy -shortest output.mp4
     ```  

     Keterangan:  
     – **slides.txt** adalah file teks berisi daftar slide dan durasinya, misalnya:  
     ```  
     file 'slide1.png'  
     duration 348.710  
     file 'slide2.png'  
     duration 207.039  
     ...  
     file 'slide7.png'  
     ```  
     (Catatan: untuk file terakhir, tidak diberi durasi agar video berakhir tepat saat audio habis).  

     – **scale & pad**: memastikan setiap gambar di**resize** proporsional sehingga muat dalam frame 1280x720. Pada contoh di atas, **force_original_aspect_ratio=decrease** akan mengecilkan gambar slide jika terlalu besar, tanpa mengubah rasio aslinya, lalu **pad** menambahkan margin putih sehingga frame pas 1280x720. Ini mencegah distorsi dan memberi latar belakang putih (selaras dengan warna kertas slide).  

     – **-c:v libx264 ... -pix_fmt yuv420p**: mengenkode video dengan codec H.264, profil untuk still image (karena tiap segment statis) dan memastikan kompatibilitas luas (yuv420p). **-c:a copy** menjaga audio asli tanpa re-encode (karena kita sudah dalam AAC yang kompatibel MP4). **-shortest** membuat proses berakhir saat audio selesai (jadi video tidak lebih panjang dari audio).  

3. **Proses Rendering:** Jalankan proses rendering/encoding. Jika menggunakan editor video, lakukan *export* atau *render* ke MP4 dengan resolusi 1280x720, frame rate ~25 atau 30 fps. Pastikan pengaturan resolusi tepat (720p). Dengan ffmpeg, perintah di atas akan menghasilkan `output.mp4`. Tunggu hingga selesai (untuk durasi ~43 menit mungkin memakan waktu beberapa menit tergantung performa).  

4. **Verifikasi Hasil:** Setelah video selesai dibuat, putar **output.mp4**. Periksa bahwa:  
   - **Audio** terdengar jelas dan lengkap (durasi sesuai aslinya).  
   - **Visual**: Slide tampil berurutan dan berganti di waktu yang tepat sesuai narasi. Tidak ada jeda yang tidak sesuai (misal slide telat ganti atau terlalu cepat).  
   - **Resolusi** benar 1280x720 dan tidak ada distorsi pada teks/gambar.  

   Pastikan juga tidak ada tambahan efek visual (sesuai permintaan, transisi cukup potong langsung). Jika semua sinkron dan sesuai, konversi berhasil.

### **1. Ekstrak Halaman PDF sebagai Gambar**
Agar file PDF dapat diubah menjadi video, setiap halamannya perlu diekstrak sebagai gambar.

#### **Cara Ekstraksi Gambar dari PDF:**
- **Menggunakan Python (Automatisasi)**
  ```python
  import fitz  # PyMuPDF
  from PIL import Image

  pdf_path = "file.pdf"
  output_folder = "images/"

  doc = fitz.open(pdf_path)
  for page_num in range(len(doc)):
      img_path = f"{output_folder}/page_{page_num+1}.png"
      pix = doc[page_num].get_pixmap(matrix=fitz.Matrix(2, 2))  # Skala 2x untuk kualitas
      img = Image.frombytes("RGB", [pix.width, pix.height], pix.samples)
      img.save(img_path, format="PNG")
  ```

- **Alternatif: Adobe Acrobat atau Online Tools**
  - Buka **Adobe Acrobat Reader** > **Ekspor ke Gambar (PNG/JPG)**
  - Gunakan situs online seperti **Smallpdf, ILovePDF** untuk mengekstrak gambar dari PDF.

---

### **2. Ekstrak Audio dari PDF**
Jika file PDF memiliki **audio tertanam**, Anda perlu mengekstraknya.

#### **Cara Mengekstrak Audio dari PDF:**
- **Menggunakan Adobe Acrobat Pro**
  1. Buka PDF.
  2. Klik kanan pada ikon audio > **Simpan sebagai**.
  3. Pilih format **MP3/WAV**.

- **Menggunakan PDF Extractor Online**
  - Gunakan **ExtractPDF.com** atau **PDFCandy** untuk mengekstrak file audio.

- **Menggunakan Python (Jika PDF berbasis Pencast)**
  Jika PDF dibuat dengan Livescribe Pencast:
  ```python
  import zipfile
  with zipfile.ZipFile("file.pencast", 'r') as zip_ref:
      zip_ref.extractall("extracted_audio/")
  ```
  Periksa folder untuk file audio **.m4a** atau **.aac**.

### **3. Sinkronisasi Slide dan Audio di Editor Video**
Setelah mendapatkan **gambar slide dan audio**, saatnya membuat video.

#### **Gunakan Editor Video (Manual)**
- **Windows Video Editor / iMovie (Mac)**
  - Impor gambar-gambar hasil ekstraksi PDF sebagai **slide**.
  - Tambahkan audio yang telah diekstrak.
  - Atur durasi setiap slide agar sesuai dengan penjelasan di audio.
  - **Ekspor sebagai MP4 (720p/1080p).**

- **Adobe Premiere Pro / Camtasia**
  - Masukkan semua gambar sebagai **track video**.
  - Masukkan audio sebagai **track audio**.
  - **Atur durasi setiap slide** berdasarkan audio.
  - Gunakan **fade transition** (opsional).
  - Ekspor video dalam format **H.264 MP4**.

### **4. Alternatif Otomatis Menggunakan Python & FFmpeg**
Jika ingin mengotomatisasi pembuatan video, gunakan Python dengan FFmpeg:

```python
import moviepy.editor as mp
import os

# Folder gambar hasil ekstraksi
image_folder = "images/"
audio_file = "audio.mp3"
output_video = "output.mp4"

# Ambil semua gambar dan atur durasi setiap slide
images = [mp.ImageClip(os.path.join(image_folder, img)).set_duration(5) for img in sorted(os.listdir(image_folder))]

# Gabungkan gambar menjadi video
video = mp.concatenate_videoclips(images, method="compose")

# Tambahkan audio
audio = mp.AudioFileClip(audio_file)
video = video.set_audio(audio)

# Simpan video dalam format MP4
video.write_videofile(output_video, fps=24, codec="libx264", audio_codec="aac")
```

- **Bitrate Audio:** 128kbps atau lebih.
