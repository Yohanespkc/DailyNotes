### Cara export dari iCloud
Di komputer, buka **iCloud Contacts** lalu login.  
Untuk export semua kontak: **Tindakan > Pilih Semua Kontak > Bagikan > Ekspor vCard**.  
Apple juga menyebut kalau beberapa kontak yang dipilih akan diexport menjadi **satu file vCard**. citeturn513841search2

- bersihkan field kosong/aneh
- kelompokkan kontak kerja/pribadi
- ubah ke CSV dulu bila perlu untuk review, lalu balik lagi ke `.vcf`

### Cara memasukkan hasilnya ke iPhone
Ada 2 cara yang paling enak:

**Cara A — lewat iCloud.com**  
Di iCloud Contacts: **Tambahkan > Impor Kontak**, lalu pilih file `.vcf` hasil edit. Kalau kontak iPhone Anda sinkron ke iCloud, hasilnya akan muncul di iPhone juga. Apple mendukung import vCard langsung di iCloud.com. citeturn513841search2turn513841search4

**Cara B — langsung di iPhone**  
Kirim file `.vcf` ke iPhone Anda lewat email/AirDrop/pesan, lalu buka lampirannya di iPhone. Apple menyebut iPhone bisa mengimpor kontak dari **vCard** dengan mengetuk file `.vcf` attachment. citeturn513841search1

### Saran supaya aman
Sebelum diedit, simpan dulu **backup asli** file `.vcf` export Anda. Apple juga menyarankan export semua kontak sebagai satu vCard untuk backup. citeturn513841search0

### Kalau Anda pakai Mac
Bisa juga export/import dari aplikasi **Contacts** di Mac:  
**File > Export > Export vCard** untuk export, lalu **File > Import** untuk import `.vcf`. Apple juga mencatat format default export adalah **vCard 3.0**. citeturn513841search3turn513841search5turn513841search6

Upload saja file kontak `.vcf` Anda, lalu tulis ingin diedit seperti apa.
