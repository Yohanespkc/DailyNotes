### 👤 User:
Bagaimana memperkecil file word menjadi 1/3 nya dari 79 MB menjadi 25 Mb.

### 🤖 ChatGPT:
Bisa. Penyebab file Word jadi 79 MB biasanya karena **gambar terlalu besar**, **gambar tidak dikompres**, atau ada **objek tersembunyi/embedded file** di dalam dokumen.

Cara paling efektif di Word:

### 1. Kompres semua gambar
Ini biasanya yang paling besar dampaknya.

Di Word:
1. Klik salah satu gambar
2. Pilih tab **Picture Format**
3. Klik **Compress Pictures**
4. Hilangkan centang **Apply only to this picture** supaya semua gambar ikut dikompres
5. Centang **Delete cropped areas of pictures**
6. Pilih resolusi:
   - **150 ppi** = bagus untuk dibaca di layar dan masih cukup oke
   - **96 ppi** = lebih kecil lagi, cocok kalau hanya untuk dibaca digital
7. Klik **OK**
8. Lalu **Save As** dengan nama file baru

Sering kali langkah ini saja bisa memangkas file sangat besar.

### 2. Save As, jangan hanya Save
Setelah kompres:
- pilih **File > Save As**
- simpan sebagai file baru

Kadang Word baru benar-benar membuang data lama setelah **Save As**.

### 3. Hapus bagian gambar yang ter-crop
Kalau dulu gambar pernah di-crop, Word sering masih menyimpan bagian yang terpotong.

Saat **Compress Pictures**, pastikan:
- **Delete cropped areas of pictures** dicentang

Ini penting sekali.

### 4. Kurangi resolusi gambar sebelum masuk ke Word
Kalau ada banyak foto dari HP atau screenshot besar:
- buka gambarnya dulu
- ubah ukurannya jadi misalnya lebar **1200–1600 px**
- lalu masukkan ulang ke Word

Karena gambar dari HP bisa 3–8 MB per gambar. Kalau ada 20 gambar, file langsung membengkak.

### 5. Cek apakah ada objek embed
Kadang file besar karena ada:
- PDF yang disisipkan
- Excel embedded
- audio/video
- icon object
- file copy-paste dari aplikasi lain

Cek dan hapus kalau tidak perlu.

### 6. Jangan pakai “Insert” gambar full-resolution dari copy-paste sembarangan
Lebih baik:
- **Insert > Pictures**
daripada copy-paste langsung dari aplikasi lain, karena kadang paste membawa data tambahan.

### 7. Matikan penyimpanan editing data yang tidak perlu
Di Word, coba cek:
- **File > Options > Advanced**
- cari bagian **Image Size and Quality**
- centang **Discard editing data**
- jangan centang **Do not compress images in file**

### 8. Simpan sebagai DOCX, bukan DOC
Kalau masih format lama **.doc**, ubah ke **.docx** karena biasanya lebih kecil.

## Cara otomatis di Mac via terminal

### Opsi paling praktis: kompres gambar di dalam DOCX
Pakai `unzip`, `zip`, dan `sips` bawaan macOS.

Misal file Anda bernama:

```bash
MyFile.docx
```

### Script otomatis
Buat file script misalnya `compress_docx.sh`:

```bash
#!/bin/bash

INPUT="$1"
QUALITY="${2:-70}"
MAX_WIDTH="${3:-1600}"

if [ -z "$INPUT" ]; then
  echo "Usage: $0 file.docx [quality] [max_width]"
  exit 1
fi

if [ ! -f "$INPUT" ]; then
  echo "File not found: $INPUT"
  exit 1
fi

BASENAME=$(basename "$INPUT" .docx)
WORKDIR="/tmp/${BASENAME}_docx_work_$$"
OUTPUT="${BASENAME}_compressed.docx"

mkdir -p "$WORKDIR"
cp "$INPUT" "$WORKDIR/original.zip"

cd "$WORKDIR" || exit 1
unzip -q original.zip -d extracted

MEDIA_DIR="extracted/word/media"

if [ ! -d "$MEDIA_DIR" ]; then
  echo "No media folder found. This doc may not contain images."
  cd - >/dev/null
  rm -rf "$WORKDIR"
  exit 1
fi

echo "Compressing images in $MEDIA_DIR ..."

find "$MEDIA_DIR" -type f \( -iname "*.jpg" -o -iname "*.jpeg" \) | while read -r img; do
  echo "Processing JPEG: $img"
  sips -Z "$MAX_WIDTH" "$img" >/dev/null
  sips -s formatOptions "$QUALITY" "$img" >/dev/null
done

find "$MEDIA_DIR" -type f -iname "*.png" | while read -r img; do
  echo "Processing PNG: $img"
  sips -Z "$MAX_WIDTH" "$img" >/dev/null
done

cd extracted || exit 1
zip -qr "../$OUTPUT" .

cd ..
mv "$OUTPUT" "$OLDPWD"/
cd "$OLDPWD" || exit 1

rm -rf "$WORKDIR"

echo "Done: ${OUTPUT}"
```

Lalu jalankan:

```bash
chmod +x compress_docx.sh
./compress_docx.sh MyFile.docx
```

Atau lebih agresif:

```bash
./compress_docx.sh MyFile.docx 60 1200
```

Arti parameter:
- `70` = kualitas JPEG
- `1600` = lebar maksimum gambar

## Cara terminal: DOCX → PDF → PDF kecil
Biasanya pakai LibreOffice dan Ghostscript.

### Install dulu
Kalau pakai Homebrew:

```bash
brew install --cask libreoffice
brew install ghostscript
```

### Convert Word ke PDF
```bash
"/Applications/LibreOffice.app/Contents/MacOS/soffice" --headless --convert-to pdf MyFile.docx
```

### Compress PDF
```bash
gs -sDEVICE=pdfwrite -dCompatibilityLevel=1.4 \
   -dPDFSETTINGS=/ebook \
   -dNOPAUSE -dQUIET -dBATCH \
   -sOutputFile=MyFile_small.pdf MyFile.pdf
```

Pilihan kualitas:
- `/screen` = paling kecil
- `/ebook` = seimbang
- `/printer` = lebih bagus, lebih besar

Kalau target 25 MB, mulai dari:

```bash
-dPDFSETTINGS=/ebook
```

Kalau masih terlalu besar, coba:

```bash
-dPDFSETTINGS=/screen
```
