### ❗️ **1. Ekstensi salah (masih .txt, bukan .html)**  
🔍 *Ciri-ciri:* File kamu tersimpan sebagai `roti_untuk_teman.html.txt`  
🔧 **Solusi:**
- Saat menyimpan di Notepad, pastikan:
  - **File name**: `roti_untuk_teman.html`
  - **Save as type**: **All Files** (bukan “Text Documents”)
  - **Encoding**: UTF-8 (opsional tapi bagus)

🔁 Kalau sudah terlanjur tersimpan sebagai `.txt`, ganti nama file:
1. Klik kanan file → Rename
2. Ubah dari:  
   `roti_untuk_teman.html.txt`  
   Menjadi:  
   `roti_untuk_teman.html`

> 💡 **Catatan:** Kadang Windows menyembunyikan ekstensi. Kalau kamu tidak melihat `.txt`, aktifkan di File Explorer:
- Buka folder → klik menu **View** → centang **File name extensions**

---

### ❗️ **2. File dibuka dengan Notepad, bukan browser**  
🔍 *Ciri-ciri:* File terbuka sebagai teks di Notepad, bukan tampilan cerita  
🔧 **Solusi:**
1. Klik kanan file → pilih **Open with > Google Chrome** (atau browser lain)
2. Kalau tidak ada pilihan, klik **Choose another app** → pilih browser kamu → centang **Always use this app**

---

### ❗️ **3. Tidak copy semua kode HTML**  
🔧 **Solusi:** Pastikan kamu menyalin **seluruh kode HTML** dari atas sampai bawah, termasuk tag `<html>...</html>`
