### **Fitur Utama Astro**

1. **Static Site Generation (SSG) by Default**:
   - Astro menghasilkan situs web statis secara default, membuatnya sangat cepat karena konten dikirimkan sebagai HTML statis.

2. **Island Architecture**:
   - Dalam pendekatan ini, bagian interaktif dari sebuah halaman (seperti komponen React atau Vue) diisolasi sebagai "pulau" kecil yang hanya memuat JavaScript jika diperlukan. Ini mengurangi ukuran JavaScript yang harus dimuat di browser.

3. **Dukungan Multi-Framework**:
   - Astro mendukung integrasi dengan berbagai framework UI seperti:

     - Vue
     - Svelte
     - SolidJS

4. **Zero JavaScript by Default**:
   - Halaman HTML yang dihasilkan tidak menyertakan JavaScript kecuali Anda secara eksplisit menambahkannya untuk kebutuhan interaktif. Ini membantu meningkatkan kinerja situs.

5. **Server-Side Rendering (SSR)**:
   - Selain SSG, Astro juga mendukung SSR, yang berguna untuk konten yang harus di-render secara dinamis di server.

6. **Sederhana dan Fleksibel**:
   - Astro menggunakan sintaks sederhana berbasis file dengan ekstensi `.astro`, yang mendukung penulisan HTML, CSS, dan JavaScript dengan mudah.

### **Apa itu Situs Web Statis?**
Situs web statis adalah situs web yang halaman-halamannya **tidak berubah** untuk setiap pengguna. Semua kontennya (teks, gambar, video, dll.) sudah **disiapkan sebelumnya** dan disimpan sebagai file HTML di server. Ketika seseorang membuka situs ini, server langsung mengirimkan file HTML ke browser tanpa perlu memprosesnya lagi.

**Contoh sederhana:**
1. Kamu menulis sebuah file HTML bernama `index.html`.
2. File itu berisi teks, gambar, dan elemen lainnya.
3. Setiap kali seseorang membuka situsmu, mereka akan mendapatkan file `index.html` persis seperti yang kamu buat.

Situs seperti ini **sangat cepat** karena server hanya perlu mengirimkan file yang sudah jadi, tanpa perlu memproses ulang setiap kali pengguna mengaksesnya.

---

### **Apa yang Dilakukan Astro?**
Astro membantu **menghasilkan situs statis** ini secara otomatis:
1. Kamu menulis kode dengan framework modern seperti React, Vue, atau bahkan file `.astro`.
2. Saat kamu membangun proyekmu (`npm run build`), Astro akan:
   - Mengambil semua konten dan komponen.
   - Mengubahnya menjadi **file HTML statis**.
3. File HTML ini kemudian di-host di server atau platform (seperti Netlify atau Vercel) dan langsung bisa diakses oleh pengguna.

---

### **Mengapa Ini Cepat?**
Karena:
1. **Tidak Ada Proses Dinamis**:
   - Tidak ada server yang harus "berpikir" untuk membuat halaman. Semua sudah disiapkan sebelumnya.
2. **Ukuran Kecil**:
   - File HTML biasanya kecil, sehingga cepat dikirimkan ke browser.
3. **Tanpa JavaScript yang Tidak Perlu**:
   - Astro hanya menambahkan JavaScript jika diperlukan (misalnya untuk tombol interaktif).

---

### **Perbandingan: Situs Statis vs Dinamis**
| **Aspek**          | **Situs Statis**                             | **Situs Dinamis**                         |
|---------------------|---------------------------------------------|-------------------------------------------|
| **Kecepatan**       | Sangat cepat (file langsung diambil).       | Bisa lebih lambat (butuh proses di server).|
| **Konten Berubah**  | Konten tetap sama untuk semua pengguna.     | Konten bisa berbeda-beda (bergantung data).|
| **Pengelolaan**     | Dibuat sekali, jarang diubah.               | Butuh database dan pengelolaan server.     |
| **Contoh**          | Blog sederhana, portofolio, dokumentasi.   | Media sosial, e-commerce, aplikasi besar. |

- **Situs Dinamis**:
   - Facebook: Halaman menampilkan postingan berbeda untuk setiap pengguna.

### **Apa yang Dimaksud dengan "Pulau" dalam Astro?**

### **Apa Itu React?**

**React** adalah sebuah **library JavaScript** yang digunakan untuk membangun **antarmuka pengguna (UI)** pada aplikasi web. React dibuat oleh **Facebook (sekarang Meta)** dan dirilis pada tahun 2013. React memungkinkan pengembang membangun komponen UI yang **dinamis** dan **dapat digunakan ulang**.

React dikenal karena menggunakan pendekatan deklaratif, sehingga pengembang hanya perlu fokus pada **apa yang ingin ditampilkan**, bukan **bagaimana menampilkannya**.

---

### **Fitur Utama React**

1. **Komponen**:
   - UI dibangun dengan komponen-komponen kecil yang dapat digunakan ulang. Setiap komponen biasanya mewakili bagian kecil dari halaman web, seperti tombol, formulir, atau header.

2. **Virtual DOM**:
   - React menggunakan Virtual DOM untuk mempercepat proses rendering. Alih-alih memodifikasi DOM langsung, React membandingkan perubahan dengan salinan Virtual DOM dan hanya memperbarui bagian yang perlu.

3. **Unidirectional Data Flow**:
   - Data dalam React mengalir dari induk (parent) ke anak (child), membuat alur data lebih mudah dipahami dan dikelola.

4. **Hooks**:
   - React menyediakan Hooks seperti `useState` dan `useEffect` untuk menangani state dan efek samping dengan lebih sederhana.

5. **JSX (JavaScript XML)**:
   - React menggunakan JSX, sintaks mirip HTML di dalam JavaScript, untuk membuat komponen lebih intuitif.

---

### **Kapan React Digunakan?**

React sangat cocok untuk:
- **Aplikasi web dinamis**: Misalnya, dashboard, e-commerce, atau media sosial.
- **Aplikasi satu halaman (SPA)**: Aplikasi yang sebagian besar logikanya berjalan di browser tanpa perlu reload halaman.
- **Proyek besar**: Dengan struktur yang kompleks dan komponen yang dapat digunakan ulang.

---

### **Contoh Penggunaan React**

#### 1. **Hello, React!**
Berikut adalah contoh komponen React sederhana:

```jsx
// App.js
import React from 'react';

function App() {
  return <h1>Hello, React!</h1>;
}

export default App;
```

**Penjelasan**:
- `import React from 'react';`: Mengimpor React untuk menggunakan fungsionalitasnya.
- `function App()`: Membuat komponen React yang merender teks "Hello, React!".
- `export default App;`: Mengekspor komponen untuk digunakan di file lain.

#### 2. **Komponen dengan State**
Contoh menambahkan **state** untuk membuat tombol yang bisa menghitung klik:

```jsx
// Counter.js
import React, { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>You clicked {count} times</p>
      <button onClick={() => setCount(count + 1)}>Click me</button>
    </div>
  );
}

export default Counter;
```

**Penjelasan**:
- `useState(0)`: Menginisialisasi state `count` dengan nilai awal `0`.
- `setCount(count + 1)`: Fungsi untuk memperbarui nilai `count` setiap kali tombol diklik.
- `onClick`: Menentukan fungsi yang akan dijalankan saat tombol diklik.

#### 3. **Menggunakan Props (Properti)**
React memungkinkan pengiriman data antar komponen menggunakan **props**.

```jsx
// Greeting.js
function Greeting({ name }) {
  return <h1>Hello, {name}!</h1>;
}

export default Greeting;

// App.js
import React from 'react';
import Greeting from './Greeting';

function App() {
  return (
    <div>
      <Greeting name="Alice" />
      <Greeting name="Bob" />
    </div>
  );
}

export default App;
```

**Penjelasan**:
- `Greeting({ name })`: Komponen menerima properti `name` dari komponen induknya.
- `Greeting name="Alice"`: Mengirim properti `name` ke komponen `Greeting`.

### **Apa Itu React?**

**React** adalah library **JavaScript** yang digunakan untuk membangun antarmuka pengguna (**UI**) pada aplikasi web. React diciptakan oleh **Facebook** (sekarang Meta) pada tahun 2013 dan kini menjadi salah satu teknologi paling populer untuk pengembangan aplikasi modern.

### **Fitur Utama React**

1. **Komponen**:

2. **Deklaratif**:
   - Dengan React, Anda hanya perlu mendeskripsikan **apa yang ingin ditampilkan**, dan React akan menangani proses pembaruan UI berdasarkan data.

3. **Virtual DOM**:
   - React menggunakan **Virtual DOM** untuk mempercepat rendering UI. Hanya bagian yang berubah di halaman yang diperbarui, sehingga aplikasi lebih cepat.

4. **Reaktivitas dengan State dan Props**:
   - **State** adalah data internal dalam sebuah komponen.
   - **Props** adalah data yang diteruskan antar komponen.

5. **Dukungan untuk Hooks**:
   - Hooks seperti `useState` dan `useEffect` mempermudah pengelolaan state dan efek samping di komponen fungsional.

---

### **Kapan Menggunakan React?**

React cocok untuk:
- **Aplikasi Web Dinamis**: Seperti media sosial, e-commerce, atau dashboard.
- **Single Page Applications (SPA)**: Aplikasi yang sebagian besar logikanya berjalan di browser tanpa perlu memuat ulang halaman.
- **Proyek dengan Komponen yang Bisa Digunakan Ulang**: Misalnya, jika Anda ingin membangun komponen seperti tombol atau formulir yang dipakai berulang-ulang.

### **Contoh Penggunaan React**

#### **1. Hello World**
Kode berikut adalah contoh React paling sederhana:

```jsx
// App.js
import React from 'react';

function App() {
  return <h1>Hello, React!</h1>;
}

export default App;
```

**Penjelasan**:
- `function App()`: Mendefinisikan sebuah komponen React bernama `App`.
- `return <h1>Hello, React!</h1>`: Komponen ini merender teks "Hello, React!" dalam elemen HTML `<h1>`.

#### **2. Menggunakan State**
React mendukung **state**, yaitu data internal yang bisa berubah dan memengaruhi UI.

```jsx
import React, { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>You clicked {count} times</p>
      <button onClick={() => setCount(count + 1)}>Click me</button>
    </div>
  );
}

export default Counter;
```

**Penjelasan**:
- `useState(0)`: Menginisialisasi state `count` dengan nilai awal `0`.
- `setCount(count + 1)`: Memperbarui nilai `count` setiap kali tombol diklik.
- `onClick`: Menghubungkan event klik dengan fungsi untuk memperbarui state.

#### **3. Menggunakan Props**
React memungkinkan data dikirim antar komponen menggunakan **props**.

```jsx
// Greeting.js
function Greeting({ name }) {
  return <h1>Hello, {name}!</h1>;
}

export default Greeting;

// App.js
import React from 'react';
import Greeting from './Greeting';

function App() {
  return (
    <div>
      <Greeting name="Alice" />
      <Greeting name="Bob" />
    </div>
  );
}

export default App;
```

**Penjelasan**:
- `Greeting({ name })`: Komponen menerima properti `name` dari komponen induknya.
- `<Greeting name="Alice" />`: Mengirimkan nilai `"Alice"` sebagai props ke komponen `Greeting`.

### **Langkah 5: Menambahkan Interaktivitas dengan React**

1. **Instal Integrasi React**:
   ```bash
   npm install @astrojs/react react react-dom
   ```

2. **Tambahkan React ke Konfigurasi**:
   Edit file `astro.config.mjs` untuk menambahkan integrasi React:
   ```javascript
   import { defineConfig } from 'astro/config';
   import react from '@astrojs/react';

   export default defineConfig({
     integrations: [react()],
   });
   ```

3. **Buat Komponen React**:
   - Buat file baru `src/components/Counter.jsx`:
     ```jsx
     import React, { useState } from "react";

     export default function Counter() {
       const [count, setCount] = useState(0);

       return (
         <div>
           <p>Count: {count}</p>
           <button onClick={() => setCount(count + 1)}>Increment</button>
         </div>
       );
     }
     ```

4. **Gunakan Komponen React**:
   - Gunakan di halaman `index.astro`:
     ```astro
     ---
     import Counter from "../components/Counter";
     ---

     <html>
       <body>
         <h1>Interactive Counter</h1>
         <Counter client:visible />
       </body>
     </html>
     ```

5. **Lihat Hasilnya**:
   - Jalankan `npm run dev` dan buka `http://localhost:3000`.
   - Anda akan melihat tombol "Increment" yang dapat diklik untuk meningkatkan angka.

### **Penjelasan Kode**

1. **Komponen Greeting.astro**:

2. **Mengimpor Komponen**:


- **Reuse**: Jika Anda membutuhkan teks "Hello, Astro User!" di banyak halaman, Anda cukup membuat komponen `Greeting` sekali, lalu menggunakannya di mana pun.
