---

## 1. Canvas Obsidian = **Papan Visual / Whiteboard Berpikir**

**Canvas** adalah **ruang visual bebas** untuk:
- melihat ide secara **spasial**
- menghubungkan banyak hal **tanpa struktur linier**
- berpikir *non-urutan* (non-linear thinking)

### Ciri utama Canvas
- Berbasis **kotak–panah–gambar–iframe**
- Drag & drop, zoom, geser bebas
- Setiap kotak bisa:
  - teks cepat
  - catatan (note)
  - gambar
  - PDF
  - link web
- Cocok untuk:
  - brainstorming
  - mind map
  - storyboard
  - arsitektur sistem
  - peta konsep

### Analogi
> **Canvas = papan tulis besar + meja kerja visual**

🧠 Cara berpikir: **intuisi, asosiasi, eksplorasi, “melihat gambaran besar”**

---

## 2. Base (Note / Vault Markdown) = **Basis Pengetahuan Terstruktur**

Yang sering disebut “base” sebenarnya:
- **Note (file .md)**
- Di dalam **Vault**
- Terhubung dengan **link, tag, metadata (YAML)**

### Ciri utama Base / Note
- Teks **linier & terstruktur**
- Bisa:
  - diberi heading
  - bullet
  - tabel
  - rumus LaTeX
- Sangat kuat untuk:
  - dokumentasi
  - penelitian
  - buku
  - kurikulum
  - MCard / PCard / VCard
- Bisa dianalisis oleh:
  - Graph View
  - Dataview
  - plugin AI
  - PKC logic

### Analogi
> **Base = perpustakaan + arsip pengetahuan**

🧠 Cara berpikir: **logis, runtut, mendalam, dapat diwariskan**

---

## 3. Perbedaan Inti (Ringkas & Tajam)

| Aspek | Canvas | Base / Note |
|---|---|---|
| Bentuk | Visual bebas | Teks terstruktur |
| Alur | Non-linier | Linier |
| Tujuan | Berpikir & eksplorasi | Menyimpan & mematangkan |
| Cocok untuk | Ide mentah, peta konsep | Pengetahuan final |
| Skala | Situasional | Jangka panjang |
| Analisis AI | Lemah | Sangat kuat |
| PKC | ❌ | ✅ |

---

## 4. Kesalahan Umum Pengguna Obsidian

❌ **Menggunakan Canvas sebagai database utama**  
→ Akhirnya sulit dicari, tidak scalable

❌ **Menulis panjang di Canvas**  
→ Hilang kekuatan markdown & metadata

✅ **Canvas = eksplorasi**
✅ **Base = kebenaran yang disimpan**

---

## 5. Pola Kerja Ideal (Best Practice)

> **Canvas → Catatan → Sistem**

Contoh alur yang sangat “GASING”:
1. **Canvas**
   - lempar ide
   - hubungkan simbol, gambar, kata kunci
2. **Note (Base)**
   - ambil kristalisasi ide
   - tulis rapi sebagai MCard / Bab / Modul
3. **Dataview / Graph / PKC**
   - hubungkan antar catatan
   - bangun “otak digital”

---

## 6. Dalam Konteks GASING, PKC, Sacred Octagon

- **Canvas**
  - peta Sacred Octagon
  - jalan cerita
  - arsitektur besar (PKC nasional)
- **Base**
  - MCard: konsep
  - PCard: proses
  - VCard: verifikasi
  - kurikulum
  - whitepaper
  - buku

📌 **Canvas = medan bermain otak**
📌 **Base = memori jangka panjang**

---

## 7. Ringkasan Satu Kalimat

> **Canvas dipakai untuk “berpikir”, Base dipakai untuk “mengingat dan membangun sistem”**

Jika mau, saya bisa:
- buat **contoh satu Canvas + Note GASING**
- desain **workflow PKC (Canvas → MCard → PCard → VCard)**
- atau template **Canvas khusus Sacred Octagon**

Tinggal bilang mau ke arah mana.

# 🎨 Contoh Canvas Obsidian (Praktis & Nyata)

## Contoh 1 — *Canvas “Sacred Octagon – Peta Ide Awal”*

Bayangkan Anda membuka **New Canvas** lalu menyusun **kotak-kotak berikut**:

```
                [ Compassion ]
                      ↑
[ Communication ] → [ Sacred ] ← [ Collaboration ]
                      ↓
     [ Critical ] ← [ Octagon ] → [ Creativity ]

                [ computational ]
                      ↑
                   [ Character ]
```

### Isi kotak:
- **Kotak tengah**
  ```
  Sacred Octagon
  - Framework pembelajaran GASING
  - 8 kecerdasan + COMPASSION
  ```

- **Kotak “Critical”**
  ```
  Critical Thinking
  - Soal jebakan
  - Diskusi kesalahan
  ```

- **Kotak “Computational”**
  ```
  Computational Logic
  - LUT
  - Pattern
  - Zero-to-hero
  ```

🔗 Panah dibuat **bebas**, tidak harus rapi  
🎯 Tujuan: **melihat keseluruhan ide sekaligus**

➡️ **Belum rapi, tidak apa-apa**  
➡️ Canvas memang tempat “berantakan yang berguna”

---

## Contoh 2 — *Canvas untuk Menulis Buku*

Judul Canvas: **Buku: Digital Mestakung**

Isi kotak secara horizontal:

```
[ Bab 1 ]
Masalah & Kondisi Kritis
     ↓
[ Bab 2 ]
Krilangkun
     ↓
[ Bab 3 ]
GASING & Sacred Octagon
     ↓
[ Bab 4 ]
PKC & AI
```

Setiap kotak hanya **bullet kasar**:
```
Bab 3:
- Anak Papua
- Zero to hero
- Joyful learning
```

📌 **Catatan penting**  
> TULIS PENDEK SAJA di Canvas  
> Jangan tergoda menulis 2 halaman

Nanti:
➡️ klik kanan kotak → *Convert to note*  
➡️ jadilah **Base Note Markdown**

---

## Contoh 3 — *Canvas Arsitektur PKC Nasional*

```
[ Citizen PKC ]
      |
      v
[ School PKC ] ---- [ Edge AI ]
      |
      v
[ District PKC ]
```

Lalu tambahkan kotak kecil:
```
[MCard]
[PCard]
[VCard]
```

Dan hubungkan dengan panah:
```
MCard → PCard → VCard
```

🎯 Canvas ini **tidak untuk dibaca rapi**
🎯 Tapi untuk:
- diskusi
- presentasi
- “menyadarkan orang” seketika

karena:

---

## Pola Emas Penggunaan Canvas ✅

Gunakan Canvas untuk:
- 🟡 “Apa saja isinya?”
- 🟡 “Bagaimana hubungannya?”
- 🟡 “Kalau digeser, apa berubah makna?”

JANGAN gunakan Canvas untuk:
- ❌ arsip jangka panjang
- ❌ tulisan buku final
- ❌ data resmi
