### ✅ **1. Cara Manual via Savefrom.net (untuk video publik)**
1. Buka video Facebook.
2. Klik kanan pada video, pilih **"Salin tautan video"** atau **"Copy video URL"**.
3. Buka [https://savefrom.net](https://savefrom.net).
4. Paste link di kolom yang tersedia.
5. Pilih kualitas video, lalu klik **Download**.

---

### ✅ **2. Pakai Situs Alternatif**
- [https://fbdown.net](https://fbdown.net)
- [https://snapsave.app](https://snapsave.app)
- [https://getfvid.com](https://getfvid.com)

**Langkahnya sama:**
1. Copy link video FB.
2. Paste ke situs tersebut.
3. Pilih resolusi.
4. Klik “Download”.

---

### ✅ **3. Gunakan Extension Browser (Chrome/Edge)**
1. Buka Chrome Web Store.
2. Cari dan pasang extension seperti **“Video Downloader for Facebook”**.
3. Saat menonton video di FB, ikon unduhan akan muncul.
4. Klik ikon untuk mengunduh.

---

### ✅ **4. Jika Video dari Grup/Private**
Jika video berasal dari grup tertutup atau akun privat, kamu bisa:
- **Gunakan screen recorder** (misalnya OBS, Xbox Game Bar di Windows, atau QuickTime di Mac).
- Atau gunakan [https://fdownloader.net/private-downloader](https://fdownloader.net/private-downloader) dengan cara:
  1. Salin **kode sumber halaman** video (right click → "View Page Source").
  2. Paste ke tool tersebut untuk mengunduh video.

---

### ⚠️ **Catatan Penting**
- **Pastikan kamu menghormati hak cipta** dan tidak menyebarkan ulang video tanpa izin dari pemiliknya.
- Beberapa video mungkin tidak bisa diunduh karena pengaturan privasi.

## 1) Melihat gambar yang dirender oleh JSX (cara normal React)
JSX **tidak menyimpan gambar di dalamnya**; JSX hanya **memanggil file gambar** lalu browser menampilkan saat app berjalan.

### Langkah cepat
1. Jalankan dev server (mis. Vite/Next/CRA)
   - Vite: `npm run dev`
   - Next.js: `npm run dev`
   - CRA: `npm start`
2. Buka URL yang muncul (biasanya `http://localhost:5173` atau `http://localhost:3000`)
3. Gambar akan tampil di halaman sesuai `<img ... />`

### Cara cek gambar berhasil termuat (paling jelas)
- Klik kanan gambar di browser → **Open Image in New Tab**
- Atau buka **DevTools → Network → Img** lalu reload, lihat file gambar ter-load atau error.

---

## 2) Melihat file gambar yang direferensikan di JSX
Cari baris seperti ini:

### A. Import gambar (umum di Vite/CRA)
```jsx
import logo from "./assets/logo.png";

<img src={logo} alt="Logo" />
```
➡️ File gambarnya ada di: `./assets/logo.png`  
Di Mac: buka Finder → cari `logo.png` → tekan Space (Quick Look) untuk preview.

### B. Pakai path langsung ke folder public
```jsx
<img src="/logo.png" alt="Logo" />
```
➡️ Biasanya file ada di folder `public/logo.png`

### C. SVG sebagai React component (sering di CRA)
```jsx
import { ReactComponent as Logo } from "./logo.svg";
<Logo />
```
➡️ File: `./logo.svg` (bisa dibuka di browser / Preview)

---

## 3) Trik cepat: cari semua referensi gambar dalam proyek
Di VS Code:
- **Cmd + Shift + F**
- Cari: `png` atau `jpg` atau `svg` atau `src="/`

Atau via terminal:
```bash
grep -R "png\|jpg\|jpeg\|svg\|src=\/" -n .
```

---

## 4) Kalau gambar “tidak muncul” (penyebab paling sering)
- Path salah (`./assets/` vs `../assets/`)
- File belum ada / beda nama huruf besar-kecil (`Logo.png` ≠ `logo.png`)
- Untuk Next.js perlu `<Image />` dan konfigurasi domain (kalau dari URL luar)
- File taruh di tempat salah (mis. pakai `/logo.png` tapi file tidak di `public/`)
