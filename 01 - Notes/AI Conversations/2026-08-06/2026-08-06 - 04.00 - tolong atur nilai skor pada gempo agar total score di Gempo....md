import { dispatch, actionCreators } from '@/flux';

### 🧩 Formula & Pola Tata Nama Berkas

```
z{Z}l{L}sb{SB}{BERMAIN}[_{MULTI_BERMAIN}]_marcia.webm
```

#### Struktur Komponen Sintaks:

| Komponen | Kode Contoh | Arti & Keterangan |
| :--- | :--- | :--- |
| **`z{Z}`** | `z2`, `z3`, `z4`, `z5` | **Zona (Zone)** — Menandakan nomor Zona pada peta kurikulum (`z2` = Zona 2, `z3` = Zona 3, dst.). |
| **`l{L}`** | `l2`, `l3`, `l4`, `l5` | **Level (Level/Bab)** — Menandakan nomor Level/Bab pada zona tersebut (`l3` = Level 3, dst.). |
| **`sb{SB}`** | `sb1`, `sb2` | **Sub-Bab (Sub-Module)** — Menandakan nomor Sub-Bab (`sb1` = Sub-Bab 1, `sb2` = Sub-Bab 2). |
| **`bermain{N}`** | `bermain1`, `bermain2`, dst. | **Modul Permainan (Game Module)** — Menandakan modul game interaktif yang diilustrasikan (`bermain1` = Bermain 1). |
| **`[_{MULTI}]`** | `_sb2bermain2` | *(Opsional)* **Gabungan Multi-Modul** — Jika video digunakan bersama untuk lebih dari satu game (contoh: `sb2bermain1_sb2bermain2` = mencakup Bermain 1 & Bermain 2 sekaligus). |
| **`_marcia`** | `_marcia` | **Sufiks Karakter / Varian Media** — Menandakan video instruksi peragaan matematika GASING versi **Karakter Marcia**. |

### 🤖 AI Agent (Antigravity)

**RTK** (singkatan dari **Rust Token Killer**) adalah sebuah alat CLI (perantara/proxy) sumber terbuka (*open-source*) yang dirancang khusus untuk **mengurangi dan mengompres jumlah token** yang dikonsumsi oleh **AI Coding Agent** (seperti Claude Code, Cursor, OpenCode, atau Antigravity).

---

### 🔍 Mengapa RTK Dibutuhkan?

Saat kamu meminta AI untuk menjalankan perintah terminal (misalnya `git status`, `npm test`, `ls -la`, atau membaca file log), terminal akan menghasilkan teks yang sangat panjang. Output tersebut sering kali berisi:
* Progress bar yang terus diperbarui.
* Baris log error yang berulang puluhan kali.
* Spasi kosong, garis pembatas, dan *boilerplate* teks yang tidak relevan.

Tanpa RTK, **seluruh teks mentah ini dimasukkan langsung ke *Context Window* AI**, yang menyebabkan:
1. **Token cepat habis** (kuota prompt cepat habis / batas percakapan tercapai).
2. **Biaya API membengkak** (pada model berbayar per-token).
3. **AI menjadi "lupa" konteks awal** karena *context window* dipenuhi teks sampah terminal.

---

### 🛠️ Bagaimana Cara Kerja RTK?

RTK bertindak sebagai **penyaring pintar** di antara terminal dan AI. Sebelum output terminal sampai ke AI, RTK melakukan 4 hal:

1. **Smart Filtering (Penyaringan Pintar):**  
   Menghapus spasi berlebih, komentar tidak penting, garis pembatas dekoratif, dan progress bar.
2. **Deduplikasi (Penggabungan Teks Berulang):**  
   Jika ada 100 baris log error yang sama, RTK mengubahnya menjadi 1 baris ringkas:  
   `[Error] Connection timeout (x100)`
3. **Grouping (Pengelompokan):**  
   Mengelompokkan daftar file berdasarkan folder atau daftar pesan *warning* berdasarkan jenis filenya.
4. **Deductive Truncation (Pemotongan Cerdas):**  
   Menyimpan baris awal dan baris akhir log (tempat informasi krusial berada), lalu memotong bagian tengah log raksasa yang tidak informatif.

---

### 📈 Manfaat Utama RTK

* **Penghematan Token 60% – 90%:** Khusus pada hasil eksekusi perintah terminal.
* **Respon AI Lebih Cepat:** Karena data yang diproses AI jauh lebih sedikit.
* **Kapasitas Percakapan Lebih Panjang:** *Context window* AI tidak cepat penuh, sehingga percakapan coding bisa berlangsung lebih lama tanpa perlu sering *reset context*.
