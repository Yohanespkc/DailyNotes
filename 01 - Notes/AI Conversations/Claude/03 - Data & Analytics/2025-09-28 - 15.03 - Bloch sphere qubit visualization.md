Saya telah membuat visualisasi interaktif Bola Bloch yang menunjukkan dengan jelas bagaimana **cos θ** dan **sin θ** berfungsi sebagai proyeksi vektor dalam mekanika kuantum. Berikut penjelasan konsep utama:

## 🔍 **Konsep Kunci Proyeksi Vektor pada Bola Bloch**

### **1. Proyeksi Vertikal (cos θ)**
- **Vektor biru (cyan)** menunjukkan proyeksi pada sumbu Z
- Panjangnya = **cos θ**, yang merepresentasikan "seberapa dekat" qubit dengan state |0⟩
- Ketika θ = 0°: cos θ = 1 (qubit berada di kutub utara = state |0⟩)
- Ketika θ = 90°: cos θ = 0 (qubit berada di ekuator)
- Ketika θ = 180°: cos θ = -1 (qubit berada di kutub selatan = state |1⟩)

### **2. Proyeksi Horizontal (sin θ)**
- **Vektor kuning** menunjukkan proyeksi pada bidang XY
- Panjangnya = **sin θ**, yang menunjukkan "seberapa jauh" qubit dari sumbu Z
- Mencapai maksimum (= 1) ketika θ = 90° (di ekuator)
- Menjadi 0 ketika θ = 0° atau 180° (di kutub-kutub)

### **3. Hubungan dengan Amplitudo Qubit**
Status qubit: **|ψ⟩ = cos(θ/2)|0⟩ + sin(θ/2)|1⟩**

- **cos(θ/2)** = amplitudo untuk state |0⟩
- **sin(θ/2)** = amplitudo untuk state |1⟩
- Probabilitas mengukur |0⟩ = **cos²(θ/2)**
- Probabilitas mengukur |1⟩ = **sin²(θ/2)**

### **🎛️ Coba Eksplorasi:**
1. **Gerakkan slider θ** untuk melihat bagaimana proyeksi berubah
2. Perhatikan hubungan geometris antara vektor state (merah muda) dengan proyeksi-proyeksinya
3. **Kasus khusus:**
   - θ = 0°: Pure state |0⟩
   - θ = 90°: Superposisi seimbang (|0⟩ + |1⟩)/√2
   - θ = 180°: Pure state |1⟩

Visualisasi ini menunjukkan bahwa fungsi trigonometri dalam mekanika kuantum bukanlah abstraksi matematis belaka, tetapi benar-benar merepresentasikan **proyeksi geometris** dari vektor state qubit pada ruang Hilbert yang dapat divisualisasikan sebagai bola unit 3D!
