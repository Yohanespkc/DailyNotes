## Apa itu MCard?

**MCard** adalah unit pengetahuan atomik, fundamental, dan tidak dapat diubah (immutable) yang menjadi tulang punggung dari seluruh sistem PKC (Personal Knowledge Container). MCard beroperasi pada **Data Plane** dalam arsitektur tiga tingkat MVP Cards.

## Struktur Inti MCard

MCard memiliki tiga atribut utama:

```javascript
interface MCard {
  content: Blob;        // Konten data (bisa teks atau media biner)
  content_hash: string; // Hash kriptografi (SHA-256) untuk identitas
  g_time: string;       // Timestamp global untuk versi
}
```

## Karakteristik Utama

1. **Content-Addressable Identity**: Setiap MCard diidentifikasi secara unik melalui hash kriptografisnya
2. **Immutable Storage**: Konten tidak dapat diubah tanpa menghasilkan hash baru
3. **Atomic Compositionality**: MCard berfungsi sebagai blok bangunan yang tidak dapat dibagi
4. **Cryptographic Verification**: Jaminan integritas melalui validasi hash

## Fungsi dan Kegunaan

- **Penyimpanan Universal**: Dapat menyimpan berbagai jenis data (teks, gambar, video, dll.)
- **Dasar Komposisi**: Menjadi fondasi untuk membangun struktur pengetahuan yang lebih kompleks
- **Verifikasi Integritas**: Memastikan data tidak rusak atau dimanipulasi
- **Referensi Stabil**: Hash yang konsisten memungkinkan referensi yang dapat diandalkan

## Dalam Konteks yang Lebih Luas

MCard bekerja bersama dengan:
- **PCard**: Untuk komposisi dan transformasi pengetahuan
- **VCard**: Untuk representasi nilai dan koordinasi ekonomi

Sistem ini memungkinkan penciptaan ekosistem pengetahuan yang dapat diverifikasi, disusun, dan dibagikan dengan aman di berbagai platform dan aplikasi.
