Saya urutkan:

**Cara 1: Drag and drop (paling cepat, cocok untuk coba-coba)**

1. Buka app.netlify.com dan login (bisa pakai akun GitHub atau email).
2. Di dashboard, pilih menu "Sites" lalu cari area "Drag and drop your site output folder here".
3. Seret folder berisi file web Prof (yang ada index.html di dalamnya) ke area itu.
4. Selesai, dalam beberapa detik web sudah live di alamat acak seperti `nama-acak-123.netlify.app`.

Kelemahannya: setiap update harus seret folder lagi secara manual. Cocok untuk web Yohanes Surya yang jarang diupdate, kurang cocok untuk yang sering berubah.

**Cara 2: Lewat Git (paling direkomendasikan)**

Ini cara yang benar untuk ketiga web Prof, karena update cukup dengan git push:

1. Push folder proyek ke repository GitHub (private juga bisa).
2. Di Netlify, klik "Add new site" lalu "Import an existing project".
3. Pilih GitHub, otorisasi, lalu pilih repository-nya.
4. Isi pengaturan build. Untuk HTML murni tanpa build process: kosongkan "Build command", dan isi "Publish directory" dengan `.` atau folder tempat index.html berada.
5. Klik "Deploy site".

Setelah ini, setiap kali Prof melakukan `git push`, Netlify otomatis deploy versi terbaru dalam 1-2 menit. Ini alur yang sama dengan gaya kerja Prof di proyek-proyek lain yang sudah pakai git.

**Cara 3: Netlify CLI (cocok untuk otomatisasi dari skrip)**

Ini yang dipakai di pipeline berita AI Prof. Instal sekali:

```bash
npm install -g netlify-cli
netlify login
```

Lalu dari folder proyek:

```bash
netlify init        # hubungkan folder ke situs Netlify (sekali saja)
netlify deploy --prod --dir .
```

Perintah `netlify deploy --prod` ini bisa dipanggil dari skrip Python atau launchd plist, persis seperti pipeline berita yang sudah jalan di Mac Prof. Cocok kalau nanti ada konten yang digenerate otomatis lalu ingin langsung terpublikasi.

**Pengaturan tambahan yang penting:**

Custom domain: di dashboard situs, masuk ke "Domain management" lalu "Add custom domain". Netlify akan minta Prof menambahkan record DNS (CNAME ke `nama-situs.netlify.app` untuk subdomain, atau A record untuk domain utama) di tempat Prof membeli domain. HTTPS otomatis aktif gratis lewat Let's Encrypt, biasanya dalam beberapa menit setelah DNS terhubung.

Ganti nama situs: di "Site configuration" bisa ubah nama acak jadi misalnya `beasiswa-gasing.netlify.app` sebelum domain custom siap.

**Target 2: Make PKC available to the entire Indonesian public, empowering people to create and enabling a cleaner, more accountable government**

PKC is about democratizing the power of AI-assisted creation. Today, tools like Antigravity empower programmers; PKC aims to empower everyone: teachers, students, civil servants, and ordinary citizens, so they can build their own learning materials, applications, and solutions. When a teacher in a small village can create her own educational software, knowledge stops being something people merely consume and becomes something they produce.

PKC as the foundation of AI-powered GovTech for clean governance

Beyond education, PKC will serve as a sovereign foundation for AI-powered GovTech, an area Pak Luhut is currently championing. Government programs such as Bansos (social assistance) lose enormous value every year to mistargeting and misuse of funds, and the ones who suffer most are the poor families the programs were created to protect. With AI built on PKC, this can change:

1. Precise targeting: AI can cross-analyze population data, welfare data, and field reports to ensure Bansos reaches the families who truly need it, not those who manipulate the system.
2. Fraud detection and prevention: AI can flag anomalies in fund distribution, duplicate recipients, and suspicious patterns in real time, closing the gaps where funds leak before the damage is done.
3. Transparency and accountability: every rupiah becomes traceable, every decision auditable. Corruption thrives in darkness; AI-powered systems turn the lights on.
4. Sovereignty: because PKC is built on open source and opencode technology hosted on Indonesian infrastructure, sensitive citizen data never leaves the country, and the government is never dependent on foreign platforms for its most critical systems.

A cleaner government is not an abstract goal. It means a poor family in a remote village actually receives the assistance the state promised them. It means public money builds schools and feeds children instead of disappearing. PKC puts Indonesian AI to work for the Indonesian people, in the classroom and in governance alike.
