## Penjelasan Matematis

Spiral eksponensial kompleks **z(t) = e^(i(a + ib))** dapat dianalisis sebagai:

Dengan parameterisasi **a = t** dan **b = konstan**:

**z(t) = e^(it + i²bt) = e^(it - bt) = e^(-bt) · e^(it)**

### Komponen Utama:
- **e^(it)**: Rotasi pada lingkaran satuan dengan kecepatan sudut konstan
- **e^(-bt)**: Peluruhan eksponensial dari magnitude (jari-jari)

### Sifat-sifat Penting:
- **Magnitude**: |z(t)| = e^(-bt) (berkurang eksponensial untuk b > 0)
- **Fase**: arg(z(t)) = t (bertambah linear dengan waktu)
- **Untuk b > 0**: Spiral masuk menuju pusat (inward spiral)
- **Untuk b < 0**: Spiral keluar menjauhi pusat (outward spiral)
- **Untuk b = 0**: Lingkaran sempurna dengan radius konstan

3. Grafik peluruhan magnitude

## Penjelasan Matematis untuk b < 0:

Ketika **b < 0**, formula berubah menjadi:

**z(t) = e^(-bt) · e^(it) = e^(|b|t) · e^(it)**

Karena -b > 0, maka **e^(-bt) MEMBESAR** secara eksponensial!

### Sifat-sifat Spiral Keluar (b < 0):

**1. Magnitude:** 
- |z(t)| = e^(|b|t) → **BERTAMBAH** eksponensial
- Mulai dari r = 1 dan terus membesar
- Kebalikan dari spiral masuk

**2. Fase:**
- arg(z(t)) = t → Rotasi tetap konstan
- Berputar berlawanan arah jarum jam
- Sama seperti b > 0

**3. Vektor Kecepatan:**
- dz/dt = (|b| + i)z
- Komponen radial: +|b|·z → mengarah **KELUAR**
- Komponen tangensial: +i·z → rotasi

**4. Geometri:**
- Spiral logaritmik ekspansif
- Jarak antar putaran bertambah eksponensial
- Divergen (tidak konvergen ke titik)

### Perbandingan b > 0 vs b < 0:

| Properti | b > 0 (Masuk) | b < 0 (Keluar) |
|----------|---------------|----------------|
| **Magnitude** | Mengecil e^(-bt) | Membesar e^(\|b\|t) |
| **Arah** | Menuju pusat | Menjauhi pusat |
| **Stabilitas** | Konvergen → 0 | Divergen → ∞ |
| **Jarak loop** | Mengecil | Membesar |
| **Kecepatan** | Mengarah dalam | Mengarah keluar |

### Interpretasi Fisika:

- **b > 0**: Sistem dengan **friksi/damping** (energi hilang)
- **b < 0**: Sistem dengan **amplifikasi** (energi bertambah)
- **b = 0**: Sistem **konservatif** (energi tetap)

Visualisasi menunjukkan bagaimana spiral dengan b negatif merupakan cerminan "time-reversed" dari spiral dengan b positif!
