 # Cara Mentranskrip Video YouTube Menggunakan Terminal

Saya bisa menjelaskan beberapa metode untuk mentranskrip video YouTube menggunakan terminal. Berikut adalah beberapa pendekatan yang bisa Anda coba:

## 1. Menggunakan youtube-dl dan whisper

Salah satu cara populer adalah menggunakan kombinasi youtube-dl (atau yt-dlp) untuk mengunduh audio dan OpenAI Whisper untuk transkripsi:

```bash
# Instalasi tools yang dibutuhkan
pip install yt-dlp openai-whisper

# Unduh audio dari video YouTube
yt-dlp -x --audio-format mp3 https://www.youtube.com/watch?v=VIDEO_ID -o audio.mp3

# Transkripsi menggunakan Whisper
whisper audio.mp3 --language Indonesian --model medium
```

## 2. Menggunakan youtube-transcript-api

Pendekatan lain adalah menggunakan API transkrip YouTube langsung:

```bash
# Instalasi
pip install youtube-transcript-api

# Penggunaan dalam Python melalui terminal
python -c "from youtube_transcript_api import YouTubeTranscriptApi; print(YouTubeTranscriptApi.get_transcript('VIDEO_ID', languages=['id', 'en']))"
```

## 3. Menggunakan Google Speech-to-Text

Jika ingin menggunakan layanan Google:

```bash
# Unduh audio dengan yt-dlp
yt-dlp -x --audio-format flac https://www.youtube.com/watch?v=VIDEO_ID -o audio.flac

# Proses dengan Google Speech-to-Text API (memerlukan akun dan kredensial)
gcloud ml speech recognize audio.flac --language-code=id-ID > transcript.txt
```

## Catatan Penting

- Ganti `VIDEO_ID` dengan ID video YouTube yang ingin ditranskrip
- Beberapa metode memerlukan koneksi internet yang stabil
- Layanan berbayar seperti Google Speech-to-Text memerlukan akun dan mungkin biaya
- Kualitas transkripsi bergantung pada kejelasan audio dan model yang digunakan
- Pastikan Anda mengikuti ketentuan layanan platform yang digunakan
