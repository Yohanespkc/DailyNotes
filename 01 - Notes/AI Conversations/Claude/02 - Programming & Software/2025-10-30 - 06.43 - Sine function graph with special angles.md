### 🤖 Claude:
Pengguna ingin saya membuat grafik fungsi sin θ sebagai fungsi θ, dengan θ dalam derajat. Mereka ingin menunjukkan titik-titik spesifik pada θ = 0°, 30°, 45°, 120°, 225°, 330°, dan 360°, dengan nilai-nilainya dalam bentuk akar.

Mari saya hitung nilai sin untuk setiap sudut:
- sin(0°) = 0
- sin(30°) = 1/2
- sin(45°) = √2/2
- sin(120°) = sin(180° - 60°) = sin(60°) = √3/2
- sin(225°) = sin(180° + 45°) = -sin(45°) = -√2/2
- sin(330°) = sin(360° - 30°) = -sin(30°) = -1/2
- sin(360°) = 0
