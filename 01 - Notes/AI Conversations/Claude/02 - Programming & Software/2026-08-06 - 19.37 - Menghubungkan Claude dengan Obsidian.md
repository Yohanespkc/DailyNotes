Ada beberapa cara untuk menghubungkan percakapan Claude dengan Obsidian, tergantung apakah Anda pakai Claude Desktop/Claude.ai atau Claude Code. Berikut ringkasannya:

## Opsi 1: Plugin MCP Connector (paling mudah, langsung dari Obsidian)

Ada plugin komunitas Obsidian bernama **MCP Connector** yang menjalankan server MCP langsung di dalam Obsidian, tanpa perlu instalasi terpisah. Plugin ini menghubungkan client MCP seperti Claude Desktop, Claude Code, dan Cline ke vault Anda dengan fitur semantic search, template, manajemen file, dan eksekusi command yang terkontrol. Server MCP-nya berjalan di dalam Obsidian sendiri, secara lokal, tanpa perlu unduh binary tambahan dan tanpa round-trip ke cloud. Cara setup: buka **Settings → MCP Connector → Access control**, lalu hubungkan Claude Desktop lewat file `.mcpb` (drag and drop) atau salin konfigurasinya.

## Opsi 2: mcp-obsidian (via Local REST API plugin)

Ini pendekatan yang lebih lama dan banyak dipakai. Anda perlu instal plugin Obsidian Local REST API, lalu hubungkan Obsidian MCP untuk akses baca/tulis catatan lewat Local REST API. Dua implementasi populer: MarkusPfundstein/mcp-obsidian (server Python, dijalankan dengan 'uvx mcp-obsidian') dan cyanheads/obsidian-mcp-server (alternatif Node yang lebih lengkap, dijalankan dengan 'npx obsidian-mcp-server'). Keduanya butuh plugin Local REST API sebagai jembatannya.

## Opsi 3: Filesystem MCP (paling sederhana, tanpa plugin Obsidian sama sekali)

Karena vault Obsidian sebenarnya cuma kumpulan file Markdown di folder biasa, Filesystem MCP resmi bisa langsung baca file vault tanpa perlu plugin Obsidian apa pun — cukup arahkan ke folder vault Anda. Ini paling cocok kalau Anda cuma butuh Claude baca/tulis catatan tanpa fitur pencarian canggih.

## Untuk Claude Code khususnya

Kalau Anda pakai Claude Code (bukan Claude Desktop/claude.ai), ada juga paket npm **obsidian-mcp** yang membaca file vault langsung dari disk tanpa perlu plugin Obsidian, dan Obsidian bahkan tidak perlu sedang berjalan. Setelah terhubung, Anda bisa minta Claude Code merangkum sesi kerja dan menyimpannya sebagai catatan Markdown baru di vault Anda, lengkap dengan frontmatter dan tag.
