**Penjelasan singkat:**

Fungsi logaritma kompleks memiliki perilaku menarik:

- **Untuk x > 0** (garis biru): log(x) = ln(x) + i·0, jadi hasilnya bilangan real murni dengan bagian imajiner = 0

- **Untuk x < 0** (garis merah): log(x) = ln|x| + i·π, jadi hasilnya memiliki:
  - Bagian real: ln|x| (sama seperti nilai absolut x)
  - Bagian imajiner: π (konstan sekitar 3.1416)

Visualisasi menampilkan:
1. **Plot 3D** (kiri): Menunjukkan kurva lengkap dalam ruang (x, Re, Im)
2. **Plot bagian real** (kanan atas): Terlihat simetris untuk x positif dan negatif
3. **Plot bagian imajiner** (kanan bawah): Nol untuk x positif, π untuk x negatif
