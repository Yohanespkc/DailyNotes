Mari kita ubah 3cos(x) + 4sin(x) ke bentuk A sin(x + φ) atau A cos(x - φ).

Kita tahu bahwa:
a cos(x) + b sin(x) = R cos(x - α)
di mana R = √(a² + b²) dan tan(α) = b/a

Atau bisa juga:
a cos(x) + b sin(x) = R sin(x + β)
di mana R = √(a² + b²) dan tan(β) = a/b

Mari gunakan pendekatan pertama:
R = √(3² + 4²) = √(9 + 16) = √25 = 5

tan(α) = 4/3
α = arctan(4/3) ≈ 0.927 radian ≈ 53.13°

Jadi: 3cos(x) + 4sin(x) = 5cos(x - α) di mana α = arctan(4/3)

Untuk mencari titik nol:
5cos(x - α) = 0
cos(x - α) = 0
x - α = π/2 + nπ (untuk n = ..., -1, 0, 1, 2, ...)

Jadi:
x = α + π/2 + nπ
