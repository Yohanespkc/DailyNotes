sin x = √2/2 terjadi pada:
- x = 45° (di kuadran I)
- x = 135° (di kuadran II)

Karena sin x positif di kuadran I dan II (0° < x < 180°), dan sin x negatif di kuadran III dan IV (180° < x < 360°).

Untuk sin x < √2/2:

1. Di interval [0°, 180°]:
   - sin x naik dari 0 ke 1 di [0°, 90°]
   - sin x turun dari 1 ke 0 di [90°, 180°]
   - sin 45° = √2/2
   - sin 135° = √2/2
   - Jadi sin x < √2/2 terjadi ketika:
     * 0° ≤ x < 45° (sin x naik dari 0 ke √2/2)
     * 135° < x ≤ 180° (sin x turun dari √2/2 ke 0)

2. Di interval [180°, 360°]:
   - Semua sin x bernilai negatif dalam interval ini
   - Karena semua nilai negatif < √2/2, maka interval penuh memenuhi
   - Perlu memperhatikan batas-batas dengan cermat

Saya membutuhkan ketelitian dalam menentukan batas-batas nilai x yang tepat memenuhi pertidaksamaan.

Interval solusi terdiri dari dua bagian:
- Rentang 0° hingga 45° dengan sin x naik
- Rentang setelah 135° hingga 360° dengan sin x memenuhi syarat

Solusi akhir dapat dinyatakan dalam notasi himpunan: x ∈ [0°, 45°) ∪ (135°, 360°]Saya akan menyelesaikan pertidaksamaan trigonometri **2 sin x - √2 < 0** untuk **0° ≤ x ≤ 360°**.

## Langkah Penyelesaian

**1) Sederhanakan pertidaksamaan:**
```
2 sin x - √2 < 0
2 sin x < √2
sin x < √2/2
```

**2) Tentukan nilai pembatas:**

Nilai pembatas terjadi ketika sin x = √2/2

Untuk 0° ≤ x ≤ 360°, persamaan sin x = √2/2 memiliki solusi:
- x = 45° (kuadran I)
- x = 135° (kuadran II)

**3) Analisis interval:**

Perhatikan grafik fungsi sin x:

- **Interval [0°, 45°)**: sin x naik dari 0 ke √2/2
  → sin x < √2/2 ✓

- **Interval [45°, 135°]**: sin x ≥ √2/2 
  → sin x < √2/2 ✗

- **Interval (135°, 360°]**: sin x turun dari √2/2 ke 0, lalu negatif, kemudian naik kembali ke 0
  → sin x < √2/2 ✓

## **Jawaban:**

**Himpunan penyelesaian:**

$$\boxed{0° \leq x < 45° \text{ atau } 135° < x \leq 360°}$$

Atau dalam notasi interval:

$$\boxed{x \in [0°, 45°) \cup (135°, 360°]}$$
