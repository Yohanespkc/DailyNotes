Ketika Bapak drag file di dalam volume/disk yang sama (misalnya dari folder WhatsApp ke folder lain di Macintosh HD), Finder secara default melakukan **Move**, bukan **Copy**, sehingga file aslinya hilang dari lokasi sumber.

Cara mengatasinya:

**Cara 1: Tahan tombol Option saat drag**
Sambil men-drag file, tahan tombol **⌥ Option** (alt). Kursor akan berubah dengan tanda **+** hijau, menandakan operasi salin. File asli tetap di folder WhatsApp.

**Cara 2: Copy-Paste biasa**
Klik kanan file di folder WhatsApp, pilih **Copy** (atau **⌘ Cmd + C**), lalu buka folder tujuan dan **⌘ Cmd + V**. Ini selalu menyalin, bukan memindahkan.

**Cara 3: Drag ke volume berbeda**
Kalau Bapak drag ke external drive atau iCloud Drive (volume berbeda), Finder otomatis menyalin tanpa perlu tombol tambahan.

**Tips tambahan:** Untuk mengingat singkatnya, sebagai cara mudah:
- Drag biasa = pindah (sama volume)
- Drag + Option = salin
- Drag + Command = paksa pindah (beda volume)

Saya sarankan pakai **Cara 1 (Option + drag)** karena paling cepat dan intuitif untuk alur kerja sehari-hari Bapak.
