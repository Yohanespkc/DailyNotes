================================================================================
             PANDUAN PENGGUNAAN SACRED OCTAGON PWA (OFFLINE APP)
================================================================================

Halo! Paket ini adalah aplikasi Sacred Octagon PWA mandiri (Progressive Web App)
yang bisa dijalankan langsung di komputer (Mac, Windows, Linux) tanpa perlu koneksi
internet penuh.

--------------------------------------------------------------------------------
1. CARA MENJALANKAN DI KOMPUTER / LAPTOP
--------------------------------------------------------------------------------
- Pengguna MAC (macOS):
  Cukup klik ganda (double-click) file:
  👉 "Buka-Sacred-Octagon-Mac.command"
  Aplikasi akan otomatis berjalan di window aplikasi tersendiri!

- Pengguna WINDOWS:
  Cukup klik ganda (double-click) file:
  👉 "Buka-Sacred-Octagon-Windows.bat"
  Aplikasi akan otomatis membuka browser lokal Anda.

- Pengguna LINUX:
  Jalankan terminal di folder ini:
  bash Buka-Sacred-Octagon-Mac.command

--------------------------------------------------------------------------------
2. CARA SHARE / INSTALL PWA KE HP TEMAN (IPHONE & ANDROID) TANPA KIRIM FILE BESAR
--------------------------------------------------------------------------------
Jika teman Anda ingin memasang Sacred Octagon langsung di HP mereka (seperti app Play Store):
Cukup bagikan link resmi:
👉 https://cf.so-gasing.com (atau https://so-gasing.com)

Lalu ikuti langkah 1-klik berikut di HP mereka:

📱 Pengguna iPhone / iPad (Safari):
1. Buka https://cf.so-gasing.com di browser Safari.
2. Ketuk ikon "Bagikan" (Share) di bagian bawah layar (kotak dengan panah ke atas).
3. Gulir ke bawah dan pilih "Tambahkan ke Layar Utama" (Add to Home Screen).
4. Ketuk "Tambah" (Add) di pojok kanan atas.
-> Ikon Sacred Octagon akan langsung muncul di layar utama iPhone dan berjalan fullscreen!

🤖 Pengguna Android (Google Chrome):
1. Buka https://cf.so-gasing.com di browser Google Chrome.
2. Akan muncul banner otomatis "Tambahkan Sacred Octagon ke Layar Utama" (atau ketuk titik tiga di pojok kanan atas -> pilih "Install Aplikasi" / "Tambahkan ke Layar Utama").
3. Ketuk "Install".
-> Aplikasi langsung terpasang di menu aplikasi Android layaknya aplikasi native!

--------------------------------------------------------------------------------
3. UNTUK APLIKASI NATIVE ANDROID (.APK)
--------------------------------------------------------------------------------
Jika teman Anda menggunakan HP Android dan ingin menginstal file APK langsung:
Kirimkan file:
👉 SacredOctagon-Android.apk (tersedia di folder dist-shareable)
Teman Anda cukup membuka file tersebut di HP Android untuk langsung menginstalnya.
