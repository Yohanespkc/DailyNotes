### 🛠️ 2. Diagnosa Masalah HP & Solusi 5 Pilar yang Telah Diterapkan

Masalah gambar terpotong dan tombol macet yang ditemukan tim Anda telah diselesaikan melalui 5 pilar perbaikan arsitektural:

```
┌────────────────────────────────────────────────────────────────────────┐
│              HASIL PERBAIKAN PWA UNTUK HP (NATIVE-GRADE)               │
├────────────────────────────────────────────────────────────────────────┤
│ 1. Viewport 100dvh     : Tombol bawah tidak tertutup toolbar browser   │
│ 2. Zero-Delay Touch    : Delay 300ms dihapus, respon tombol 0ms instan │
│ 3. Anti-Clipping Media : Semua gambar & kartu pas di layar HP          │
│ 4. Auto-Scale Arena    : Mode landscape HP otomatis scale proporsional │
│ 5. Mentor De-conflict  : Prof. Gasing tidak lagi memblokir tombol game │
└────────────────────────────────────────────────────────────────────────┘
```

1. **Pilar 1: Dynamic Viewport Height (`100dvh`)**
   - **Masalah:** Browser HP memiliki toolbar URL di atas dan navigasi di bawah yang tingginya dinamis. Menggunakan `100vh` standar menyebabkan tombol-tombol bawah (numpad, kartu pilihan, tombol kirim) terdorong keluar layar atau tertutup bar browser.
   - **Solusi:** Diimplementasikan `100dvh` (Dynamic Viewport Height) dan `padding-top: 0` pada perangkat bergerak di [`mobile-divergence.css`](file:///Users/yohanessurya/Documents/Development/so/worktrees/main-bf/web/src/styles/tokens/layout/mobile-divergence.css) dan [`[gameKey].astro`](file:///Users/yohanessurya/Documents/Development/so/worktrees/main-bf/web/src/pages/game/%5BgameKey%5D.astro). Seluruh area game kini pas 100% dengan layar yang terlihat.

2. **Pilar 2: Eliminasi Delay Sentuh 300ms (`touch-action: manipulation`)**
   - **Masalah:** Browser HP secara default menunda eksekusi klik selama 300ms untuk mendeteksi *double-tap zoom*. Jika anak menekan tombol dengan cepat, browser mengiranya sebagai *gesture zoom* sehingga tombol terasa macet.
   - **Solusi:** Ditambahkan `touch-action: manipulation !important` serta penghapusan `-webkit-tap-highlight-color` pada seluruh tombol, numpad, dan kartu. Klik jari kini merespon instan dalam **0 milidetik**.

3. **Pilar 3: Anti-Clipping Media & Auto-Fit Kartu**
   - **Masalah:** Gambar karakter, wadah soal, atau kartu dengan lebar tetap (misal `w-[600px]`) meluap ke samping pada layar HP sempit (360px–390px) dan terpotong oleh `overflow: hidden`.
   - **Solusi:** Diterapkan aturan anti-clipping universal:
     ```css
     .bermain-engine img, .bertualang-engine img, .topdown-engine img {
       max-width: 100%;
       height: auto;
       object-fit: contain;
     }
     ```

4. **Pilar 4: Universal Responsive Arena Scaling (Mode Landscape HP)**
   - **Masalah:** Pada mode landscape HP (tinggi layar hanya ~360px–390px), tumpukan soal matematika dan numpad melebihi tinggi layar sehingga tombol konfirmasi di bawah terpotong.
   - **Solusi:** Ditambahkan skala otomatis dinamis (`transform: scale(0.68 - 0.92)`) khusus untuk layar pendek ($\le 560\text{px}$), sehingga seluruh elemen matematika mengecil secara proporsional dan muat utuh di layar.

5. **Pilar 5: De-confliction Karakter Mentor Prof. Gasing**
   - **Masalah:** Maskot Prof. Gasing di pojok kiri bawah (`bottom: 2%, left: 3%`) sebelumnya memiliki lebar 112px dengan `pointer-events: auto`. Di layar HP, tubuh sang profesor menutupi tombol kartu atau tombol lompat di belakangnya sehingga tidak bisa diklik.
   - **Solusi:** Di HP, maskot diperkecil ke 65% dan diberikan `pointer-events: none` pada area transparan, sehingga sentuhan jari siswa langsung tembus ke tombol permainan di bawahnya tanpa hambatan.

### 🛡️ 3. Jaminan "Desktop Invariance" (Web 100% Tidak Berubah)

Semua aturan di atas dibungkus dalam blok CSS terisolasi:
```css
@media screen and (max-width: 1024px), (pointer: coarse) {
  /* HANYA AKTIF PADA HP & TABLET */
}
```
Sedangkan untuk Desktop dan Laptop (`min-width: 1025px`, `pointer: fine`), aturan tersebut **sama sekali tidak aktif**. Tampilan desktop tetap menggunakan tata letak presisi yang sudah terbukti andal.
