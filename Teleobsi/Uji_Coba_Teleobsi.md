# Uji Coba Teleobsi
Ini tes simpan langsung ke folder Teleobsi.


### 🚀 Cara Penggunaan Terbaru:

1. Buka aplikasi via shortcut di Desktop:  
    👉 **
    
    ![](vscode-file://vscode-app/Applications/Antigravity%20IDE.app/Contents/Resources/app/extensions/theme-symbols/src/icons/files/document.svg)
    
    Buka TeleShare Telegram.command** _(atau buka `http://localhost:8085`)_
2. Drag & drop file `.md` dari folder **`Teleobsi`** Anda ke aplikasi.
3. Teman yang menerima tinggal mengklik tombol **"💾 Simpan ke Teleobsi"** (dan dapat mengubah nama filenya jika diinginkan), maka file tersebut akan langsung masuk ke dalam folder **Teleobsi** Obsidian milik mereka!
