# 🎨 Panduan Lengkap Fungsi Setiap Tombol di Excalidraw Obsidian

Dokumen ini berisi panduan referensi lengkap mengenai fungsi, kegunaan, dan shortcut keyboard untuk **setiap tombol di Excalidraw**.

---

## 🛠️ 1. Bilah Alat Utama Melayang Atas (Top Main Toolbar)

Toolbar melayang di bagian atas kanvas adalah alat utama Anda untuk membuat objek:

| Ikon & Tombol | Shortcut | Nama Alat | Fungsi & Cara Pemakaian |
| :--- | :---: | :--- | :--- |
| ✋ **Hand / Pan** | `H` / `Space` | Geser Kanvas | Menggeser posisi kanvas tanpa mengubah/mengedit objek. |
| ↖️ **Selection** | `V` atau `1` | Penunjuk / Select | Memilih, memindahkan, meresize, atau memutar objek. |
| ▢ **Rectangle** | `R` atau `2` | Persegi Panjang | Membuat kotak atau persegi. Tahan `Shift` untuk persegi sama sisi. |
| ◇ **Diamond** | `D` atau `3` | Belah Ketupat | Membuat bentuk jajaran genjang/diamond (biasa untuk kondisi flowchart). |
| ◯ **Ellipse** | `O` atau `4` | Lingkaran / Elips | Membuat lingkaran. Tahan `Shift` untuk lingkaran sempurna. |
| ➡️ **Arrow** | `A` atau `5` | Panah | Membuat garis panah. **Klik 3x** untuk membuat panah melengkung halus. |
| — **Line** | `L` atau `6` | Garis Lurus | Membuat garis pembatas lurus tanpa kepala panah. |
| ✏️ **Draw** | `P` atau `7` | Pensil Bebas | Menggambar bebas secara manual menggunakan mouse/pen tablet. |
| 🔤 **Text** | `T` atau `8` | Teks / WikiLink | Menulis teks biasa atau link catatan `[[Nama Catatan]]`. |
| 🧹 **Eraser** | `E` atau `0` | Penghapus | Menghapus objek dengan mengeklik atau mengusap di atasnya. |
| 🖼️ **Image** | `9` | Sisip Gambar | Mengunggah dan menyisipkan file gambar (PNG/JPG) ke kanvas. |
| 🔲 **Alat Tambahan** | - | Menu Opsi | Membuka menu alat tambahan (Frame, Web Embed, Laser Pointer, AI Tools). |

## 🎨 2. Panel Properti Elemen (Bilah Kiri saat Objek Terpilih)

Panel di sebelah kiri layar digunakan untuk mengatur warna dan gaya bentuk objek yang sedang Anda pilih:

1. **Stroke Color (Warna Garis):** Mengubah warna garis luar objek atau warna teks.
2. **Background Color (Warna Isi):** Mengubah warna dalam (*fill*) objek persegi/lingkaran.
3. **Fill Style (Gaya Isian):**
   - *Hachure:* Pola arsiran corat-coret tangan khas Excalidraw.
   - *Cross-hatch:* Pola arsiran silang.
   - *Solid:* Warna blok padat penuh.
4. **Stroke Width (Ketebalan Garis):** Mengatur garis tipis, sedang, atau tebal.
5. **Stroke Style (Tipe Garis):** Garis utuh (*Solid*), putus-putus (*Dashed*), atau titik-titik (*Dotted*).
6. **Sloppiness / Roughness (Tingkat Keacakan):**
   - *Architect:* Garis rapi lurus presisi.
   - *Artist:* Garis bergaya arsitektur alami.
   - *Cartoon:* Garis bergaya sketsa kartun bebas.
7. **Roundness (Sudut & Kelengkungan):**
   - *Sharp:* Sudut tajam bersiku.
   - *Curved:* Sudut membulat / garis melengkung halus (untuk panah lengkung).
8. **Opacity (Transparansi):** Mengatur tingkat kejelasan/transparansi objek (0% - 100%).
9. **Layers / Z-Index:** Mengatur tumpukan posisi objek (Kirim ke Belakang / Bawa ke Depan).
10. **Alignment & Distribute:** Merapikan posisi beberapa objek sekaligus (Rata Kiri, Tengah, Kanan, Rata Atas/Bawah).

## 📌 3. Bilah Vertikal Sebelah Kanan (Right Action Sidebar)

Sidebar vertikal melayang di sebelah kanan layar berisi kontrol navigasi cepat:

| Ikon | Nama Fitur | Fungsi |
| :---: | :--- | :--- |
| 🖊️ | **Pen Mode** | Mode khusus jika menggunakan stylus/pen tablet agar jari tidak sengaja mencoret. |
| 📄+ | **New Canvas** | Membuat kanvas Excalidraw baru. |
| 🔲 | **Frame Tool** | Membungkus beberapa objek ke dalam satu bingkai (*Frame*). |
| 📖 | **Library (Buku)** | Membuka panel toko pustaka 515+ ikon gratis yang telah terinstal. |
| 🔒 | **Lock Tool** | Mengunci alat menggambar aktif agar tidak kembali ke pointer setelah menggambar 1 objek. |
| ✋ | **Pan Mode Toggle** | Mengunci mode geser kanvas. |

---

## 🔍 4. Bilah Bawah & Navigasi Kanvas (Bottom Navigation)

* ☰ **Hamburger Menu (Pojok Kiri Bawah):** Membuka opsi canvas (Ubah Warna Background Kanvas, Export ke SVG/PNG, Clear Canvas).
* **Zoom Controls (Tengah Bawah):**
  - Tombol `-` dan `+` untuk memperbesar/memperkecil.
  - Klik angka persentase (misal `100%`) untuk reset zoom ke ukuran normal.
* ↶ **Undo (`Cmd + Z`):** Membatalkan langkah terakhir.
* ↷ **Redo (`Cmd + Shift + Z`):** Mengembalikan langkah yang dibatalkan.
