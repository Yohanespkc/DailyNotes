# 🎨 Panduan Lengkap Belajar Excalidraw di Obsidian

Selamat datang di panduan bertahap untuk menguasai **Excalidraw**! Excalidraw memungkinkan Anda membuat diagram alur, mind-map, dan peta ide visual yang terintegrasi penuh dengan catatan Obsidian.

---

## 📍 Langkah 1: Dasar Menggambar & Navigasi

1. **Membuat Kanvas Baru:**
   - Tekan `Cmd + P` -> pilih **`Excalidraw: Create new drawing`**.
   - Atau klik ikon papan gambar Excalidraw di bilah paling kiri (*Left Ribbon*).
2. **Toolbar Utama (Atas Layar):**
   - 🟥 **Rectangle / Ellipse (R / O):** Untuk membuat kotak/lingkaran konsep.
   - ➡️ **Arrow (A):** Untuk menghubungkan antar konsep (panah otomatis menempel di kotak).
   - ✍️ **Freedraw (P):** Untuk corat-coret tangan bebas.
   - 🔤 **Text (T):** Untuk menambahkan tulisan.
3. **Navigasi Kanvas:**
   - **Geser Kanvas:** Tahan `Spacebar` + geser mouse/trackpad.
   - **Zoom In / Out:** Tahan `Cmd` + scroll mouse.

---

## 🔗 Langkah 2: Menghubungkan Gambar ke Catatan Obsidian (`WikiLinks`)

Ini adalah fitur paling sakti di Obsidian! Anda bisa membuat diagram yang jika diklik akan membuka file catatan:

1. Buat kotak atau teks di Excalidraw.
2. Tulis nama file menggunakan format `[[WikiLink]]`, contoh:
   `[[00 - Dashboards/Dashboard Gasing]]` atau `[[01 - Notes/Daftar Tugas]]`
3. Tekan **`Cmd + Klik`** pada teks tersebut. Obsidian akan **langsung membuka file catatan tersebut**!

---

## 📚 Langkah 3: Menggunakan Pustaka Ikon (Excalidraw Libraries)

Anda tidak perlu menggambar semuanya dari nol!
1. Di Excalidraw, lihat ikon **Buku / Library** 📚 di toolbar atas.
2. Klik **Browse Libraries** (akan membuka browser Excalidraw Store).
3. Cari pustaka ikon gratis yang Anda suka (misal: *Flowchart*, *Software Architecture*, *UI elements*, atau *Stick Figures*).
4. Klik **Add to Excalidraw**. Sekarang ribuan ikon siap di-drag ke kanvas Anda!

---

## 🖼️ Langkah 4: Menyisipkan Diagram ke Catatan Teks

Untuk menampilkan diagram Excalidraw Anda di tengah catatan biasa:
1. Buka catatan biasa (misal `Catatan Pembelajaran 1.md`).
2. Ketik perintah embed:
   ```markdown
   ![[Diagram Pembelajaran Gasing.excalidraw]]
   ```
3. Diagram akan tampil rapi di tengah teks. Jika diagram tersebut digambar ulang, tampilannya di dalam teks akan **otomatis ter-update secara real-time**!

---

## 🏆 Tantangan Praktik Pertama Anda:
Buatlah kanvas Excalidraw baru yang berisi 3 kotak sederhana:
1. Kotak 1: Tulis `[[00 - Dashboards/Dashboard Gasing]]`
2. Hubungkan panah ke Kotak 2: Tulis `[[01 - Notes/Daftar Tugas]]`
3. Hubungkan panah ke Kotak 3: Tulis `[[02 - Resources/Videos/Koleksi Video Referensi]]`

Cobalah `Cmd + Klik` pada kotak-kotak tersebut untuk merasakan navigasi visual interaktif!
