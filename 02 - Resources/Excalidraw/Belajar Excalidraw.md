---

## 📌 Pendahuluan: Mengapa Menggunakan Excalidraw?

**Excalidraw** adalah plugin paling hebat di Obsidian untuk menggabungkan **teks cerdas** dengan **gambar bebas**. Dengan Excalidraw, Anda bisa:
1. Memvisualisasikan ide, mind-map, dan diagram alur sistem (*flowchart*).
2. Menghubungkan elemen gambar langsung ke file catatan Obsidian (`[[WikiLinks]]`).
3. Menyisipkan diagram visual ke tengah-tengah penjelasan teks biasa (`![[Canvas.excalidraw]]`).

---

## 🚀 Tahap 1: Instalasi & Konfigurasi Awal (1 Menit)

1. Buka **Settings** `⚙️` di Obsidian (pojok kiri bawah).
2. Masuk ke menu **Community plugins** -> klik **Browse**.
3. Cari **`Obsidian Excalidraw`** (karya Zsolt Viczián).
4. Klik **Install**, lalu klik **Enable**.
5. *Opsional:* Buka Settings Excalidraw, atur folder penyimpanan default ke `02 - Resources/Excalidraw`.

## 🎨 Tahap 3: Panduan Praktik Berulang

Untuk menguasai Excalidraw, luangkan waktu mempraktikkan 4 fitur inti ini:

1. **Membuat Link Ke Catatan (`[[ ]]`):**
   - Ketik `[[Dashboard Gasing]]` di kanvas, lalu **`Cmd + Klik`** tepat pada tulisannya untuk melompat ke file tersebut.
2. **Menggambar Garis Panah Melengkung Mulus:**
   - Tekan **`A`** (Arrow Tool) -> **Klik 3x** di kanvas (Titik Awal ➔ Titik Puncak Lengkung ➔ Klik 2x di Ujung).
3. **Memanfaatkan 515+ Ikon Pustaka Terinstal:**
   - Klik ikon **Buku/Library 📖** (ikon ke-4 di strip vertikal kanan layar Excalidraw) -> Drag & drop ikon *Software Architecture*, *Stick Figures*, atau *Math Symbols* ke kanvas Anda!
4. **Menyisipkan Canvas ke Catatan Teks:**
   - Ketik `![[Diagram Pembelajaran Gasing.excalidraw]]` di catatan Markdown untuk menampilkan gambar diagram secara live sync.
